# T-L1-010.2 · 三执行器对象类输入接线（`ctx.inputs` + 来源标注 + 降级）

> 2026-09-28 由 `T-L1-010` ④ 对齐拆分。④ 对齐结论见 [D-056](../决策日志.md)。

## 目标

把三处对象类输入从「可解释默认口径」改为**消费 [`ctx.inputs`](T-L1-010.1-input_schema运行期输入通道.md)**（调用方读 L2 记忆后注入的真实用户数据），并让载荷的来源标注从「默认口径说明」变为真正的**来源标注**；取不到时**回落当前默认口径并显式区分**：

| 执行器 | 输入键 | 形态 | 记忆侧取值面 | 有记忆时的口径 | 无记忆时的口径（今天，不变） |
|---|---|---|---|---|---|
| `portfolio-stress-test` | `portfolio` | `object` | `attention.holdings` | 只按组合内标的推演，`portfolio_source` 记注入对象的 `source` | 本地缓存最新交易日在市标的**等权**，标 `local-cache-equal-weight` |
| `opportunity-mine` | `preference` | `object` | `attention.sector_preferences` / `.theme_interests` + `identity.risk_preference` | 候选按 `sectors`（查 `stock_industry`）/ `themes`（匹配 `reasons`）过滤，`risk` 随载荷回显 | `preference: "none"`（原优选池排序） |
| `strategy-design` | `universe` | `string`（逗号分隔 `stock_id` 串） | `attention.holdings` / `.watchlist` | 回测窗口只纳入该池，报告出 `universe_source` | 全市场等权 + `universe_source` 记默认口径；`signal_check` 补**信号定义来源**（上游 `skill_id` / 未提供） |

**不冒充用户输入**（[D-028](../决策日志.md) 的初衷）：三处载荷一律自带来源标注，上层据此提示「当前用的是默认口径」。三处的**形态**与降级口径由 [03 §2.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 登记（[D-056](../决策日志.md)）。

## 验收标准（Given-When-Then）

- **GWT-1 取数路径**：给定 `ctx.inputs` 分别含合法的 `portfolio`（`{"codes": [stock_id…]}`）/ `preference`（`{"sectors": [...], "themes": [...], "risk": "…"}`）/ `universe`（逗号分隔的 `stock_id` 串，同 `keywords` 的串约定），当执行对应执行器，则取值面改为该对象——`portfolio-stress-test` 的 `holdings` ＝ 组合标的数且**不掺入池外标的**；`opportunity-mine` 的候选按 `sectors`（查 `stock_industry`）/ `themes`（匹配 `reasons`）过滤；`strategy-design` 的回测序列**只含**该池代码。
- **GWT-2 来源标注可区分**：有记忆时 `portfolio_source` / `preference` / `universe_source` 的来源串与无记忆时的默认串**不相等**（机器可判，不靠人读）。标注取自**注入对象自带的 `source`**（缺省 `"inputs.<键>"`）——「这数据来自哪个记忆维度」由**调用方**写进对象（如 `attention.holdings`），执行器只如实回显，不臆测（[铁律 5](../../项目管理/工程宪法.md) 可解释）。
- **GWT-3 降级语义**：给定 `ctx.inputs` 缺该键（调用方未注入 / 记忆里无该维度），则回落**今天逐字节的默认口径**（全市场等权 / `preference: "none"` / 全市场等权 + `signal_check.reason: "未提供信号定义"`），且来源标注显式写「默认口径」——**不冒充**用户输入。
- **GWT-4 空态**：`ctx.inputs` 为 `{}` 时三执行器均不抛错、不 `failed`（`ok` / `empty` 依数据面而定），行为与今天一致；[04 §7](../../docs/技术架构-v2/04-L2-记忆图谱.md) 的「某维度无记忆」表达为**没有该键**，执行器不因缺键报错。
- **GWT-5 不越界**：`src/st_agent/l1/**` **不出现** 对 `st_agent.l2.*` 的 import（[铁律 7](../../项目管理/工程宪法.md)；`tests/test_layering.py` 兜底）——记忆的读取与转换在调用方 / 集成关卡，不在 L1。

## 假设与前提

- **A1** 三处输入的**记忆侧取值面**成立——`attention.holdings` / `.watchlist` 是 `stock_id` 列表、`sector_preferences` / `theme_interests` 是板块 / 题材名、`identity.risk_preference` 是风格串（[04 §1](../../docs/技术架构-v2/04-L2-记忆图谱.md) 节点模型）；且**板块偏好可落到数据面**——候选的行业由 [`stock_industry`](../../src/st_agent/l0/market/schema.sql)（`industry` 列）供给，无需为新过滤面立表 ｜ 若错（节点字段不足以表达偏好，或行业面不可用）则须改 L2 节点模型（`T-L2-001.1` 已 `done`，属契约返工）或改过滤口径 ｜ 验证：调用方汇取的 `inputs` 形态（本叶用例的注入对象即该形态的样本）+ `stock_industry` 查询实测。
- **A2** 「回落默认口径」是正确降级（而非返回 `empty`）——[D-028](../决策日志.md) 已否决「恒失败」，且 [L1 册 `C2`](../遗留问题/L1-遗留问题.md) 要求「**显式区分**默认口径与用户数据」而非「无数据即空」｜ 若错（应返回 `empty`）则 `portfolio-stress-test` 退回「无记忆即空」，须改 GWT-3 与本叶用例 ｜ 验证：本叶 GWT-3 用例 + [D-056](../决策日志.md) 的人决记录。
- **A3** `strategy-design` 的记忆输入是**回测标的池**而非「信号定义」（记忆六类节点无信号定义一类；`signal_spec` 仍只来自上游）｜ 若错（要求信号定义也从记忆取）则须先为信号定义在 L2 立节点类型（跨层契约变更）｜ 验证：[D-056](../决策日志.md) 的人决 + 本叶 GWT-2 的来源标注（信号定义来源取上游 `skill_id` / 未提供）。
