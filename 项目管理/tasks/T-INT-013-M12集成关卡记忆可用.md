# T-INT-013 · M12 集成关卡 · 记忆可用

## 目标

在真链路上验收 M12：空存储能经 onboarding/显式偏好写入节点；模型能按主题/节点主动读取记忆；中文主题检索有非零命中；Agent 循环使用 `investigate` 亲和与会话主任务；长运行中时钟推进；切片计量/截断与边索引可用；预算舍弃提示指向真实存在的读取工具。

## 验收标准（Given-When-Then）

- GWT-1：Given 全新存储（`memory` 分区只有 `manifest.bin`），When 完成 onboarding 或写入一条显式偏好，Then 节点落盘；When 模型调用 `sk_memory_read` / `MemoryReader.query`，Then 能读回该节点，不再返回空。
- GWT-2：Given 中文主题「最近哪些股票板块比较热门」与相关节点，Then 主题命中 > 0 且排序参与；Given 用户输入「继续」且会话有主任务，Then 记忆 topic 取主任务；Given `task_type=investigate`，Then 候选节点类型收窄。
- GWT-3：Given 长运行（时钟推进），Then 时近度/置信度随查询推进；Given N 个节点与 E 条边，Then 单次查询对边文件最多读一次；Given 一条超大切片，Then 跳过它继续收后面更小的相关切片；Given list/timeline 视图，Then 预算计量不含 `edges`。
- GWT-4：Given 记忆因预算被舍弃，Then prompt 指向的 `sk_memory_read` 真实存在于工具目录；Given 模型调用它，Then 返回切片或显式空态，不指向不存在的能力。
- GWT-5：Given 全量离线套件与 `verify_docs.py --strict`，Then 全过；若实现触到 `l0/llm/**` / `l0/net/gateway.py` / `l1/runtime.py` 的 LLM 装配段，则另跑 `-m live tests/live/test_llm_live.py` 并写进执行日志。

## 接口面

子叶并集（详见各叶）：

- **输入**：`MemoryReader` / `MemoryGraph` / `MemoryWriter` / `OnboardingProtocol`（[`l2/memory`](../../src/st_agent/l2/memory)）· `sk_memory_op` / 新读取工具（[`subprotocols.py`](../../src/st_agent/l3/runtime/subprotocols.py)）· `assemble_context` / `_context_inputs`（[`session.py`](../../src/st_agent/l3/chat/session.py) / [`composition/agent.py`](../../src/st_agent/composition/agent.py)）· 会话主任务（[`T-AGT-033.3`](T-AGT-033.3-任务锚点与历史装载.md)）。
- **输出**：M12 端到端证据（写入→读取→检索→上下文）· 真链路运行记录 · 全量套件与文档校验结果。

## 可关闭的遗留

无（新建关卡；④ 对齐时逐册复核 L0 / L1 / L2 / L3 / L5 / L6 未闭区）。

## 假设与前提

- **A1**：M12 验收使用真实 `Store`（可在临时根上建空存储），不要求用户真实数据；真实 `D:\Documents\STAgent` 只作只读对照。
- **A2**：本关卡的离线链路使用替身/临时存储；真实 LLM 出网只在实现触到联网面时作为强制附加项。
- **A3**：onboarding 与显式偏好写入都可作为“首次节点”的来源；二者至少一条可用即满足 GWT-1 的写入侧。
