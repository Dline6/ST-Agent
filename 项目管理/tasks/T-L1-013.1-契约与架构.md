## 验收标准（Given-When-Then）

- **GWT-1 · 容器契约**：Given [01](../../docs/技术架构-v2/01-平台共享契约.md)，When 读到新节，Then 含三要素——**`ResourceEntry` 形状**（`kind` / `version` / `payload`）、**kind 开放注册语义**（「kind → loader」分派，不固定 closed enum，见父 `A1`）、**装载语义**（幂等 / 按 kind 分发 / 更新走 §9 版本语义）。
- **GWT-2 · 与既有节的边界**：Given 该新节，When 对照 [§2 SkillDescriptor](../../docs/技术架构-v2/01-平台共享契约.md) / [§6 中性化](../../docs/技术架构-v2/01-平台共享契约.md) / [§7 配置元模型](../../docs/技术架构-v2/01-平台共享契约.md) / [§9 版本化](../../docs/技术架构-v2/01-平台共享契约.md)，Then **不重复定义**它们的形态——容器只定「装载/分发」面，各 kind 的 payload 形态归其原有出处（Skill → §2、规则库 → §6、Onboarding 条目 → §7、命令 → [05 §8](../../docs/技术架构-v2/05-L3-对话主入口.md)）。
- **GWT-3 · 四层声明齐全**：Given 四份文档，When 读各自的相关节，Then [03 §1/§2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 声明 Pack 内容＝Skill 描述体 + 类型化资源条目、L1 承载容器与装载入口；[04 §7](../../docs/技术架构-v2/04-L2-记忆图谱.md) / [05 §8](../../docs/技术架构-v2/05-L3-对话主入口.md) / [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 各自的「可随官方 Pack 更新」**指名**为「由 Pack 的对应 kind 承载、经注入取」，不再是空悬表述。
- **GWT-4 · 回退口径写明**：Given 各层声明，When 读，Then 显式写明「Pack 缺席时既有缺省仍生效」（父 `A2`），不留「必须注 Pack 才能跑」的隐含前提。
- **GWT-5 · 文档一致性**：Given 全部改动，When 跑 `python tools/verify_docs.py --strict`，Then 断链 0、检查 1–9 全过。
