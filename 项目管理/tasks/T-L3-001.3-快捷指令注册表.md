# T-L3-001.3 · 快捷指令注册表（§8）

## 目标

兑现 [05 §8](../../docs/技术架构-v2/05-L3-对话主入口.md) 的快捷指令面：`/` 触发的命令注册表，每条 = 预置意图模板（跳过部分澄清步骤）；schema 含指令名、描述、意图模板、参数预填；命名过 [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 中性校验；注册表可随官方 Pack 更新。本叶交付**注册表与解析面**（数据），不含界面菜单渲染。

## 验收标准（Given-When-Then）

- **GWT-1 · 注册表 schema**：Given 一条快捷指令，When 构造，Then 恰含 [§8](../../docs/技术架构-v2/05-L3-对话主入口.md) 所列四项——**指令名 / 描述 / 意图模板 / 参数预填**（缺项或多余必填项即拒），且**各字段形态固定**、可序列化往返。
- **GWT-2 · `/` 触发解析**：Given 一段以 `/` 开头的输入，When 解析，Then 命中对应指令并产出「意图模板 + 参数预填 + 用户补充参数」的合并结果；未命中时返回 `empty` 并**带原因与可用指令清单**（不静默当普通消息、不猜最相近的一条）。
- **GWT-3 · 命名过中性校验**：Given 一个含人名 / 性格标签 / 拟人后缀的指令名（如「老张盯盘」「激进派回测」），或描述含第一人称 / 情感动词，When 注册，Then **显式拒绝并给出中性修改建议**（[01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 执行点 1 的 `check_name`）；校验点**不可关闭、不可绕行**（无开关参数）。
- **GWT-4 · 预置指令集**：Given 全新环境，When 列出注册表，Then 至少含 [§8](../../docs/技术架构-v2/05-L3-对话主入口.md) 点名的 `/盯盘` `/回测` `/压测` `/今日看板` `/反思`，且**逐条通过命名校验**（预置项自身不豁免）。
- **GWT-5 · 可随官方 Pack 更新**：Given 注册表已含一个来源为官方的一组指令，When 以同一来源传入一组新指令，Then 该来源的条目被整体替换、**用户自定义条目不受影响**；替换**不触碰校验点**（新条目同样过 GWT-3）。见任务 `A1`（Pack 侧承载的一端不在本叶）。

## 假设与前提

- **A1 · 「可随官方 Pack 更新」的 L3 侧落成「来源分组 + 整组替换」，Pack 侧承接待人立项**：[05 §8](../../docs/技术架构-v2/05-L3-对话主入口.md) 说注册表「可随官方 Pack 更新」，而官方 Pack 的种子在 L1（[`l1/skills/pack.py`](../../src/st_agent/l1/skills/pack.py)，现只含 Skill）。本叶在 L3 侧给出 `source`（`official` / `user`）与按来源整组替换的入口，使 Pack 一旦承载命令种子即可直接注入；**Pack 侧承载**须先动 [03 §1](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 的包结构（铁律 8：01 → 架构 → 代码），越出本叶 `depends_on`，故登记为 L3 册遗留（待人立项）。若错（须本叶即并入 L1 包）：返工面 = 03 §1 包结构 + `l1/skills/pack.py` + 本叶的装配接线。
- **A2 · 意图模板引用 §3.1 的六类意图，枚举由本叶定义**：[§8](../../docs/技术架构-v2/05-L3-对话主入口.md) 的「意图模板」需要一个意图词汇表，而 [§3.1](../../docs/技术架构-v2/05-L3-对话主入口.md) 的分类表归 [`T-L3-002`](T-L3-002-意图理解与澄清协议任务派发总线.md)（本叶的上游是它）。本叶按 §3.1 原文定义 `INTENT_KINDS`（六类，机器可读副本，同 [04 §1](../../docs/技术架构-v2/04-L2-记忆图谱.md) `NODE_TYPES` 的做法）供其复用，**不新造第二套词汇**。若错（须留给 T-L3-002 定义）：返工面 = `INTENT_KINDS` 迁至 T-L3-002 的模块，本叶改为引用。
- **A3 · `参数预填` 是对 Skill 声明参数的**覆盖值**，不引入新参数体系**：[§8](../../docs/技术架构-v2/05-L3-对话主入口.md) 的「参数预填」直接对齐 [01 §2](../../docs/技术架构-v2/01-平台共享契约.md) `SkillDescriptor.parameters` 的键，预填值只做**默认值覆盖**，不新增参数类型（对象类输入的缺口见 [L1 册 `C2`](../遗留问题/L1-遗留问题.md)，归 [`T-L1-010`](done/M2/T-L1-010-官方Pack对象类输入接线.md)）。若错：返工面 = `param_defaults` 的形态与合并规则。
