# T-UI-012.3 · 生成式 UI 宿主

> [T-UI-012](T-UI-012-Chat主界面对话流与生成式UI宿主.md) 的**生成式 UI 宿主叶**（[D-110](../决策日志.md) ①）。把 [05 §6](../../docs/技术架构-v2/05-L3-对话主入口.md) 已实现、却「在 UI 里没有宿主」的渲染件（`context_card` / `trace_timeline` / `config_draft_card` / `permission_approval_card` / `divergence_map` / `heatmap` / `trend_chart` 等）接进对话流——回复信封里的 `UiDescription` 交**既有**注册表渲染，未登记 / 未实现型走**显式降级**，「钉」入口就位（落点归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)）。

## 目标

三件交付，都挂在 [`.1`](T-UI-012.1-对话骨架与快捷指令.md) 立起的对话流上：

1. **生成式 UI 宿主**——一条 `dispatch` 返程若带 `description`（[01 §12](../../docs/技术架构-v2/01-平台共享契约.md) 的 `UiDescription`），交**既有** [`render.js`](../../src/st_agent/ui/web/js/render.js) 的 `renderEnvelope` 渲染（它按 [`registry.js`](../../src/st_agent/ui/web/js/registry.js) 的组件类型注册表调度）；宿主把组件挂进对话流对应回复的位置，**不新建渲染路径**、**不解析任意代码**。
2. **未登记 / 未实现型的显式降级**——按 [01 §12 降级口径](../../docs/技术架构-v2/01-平台共享契约.md)：类型名 + 中性说明 + 可折叠原始描述，**不执行、不猜测、不静默丢弃**；按 [11-sitemap §2.1](../../docs/PRD-v2-Agent/11-sitemap.md) 与父 GWT-2 的口径**不用错误红**（虚线边框的中性占位，与「渲染失败」错误态区分）。这需要把既有 `render.js` 的 `degraded()` 由 `state--error` 改中性降级呈现（见假设 A1）。
3. **「钉」入口**——容器动作（[01 §12](../../docs/技术架构-v2/01-平台共享契约.md)：**动作不进描述**），在每个可钉组件上就位；钉住后的持久组件面归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)，故本叶以「**尚未接入 + 点名归属**」呈现（**不**伪造、**不**静默 no-op）。推理链展开面板入口同理点名 [`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md)。

**本批的边界**（不越界）：

- **不新建渲染路径 / 不新造组件型**——新组件型归 [`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)（已 `done`）；本叶只接宿主。
- **不实现钉住落盘**——归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)（其 `depends_on` 含本叶）。
- **不动后端产出面**——`description` 由 L3 描述件产出（[`describe.py`](../../src/st_agent/l3/render/describe.py)，`done`）；本叶只消费。
- **不引构建链**（[D-063](../决策日志.md)）；**不越层取数**（[铁律 7](../工程宪法.md)）。

## 验收标准（Given-When-Then）

- **GWT-1** Given 一条带 `description` 的回复（如 `analyze` 去向返程的 `divergence_map`，或 `query` 返程的 `table` / `trace_timeline`），When 渲染，Then 该 `UiDescription` 交生成式 UI 宿主按注册表渲染进对话流对应位置（覆盖 ≥5 型）；Given `description` 为 `null`，Then 该位置不摆空壳。
- **GWT-2** Given 一个未登记 / 本版本未实现的 `component_type`，When 渲染，Then 走**显式降级占位**（类型名 + 中性说明 + 可折叠原始描述），**不用**错误红、**不**静默丢弃、**不**执行描述里的任何内容。
- **GWT-3** Given 描述里 `text_kinds=generated` 的槽未过中性门，When 出站，Then 后端已回 `validation_failed`（[01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2）；前端按该信封呈现，**不**自行复检、**不**渲染被阻断的正文。
- **GWT-4** Given 一个可钉组件，When 渲染，Then 「钉」入口就位；点击即「尚未接入 + 点名 `T-UI-013`」（不伪造、不静默 no-op）；推理链展开入口同理点名 `T-UI-016`。Given 本叶改动，When 跑范围套件（含前端纯净度静态扫描 [`test_frontend_pure.py`](../../tests/ui/test_frontend_pure.py)）+ `verify_docs.py --strict`，Then 全绿、检查 1–9 全过 0 断链。
- **GWT-5** Given 本叶界面文案（降级说明 / 钉入口 / 未接入提示），When 逐条核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写、**无拟人化**。

## 接口面

- **输入**（消费的前置接口）：
  - `POST /api/chat {action:"dispatch"}` 返程的 `description` 键（`done`，`DialogFacade._turn`）——`UiDescription`（`{description_id, component_type, title, slots, layout, as_of, text_kinds}`）或 `null`；仅在 `dispatch` 返程出现（澄清 / 确认往返不带）。
  - 既有渲染调度：[`render.js`](../../src/st_agent/ui/web/js/render.js) 的 `renderEnvelope` + [`registry.js`](../../src/st_agent/ui/web/js/registry.js) 的 `RENDERERS` / `rendererFor`（`done`，[`T-UI-001.3`](done/M1/T-UI-001.3-契约登记与组件注册表宿主.md) 交付）——本叶**复用**并按其降级口径订正 `degraded()`。
  - 页面宿主与挂载点：[`pages/chat.js`](../../src/st_agent/ui/web/js/pages/chat.js)（`.1` 交付）。
- **输出**（本任务交付的公共 API / 落盘位置）：
  - `src/st_agent/ui/web/js/pages/chat.js`——把回复的 `description` 交 `renderEnvelope` 渲染进对话流；「钉」入口与推理链入口的「未接入 + 点名」呈现。
  - `src/st_agent/ui/web/js/render.js`——`degraded()` 由错误红改为**中性降级占位**（虚线框 + 类型名 + 说明 + 可折叠原始描述），与 [01 §12 降级口径](../../docs/技术架构-v2/01-平台共享契约.md) 及父 GWT-2 对齐。
  - `src/st_agent/ui/web/css/app.css`——降级占位 / 钉入口的中性样式。
  - 前端守卫（`tests/ui/**`）——描述按注册表渲染、未登记型降级不用错误红、动作不进描述（描述里无 URL / 方法被当论据）。
  - **不交付**：钉住落盘 / 工作区读面（[`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)）· 推理链展开面板本体（[`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md)）· 新组件型（[`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)）· 契约文档变更。

## 假设与前提

- **A1**：生成式 UI 宿主＝把回复的 `description` 信封渲染进对话流，**复用**既有 `renderEnvelope`（已按注册表调度 + 未登记型降级），**不新建渲染路径**（[05 §6](../../docs/技术架构-v2/05-L3-对话主入口.md) / [01 §12](../../docs/技术架构-v2/01-平台共享契约.md)）。既有 `render.js` 的 `degraded()` 当前用 `state--error`（错误红），与本叶 GWT-2「不用错误红」及 [01 §12 降级口径](../../docs/技术架构-v2/01-平台共享契约.md) 需订正为**中性降级占位**——该订正**不改**降级语义（仍显式、不执行、不丢弃），只改呈现档。**若错的影响**：若保留错误红，则「渲染失败」与「未实现型降级」两类不可分，与父 GWT-2 冲突。**验证方式**：GWT-2 断言未登记型呈现**无** `state--error`；`tests/ui/test_ui_six_states.py` / `test_ui_description_path.py` 复核不回归。
- **A2**：`description` 仅在 `action=dispatch` 返程返回（[`_turn`](../../src/st_agent/app.py) 口径：`post` 分支恒 `None`），故生成式 UI 只在**确认后派发**出现；澄清 / 确认往返不带 `description`。**若错的影响**：若 `post` 返程也应带描述，则「即时生成看板」类交互（[story-01](../../docs/PRD-v2-Agent/story-01-chat-as-os.md) 的 Given）会缺描述通道。**验证方式**：GWT-1 用真组合根 dispatch 一条 `analyze` 意图走查；GWT-3 复核 `description=null` 分支。
- **A3**：「钉」入口与推理链展开入口在本叶**只出入口**，其落点归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md) / [`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md)——以「尚未接入 + 点名归属」呈现，**不**伪造、**不**静默 no-op。**若错的影响**：若在本叶实现钉住落盘，会越界并与 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md) 重复。**验证方式**：GWT-4 断言点击呈现「未接入 + 点名」。
