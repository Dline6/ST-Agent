# T-AGT-004.1 · 工具目录消费与循环工作上下文装配

## 目标

立起循环运转所需的**两样输入**——工具目录与工作上下文——作为**纯装配件**（无 LLM、无副作用、可单测）：

1. **消费工具目录**：取 [`T-AGT-003`](T-AGT-003-工具目录读面.md) 的工具条目，按 [01 §2](../../docs/技术架构-v2/01-平台共享契约.md) 的口径装配为**模型可见形态**（本叶定**暴露哪些字段**，那是实现口径）。
2. **循环工作上下文**：装配「任务 + 工具目录 + 已执行动作与结果」的脚手架，供 [`T-AGT-004.2`](T-AGT-004.2-循环驱动、协议端口与上界.md) 每轮取用。
3. **截断与外置留指针**：单条结果超阈值即**截断 + `log_ref` 指针**（[D-090](../决策日志.md) ⑧）——指针指向既有 `execution_log` 的 `skill-run/<skill_run_id>.json`，**不新建存储**。
4. **预算口径**：给出上下文的规模口径与超限策略；**本期不做压缩**（[D-090](../决策日志.md) 冻结范围）。

## 验收标准（Given-When-Then）

- **GWT-1 · 目录进上下文且可追溯**：Given 一份工具目录，When 装配，Then 上下文中**每个条目可回指其 `skill_id`**（不丢来源）。
- **GWT-2 · 空目录显式化**：Given 目录为空（注册表尚无 Skill），When 装配，Then **显式空态**（不得装配出「可调用但无工具」的上下文让模型空转）。
- **GWT-3 · 大结果截断留指针**：Given 一条超过阈值的工具结果，When 装配，Then 上下文中为**截断形态 + `log_ref`**，且该指针**指向真实存在的记录**（可点击复核）。
- **GWT-4 · 小结果不截断**：Given 未超阈值的结果，When 装配，Then **逐字节原样**进上下文（不无谓改写）。
- **GWT-5 · 已执行动作按序保留**：Given 若干轮已执行的动作与结果，When 装配，Then 保持**发生顺序**且每项可辨「当时依据什么、拿到什么」。
- **GWT-6 · 纯函数**：Given 同一输入，When 装配两次，Then 结果**逐字节一致**（无时间戳 / 随机序等不确定性混入）。

## 假设与前提

- **A1 · 工作上下文**不是** [`assemble_context`](../../src/st_agent/l3/chat/session.py)**——前提：后者装的是**会话上下文**（近端消息 + 记忆切片，4000 字符预算），本叶装的是「任务 + 工具目录 + 动作与结果脚手架」；二者可共用预算工具，但**装配逻辑不同**。
  **若错的影响**：若误把 `assemble_context` 当既有大半资产复用，会把会话消息与工具结果混进同一预算，模型看到的是对话记录而非工作状态——**这是本次调研标出的最易踩的坑**（[调研报告](../../docs/Agent自主能力调研报告.md) §8.4）。
  **验证方式**：GWT-5 以「动作与结果按序」钉住本叶的形态来源；`assemble_context` 的既有用例**不改**（它仍是会话面的）。
- **A2 · 截断阈值与指针形态取「既有记录路径」**——前提：`SkillRunner` 已把每次执行落 `execution_log`，故指针天然存在（[D-090](../决策日志.md) ⑧「`SkillRunner` 已落 `execution_log`，指针天然存在」）。
  **若错的影响**：若须新建外置存储，返工面 = 指针形态与一条新的存储约定。
  **验证方式**：GWT-3 以「指针指向真实存在的记录」钉住 —— **分工已定**（2026-10-07 ④ 对齐）：本叶是**纯函数**、不碰 `Store`，故本叶断言指针**由该步真实的 `skill_run_id` 派生**且形态取自 L1 的单一真相源（`RUN_PREFIX`）；「记录真的可读」由 [`.2`](T-AGT-004.2-循环驱动、协议端口与上界.md) 的驱动用例（**真** `SkillRunner` + 真 `Store`）端到端钉住。
- **A3 · 本叶暂不含「记忆注入」**——前提：[05 §10](../../docs/技术架构-v2/05-L3-对话主入口.md) 的循环工作上下文定义为「任务 + 工具目录 + 已执行动作与结果」，未含记忆切片；记忆注入在既有链路里走 L4 的编排面（[`l4/deliberation.py`](../../src/st_agent/l4/deliberation.py) 的 `_read_memory`）。
  **若错的影响**：若 ④ 对齐判定循环也须注入记忆，返工面 = 本叶的装配件加一段（**且须回答「L3 直接读 L2 还是经端口」**）。
  **验证方式**：本叶按 [05 §10](../../docs/技术架构-v2/05-L3-对话主入口.md) 原文实现；若须扩范围，须回 [D-090](../决策日志.md) 复议。
