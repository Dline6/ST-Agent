# T-UI-013 · 工作区：钉住的持久组件

> **M6 七面功能叶之一**（[D-103](../决策日志.md)）。承接 [11-sitemap §2 工作区](../../docs/PRD-v2-Agent/11-sitemap.md)——生成式 UI 里「钉」下来的看板 / 图表 / 卡片 / 回测报告在对话之外**持久留驻**、可刷新可下钻。

## 目标

把 [11-sitemap §2 工作区](../../docs/PRD-v2-Agent/11-sitemap.md) 声明的一条屏做成可用界面：

- **钉住的持久组件**：看板 / 图表 / 卡片 / 回测报告；支持**刷新** / **下钻**（跳转推理链或 Skill 详情）/ **取消钉住**

**本批的边界**（不越界）：

- **「钉」入口归 [`T-UI-012`](T-UI-012-Chat主界面对话流与生成式UI宿主.md)**——本叶只消费被钉住的描述，不重造入口。
- **下钻终点归属于各分区叶**——「跳转推理链」落 [`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md)、「跳 Skill 详情」落 [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md)；本叶只出跳转，不建目标页。
- **新形态（如钉板 `pinned_board`）归 [`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)**——本叶不自行登记组件型。

## 验收标准（Given-When-Then）

- GWT-1：Given 一个被钉住的组件，When 打开工作区，Then 该组件以**持久**形态呈现（非对话内一次性），且刷新 / 下钻 / 取消钉住三个动作齐备
- GWT-2：Given 点「下钻」，When 目标为推理链或 Skill 详情，Then 跳到对应页（[`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md) / [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md)），**不**在本页内联一份私有实现
- GWT-3：Given 被钉组件的数据面非 `ok`，When 呈现，Then 按 [01 §5 六态](../../docs/技术架构-v2/01-平台共享契约.md) 如实（`empty` 说原因 / `unavailable` 说不可用原因与最后更新），**不静默留空**
- GWT-4：Given 文案，When 核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**
- GWT-5：Given 真组合根 + 真回环服务，When 在 Edge 走查「钉 → 工作区呈现 → 刷新 → 下钻 → 取消钉住」，Then 全程可用、六态如实、控制台无新增报错
