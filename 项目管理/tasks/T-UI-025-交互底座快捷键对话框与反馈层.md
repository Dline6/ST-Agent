# T-UI-025 · 交互底座：快捷键、命令面板、真对话框、反馈四层与忙碌分级（P2）

> **M7 桌面形态叶之三**（[D-120](../决策日志.md) / [D-121](../决策日志.md)）。口径见 [14 册](../../docs/PRD-v2-Agent/14-desktop-form.md) §5（层级与浮层）与 §8（交互底座）。

## 目标

补齐**桌面应用的交互底座**——现状在这块是**零**：`app.css` 里 `position:` / `box-shadow` / `transition` / `:active` 各 **0** 处，`keydown`/`keyup` 处理器 **0** 个，`Escape` 引用 **0** 处，`role="dialog"`/`aria-modal` **0** 处。

- **层级与浮层令牌**：`--z-*`（content / sticky / rail / popover / modal / toast / tooltip）、`--shadow-1..3`、`--dur-fast/base/slow` + `--ease-out`。**没有这一层就做不出浮层**——现行所有「对话框」被迫退化成页内块，正是它的后果
- **快捷键表**（14 册 §8.1 全表）：`Ctrl+K` 命令面板、`Ctrl+1…8` 切分区、`Ctrl+B`/`Ctrl+J` 折叠左右栏、`Ctrl+,` 设置、`/` 聚焦输入、`Ctrl+Enter` 提交、`Esc` 关最上层浮层、`F5` 刷新、`F1` 快捷键表、`Alt+←/→` 面内进退、`Ctrl+F` 面内查找
- **命令面板**：模糊搜索「页面 / 动作 / 记忆节点 / Skill」，**键盘全流程可操作**
- **真对话框 `dialog`**：遮罩 + `role="dialog"` + `aria-modal="true"` + **焦点陷阱** + `Esc` + 焦点归还；**`sheet`**：右侧滑出面板（节点详情 / Skill 详情 / 视角详情），不遮主区
- **反馈四层**：inline field（字段级）/ inline block（六态 chrome，**沿用服务端下发模型不动**）/ **toast**（4–8s 可撤销）/ banner（离线，沿用）/ dialog（阻断性）
- **忙碌分级**：<100ms 无指示 → 100ms–1s 不确定进度 → 1–10s 确定进度或可离开 → >10s 转后台 + 完成通知 → >1min **必须可离开**。并区分 `.disabled`（不可用）与 `.is-busy`（正在忙）——现状两者都用 `opacity:.5` + `cursor: progress`（4 处）
- **右键菜单 `context-menu`**：层级 ≤ 1，删除类项置底（现状 `contextmenu` 处理器 **0** 个）
- **破坏性确认改版**：把「**连点 3 次 + 进度计数**」（`settings.js`）换成**真对话框 + 列明影响对象与范围 + 输入确认词**——前者既不说明范围，也不适用于键盘与读屏用户

## 验收标准（Given-When-Then）

- GWT-1：Given 应用，When 按 `Ctrl+K`，Then 命令面板打开且**可纯键盘**完成「搜索 → 选中 → 执行」；`Esc` 关闭并把焦点还给原控件
- GWT-2：Given 任一阻断性动作（清空 / 回滚 / 撤销凭据 / 导出隐私数据），When 触发，Then 出现**真对话框**（`role="dialog"` + `aria-modal` + 焦点陷阱）；Tab 不逃出对话框；`Esc` 可关；关闭后焦点归还
- GWT-3：Given 长动作，When 耗时跨过 100ms / 1s / 10s 三档，Then 分别出现「无指示 / 不确定进度 / 确定进度或可离开 / 转后台并通知」，且**不阻塞**超过 1 分钟
- GWT-4：Given 一次成功动作，When 完成，Then 出 toast（4–8s 自动消失、可撤销），且**不只**依赖行内文字
- GWT-5：Given 「完全清空」，When 触发，Then 弹出的对话框**列明将被删除的对象与范围**并要求输入确认词；**不再**是连点计数
- GWT-6：Given 键盘用户，When 只按键盘走完「进分区 → 打开详情 → 提交动作 → 关闭浮层」，Then 全程无鼠标依赖、焦点环处处可见

## 备注

**六态是服务端下发的呈现档，本叶不动它**——反馈四层里的 `inline block` 即既有六态 chrome，只是把其余三层补上。**`Ctrl+W`/`Ctrl+Q` 不在本叶**：关窗与退出属壳行为，归 [`T-UI-027`](T-UI-027-桌面壳闭合与默认启动路径.md)。**拆分触发**：浮层件（dialog/sheet/toast/context-menu）与键盘底座（快捷键/命令面板/焦点陷阱）可能各自 GWT>5，④ 时按需转分组节点。
