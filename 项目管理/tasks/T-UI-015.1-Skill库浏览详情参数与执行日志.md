# T-UI-015.1 · 能力区：Skill 库浏览、详情、参数配置与执行日志

> [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md) 三叶之一（[D-117](../决策日志.md) ①）——把 `/skills` 立起来：Skill 清单、单 Skill 详情、**参数配置面板**（带动作）与**执行日志页**。MCP Hub 归 [`.2`](T-UI-015.2-MCPHub服务器与权限确认.md)，Studio 附加面归 [`.3`](T-UI-015.3-Studio附加面与工作流调试.md)。

## 目标

把 [11-sitemap §2 能力](../../docs/PRD-v2-Agent/11-sitemap.md) 里 story-02 的四条屏做成可用界面——`/skills` 现**登记在册但无 `render`**（走六态可用性探针），`SkillsFacade` 已装配真 `SkillRegistry` 却**零读面**：

- **Skill 库浏览页**（[§2.1](../../docs/PRD-v2-Agent/11-sitemap.md)：复用 `table`，逐条并列）——逐 Skill 出名称 / 标识 / 来源 / 离线档 / 依赖 / 版本策略
- **Skill 详情页**（复用 `report_card`，多段式陈述）——基本信息 / 可配参数 / 依赖 / 权限声明 / 输入输出契约
- **Skill 参数配置面板**（复用 `setting_panel`，**带动作**）——`SkillRegistry.set_parameters` 真落值；两型分工见 [01 §12](../../docs/技术架构-v2/01-平台共享契约.md)（`config_draft_card` 只读 / `setting_panel` 带动作）
- **Skill 执行日志页**（复用 `table`，逐条留痕）——读 `execution_log` 分区 `skill-run/<skill_run_id>.json`（[`SkillRun`](../../src/st_agent/l1/runner/models.py)）的**列表读面**

**本批的边界**（不越界）：

- **不重造任何渲染件**——`table` / `report_card` / `setting_panel` 均已实现（[01 §12](../../docs/技术架构-v2/01-平台共享契约.md) 本期登记并实现表），本叶只做**宿主页与取数**。
- **不新开分区、不改 L1 落盘口径**——执行日志读的就是 §1.2 步骤 5 既落的 `skill-run/` 前缀（[03 §1.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)），只新增一条**只读列表**面。
- **Skill 本体归 L1**——本叶只呈现，不改 `SkillRegistry` 的注册 / 版本 / 参数语义。
- **官方 Pack 更新处置（`pending_updates`）呈现归本叶、处置动作**经 `setting_panel` 的 `confirm_update` / `skip_update` 两条动作；不新造第二套更新语义。
- **能力安装 / 导入审批面归 L3 对话面**（`T-L3-006` 已交付）——本叶不重造。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 能力](../../docs/PRD-v2-Agent/11-sitemap.md) 的 story-02 四条屏，When 逐条走查，Then 清单 / 详情 / 参数配置 / 执行日志各有可见载体，`/skills` 退出六态探针页
- GWT-2：Given 单 Skill 参数改值，When 提交，Then 经 `SkillRegistry.set_parameters` 真落值（刷新后仍为新值）并产生变更留痕；值非法（超出 `ParameterSpec` 值域 / 未声明参数名）⇒ `validation_failed` + 原因，**不落值**
- GWT-3：Given 执行日志页，When 打开，Then 出 `SkillRun` 逐条留痕（Skill / 参数快照 / 耗时 / 信封状态）；该 Skill **从未执行过** ⇒ `empty` + 原因，**不静默留空**
- GWT-4：Given 数据面非 `ok`，When 呈现，Then 按 [01 §5](../../docs/技术架构-v2/01-平台共享契约.md) 六态如实——能力池空 ⇒ `empty` + 原因、面未接线 ⇒ `unavailable` + 点名、标识不认识 / 不存在互不冒充
- GWT-5：Given 文案，When 核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**（Skill 无人名 / 无第一人称）；Skill 自述（`description`）作 `data` 槽原样呈现
- GWT-6：Given 真组合根 + 真回环服务，When 在 Edge 走查「清单 → 详情 → 改参 → 执行日志」，Then 全程可用、控制台无新增报错

## 假设与前提

- **A1**：`Skill 执行日志页` 的取数口**只能**是 `execution_log` 分区 `skill-run/` 前缀的**新增列表读面**——L1 现有读面（[`l1/reuse/registry.py`](../../src/st_agent/l1/reuse/registry.py)）只按 `skill_run_id` 取**单条**，全仓无任何「列出某 Skill 的历次执行」的口。**若错的影响**：若无列表读面，日志页只能退化为「按 `trace_id` 锚点单条取」（页面无入口则永远查不到东西），GWT-3 不成立。**验证方式**：全仓 grep `list_files("execution_log")` 与 `RUN_PREFIX` 确认无既有列表消费者；集成用例在真组合根上先跑一次 Skill、再经日志面**读回同一条** `skill_run_id`。
- **A2**：`SkillRegistry.set_parameters` 是**参数落值的唯一写口**（[03 §1.1](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)：Skill 无状态，用户状态只存 L2 记忆与配置注册表）——表现层不自建第二份参数真相源。**若错的影响**：若参数另有落点（如配置注册表 `settings-*` 族），会造出「改了这里、那里没变」的双写。**验证方式**：读 [`registry.py`](../../src/st_agent/l1/skills/registry.py) 的 `set_parameters` 与 `_skill_path` 确认其落 `config` 分区描述体；集成用例断言改值后经 `SkillRegistry.get` 读回同一值。
- **A3**：`SkillRun` 的**输入快照**（`params` / `inputs`）与输出**信封**（`envelope`）足以支撑日志页（Skill / 参数 / 耗时 / 状态），无需 L1 新增字段。**若错的影响**：若 PRD 的「执行日志」还要求**逐依赖链**展开，则须另读 `upstream` 关联的多条记录——本叶按 `upstream` 字段如实列出链路，不新造聚合。**验证方式**：读 [`runner/models.py`](../../src/st_agent/l1/runner/models.py) 的 `SkillRun` 字段表；用例断言日志行含 `skill_id` / `duration_ms` / `envelope.status` / `upstream`。
- **A4**：`/skills` 的页面**子面聚合**走**查询串**（`?skill=<id>`，同 `/memory?node=<id>` 先例），**不引动态段**——[`PAGE_PATHS`](../../src/st_agent/ui/app.py) 仍是精确匹配集合（[11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md)）。**若错的影响**：引动态段会打破 `test_ui_shell_routing.py` 的漂移断言与静态壳的精确匹配，须改页面登记模型。**验证方式**：读 [11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 的 `/skills` 行（一条路径承载四条屏）与 [`pageFor`](../../src/st_agent/ui/web/js/pages.js) 的精确匹配实现；走查确认 `?skill=` 冷开可用。
- **A5**：官方 Pack 的**12 个 Skill 一律 `permissions=()`**（[03 §2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)），故详情页的权限段在出厂态是**空集**——按六态如实出「无权限声明」而非隐藏该段。**若错的影响**：隐藏空段会让「无声明」与「面缺失」无法区分。**验证方式**：集成用例断言真组合根上详情页**含**权限段且内容为「无声明」措辞。
