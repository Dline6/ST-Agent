# T-UI-014.2 · 记忆区节点详情与修正历史

> [`T-UI-014`](T-UI-014-记忆区三视图画像卡与节点详情.md) 三叶之一（[D-111](../决策日志.md) ①）。补 [11-sitemap §2 记忆](../../docs/PRD-v2-Agent/11-sitemap.md) 的两条屏——**节点详情页 / 修正历史页**（[§2.2](../../docs/PRD-v2-Agent/11-sitemap.md)：`/memory?node=<id>` 与 `/memory?node=<id>&view=revisions`，**不新增路径**）。修正在 L2 已是**新增节点作新版本**（[04 §4](../../docs/技术架构-v2/04-L2-记忆图谱.md)：旧节点一字不改 + `evolves_from` 边），旧值经 `revision_history`（整节点快照）保留供审计——本叶只做**呈现**，不改写路径。

## 目标

- **节点详情页**：单节点的类型 / 标签 / 置信度（有效值与基线**并置**）/ 来源 / 隐私分级 / 专属字段 / 相接边；进入方式 `/memory?node=<id>`
- **修正历史页**：该节点的 `revision_history` 逐条呈现（**旧值原样保留供审计**、新值不覆盖历史），进入方式 `/memory?node=<id>&view=revisions`；取材 `timeline_view`

**本批的边界**（不越界）：

- **修正的写入归 L2**（[`MemoryWriter.edit_node`](../../src/st_agent/l2/memory/writer.py)）——本叶只**读并呈现**，不发起写
- **节点 id 的呈现**：`memory_node_id` 是 [04 §1](../../docs/技术架构-v2/04-L2-记忆图谱.md) 的节点标识，直接呈现即可；`entity_id` 在 [04](../../docs/技术架构-v2/04-L2-记忆图谱.md) / [01](../../docs/技术架构-v2/01-平台共享契约.md) 两契约中**不出现**（[D-111](../决策日志.md) ②）
- **三视图与画像卡归 [`.1`](T-UI-014.1-记忆区三视图与画像卡.md)、导入导出与 Onboarding 归 [`.3`](T-UI-014.3-导入导出面板与Onboarding.md)**

## 验收标准（Given-When-Then）

- GWT-1：Given 一个节点 id，When 打开详情页，Then 出类型 / 标签 / 置信度（**有效值与基线并置**）/ 来源 / 隐私分级 / 专属字段 / 相接边
- GWT-2：Given 有修正历史的节点，When 打开修正历史页，Then 逐条出「被替换时刻 + 旧值 + 缘由」，**新值不覆盖历史**
- GWT-3：Given 不存在的节点 id，When 打开详情页，Then 显式报「无此节点」（**不静默空页、不 500**）
- GWT-4：Given 记忆本体与系统文案混排，When 渲染，Then 记忆本体原样（[D-053](../决策日志.md)）、系统文案经生成文案槽下发，**无拟人化**（[契约 9](../../docs/PRD-v2-Agent/10-platform-capabilities.md)）
- GWT-5：Given 真组合根 + 真回环服务，When 在 Edge 走查详情页与修正历史页，Then 全程可用、控制台无新增报错

## 接口面

- 输入（消费的前置接口）：
  - `graph` 鸭子端口经 [`GraphFacade`](../../src/st_agent/app.py) 取 `graph`（[`MemoryGraph.get_node`](../../src/st_agent/l2/memory/graph.py) / `edges_of`）
  - [`MemoryNode`](../../src/st_agent/l2/memory/models.py) 的 `revision_history`（`RevisionEntry`：`replaced_at` / `previous` / `reason`）
- 输出（本任务交付的公共 API / 落盘位置）：
  - `GET /api/memory/node?id=<node_id>` —— 只读；出节点详情 `report_card`；id 缺失 ⇒ `validation_failed`，节点不存在 ⇒ `unavailable` + 点名，面缺席 ⇒ `unavailable`
  - `GET /api/memory/node/revisions?id=<node_id>` —— 只读；出修正历史 `timeline_view`（无历史 ⇒ `empty` + 原因）
  - [`src/st_agent/ui/web/js/pages/memory.js`](../../src/st_agent/ui/web/js/pages/memory.js) —— 详情 / 修正历史两视图 + 查询串路由（`?node=` / `?node=…&view=revisions`）

无（逐册读未闭区同 [`.1`](T-UI-014.1-记忆区三视图与画像卡.md)；**Q-014 经 [D-111](../决策日志.md) ② 查明为格式示例演示文本、非真实未决**，本叶呈现节点标识不因它停手）。

## 假设与前提

- **A1**：置信度「有效值与基线并置」的取材面是 [`MemorySlice`](../../src/st_agent/l2/memory/reader.py) 的 `confidence` / `base_confidence`；但**按 id 取单节点**不经切片查询——详情页的基数取自 `MemoryNode.confidence`（写入时刻的记录），并**显式标注**它非有效值。若错的影响：详情页会把存储值当有效值；验证方式：断言详情页文案含「存储值」标注
- **A2**：修正历史的排序按 `replaced_at` **降序**（最新修正在上）。若错的影响：审计链倒序难读；验证方式：造两条修正，断言首条为较晚者
- **A3**：`?node=` 走查询串（[11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md)「带标识的面走查询串」），路径集仍是有限字面量集合。若错的影响：会引入动态段、破坏壳的精确匹配；验证方式：`test_ui_shell_routing.py` 的既有断言不漂移
