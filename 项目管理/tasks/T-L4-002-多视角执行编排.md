# T-L4-002 · 多视角执行编排

## 目标

交付 [06 §2 执行编排](../../docs/技术架构-v2/06-L4-多视角推理.md) 的 L4 侧编排件：给定主题 + 模式（快速/深度），对**启用视角**逐个跑其 `skill_bundle`（经注入的 `SkillRunner`，**并行 + 失败隔离**）、注入 [`MemoryReader`](../../src/st_agent/l2/memory/reader.py) 的 `deliberation` 记忆切片，把每视角产出为结构化 [`LensOpinion`](../../src/st_agent/contracts/capability_types.py)（**过 [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 输出中性化校验**）；并提供 §2.4「决策沉淀」经注入 `MemoryWriter` 写 `history` 节点。**只到编排**：§3 交叉对照 / §4 Mini Debate 属 [`T-L4-003`](T-L4-003-交叉对照MiniDebate冲突质询.md)，§5 可视化 / §6 边界情形属 [`T-L4-004`](T-L4-004-分歧图可视化边界与特殊情形.md)，均不在本任务。

**范围边界（关键）**：L3 总线的 `analyze` 去向登记 `wired=False, owner="T-L4-002"`，但**铁律 7 禁止 L3 import L4**，且组合根 [`app.py`](../../src/st_agent/app.py) 的层扫描用例锁死 `APP_ALLOWED_IMPORTS={contracts,l0,l1,l2,l3}`——把 L4 接进总线/组合根属 [`T-INT-003`](T-INT-003-M2集成关卡多视角决策闭环.md)（M2 关卡）的装配（同 M1 关卡补 `app.py` 的先例）。本任务交付**自足的 L4 编排件 + 可注入端口**，不碰 L3/组合根。

## 验收标准（Given-When-Then，从 Story 4 + 06 §2 抄，限本任务范围）

- **GWT-1** Given 深度模式 + 已播种阵容，When `deliberate(topic, mode="deep")`，Then 对**全部启用视角**各产一条 `LensOpinion`（01 §3 七字段齐：`stance`/`key_reasons`/`evidence_refs`/`confidence`/`skills_triggered`/`trace_id`/`lens_id`），全程经 `check_output` 无拟人化措辞；执行前经 `MemoryReader` 注入 `deliberation` 切片（`SliceQuery.task_type="deliberation"`），记忆节点证据计入 `evidence_refs`（`memory_node_id`）并在该视角 Trace 记 `memory_read` 步。
- **GWT-2** Given 快速模式且未指定 `lens_ids`，When 执行，Then 默认取 `FAST_COMBO`（机会+风险+基本面三视角，按名经阵容解析 `lens_id`）；Given 显式传入 `lens_ids`，Then 覆盖默认组合（逐项 `roster.get` 寻址）。
- **GWT-3** Given 某视角的 `skill_bundle` 无 `ok` 数据（全 `failed`/`validation_failed`/`dependency_failed`/`empty`）或 bundle 为空，When 执行，Then 该视角 `stance="insufficient-data"`（数据不足如实标注，见 A4），**其余视角照常产出**（失败隔离，不抛穿、不阻塞他者）。
- **GWT-4** Given 某视角有 `ok` 数据，When 合成，Then 信心度经 `Lens.confidence_policy.evaluate(数据充分度)` 分档（`ok` Skill 占比）；**默认合成器不臆断方向**——有数据标 `neutral`（真方向研判属注入的合成端点，见 A1），`key_reasons` 为中性陈述式；注入合成器可返回 `positive`/`negative`/`neutral` 方向（其产出仍逐条过 `check_output`，命中即降级 `insufficient-data`）。
- **GWT-5** Given 用户在 Deliberation 后做出决策，When `record_decision(decision, reasoning, adopted_lens_ids, ignored_lens_ids)`，Then 决策 + 理由 + 采纳/忽略视角经注入 `MemoryWriter.add_node` 落 `history` 节点（`source="user_stated"`，同 [`write_preference`](../../src/st_agent/app.py) 先例）；Given 未注入写入面，Then 返回 `unavailable` + 点名归属（`T-INT-003`），**不静默丢弃**。

## 接口面

**输入（逐条点名上游任务 id + 具体 API/落盘位置）**：
- [`T-L4-001`]：[`l4/roster.py`](../../src/st_agent/l4/roster.py) 的 `LensRoster.list_enabled()` / `get(lens_id)`（选视角）· [`l4/lens.py`](../../src/st_agent/l4/lens.py) 的 `Lens`（`skill_bundle` / `confidence_policy`）与 `ConfidencePolicy.evaluate(sufficiency)`（信心度分档）
- [`T-L1-001`]：[`l1/runner/runner.py`](../../src/st_agent/l1/runner/runner.py) 的 `SkillRunner.run(skill_id, values, *, inputs=, trace=, approved_permissions=, initiator=, purpose=) -> RunOutcome`（`.envelope` / `.trace` / `.skill_run_id`）——跑视角 skill_bundle，鸭子类型注入
- [`T-L2-001.3`]：[`l2/memory/reader.py`](../../src/st_agent/l2/memory/reader.py) 的 `MemoryReader.query(SliceQuery(task_type="deliberation", topic=...)) -> MemorySliceResult`（`.slices[].node.memory_node_id` / `.envelope`）——偏好切片注入，鸭子类型注入
- [`T-L2-001.2`]：[`l2/memory/writer.py`](../../src/st_agent/l2/memory/writer.py) 的 `MemoryWriter.add_node(HistoryNode)`（§2.4 决策沉淀）——经 `checked_node`/`new_node_id` 构造（同 [`app.py`](../../src/st_agent/app.py) 先例），鸭子类型注入
- [`T-SC-001`]：[`contracts/capability_types.py`](../../src/st_agent/contracts/capability_types.py) 的 `LensOpinion` / `Stance` / `Confidence`（01 §3）· [`contracts/neutrality.py`](../../src/st_agent/contracts/neutrality.py) 的 `NeutralityGuard.check_output(text)`（01 §6 执行点 2）· [`contracts/trace.py`](../../src/st_agent/contracts/trace.py) 的 `Trace.append_step` / `TraceStep`（每视角一条链）· [`contracts/result_envelope.py`](../../src/st_agent/contracts/result_envelope.py) 的 `ResultEnvelope` / `EvidenceRef`（01 §5）
- [`T-L0-003`]：[`l0/llm/client.py`](../../src/st_agent/l0/llm/client.py) 的 `LlmClient.invoke`（真方向合成端点）——**本任务不直接调用**，经注入的 `synthesizer` 端口在 `T-INT-003` 组合根接（见 A1/A2）

**输出（本任务交付的公共 API 与落盘位置）**：
- 新建 [`l4/deliberation.py`](../../src/st_agent/l4/deliberation.py)——`Deliberation` 编排门面：
  - `deliberate(topic, *, mode="deep", lens_ids=None) -> DeliberationResult`（含 `envelope` / `opinions: tuple[LensOpinion,...]` / `traces: tuple[Trace,...]`）；快速/深度选择、并行执行、失败隔离、中性化输出校验、信心度分档
  - `record_decision(...) -> ResultEnvelope`（§2.4 决策写 `history`；未注入写入面 → `unavailable` 点名）
  - `FAST_COMBO`（快速模式默认视角名常量，06 §2.1）
  - `OpinionSynthesizer` 鸭子端口（`synthesize(lens, ok_runs, memory_slice_ids, sufficiency) -> SynthesizedView{stance, reasons}`）+ 默认确定性合成器 `_DefaultSynthesizer`（不触网，见 A1）
- 落盘：编排本身**不落盘**（观点为计算产物；决策沉淀经注入 `MemoryWriter` 落 `memory` 分区，路径由 L2 决定，非本任务）

## 假设与前提

- **A1**：观点合成的**方向研判**（`positive`/`negative`）经注入 `synthesizer` 端口完成，真 LLM 合成端点在 [`T-INT-003`](T-INT-003-M2集成关卡多视角决策闭环.md) 组合根接；本任务自带**确定性默认合成器**——有 `ok` 数据标 `neutral`、信心度按数据充分度分档，**不臆断方向、不触网**（同 [`T-L4-001`](T-L4-001-视角模型Lens常设阵容用户可增删.md) 纯本地定义层，**不触发 live 子集强制项**）。**若错**（负责人要求本任务即接真实 LLM 出网合成）：须补 `-m live tests/live/test_llm_live.py` 并在执行日志验证行写明。**验证**：`l4/deliberation.py` 不 import `l0.llm`、不含出网调用；测试全用注入替身。
- **A2**：编排**不接 L3 总线 / 组合根**——`analyze` 去向接线属 [`T-INT-003`](T-INT-003-M2集成关卡多视角决策闭环.md)（铁律 7 禁 L3 import L4；`app.py` 层扫描用例 `APP_ALLOWED_IMPORTS` 锁 l0–l3，装配 l4 即越界）。本任务交付自足 L4 件 + 可注入端口（runner/reader/writer/synthesizer/executor）。**若错**（若判定接线归本任务）：需同步改 `app.py` 与 `test_layering.py` 的允许集，触发组合根返工。**验证**：`test_layering.py` 全绿（`l4/**` 只向下 import contracts/l0/l1/l2）。
- **A3**：§2.4 决策沉淀经注入 `MemoryWriter.add_node` 落 `history` 节点、`source="user_stated"`（用户显式决策，非副驾推断，同 [`write_preference`](../../src/st_agent/app.py) 先例）；节点 `event` 承载决策文本、理由与采纳/忽略视角折叠进该字段（`HistoryNode` 无专属「理由/采纳」字段，见 [`l2/memory/models.py`](../../src/st_agent/l2/memory/models.py)）。L4 **不**自校验决策内容（写语义归 L2）。**若错**（若要求 `inferred`+provenance 或独立字段承载采纳面）：改 `source` / 提出 L2 节点扩展。**验证**：GWT-5 两用例（注入 writer 落节点成功 / 未注入 `unavailable` 点名）。
- **A4**：失败隔离即 `stance="insufficient-data"`，**不新建错误分支、不抛穿**——`SkillRunner.run` 的运行时失败一律走信封（`failed`/`dependency_failed`/`validation_failed`/`empty`/`unavailable`），某视角 bundle 全非 `ok` 或为空即标数据不足；其余视角照常。**若错**（若要求区分「视角执行异常」与「数据不足」两态）：需扩 `Stance` 或加独立降级标注，触 01 §3。**验证**：GWT-3 用例（一视角注入抛错 Skill → 该视角 `insufficient-data`、他者 `ok`）。
