# T-SC-001.4 · 配置元模型与 SkillDescriptor/LensOpinion 结构类型

## 目标
实现 [01-平台共享契约](../../docs/技术架构-v2/01-平台共享契约.md) 的结构型契约：§2 SkillDescriptor（L1 注册/L3 调度/生态分享共用）、§3 LensOpinion（视角唯一合法输出形态）、§7 配置注册表条目（config_id→value_schema/description_for_chat/panel_form_spec/change_policy）、§9 版本化语义（major.minor + 变更日志 + 下游待检查）、§10 权限声明模型（三项权限 + 超声明拦截语义）。本子任务交付类型与校验规则，注册表存储等由 L0/L1 各自任务承载。

## 验收标准（Given-When-Then）
- GWT-SC2：Given 一个 Skill 元数据，When 构造 SkillDescriptor，Then 必填字段（source/offline_level/version_policy 等）齐全且枚举合法，`name` 过 §6 校验。
- GWT-SC3：Given 一个视角输出，When 构造 LensOpinion，Then stance/confidence 走枚举、key_reasons 无第一人称、evidence_refs 只引用 §1 合法 ID 类型。
- GWT-SC7：Given 一个可配置项，When 注册到配置元模型，Then 获得 config_id / value_schema / default / description_for_chat / panel_form_spec / scope / change_policy 七字段。
- GWT-SC9：Given 一个版本升级，When 主版本变更，Then 判定为契约不兼容；次版本变更判定为兼容增强。
- GWT-SC10：Given 一个权限声明列表，When 校验，Then 仅接受 §10 三项权限（local_read / net_access / exec_command）且 scope 语法合法。
