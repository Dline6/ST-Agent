# T-L0-001 · 存储分区 · 落盘加密 · 损坏恢复

## 目标
实现 [02 §2](../../docs/技术架构-v2/02-L0-本地优先基座.md) 存储子系统：七个逻辑分区的分区注册与目录布局、全分区落盘加密（密钥由用户主密码派生）、分区级完整性校验与损坏恢复（最近备份恢复 / 无备份进入冷启动）。这是 L0 一切持久化（T-L0-002 secrets、T-L0-005 data_cache 等）的物理底座。

## 验收标准（Given-When-Then）
- GWT-1（分区独立性）：Given 已初始化的存储根，When 查看分区布局，Then 七个分区（memory / config / chat_history / execution_log / reflection / data_cache / secrets）各自独立成目录、可独立导出、可独立清空，互不混落数据。
- GWT-2（落盘加密与密码校验）：Given 用户主密码，When 初始化存储，Then 主密码经标准口令派生（PBKDF2）派生主密钥，全部分区内容以 AES-256-GCM 加密落盘，盘上无明文用户数据；`secrets` 分区在此基础上单独隔离（独立派生密钥），密钥材料不出现在其他分区；When 用错误主密码打开，Then 校验失败、拒绝打开、数据不被破坏，不设任何由产品方持有的恢复通道（密码丢失 = 数据不可恢复）。
- GWT-4（读写闭环）：Given 已解锁的存储，When 向任一分区写入再读回，Then 数据往返一致（加密对上层透明）；分区级校验和通过。
- GWT-5（损坏检测与恢复）：Given 任一分区数据被篡改/损坏，When 打开存储并校验，Then 该分区被标记损坏并明确报告损坏范围（分区名+原因），其余分区不受影响；配合最近备份可恢复该分区（备份恢复流程在 T-L0-006 按本任务的分区级校验和口径兑现）；无备份时明确告知丢失范围、进入冷启动流程（该分区重建为空、其余分区可用）。
- GWT-6（零接触）：Given 任意操作，When 检查存储根与日志，Then 无任何数据发送到产品方服务器，无产品方持有的密钥或后门（本地优先铁律）。
