# T-UI-014 · 记忆区：三视图、画像卡与节点详情

> **M6 七面功能叶之一**（[D-103](../决策日志.md)）。补上 [11-sitemap §2 记忆](../../docs/PRD-v2-Agent/11-sitemap.md)——现前端只有 [`/memory`](../../src/st_agent/ui/web/js/pages/memory.js) 的持仓 / 关注两张表（[`T-UI-009`](T-UI-009-记忆区持仓行情读面.md) 的交付，**非 IA 列项**），记忆图谱本体（三视图 / 画像 / 节点详情 / Onboarding）**无页面**。

## 目标

把 [11-sitemap §2 记忆](../../docs/PRD-v2-Agent/11-sitemap.md) 声明的五条屏做成可用界面：

- **图谱视图 / 列表视图 / 时间线视图**：三种组织**共享同一查询层**（[故事 story-03](../../docs/PRD-v2-Agent/story-03-memory-graph.md)）
- **偏好画像卡**：「当前画像」摘要，**不超过 5 条**关键标签
- **节点详情页 / 修正历史页**：修正保留旧值供审计
- **导入导出面板**：导出前显示「本次包含哪些信息」清单 + 确认门
- **Onboarding 对话**：建立初始画像（风险偏好 / 投资年限 / 关注板块）

**本批的边界**（不越界）：

- **图谱形态若需新组件型，归 [`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)**——`01 §12` 现**无**节点-边图型；本叶不自行登记。
- **持仓 / 关注行情读面**（[`T-UI-009`](T-UI-009-记忆区持仓行情读面.md)）**已交付**，本叶在其上补 IA 声明的屏，**不重造**。
- **导入导出面板与 ECO 的导入校验页不同源**——此处是「记忆导出前的信息清单 + 确认门」（[story-03](../../docs/PRD-v2-Agent/story-03-memory-graph.md)），ECO 的 `/eco/*` 是 Skill / 工作流分享，不混。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 记忆](../../docs/PRD-v2-Agent/11-sitemap.md) 的五条屏，When 逐条走查，Then 每条有可见载体——三视图共享同一查询层、画像卡 ≤5 标签、节点详情与修正历史保留旧值、导入导出面板有清单 + 确认门、Onboarding 建初始画像
- GWT-2：Given 记忆节点，When 查看详情与修正历史，Then 修正**保留旧值供审计**，新值不覆盖历史
- GWT-3：Given 导出动作，When 触发，Then 先出「本次包含哪些信息」清单 + 确认门；未经确认不导出
- GWT-4：Given 记忆内容（`data` 槽）混合生成文案，When 渲染，Then 记忆本体**原样呈现**（[D-053](../../项目管理/决策日志.md)）、自有 UI 文案走中性改述，**无拟人化**（[契约 9](../../docs/PRD-v2-Agent/10-platform-capabilities.md)）
- GWT-5：Given 数据面非 `ok`，When 呈现，Then 按六态如实（空记忆 → `empty` + Onboarding 引导），**不静默留空**
- GWT-6：Given 真组合根 + 真回环服务，When 在 Edge 走查三视图 / 节点详情 / Onboarding / 导入导出，Then 全程可用、控制台无新增报错
