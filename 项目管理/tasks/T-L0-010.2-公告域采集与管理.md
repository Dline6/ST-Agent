# T-L0-010.2 · 公告域采集与管理

## 目标

交付**公告域**的完整链路，**本叶子收口 [L1 册 `C1`](../../项目管理/遗留问题/L1-遗留问题.md)**——`stock-watch` 的「关键词」盯盘条件由此获得评估路径。

- **表组**：`announcement`（元数据行：`id` / `code` / `title` / `type` / `pub_date` / `url` / `file_path` / `source_id` / `coverage`）+ 正文**落文件**（`data_cache` 文本目录，经 `.1` 的文本承载基件）
- **标识**：`announcement_id` 取**业务键（代码 + 标题 + 披露日期）的确定性摘要**、长度有界（[01 §1](../../docs/技术架构-v2/01-平台共享契约.md) / [D-031](../../项目管理/决策日志.md)）——跨源的同一公告得**同一 ID**，去重与合并一步到位；**不沿用源方 ID**
- **主备**：**权威源优先**——巨潮为主源（证监会指定披露平台、覆盖全市）；深交所官方（**仅深市**）/ 东财（**仅沪市**）为**按覆盖分片**的兜底，须以 `coverage` 列**显式标注**（[D-030](../../项目管理/决策日志.md) / `Q-003` 决议）
- **新鲜度**：事件驱动（无固定节奏）；须能回答「**是否存在已知不可回补的空窗**」——档案型文本在源端失效后**不可重取**（[05 不可逆缺口](../../docs/数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md)）
- **实现**：按 [铁律 8](../../项目管理/工程宪法.md) 先改 [story-08](../../docs/PRD-v2-Agent/story-08-mcp-hub.md) 的官方 MCP Server 清单措辞（改述为「官方数据源经 L0 采集 + 官方 MCP 暴露面（读侧适配器）」），并复核 [03 §2.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 对 `stock-watch`「关键词」条件的职责措辞

## 验收标准（Given-When-Then，从 Story 抄）

（④ 对齐定稿；实现与机器可查证据见 `tests/l0/`）
  - GWT-1 端到端可查：Given 本地库与一次公告同步，When 按代码查公告，Then 返回带 `announcement_id` 与正文可读的记录
  - GWT-2 **关键词可评估**（**收口 `C1`**）：Given 本地缓存含含关键词的公告，When 跑 `stock-watch`，Then 「关键词」条件**出现在触发理由中**、`unevaluated_conditions` **不再包含**「关键词」
  - GWT-3 跨源去重：Given 同一公告来自两条源，When 入库，Then 合并为**一行**（同 `announcement_id`），不产生重复
  - GWT-4 覆盖显式：Given 主源不可用而降级到分片备胎，When 查询，Then 载荷标注**覆盖范围变化**（不得让「换了源」看起来像「没有数据」）
  - GWT-5 不可逆缺口可判：Given 某日未抓到且源端随后失效，When 自检，Then 该空窗被登记为**已知不可回补**，而非普通陈旧

## 假设与前提

- A1 公告的**业务键**取 `(code, title, pub_date)`——跨源的同一篇公告由此得**同一 ID**（去重与合并一步到位）/ 若错（源方标题措辞不同致跨源重复）：去重退化为「同源内去重」，需另立标题归一化口径 / 验证：GWT-3「同一公告来自两源 → 一行」。
- A2 主备让位以**写入序**实现（主 `INSERT OR REPLACE`、备 `INSERT OR IGNORE`），不引入优先级表 / 若错（须显式优先级）：返工面＝`_role_clause` + 所有域 loader / 验证：GWT-3「备胎不覆盖主源」+ 断言 `coverage` 仍为 `all`。
- A3 公告域为**档案型**（源失效后不可重取），故空窗须判为**可能永久** / 若错（当作普通陈旧）：用户会以为「等下次同步就好」，实则永久缺失 / 验证：`ARCHIVAL_DOMAINS` 含 `announcement`；GWT-5 `archival_gaps` 全标 `recoverable=False`。
- A4 关键词条件取「**近期**披露」语义，回看窗口 30 日（常量，不开放为参数）/ 若错（须可配）：返工面＝`ambient.py` 常量 + 种子参数 / 验证：GWT 的 lookback 用例（120 日前的公告不触发）。
