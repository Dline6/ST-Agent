# T-INT-008 · M7 集成关卡 · 打包发布

> **M7 的收口关卡**（[D-103](../决策日志.md) ① 拆出的「打包发布」里程碑）。M7 各叶分别交付安装器与签名，**关卡**把它们装成一条**可交付的发布链**并在**真机**上验收——这是单叶用例（构建机上的分面测试）覆盖不到的部分。

## 目标

M7 的收口：在**一台干净的真 Windows 机**上端到端验收「**安装 → 首启 → 全 IA 页面走查 → 卸载**」，并把发布清单定稿：

- **真机验收**：干净 Windows 机 → 安装 → 首启握手 → 打开回环界面 → 按 [11-sitemap §2](../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集**逐区走查**（装完之后用户真的能用）→ 卸载 → 程序清干净、数据面按口径处置
- **发布清单**：产物清单（安装包 + 校验和 + 签名信息）、各平台交付状态（Windows ✅ / macOS ⚠️ 未产出 / Linux ⚠️ 未产出，[packaging/README](../../packaging/README.md)）、首启前置（WebView2）
- **端到端数据流**：按 [00 §5](../../docs/技术架构-v2/00-架构总览.md) 在**冻结产物**上验证——后端口常驻 + 壳客户端，不是源码跑的 `python -m st_agent`

**锚点**：验收标准取自 [00 §5](../../docs/技术架构-v2/00-架构总览.md) 的端到端数据流与 [11-sitemap](../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集；**不重复**单叶已覆盖的构建 / 签名单元行为。
