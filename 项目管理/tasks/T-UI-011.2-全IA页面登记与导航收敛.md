# T-UI-011.2 · 全 IA 页面登记与导航收敛

> [T-UI-011](T-UI-011-底座与骨架多面端口注入与全IA页面登记.md) 的**页面登记叶**（[D-109](../决策日志.md) ①）。把 [11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 声明的页面集**补至全集**（六条待登记路径）、并把 `nav` 由「列全部登记项」收敛为「**按分区根聚合**」，使七面功能叶只剩「往已登记的页面里填内容」。

## 目标

三件交付，都落在**页面登记与壳的导航**（本叶**不填任何业务内容**）：

1. **六条新页面登记**——[`PAGE_PATHS`](../../src/st_agent/ui/app.py) 补 `/workspace` · `/skills` · `/mcp` · `/deliberation` · `/delivery` · `/settings`（12 → 18 条），[`pages.js`](../../src/st_agent/ui/web/js/pages.js) 同批补同名六条（13 → 19 条含根），**两端同源**。各条 `statusPath` 指向 [`.1`](T-UI-011.1-多面端口注入与各面门面装配.md) 交付的**同名面探针**。**不填 `render`**——各页内容归七面功能叶。
2. **`nav` 收敛为按分区根聚合**——[`main.js`](../../src/st_agent/ui/web/js/main.js) 的 `buildNav` 由「列全部登记项」改为「**只列各分区的页面根**」（§2.2 导航模型口径：顶层项按分区根聚合、子面不占顶层项、一层平铺不分级）。在 [`pages.js`](../../src/st_agent/ui/web/js/pages.js) 的登记项上以 **`root: true`** 显式标出各分区根（`/` · `/workspace` · `/memory` · `/skills` · `/deliberation` · `/delivery` · `/reflection` · `/settings`），子面（`/studio` · `/mcp` · `/eco/**` · `/reflection/**` 其余 · `/settings/evolution`）不标。
3. **防漂移守卫**——[`tests/ui`](../../tests/ui/test_ui_shell_routing.py) 增三条：① §2.2 声明集 **⊇** `PAGE_PATHS ∪ {/}`（全集，非只「不超出」）；② `root: true` 的集合 **＝** 从 §2.2 表格解析出的**各分区首行路径**；③ 每条登记项**都有** `statusPath` 且其指向的路径在 [`.1`](../../src/st_agent/ui/app.py) 的路由表里真实存在（探针不落空）。

**本批的边界**（不越界）：

- **不填业务内容**——七条新页面首屏一律走 [`main.js`](../../src/st_agent/ui/web/js/main.js) 的**六态可用性探针**（只证「路由通、端口在不在」，不冒充业务内容）；各页 `render` 归七面功能叶。
- **不改壳的路由机制**——`PAGE_PATHS` 精确匹配 + SPA 回退 + 令牌只压 `/api/*`（[D-063](../决策日志.md)）不变；不为带标识的面引动态段（走查询串，[§2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 口径）。
- **既有 13 条条目内容逐字保留**——路径 / 标题 / `statusPath` / `render` 均不改；登记表改按 [§2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 的**分区序**排布（顺序只影响 `nav` 的展示次序，不改任何路由）。`/settings` 与既有 `/settings/evolution` **并存不冲突**——`PAGE_PATHS` 是精确匹配集合，前者不吞后者。
- **不动既有四端口与探针语义**（归 [`.1`](T-UI-011.1-多面端口注入与各面门面装配.md)）。
- **不引构建链**（[D-063](../决策日志.md)）。

## 验收标准（Given-When-Then）

- **GWT-1** Given [11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 声明的 19 条路径，When 对位 [`PAGE_PATHS`](../../src/st_agent/ui/app.py) 与 [`pages.js`](../../src/st_agent/ui/web/js/pages.js)，Then 两端**逐项相等**（前端路径集 − `{"/"}` ＝ `PAGE_PATHS`）且**覆盖全集**（声明集 ⊆ 前端路径集）——每条声明的屏有宿主路径、每条路径两端同源，**无屏无家可归**。
- **GWT-2** Given 六条新页面路径与既有路径，When **不带令牌**首导航，Then 回同一静态壳（HTTP 200、`text/html`、`<title>ST Agent`）；且**未填 `render` 者**出六态可用性探针（`ok` / `unavailable` **如实**呈现，非 ok 带原因与最后更新时间）——**不**出错误红、**不**静默留白。未知路径仍 404。
- **GWT-3** Given `nav` 收敛口径，When 渲染壳，Then 顶层导航项**只**含各分区的页面根（8 项），子面**不占**顶层项；且「分区根集合」与从 §2.2 表格**逐分区取首行路径**所得集合**一一相等**（机器守卫，非人工核对）。
- **GWT-4** Given 每条已登记页面，When 查其 `statusPath`，Then 该探针路径在 [`.1`](T-UI-011.1-多面端口注入与各面门面装配.md) 的 `_GET_ROUTES` 里**真实存在**（对真回环面 GET 得 200 + 合法信封），探针**条数 ＝ 页数**。
- **GWT-5** Given 全项目相对链接，When 在 `项目管理/` 下跑 `python tools/verify_docs.py --strict`，Then 检查 1–9 全过、0 断链；同批跑 `pytest tests/contracts tests/test_layering.py tests/test_tools.py tests/integration tests/ui` 全绿。

## 假设与前提

- **A1**：`nav` 收敛后**子面不再占顶层项**，其可达性由「所在页内的导航与结果组件」承担（[§2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 导航模型口径）。**若错的影响**：`/studio` · `/eco/**` · `/mcp` 等**既有**子面在七面叶落地「页内导航」之前，从 `nav` 不可达（URL 仍可直达，静态壳照常回）。**缓解与验证**：GWT-3 以机器守卫钉住「顶层项 ＝ 分区根」这一**口径**；上列子面的页内入口归 [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md) 等七面叶——本叶在 `## 备注` 显式记录该**过渡态**，不静默。
- **A2**：**分区根 = §2.2 表格里该分区出现的首行路径**。**若错的影响**：`root: true` 标错页，用户从 `nav` 进不去某分区。**验证方式**：GWT-3 的守卫从 §2.2 表格逐分区取首行路径、与 `root: true` 集合严格相等（不硬编码期望集）。
- **A3**：页面路径**不落 `render`**（本叶不填内容），故新页面首屏走六态可用性探针。**若错的影响**：若误挂 `render`，会把「未实现」伪装成「已实现」。**验证方式**：GWT-2 断言新页面首导航回静态壳 + 探针如实（`/workspace` 应为 `unavailable` + 点名，即 [`.1`](T-UI-011.1-多面端口注入与各面门面装配.md) A3 的可见后果）。
- **A4**：新增守卫用**解析 Markdown 表格**取声明路径与分区根（同既有 `_declared_page_paths()` 的静态解析取向，无 JS 运行时）。**若错的影响**：守卫脆弱、易误报；退路是在 Python 侧维护声明集副本（那会引入第二真相源，**不取**）。**验证方式**：声明集用反引号包裹的路径字面量书写，正则只取 `` `/…` `` 形态。
- **A5**：`/settings` 与既有 `/settings/evolution` **并存不冲突**——`PAGE_PATHS` 是精确匹配集合，`/settings/evolution` 不会被 `/settings` 吞掉。**若错的影响**：`/settings/evolution` 回 `/settings` 的壳，既有演进授权页失准。**验证方式**：GWT-1 的两端相等断言 + GWT-4 逐路径 GET 回壳。
