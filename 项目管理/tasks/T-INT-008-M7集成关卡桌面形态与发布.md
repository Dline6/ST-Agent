# T-INT-008 · M7 集成关卡 · 桌面形态

> **M7 的收口关卡**（[D-103](../决策日志.md) ① 拆出、[D-121](../决策日志.md) 重定范围、[D-136](../决策日志.md) 二次收窄）。M7 自 [D-136](../决策日志.md) 起 ＝ **桌面形态**（五叶：令牌 / 外壳 / 交互 / 读面 / 壳闭合）——**发布两叶（安装器 / 签名）已移出 M7、`milestone` 置空悬空**，待负责人择时单独立「发布」里程碑。故本关卡**收口即 M7 可归档**，不再等打包与真机安装。

## 目标

M7 的收口：在**桌面壳形态**上端到端验收「**后端常驻启动 → 首启握手 → 壳窗口 → 桌面形态走查 → 全 IA 页面走查 → 关键链路**」：

- **形态验收**（[D-121](../决策日志.md) 新增）：首启后逐项确认 [14 册](../../docs/PRD-v2-Agent/14-desktop-form.md) 的形态成立——三栏齐备且**外壳不随滚动移动**（滚到底后左栏 / 命令栏 / 状态栏仍在视口内）、左栏两级可展开、右栏 Chat 伴随栏可折叠与拖宽、主区可 `split-pane`、读面为 `compact` 密度；键盘可走完一条主线且焦点环处处可见
- **全 IA 页面走查**：按 [11-sitemap §2](../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集逐区走查（装不装包不影响本项——走 **壳窗口**而非浏览器标签页）
- **端到端数据流**：按 [00 §5](../../docs/技术架构-v2/00-架构总览.md) 验证**后端口常驻 + 壳客户端**（[00 §1.1](../../docs/技术架构-v2/00-架构总览.md) 的进程形态），不是浏览器直开
- **发布面不在本关卡**（[D-136](../决策日志.md)）：安装器、签名、真机安装与卸载随悬空的 [`T-UI-019`](T-UI-019-Windows安装器与安装体验.md) / [`T-UI-020`](T-UI-020-代码签名与安装包可信性.md) 一并移出

**锚点**：验收标准取自 [00 §5](../../docs/技术架构-v2/00-架构总览.md) 的端到端数据流、[11-sitemap](../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集与 [14 册](../../docs/PRD-v2-Agent/14-desktop-form.md) 的形态条目；**不重复**单叶已覆盖的单元行为。
