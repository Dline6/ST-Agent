# T-L1-001.4 · 输出复用 + 新鲜度查询

## 目标
实现 03 §1.3 输出复用：成功输出登记为可引用结果，后续经 `skill_run_id` 引用；复用时校验 `as_of`，freshness 查询复用 L0 数据缓存同步状态表口径（**`BaoStockSync.freshness_verdict` → `StalenessVerdict`**；`MarketDb` 只提供 `as_of(domain)` / `snapshot_id()` / `freshness()` 行——「逐表水位 + 陈旧判据 → verdict」这一步在 `BaoStockSync`，见 [02 §5](../../docs/技术架构-v2/02-L0-本地优先基座.md) 与 [数据库设计 §05](../../docs/数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md)），不另建第二套口径。空/不可用走 `empty`/`unavailable` 分支。

## 验收标准（Given-When-Then）
- GWT-8（数据不可用不编造）：Given 数据源不可用，When Skill 执行，Then 明确返回 `unavailable` 状态（含最后更新时间），而非编造结果。
- GWT-9（空结果结构化）：Given Skill 无输出（如今日无高危信号），When 执行完成，Then 返回结构化空结果 + 原因说明（`empty` 必带 reason）。
- GWT-F（过期引用自决）：Given 引用过期快照的 `skill_run_id`，When 复用查询，Then 返回 freshness  verdict 供上层决定重算或继续用。

## 接口面
**输入**（消费的上游交付）：
- `T-L1-001.2` —— `st_agent.l1.runner.SkillRunner`（`run()` → `RunOutcome`；`_execute.finish` 为唯一出口，落 `SkillRun`）、`SkillContext`（`skill_id` / `skill_run_id` / `trace_id` / `upstream` / `llm` / `gateway`）；`st_agent.l1.runner.models.SkillRun` 与 `RUN_PREFIX`（落盘 `execution_log` 分区 `skill-run/<skill_run_id>.json`）
- `T-L0-005` —— `st_agent.l0.market.BaoStockSync.freshness_verdict(domain) -> StalenessVerdict`（`l0/market/sync.py`，域→`DOMAIN_TASKS`）；`MarketDb.snapshot_id()` / `as_of(domain)`（`l0/market/db.py`）
- `T-L0-001` —— `Store.put/get/list_files`（`execution_log` 分区读写）
- 契约：`01 §5`（ResultEnvelope 分支不变量）/ `§8`（`as_of`、最后更新）/ `§11`（事件）；`03 §1.2` 步骤 6 输出登记 / `§1.3` 输出复用；`数据库设计 §05` 陈旧判据

**输出**（本任务交付的公共 API 与落盘位置）：
- `st_agent.l1.reuse` —— 新子系统：`OutputRegistry`（`register` / `get` / `is_registered` / `reuse`）、`MarketFreshnessOracle`（L0 口径适配器）、`age_based_verdict` / `DEFAULT_MAX_AGE`（无 L0 时的超龄兜底）、`unavailable_envelope(verdict, reason)`（GWT-8 的「最后更新时间」唯一来源）、`ReusableOutput` / `ReuseView` / `OUTPUT_PREFIX`
- 落盘：`execution_log` 分区 `skill-output/<skill_run_id>.json`（可复用登记**索引**：`skill_run_id` / `skill_id` / `status` / `as_of` / `registered_at`；载荷单一来源于 `skill-run/<id>.json`，不复制）
- `SkillRunner` 新增可选参 `outputs=None` / `freshness=None`（两者为 None 时行为与现状逐字节一致）；`SkillContext` 新增 `freshness` 句柄（执行器自查数据源新鲜度）
- `_outputs` 非空时：`ok` / `empty` 自动登记为可复用结果（§1.2 步骤 6）

## 假设与前提
- A1 可复用登记取**索引化**形态（只登记 `skill_run_id`/`skill_id`/`status`/`as_of`/`registered_at`，载荷单一来源于 `SkillRun` 记录，不复制一份）/ 若错：登记形态返工（改自包含载荷需接受双份存储）/ 验证：登记后索引无 payload 断言 + `reuse` 从 `skill-run/` 取回载荷
- A2 `ok` 与 `empty` **均**登记为可复用（`empty` 是合法结论，且上游 `empty` 按 §1.2 不算依赖失败）；失败类分支不登记 / 若错：登记口径返工 / 验证：GWT-9 + 非 ok 分支不落 `skill-output/` 断言
- A3 runner 经**可选参数**注入（`outputs=None` / `freshness=None` 时行为与现状完全一致，`ctx` 透传不变）/ 若错：接线形态返工 / 验证：回归用例（None 时 `skill-output/` 为空且 `ctx.freshness is None`）
- A4 登记失败 → 信封转 `failed`（含 `log_ref`，禁止静默失败）/ 若错：失败分支返工 / 验证：注入必抛的 `Store` 桩断言信封为 `failed`
- A5 freshness 复用 L0 口径（**`BaoStockSync.freshness_verdict(domain)`** → `StalenessVerdict`；适配器对任何提供该方法的对象做鸭子类型，L1 不 import L0；无 L0 库时按 `as_of` 超龄默认判）/ 若错：复用查询返工 / 验证：过期引用测试（对齐已确认）
- A6 空/不可用走 `empty`/`unavailable` 构造期不变量分支（empty 必 reason 且 data 为 None；unavailable 必 `last_updated_at`）/ 若错：信封分支返工 / 验证：GWT-8/9 测试
- A7 Skill 无状态（用户状态只在 L2/配置，输出登记只存输入快照 + 结果，不存用户态）/ 若错：分享链返工 / 验证：无状态断言
- A8 **`domain` 由复用查询方给出**（不在登记时固定），故 `ReusableOutput` 不带 `domain` 字段 / 若错：登记形态返工 / 验证：`reuse(domain=…)` 与 `reuse()` 分别走 L0 与超龄两条路径
- A9 有 oracle + domain 时，判据 = L0 该域判定 **并**「输出 `as_of` 早于该域当前截止时间」补判；无 oracle / 无 domain 时纯超龄判（`DEFAULT_MAX_AGE = 24h`，对齐 §05「日线 T 日日终可得」）/ 若错：判据返工 / 验证：GWT-F 两条路径分别断言
