# T-AGT-008 · 工具面契约与内置原语注册面

> **分组节点**：本节点不直接交付，交付由 [`T-AGT-008.1`](T-AGT-008.1-契约工具源加builtin.md) / [`T-AGT-008.2`](T-AGT-008.2-内置原语注册与执行器.md) / [`T-AGT-008.3`](T-AGT-008.3-参数通道与目录合并.md) 承接；父状态与父 `depends_on` 由 `render_ledger.py render` 按 children 派生。

## 目标
让模型可见的工具面从「仅 Skill」扩为「Skill ∪ 内置原语」，且**仍只有一个注册面**（[01 §2](../../docs/技术架构-v2/01-平台共享契约.md)）。

## 验收标准（Given-When-Then）
- 分组节点不单独验收——由三叶（契约 / 注册与执行器 / 参数通道）合成。

## 接口面
- 输入（消费的前置接口）：无上游任务；三叶各自消费的既有接口见 [`T-AGT-008.1`](T-AGT-008.1-契约工具源加builtin.md) / [`.2`](T-AGT-008.2-内置原语注册与执行器.md) / [`.3`](T-AGT-008.3-参数通道与目录合并.md) 的「接口面」节。
- 输出（本任务交付的公共 API / 落盘位置）：三叶的交付合成——`SkillSource` 的 `builtin` 与三条写面语义（`.1`）、`l1/builtin/` 注册与执行器安装面（`.2`）、`ToolEntry` 的通道声明与 `split_arguments`（`.3`）；本节点不单独交付。

## 可关闭的遗留
无（逐册核过 L0 / L1 / L2 / L3 / L5 / L6 的未闭区，无「归属＝本任务」或「解封条件＝本任务 `done`」的条目）。
