# T-AGT-015.3 · 首次告知与出网开关

## 目标
把「什么会出网」讲清楚，并让用户能一键关掉。

## 验收标准（Given-When-Then）
- GWT-1：Given 首次使用搜索 / 抓取，Then 告知数据出境范围并取得同意。
- GWT-2：Given 用户关闭，Then 工具不可用且原因显式。
- GWT-3：Given 关闭状态，Then 不发起任何出网请求。
