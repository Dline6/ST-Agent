# T-UI-028.7 · 数据同步运行态（P0）

## 目标

- 批次可取消：任务间检查取消令牌，终态 `cancelled`，已完成结果保留。
- 运行中只轮询轻量批次快照，不在轮询路径做整库统计；`overview()` 合并为一次只读连接。
- 逐任务结果展示中文名、状态、行数、`as_of`、耗时、错误。
- 「全选 / 同步全部」不含默认关闭与备源任务；首次全量或大规模同步给规模警告与二次确认。
- 保持单飞与失败不连坐的既有口径。

## 验收标准（Given-When-Then）

- GWT-1：Given 批次运行中，When 点「停止同步」，Then 在任务间停止，终态 `cancelled`，已完成结果保留，未执行任务显式标注。
- GWT-2：Given 运行中轮询，Then 只调 `GET /api/settings/data/job`；该端点只返回批次快照，不读取表行数、不整库统计。
- GWT-3：Given 批次结束，Then 逐任务结果显示中文名、状态、行数、`as_of`、耗时与错误。
- GWT-4：Given 点「全选 / 同步全部」，Then 默认关闭任务与备源任务不被选中；首次全量（水位为空）或大规模同步先给规模警告并需确认。
- GWT-5：Given 已有批次在跑，When 再次启动，Then 仍明确拒绝；单个任务失败不影响其余任务。

## 接口面

- 输入：
  - [`T-UI-028.6`](T-UI-028.6-数据同步范围与预检.md) 的 `start` / `preflight` 与批次快照字段。
  - `BaoStockSync.run_task(cancel=...)` / `InfoSync.run_task(cancel=...)`（已达的取消参数）。
  - `MarketDb.sync_state_rows()` / `table_counts()`。
- 输出：
  - `DataSyncRunner.cancel()`；批次快照增加 `cancelled` / `per-task started_at` / `finished_at` / `duration_ms` / `applied_range` / `applied_codes`。
  - `UiApp.api_settings_data_job`；`GET /api/settings/data/job`；`POST /api/settings/data/sync/cancel`。
  - `MarketDb` 提供一次只读连接取 `sync_state` + 表行数（overview 用）。
  - `settings.js` 的进度、结果与停止按钮；`app.css` 的结果表样式。

## 可关闭的遗留

无（逐册查未闭区：与 T-UI-028.5 同批核查，无归属本任务的条目）。

## 假设与前提

- A1：`run_task` 只在请求边界检查 `cancel`；数据源登录 / 建库阶段在抓取器内部，停止**不是瞬时**（连接阶段可能等源端超时）。UI 文案写明「当前请求结束后停止」，并在连接阶段显示「正在连接数据源…」。若错：用户以为点击后立即中断。验证方式＝阻塞替身用例断言状态转 `cancelled` 且已完成结果保留；浏览器实测连接阶段显示阶段提示。
- A2：批次快照只在内存，进程重启后丢失；`sync_state` 仍保留逐任务结果。若错：需要持久化批次（本批不做）。验证方式＝重启用例只断言 `sync_state` 可读。
- A3：轻量 job 端点不承担总览刷新；页面在批次结束后再取一次 `/api/settings/data`。若错：状态与行数不更新。验证方式＝UI 契约测试断言结束路径会重取总览。
- A4：「全选」排除默认关闭与备源，但显式勾选仍可运行。若错：分钟线等任务不可用。验证方式＝显式勾选用例。
