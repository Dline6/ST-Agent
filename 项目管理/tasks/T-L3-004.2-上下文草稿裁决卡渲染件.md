# T-L3-004.2 · 上下文 / 草稿 / 裁决卡渲染件

> 本叶渲染的是**上游任务已交付的视图数据**（[`T-L3-001.2`](T-L3-001.2-上下文卡片与空状态.md) / [`T-L3-003.2`](T-L3-003.2-双通道登记面与处置三态.md) / [`T-L3-005.1`](T-L3-005.1-冲突裁决承接事件与memory_op去向接线.md)）——本叶**不改**这些产出，只把它们的描述件补上并渲染。

## 目标
交付三个组件的**描述件 + 渲染件**：`context_card`（首页上下文卡片）、`config_draft_card`（配置草稿卡 / 面板视图）、`conflict_adjudication_card`（冲突裁决卡），并注册进 [`T-UI-001.3`](T-UI-001.3-契约登记与组件注册表宿主.md) 的注册表。

## 验收标准（Given-When-Then）
- Given一个 [`ContextCard`](../../src/st_agent/l3/home/card.py)，When 渲染，Then 六段按各自 `state`（`ok` / `empty` / `unavailable`）呈现，**非 ok 段显原因**（不静默留空），画像段标签 ≤5
- Given [`PanelView`](../../src/st_agent/l3/config/handling.py) / [`ConfigDraft`](../../src/st_agent/l3/config/draft.py)，When 渲染，Then 出 `config_draft_card`——**只渲染、不落值**（配置生效归登记面端口，见 [D-061](../决策日志.md)）
- Given一个 [`ConflictAdjudication`](../../src/st_agent/l3/conflict/adjudication.py)，When 渲染，Then 出 `conflict_adjudication_card`，两方内容**并列呈现、不合并、不给统一建议**（[铁律 4](../工程宪法.md)），方向未判定时显式标注
- Given [08 §2](../../docs/技术架构-v2/08-L6-反思演进.md) 的反馈面，When 需要渲染上述卡，Then **复用同一渲染件**
- Given 描述中出现未登记的槽名或字段，When 渲染，Then 显式降级（不猜测、不静默丢弃）

## 接口面
- **输入**：
  - [`l3/home/card.py`](../../src/st_agent/l3/home/card.py)——`ContextCard`（`envelope` / `title` / `greeting` / `is_empty` / `sections` / `graph_target` / `onboarding_target` / `empty_hint` / `as_of`）· `CardSection`（`key` / `title` / `state` / `items` / `tags` / `total` / `limit` / `reason` / `producer`）· `CardTag` · `SECTION_KEYS`
  - [`l3/config/draft.py`](../../src/st_agent/l3/config/draft.py) 的 `ConfigDraft` · [`l3/config/handling.py`](../../src/st_agent/l3/config/handling.py) 的 `PanelView`（`target` / `params` / `values`）
  - [`l3/conflict/adjudication.py`](../../src/st_agent/l3/conflict/adjudication.py) 的 `ConflictAdjudication`（`conflict_id` / `kind` / `dimension` / `proposed` / `existing` / `header` / `question` / `actions` / `directions` / `stance_undecided`）
  - [`T-UI-001.3`](T-UI-001.3-契约登记与组件注册表宿主.md) 的 `ui_description` 契约与注册表宿主
- **输出**：
  - `src/st_agent/l3/render/describe.py`——`describe_context_card()` / `describe_draft()` / `describe_adjudication()`（均 `-> ResultEnvelope`）
  - `src/st_agent/ui/web/js/plugins/l3/{context_card,config_draft_card,conflict_adjudication_card}.js`——三个渲染件（并注册）

## 假设与前提
- **A1 · 本叶只交付 [`T-INT-002`](T-INT-002-M1集成关卡首次可对话.md) 点名的渲染面**——前提：M1 只点名推理链展开与三态渲染；本叶的三类卡是**上游已交付视图数据**的渲染补全（[D-063](../决策日志.md) 的 M1 最小面口径）。若错（M1 需看板全量）：返工面＝范围扩张。验证方式：逐条对位 `T-INT-002` 验收段。
- **A2 · 三类卡按跨层可复用实现**——前提：[08 §2](../../docs/技术架构-v2/08-L6-反思演进.md) 的反馈面与报告面要复用同一渲染件。若错（L3 私有）：L6 渲染面重写。验证方式：注册表中三型均可被 L6 的渲染面直接取用。
- **A3 · 渲染范围不越界到 Studio 画布与设置面板**——前提：[D-060](../决策日志.md) ⑤ / [D-061](../决策日志.md)（画布归 L1、设置面板归 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md)）；[05 §5](../../docs/技术架构-v2/05-L3-对话主入口.md) 明说工作流草稿的接受 / 微调 / 拒绝由 Studio 的**草稿会话**承载，L3 不另造。若错（越界实现）：与既有归属叠床架屋。验证方式：交付的组件类型清单不含画布 / 设置面板。
- **A4 · 分歧并列是渲染面的硬约束**——前提：[铁律 4](../工程宪法.md) 与 [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 的中性要求；裁决卡的两方内容属**数据展示、不过 §6**（[D-062](../决策日志.md) / [D-053](../决策日志.md)），而卡片**自有文案**（抬头 / 问句 / 动作标签）须过执行点 2。若错（合并分歧或复检数据）：前者违铁律 4，后者误伤用户数据。验证方式：两向红-绿用例（自有文案命中即阻断、两方内容命中即放行）。
- **A5 · `text_kinds` 是槽级标签，故按「生成文案槽 / 数据槽」分离设计**（2026-09-29 本批 ④ 对齐选型，决策 [D-064](../决策日志.md)）——前提：[`NeutralityGate`](../../src/st_agent/ui/neutrality_gate.py) 递归扫一个槽内的**全部**字符串，而三类卡都是混合来源（上下文卡片：段名 / 不可用原因是本层文案，`items` / `tags.label` / `thesis.view` 是记忆本体；草稿卡：`understanding_summary` 与参数值是数据，未澄清项问句与来源标签是生成文案；裁决卡：两方 `fields` 是记忆本体，抬头 / 问句 / 动作标签 / 方向候选是生成文案）——不分离则两向都错。切法：`sections` / `values` / `defaults` / `sides` / `targets` 等为**数据槽**，`labels` / `panels` / `questions` / `header` / `actions` / `directions` 等为**生成文案槽**，渲染件按 `key` 并联。若错（须支持同槽混合）：返工面＝槽词汇表与三型渲染件。验证方式：两向红-绿用例（数据槽含触发性措辞仍放行 / 生成文案槽命中即阻断）。
- **A6 · `ui/registry.py` 的必填槽按真实槽词汇表收紧**——前提：[`T-UI-001.3`](T-UI-001.3-契约登记与组件注册表宿主.md) 声明 `REQUIRED_SLOTS` 时槽词汇表尚不存在（该处是占位猜测）；本批把 `context_card` 由 `("sections",)` 收紧为 `("sections","labels")`、`config_draft_card` 由 `("summary",)` 改为 `("target","panels")`（`summary` 只在草稿分支存在，**面板视图分支无摘要**，故不能作必填）。若错（须保留原声明）：面板分支的描述会被服务端判为「缺必填槽」而阻断。验证方式：两分支各出一条无缺槽断言，且 `tests/ui/test_ui_registry.py` 的「两侧不漂移」用例同批收紧。
