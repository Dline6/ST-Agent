# T-L1-001.1 · Skill 注册发现 + 参数校验 + 版本管理

## 目标
实现 03 §1.1（注册与发现）+ §1.4（版本管理）：SkillDescriptor 注册表经 `Store` 的 `config` 分区持久化，注册时过 §6 中性命名校验与 §10 权限语法校验，参数超范围拦截，官方 Pack 约 12 个 Skill 种子自动可用，版本 `follow-latest/locked` + 主版本变更标「待检查」。同时定义 `skill_id` 版本后缀拼接规则（兑现 T-SC-001 遗留①）。

## 验收标准（Given-When-Then）
- GWT-1（Pack 自动可用）：Given 首次启动，When 注册表初始化，Then 官方 Pack 约 12 个 Skill（公共认知 6 + 主动服务 6）自动可用，无需额外下载。
- GWT-5（更新可选）：Given 官方发布新版本，When 查询更新，Then 显示变更日志 + 影响范围，可更新 / 跳过 / 锁定旧版；主版本变更时引用方自动标「待检查」，确认后才升级。
- GWT-7（参数拦截）：Given 参数超出 ParameterSpec 范围，When 注册/更新参数默认值或调用传参，Then 校验拦截 + 说明理由，不允许保存。
- GWT-R（注册不变量）：Given 任一 SkillDescriptor，When 注册，Then `skill_id` 符合 `sk_<名>_v<主>.<次>` 拼接规则且全局唯一，重复注册显式拒绝不静默覆盖。

## 假设与前提
- A1 `skill_id` 形态取 `sk_<注册名>_v<主>.<次>`（注册名小写 kebab，版本取 SkillDescriptor 版本两位，主版本变更即新 ID，老 ID 保留供锁定）/ 若错：注册与引用面返工 / 验证：GWT-R 注册测试（对齐已确认）
- A2 注册本体放 `config` 分区 `skill-registry/<skill_id>.json`，更新历史与待检查标记同分区 `skill-update/` 下 / 若错：存储布局返工 / 验证：落盘分区断言
- A3 命名中性校验复用 `NeutralityGuard.check_name` 回调注入（契约包既定依赖倒置），权限语法复用 `validate_permissions` / 若错：校验链返工 / 验证：非法命名/权限注册拒绝测试
