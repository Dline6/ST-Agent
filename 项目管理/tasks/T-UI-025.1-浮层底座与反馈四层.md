# T-UI-025.1 · 浮层底座与反馈四层（P0）

> M7 叶之三的第一半（[T-UI-025](T-UI-025-交互底座快捷键对话框与反馈层.md) 按「GWT > 5」拆出）。
> 口径见 [14 册](../../docs/PRD-v2-Agent/14-desktop-form.md) §5（层级与浮层）、§6.1（新增件）、§8.2–§8.4（对话框 / 反馈四层 / 忙碌分级）。

## 目标

先补**浮层与反馈的底座**——没有它，对话框、菜单、toast 都做不出来，破坏性确认只能继续退化成页内块。

- **层级与浮层令牌**：`--z-*`（content / sticky / rail / popover / modal / toast / tooltip）、`--shadow-1..3`、`--dur-fast/base/slow` + `--ease-out`；同批补 `forced-colors` 适配
- **真对话框 `dialog`**：遮罩 + `role="dialog"` + `aria-modal="true"` + 焦点陷阱 + `Esc` + 焦点归还
- **右侧滑出面板 `sheet`**：非阻断，不遮主区；首个消费方＝Skills 页「快速查看」
- **toast**：右下角堆叠，4–8s 自动消失、可撤销；成功 / 信息 / 失败三型
- **右键菜单 `context-menu`**：层级 ≤ 1，删除类项置底；首个消费方＝工作区条目（复用其既有动作按钮）
- **忙碌分级**：<100ms 无指示 → 100ms–1s 不确定进度 → 1–10s 可离开 → >10s 释放控件并转后台通知 → >1min 不阻塞；`.disabled`（不可用）与 `.is-busy`（正在忙）语义分开
- **破坏性确认改版**：设置「完全清空」与演进「出厂回滚」由「连点 3 次 + 进度计数」改为**真对话框 + 列明影响对象与范围 + 输入确认词**（清空 / 回滚）；凭据吊销、记忆导出、变更回滚同批改为对话框

## 验收标准（Given-When-Then）

- GWT-1：Given 任一阻断性动作（清空 / 回滚 / 吊销凭据 / 导出记忆 / 回滚变更），When 触发，Then 出现真对话框（`role="dialog"` + `aria-modal="true"` + 焦点陷阱）；Tab 不逃出、`Esc` 可关、关闭后焦点归还
- GWT-2：Given 长动作，When 耗时跨过 100ms / 1s / 10s 三档，Then 分别出现「无指示 / 不确定进度 / 可离开 / 释放控件并转后台通知」，且不阻塞超过 1 分钟
- GWT-3：Given 一次成功动作，When 完成，Then 出 toast（4–8s 自动消失、可撤销）；撤销按钮只在有反动作处出现（钉住 → 取消钉住）
- GWT-4：Given 工作区条目，When 右键，Then 弹出层级为 1 的菜单，删除类项置底；Skills 页「快速查看」以 sheet 打开、不遮主区
- GWT-5：Given「完全清空」，When 触发，Then 对话框**列明将被删除的对象与范围**并要求输入确认词「清空」；出厂回滚同形（确认词「回滚」），不再连点计数

## 假设与前提

- A1：目标引擎（pywebview 的系统 WebView）支持 `role="dialog"`、`aria-modal` 与自管焦点陷阱；若某引擎不认，退化表现是「语义缺失但功能仍可用」，验证方式＝浏览器走查逐项测 Tab / Esc / 焦点归还。影响面：仅无障碍语义，不改结构。
- A2：破坏性动作的服务端硬闸不变（清空仍认三枚有序令牌、出厂回滚仍认 3 次）——前端只改**确认形态**，不代服务端判定。若错：请求会被拒，界面按 `failed` / `validation_failed` 如实呈现。验证方式＝既有路由套件与真实端点。
- A3：toast 的「撤销」只在有反动作处提供（钉住 → 取消钉住）；无反向动作的成功动作不出假「撤销」。若错：撤销按钮点了无效，故宁可不给。验证方式＝走查钉住后撤销。
- A4：>10s 的「转后台」＝释放控件 + toast 告知可离开、完成时再通知；浏览器请求仍在当前页面生命周期内继续，不伪造后台任务或百分比进度。若错：用户离开页面则请求可能中断，界面不谎报已完成后台化。验证方式＝长动作计时观察与代码自审。
- A5：sheet 与右键菜单的首个消费方取 Skills「快速查看」与工作区条目（负责人 2026-10-22 拍定），不改既有 `?skill=` 路由与页面集。若错：sheet 无消费方即成死代码，故至少一处真实入口。验证方式＝浏览器走查。
