# T-L5-001.2 · 注意力预算与情境模式

## 目标
交付 [07 §2](../../docs/技术架构-v2/07-L5-主动触达.md) 的**注意力预算**：情境 × 时段 × 内容类型三维矩阵、五情境模式与手动切换，以及「这条信号此刻该单独触达、还是汇总进日报」的**格位判定**；并把预算配置注册进 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md) 的统一配置注册表。

**两处已现成、本叶不重造**（2026-10-06 读码核实）：

- **注册表门面**（[T-L1-012](done/M2/T-L1-012-统一配置注册表门面.md)，01 §7）：本叶只交付**族的适配器**（住 L5、由组合根注入，先例＝L2 [`MemoryPolicyFamily`](../../src/st_agent/l2/memory/registry_adapter.py)），另复用 [`l1.registry.naming`](../../src/st_agent/l1/registry/naming.py) 的 `config_path` / `new_change_id` / 两分区常量，**不另造路径规则**。
- **级别轴**：`SignalLevel` 复用 [`.1`](T-L5-001.1-信号模型与采纳.md) 的取值集合，不另造一份。

**边界（本叶只给上限，不做计数）**：`max_per_slot`（格位节奏）是交下游的**上限**；**计数状态、合并、排队与日报本体**归 [T-L5-003](T-L5-003-每日报告去重频控推送疲劳监控.md)（§5–§6）与 [T-L5-002](T-L5-002-渠道适配器投递编排与升级链.md)（§4）。本叶的判定是**纯函数**：同一输入恒得同一结论。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 全新装置（无任何落盘条目），When 取「注意力预算地图」，Then 得**情境 × 时段 × 内容类型**的完整矩阵（5 情境 × 5 时段 × 4 内容类型格位，每格带允许级别集合、节奏上限与**来源标注** `configured` / `default`），且缺省策略是「**少而准**」——未配置格位只放行 `emergency`，其余汇总进日报
- **GWT-2**：Given 一条已采纳的信号（`level` + 内容类型 + 时刻），When 判定，Then 得 `BudgetVerdict`——命中哪一个（情境 / 时段 / 内容类型）格位、该格位的允许级别集合与节奏上限、`admitted`、`dispatch`（`separate` 单独触达 / `daily_report` 汇总进日报）与中性 `reason`
- **GWT-3**：Given 一条 `routine` 信号且该格位未放行 routine，When 判定，Then `dispatch="daily_report"`（**不丢弃、不静默消失**）；Given 用户把 routine 显式配进该格位，When 再判定，Then 改判 `separate`
- **GWT-4**：Given 当前情境为工作日，When `switch_mode("vacation")`，Then **下一次判定即按休假格位**（无需重启、无需重读盘），且该模式**落盘存活**（重开仍为休假）；非法模式值即拒
- **GWT-5**：Given 预算配置，When 经 01 §7 门面读，Then 得到登记条目（点分 `config_id` · `panel_form_spec.widget="matrix"` · `change_policy` 指明需确认）——**对话通道与面板通道读到同一份值**（门面读到的值 == 本层自有面读到的值）；`attention-budget.current-mode` 可经门面 `set` 落值（委托本层 `switch_mode` 并留痕），两个对象条目（`slots` / `matrix`）的 `set` **fail-closed 并点名 owner**
- **GWT-6**：Given 越界配置（未知级别 / 未知内容类型 / 未知时段 id / 时钟区间非法 / 空允许级别集 / 节奏 ≤0 / 时段集合未覆盖全天或相互重叠），When `set_*`，Then **逐类显式拒绝并点名违规点**，不落盘、不留痕；给定值**与当前取值相同**，Then 同样不落盘、不留痕（01 §7）
- **GWT-7**：Given 跨零点时段（如 `23:00–07:00`），When 判定 `02:00` 与 `12:00`，Then 前者命中该时段、后者不命中
- **GWT-8**：Given 某条落盘条目损坏，When 读，Then 回落内置缺省（判定照常）**且 `entry()` 报错暴露损坏**，不因一条配置读不动而停摆

## 假设与前提
- **A1 · 两轴口径＝时钟区间 + 受控枚举**（2026-10-06 ④ 对齐拍定，同批写进 [07 §2](../../docs/技术架构-v2/07-L5-主动触达.md)）——时段＝`HH:MM–HH:MM`（支持跨零点），故「每天早晨 8 点」这类用户配置与格位边界同一口径；内容类型＝四个受控值（`long_form` / `brief` / `interactive` / `retrospective`），**不接受自由字符串**。若错（要求命名时段带 / 自由标签）：返工面＝`TimeSlot` / `ContentType` 与缺省矩阵。验证方式：GWT-1 / GWT-6 / GWT-7 用例。
- **A2 · 格位取值是「对象」⇒ 写面归 owner，族只读；唯 `current-mode` 是可写标量**（2026-10-06 ④ 对齐拍定）——前提：[01 §7](../../docs/技术架构-v2/01-平台共享契约.md)「取值为对象 / 列表的条目不在统一标量落值面内」，先例＝L2 `memory-policy`（只读）；而模式是单值枚举、正合「逐条目一次落值」，故经门面 `set` 委托 `switch_mode`（先例＝L1 `scheduler-policy` 的可写标量）。若错（要求整族只读 / 整族可写）：返工面＝族适配器的 `apply` 分支。验证方式：GWT-5 用例（可写项落值留痕、对象项 fail-closed 点名 owner）。
- **A3 · 时段集合须覆盖全天且互不重叠**——前提：判定须是**全函数**（任一时刻恰命中一个时段），否则「没命中任何格位」会造出第三种状态、与 [00 §6 失败显式化](../../docs/技术架构-v2/00-架构总览.md) 的取向相悖；用户想「这段时间不要打扰」可把该格位配成只放行 `emergency`，无需留空洞。若错（允许空洞并要求回落）：返工面＝`resolve` 的空洞分支与 `set_slots` 校验。验证方式：缺省四+一段覆盖 24 小时的用例 + 重叠 / 空洞被拒的用例。
- **A4 · 本叶只给节奏上限、不做计数**——前提：§6 的去重与频控已归 [T-L5-003](T-L5-003-每日报告去重频控推送疲劳监控.md)，若本层自持计数器就会与 §6 出现两套记账。若错（要求本层计数）：返工面＝`AttentionBudget` 增状态面 + 与 T-L5-003 的落点重复。验证方式：`resolve` 为纯函数（同输入恒同结论、不写盘）的用例。
- **A5 · 缺省矩阵的数值取自 Story 的例，可被用户逐格覆盖**——前提：[story-07](../../docs/PRD-v2-Agent/story-07-ambient-delivery.md) 只给了三处例（早通勤可看长内容 / 盘中只推紧急 / 晚间交互式 / 周末长周期回顾）与总策略「少而准」，故兜底格位只放行 `emergency`，另加三条**有出处**的内置覆盖；其余格位一律走兜底。若错（产品要另一套缺省）：返工面＝`DEFAULT_SLOTS` / 内置覆盖三条。验证方式：GWT-1 的矩阵快照用例（逐格标注来源）。
