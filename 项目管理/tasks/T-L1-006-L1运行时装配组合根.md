# T-L1-006 · L1 运行时装配（组合根）

## 目标

给定一个已解锁的 `Store`，装配出可用的 L1 运行时——L0 四件（`EndpointRegistry` / `CredentialVault` / `EgressGateway` / `LlmClient`）→ L1 能力面（`SkillRegistry` 含官方 Pack 播种 + `SkillSandbox` + `SkillRunner` + 输出复用 + 工作流库）→ 外围接线（MCP Hub 与移除回收、`Scheduler` 与在线翻转补跑）；并完成 [Q-001](../阻塞与未决.md) / [D-005](../决策日志.md) 留待的 `provider → host` 归属复核。

Story 02 验收①（首次启动官方 Pack 自动可用）与 M0 关卡 [`T-INT-001`](T-INT-001-M0集成关卡骨架打通冒烟.md) 的 GWT-1（装配即用）都以本任务为前提。

## 验收标准（Given-When-Then，从 Story 抄）

Story 02 的验收段**不含**「组合根装配」条，故 GWT 逐条锚定 [Q-001 决议 D-005](../决策日志.md)、[03 §1.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) / [§5.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) / [§6](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)、[02 §4](../../docs/技术架构-v2/02-L0-本地优先基座.md) / [§6](../../docs/技术架构-v2/02-L0-本地优先基座.md) 与 Story 02 验收①，按叶子分散承载——见各叶子文件的 GWT 节（`.1` 四条 + `.2` 四条 + `.3` 四条 + `.4` 三条）。

## 拆分记录（③ 已执行）

命中拆分触发（GWT 合计 15 条 ≫ 5；跨七个契约小节——[01 §7](../../docs/技术架构-v2/01-平台共享契约.md) / [01 §10](../../docs/技术架构-v2/01-平台共享契约.md) / [02 §4](../../docs/技术架构-v2/02-L0-本地优先基座.md) / [02 §6](../../docs/技术架构-v2/02-L0-本地优先基座.md) / [03 §1](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) / [03 §5](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) / [03 §6](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)；预计 Agent 会话轮次 > 20），已拆为四个叶子：

- `T-L1-006.1` L0 面装配与 `provider → host` 归属复核：`Store` → `EndpointRegistry` / `CredentialVault` / `EgressGateway` / `LlmClient`；D-005 的「暂归 L1」复核定案（02 §4 / §6）
- `T-L1-006.2` L1 能力面装配：`SkillRegistry`（官方 Pack 播种 + 执行器注册）+ `SkillSandbox`（携端点与映射）+ `SkillRunner` + 输出复用 + 工作流库（03 §1.1 / §1.2 / §1.3 / §1.5 / §2）
- `T-L1-006.3` MCP 面装配与移除回收接线：`McpServerRegistry` / `McpSkillMapper` / `McpHubStateMachine` 装配 + 「删除即回收」接线 + 生命周期当前态记录回收（销 L1 册 `B1`，03 §5.1 / §5.2 / §5.3）
- `T-L1-006.4` 调度面装配与在线翻转补跑：`Scheduler` 装配（注入权限来源）+ 在线态翻回时触发 `catch_up`（03 §6 + 02 §7）

④ 对齐定案两处：**`provider → host` 映射维持 L1 沙箱**（Q-001 / D-005 的「暂归」正式定案——`LlmEndpoint` 无 host 字段，迁 L0 须改 [02 §4](../../docs/技术架构-v2/02-L0-本地优先基座.md) 而收益为零，仅改由组合根**注入**）；**L0 册 `B2` 的会话密钥缓存以「会话级单次解锁」兑现**（组合根持一个已解锁 `Store` 供整个会话复用，口令派生每会话每存储只跑一次；**不做**进程内密钥缓存，避免口令 / 校验值长驻内存）。

父任务 `T-L1-006` 的 `status` 由 children 派生，不再手填。
