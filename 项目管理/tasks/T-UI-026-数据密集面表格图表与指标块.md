## 目标

把读面从「一屏放不下几行」修到**桌面级的密度与可操作性**：

- **`data-table` 全套**：sticky 表头、列排序（三态：升 / 降 / 无）、列宽可拖拽且**持久化**、双击自适应列宽、行选中（`--accent-weak` 底 + 1px `--accent` 描边）、`Ctrl+点击` 多选、**键盘行导航**（`↑↓` / `Home`/`End` / `PageUp/Down` / `Enter` / `Space`）、`Ctrl+C` **复制选中行为 TSV**
- **密度双档**：`[data-density]` 换一组行高与单元内距变量（同一套组件换变量，**不是两套组件**）；`compact` 为数据读面默认（持仓表 / 执行日志 / 推送历史 / 网络活动），用户可改默认、也可在具体表上临时切
- **大表策略**：行数超阈值时分页或虚拟滚动**二选一**——不做「无限长表」
- **图表交互**：`trend_chart` 加 hover 十字线 + 数值浮层 + 时间范围切换（1D / 1W / 1M / 1Y / ALL）；**缺值点留断口、不按 0 连线**（保留现行正确行为）
- **`metric` 指标块**：数字走 `--text-metric` + `--font-num`，标签在上、口径在下
- **`split-pane`**：主区左右分栏，可拖宽、可交换、可单侧折叠——**它是[铁律 4](../工程宪法.md)「分歧并列不合并」的结构载体**，比「多张卡挤在一栏里」更贴合口径

## 验收标准（Given-When-Then）

- GWT-1：Given 一张多行表，When 滚动主区，Then 表头常驻；点击表头可排序且三角指示三态正确
- GWT-2：Given 一张表，When 拖拽列边界，Then 列宽改变并**跨跳页保持**；双击边界自适应内容宽
- GWT-3：Given 一张表，When 全程只用键盘，Then 可 `↑↓`/`Home`/`End`/`PageUp/Down` 移动、`Enter` 打开、`Space` 选中；`Ctrl+C` 复制出的内容为 **TSV** 且列序与屏上一致
- GWT-4：Given 同一张表，When 在 `comfortable` 与 `compact` 间切换，Then 行高与内距按档变化，**列宽与选中态不丢**，且两种密度下数字列仍右对齐 + `tabular-nums`
- GWT-5：Given `trend_chart`，When hover 任一点，Then 出十字线与数值浮层；序列缺值时**留断口**而非按 0 连线
- GWT-6：Given 一个多视角结论页，When 用 `split-pane` 并列两方，Then 两栏同权、可拖宽、**不产生任何「合并后」的块**

## 备注

**本叶不新增组件型、不动描述契约**——`table` 的列级词汇（`text` / `number` / `direction`）与「编码归渲染面」的口径（[D-105](../决策日志.md)）一律保留，本叶加的是**壳面交互**（排序 / 列宽 / 选中 / 键盘 / 复制）与**双档密度**。**虚拟滚动与分页二选一**是刻意的：两者叠加会让「键盘 `Home`/`End` 与 `Ctrl+C` 全选」的语义互相打架。**拆分触发**：表格能力 / 图表交互 / 指标块与分栏三块可能各自 GWT>5，④ 时按需转分组节点。
