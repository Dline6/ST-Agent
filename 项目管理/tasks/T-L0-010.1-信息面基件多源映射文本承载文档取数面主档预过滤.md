# T-L0-010.1 · 信息面基件（多源映射 + 文本承载 + 文档取数面 + 主档预过滤）

## 目标

交付四域共用的**四件基件**，使 `.2`–`.5` 各自只写域语义、不各造一套。**本任务不碰任何具体域语义**。

1. **元数据层扩展**——新增 `indicator_source_map(indicator_key, source_id, source_api, api_field)`：`indicator_dictionary` 的 `indicator_key` 为主键、`source_api` / `api_field` **单值**，无法表达「同一列来自多源」；本表**纯增量**承载之（不动既有主键、不改既有种子生成口径），DDL 同步落 `docs/` 与包内两份 `schema.sql`（内容须保持一致的不变量）
2. **文本承载基件**——`data_cache` 分区的**文本目录规约**（`<域>/<代码>/<日期>/<id>.txt`，经 `Store.put` 加密落盘）+ **表行/文件一致性判据**（「表在而文件缺」→ 损坏，走分区恢复；「文件在而表缺」→ 孤儿，可回收）
3. **L0 文档取数面**——`list_docs(filter)` / `read_doc(doc_id)` / `search_docs(query, scope)` 三件，与 `MarketDb.query` **同构**的鸭子类型注入（L1 侧不 import L0 具体类）；文件缺失一律返回 `unavailable` 信封，**判定只在 L0 一处**
4. **主档预过滤基件**——按 `security` 成员判定 + 过滤 + **`filtered_unmapped` 计数与样例代码**：域表 `code` 是硬外键且 `PRAGMA foreign_keys = ON`，**一条未收录记录即可炸掉整批**，故**必须预过滤**而非靠 DB 报错兜底（[D-032](../决策日志.md)）

## 验收标准（Given-When-Then，从 Story 抄）

（④ 对齐定稿；实现与机器可查证据见 `tests/l0/`）
  - GWT-1 多源映射**纯增量**：Given 既有库与种子，When 建库并读 `indicator_dictionary`，Then 主键与既有种子逐字段不变；新表存在且可容纳同一 `indicator_key` 的多行（不同 `source_id`）
  - GWT-2 文本两段**同源同现**：Given 一条含正文的记录，When 写入，Then 表行与文件同时存在且 `source_id` 一致；**缺文件判损坏、缺表行判孤儿**，两种不一致都不静默
  - GWT-3 取数面**不越沙箱**：Given L1 侧执行器，When 经文档取数面读正文，Then **不涉** `local_read:<path-scope>`（缓存内读属数据访问）；且 Skill 侧无直接文件读取路径
  - GWT-4 主档预过滤**不炸批**：Given 源端返回含未收录代码的批次，When 同步，Then 未收录行被过滤、计数与样例如实登记，**批次不失败**，已收录行正常入库
  - GWT-5 **已知空集 ≠ 数据缺失**：Given 未覆盖交易所的标的，When 查询，Then 载荷能区分「被过滤」与「源端无此记录」

## 接口面

- 输入（消费的前置接口）：
  - `T-L0-001` [`l0/storage/store.py`](../../src/st_agent/l0/storage/store.py)：`Store.put/get/list_files/delete(partition, name, bytes)`——「分区 + 分区内安全相对路径 → bytes」的通用 KV，含逐文件 `digest`+`size` 清单与分区级校验；路径规约由 `_check_rel_name` 管（允许嵌套、禁 `..` 与前导 `/`）。**文本正文的落盘唯一入口**
  - `T-L0-005` [`l0/market/db.py`](../../src/st_agent/l0/market/db.py)：`MarketDb.query(sql, params=()) -> ResultEnvelope`（`ok`/`empty`/`unavailable`）、`tables()`、`transact()`（可写事务、提交后写回分区）、`freshness()`、`last_updated_at()`；`T-L0-005` [`schema.sql`](../../src/st_agent/l0/market/schema.sql)（建库 DDL 的包内副本，与 docs 副本同内容）
  - `T-L0-008`：分区级互斥与原子落盘（`Store` 的既有保证，本任务只依赖不改造）
- 输出（本任务交付的公共 API / 落盘位置）：
  - 新子包 `st_agent.l0.info`：
    - `info.docs`：`DocStore`（`write/read/exists/delete/list_paths`）、`DocConsistency(missing_file, orphan_file)`、`audit_docs(store, referenced, domain)`、`text_path(...)`（`<TEXT_ROOT>/<域>/<代码>/<日期>/<标识>.txt`，由标识确定性派生）、`DocSource` 协议与 `LocalDocSource`（`list_docs` / `read_doc` / `search_docs`，与 `MarketDb.query` **同构的鸭子类型**——L1 侧不 import L0 具体类）
    - `info.prefilter`：`master_codes(db) -> frozenset | None`（**主档不可用返回 None，不返回空集**）、`filter_unmapped(rows, code_of, known, sample_limit=20) -> (保留行, UnmappedCount)`、`UnmappedCount(rows_filtered, codes_distinct, sample)`（`.is_clean` / `.describe()`）
    - `info.errors`：`InfoError` / `InfoValidationError` / `InfoFetchError` / `InfoFetchUnavailableError`
  - DDL：`indicator_source_map(indicator_key, source_id, source_api, api_field)`（主键含 `source_id`）——**同步落两份** `schema.sql`（`docs/数据库设计-BaoStock数据层/schema.sql` 与包内副本，内容一致的不变量）
  - 落盘：文本正文 → `data_cache/<TEXT_ROOT>/…`（与 `market.db` 同分区同加密，**不新增分区**）
  - 消费方：`T-L0-010.2`–`.5`（各域 loader 经 `_with_stock_id` + `filter_unmapped` + `DocStore`）、[`T-L1-004.3`](done/M0/T-L1-004.3-主动服务Bundle执行器.md)（关键词条件经 L0 查询面读公告表）

## 假设与前提

- A1 文本正文落 `data_cache` **即**满足落盘加密与校验（不新增第八个分区）/ 若错（须独立分区或独立密钥）：返工面＝`TEXT_ROOT` 落点 + `Partition` 注册表（`PARTITIONS` 是代码内封闭列表，加分区属契约级变更）/ 验证：GWT-2 往返 + 落盘明文 0 命中（与 `market.db` 同一 `Store` 加密通道）。
- A2 文档取数面以**鸭子类型**交付，L1 侧不 import L0 具体类（与官方 Pack 的 `GWT-5` 同取向）/ 若错（须硬绑 `MarketDb`）：`test_layering` 仍通过（向下依赖合法），但 Fake 注入口收窄、离线装配变难 / 验证：`TestGwt3DocSourceDoesNotBypassStore` 的 AST 断言 + 执行面**无 `open()` / 无 `pathlib`**（直连文件系统即成机器可查的反例）。
- A3 `indicator_source_map` **纯增量**：不动 `indicator_dictionary` 主键、不改既有种子生成口径 / 若错（须改主键）：返工面＝已 `done` 的 `T-L0-005` 面（表结构 + 种子生成 + 06 文档）/ 验证：GWT-1 建库前后 `indicator_dictionary` 行数与主键集合逐字段不变。
- A4 未收录代码的**预过滤在同步侧**实现（不靠 DB 报错兜底）/ 若错（依赖外键报错）：`PRAGMA foreign_keys=ON` 下**一条记录即炸整批**，`run_task` 会整体 `failed` 而非过滤 / 验证：GWT-4 全市场批次含北交所代码时批次成功、已收录行正常入库。
- A5 「归一」下沉到**引擎侧**统一做（抓取器只产原始代码）/ 若错（各抓取器自带归一）：号段规则散落多处、易漂移 / 验证：`TestCodeNormalization`（含北交所号段标 `bj.` 而非误标 `sh.`）+ `.3`/`.4` 的裸码用例。
