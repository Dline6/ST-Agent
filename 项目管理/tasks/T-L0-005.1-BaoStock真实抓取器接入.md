# T-L0-005.1 · BaoStock 真实抓取器接入与首次真实入库

## 目标
兑现 T-L0-005 遗留③——按 `Fetcher` 协议封装真实 `baostock` 抓取器（`login → 批量 query → logout`），跑通首次真实入库（元数据 + 一小批行情），抓取经网关审计。

## 验收标准（Given-When-Then）
- GWT-1 真实登录拉取：Given 本机联网且装好 `baostock` 包，When 执行 `bs_calendar`（小窗口）+ `bs_security_basic`，Then 真实行入库（`trade_calendar` / `security` 有行），网关记 `data_fetch`/`baostock` 审计。
- GWT-2 行情样本入库：Given 元数据已就绪，When 对 1–2 只证券跑 `bs_k_daily`（近 5 个交易日，`adjustflag=3`），Then `k_line_daily` 有行且水位回写，全程无 Fake 注入。
- GWT-3 失败可解释：Given 源不可达或包缺失，When 执行同步，Then 走 `unavailable`/`failed` 显式分支（不抛裸异常、不写脏水位）。
