# T-SC-001.3 · 中性化校验器 Neutrality Guard

## 目标
实现 [01-平台共享契约](../../docs/技术架构-v2/01-平台共享契约.md) §6 的中性化校验器：命名校验（拒人名/性格标签/拟人后缀）、输出校验（禁第一人称/情感表达/对话体）、命名建议（只产中性候选名）。规则库（否定词表 + 结构规则）可更新，但三个强制执行点不可配置关闭。

## 验收标准（Given-When-Then）
- GWT-4：Given 任一对外可见文本（Skill 名、视角输出），When 过中性化校验（§6），Then 拟人化表达被判失败。
- GWT-4a：Given 合法中性命名（如「机会视角」「流动性视角」），When 过命名校验，Then 通过；Given 含人名/性格标签（如「激进派」）/拟人后缀的命名，Then 拒绝并给出中性替代建议。
