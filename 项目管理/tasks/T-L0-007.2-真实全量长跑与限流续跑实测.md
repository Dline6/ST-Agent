# T-L0-007.2 · 真实全量长跑与限流续跑实测

## 目标
用 [T-L0-007.1](T-L0-007.1-脚本化全量同步与续跑语义.md) 的长跑脚本 + [T-L0-017](T-L0-017-BaoStock长跑能力分批写入断点续跑与重试退避.md) 的分批 / 续跑 / 退避能力，在**真实网络**上跑一次**沪深300 口径的首次全量同步**，观测限流与中断续跑，产出**真实数据基线**（各域水位、行长、耗时、体量）替代一次性手工操作。数据**留用不删**（落专门持久根，见验证行）。

**窗口口径（2026-10-04 人定，取代原「1990 起全历史」）**：K 线类任务的取数起点降级为**近一年**（滚动窗口，起点由脚本 `--start` 显式给出，收工记录实际取值）。理由：① 全历史实测单码 15–22s、全市场 ≈85h 且逐码整库加解密使其再翻数倍，而近一年单码仅 0.8–1.7s（726 行）；② 近一年下每码行数 < 页大小（2000），**不触发翻页**，静默截断风险随之归零；③ M1 的数据面需求不依赖 1990 年起的历史深度。**全历史回填另立**，登记于 [L0 册](../遗留问题/L0-遗留问题.md) C 段（归属＝人决），不留在本任务的隐性缺口里。

**码表口径（2026-10-05 人定，取代原「全市场 8991 只」）**：逐码任务的码表收窄至**沪深300 最新一期成分**（脚本新增 `--universe hs300`，取 `index_constituent` 中 `index_key='hs300'` 的 `max(update_date)` 那期，≈300 只），财务域 `--quarters` 取 **4**。理由：① 全市场 8 季口径下 `bs_fin_quarter` 独占 ≈43 万次请求（占全量 86%），远超源端「单日 5 万次拉黑」红线；收窄码表约 30 倍后总请求降至 **≈9.6 千次**，单日跑得完；② 本任务的验收对象是**真实链路可用 + 真实基线在案**，非全市场覆盖面；③ 码表与窗口一样由人定，**全市场码表回填另立**，登记于 [L0 册](../遗留问题/L0-遗留问题.md) C 段。**覆盖口径**：只填沪深300 时 `sync_state` 水位仍推进到当前交易日，故 `freshness_verdict` 显示「新鲜」**不等于**「覆盖全市场」——本批用**文档口径兜住**（摘要 `params.universe` + 执行日志提示），**不改 schema**。

## 验收标准（Given-When-Then）
- GWT-0 真实链路冒烟（小样本，先行）：Given 真网络 + 真实加密库，When 依次跑 `setup` → 日历 → 证券主档 → 全量快照 → 3 只真实 A 股日线全历史，Then 各步 `ok`、数据面非空、抓取全部经网关留审计、盘上无明文——证明整条管道可用。**（2026-09-26 已通过，见执行日志 `[T-L0-007.2]`）**
- GWT-1 首次全量同步（近一年窗口 · 沪深300 码表）：Given 全新 `data_cache` + 真实网络，When 以 `--universe hs300 --start <近一年起点> --quarters 4` 跑 [`run_full_sync.py`](../tools/run_full_sync.py)（元数据、K 线、财务、板块、宏观各域，K 线类起点＝近一年），Then 先导任务先填好主档与成分、码表＝沪深300 最新一期成分，逐表水位推进至当前交易日，`freshness_verdict` 各域非 `stale`，抓取全部经 L0 网关留审计，且摘要 `params.universe == "hs300"`。
- GWT-2 限流与续跑：Given 源端限流 / 断连、中途中断，或**日请求预算收手**（缺省 4 万，源端单日 5 万拉黑），When 重跑同一任务，Then 增量续跑不重复写、水位单调不回退、失败留有可查原因（不静默失败、不用旧数据冒充新数据、不入库半截结果集）。
- GWT-3 基线记录：Given 长跑完成，When 查脚本摘要，Then 长跑耗时与各域数据量基线记录在案（可与他机复跑对比），并记录实际使用的窗口起点、**码表口径（universe）**、财务季度数与分片参数。
- GWT-4 覆盖口径显式：Given 码表收窄至沪深300，When 查摘要与执行日志，Then 摘要 `params.universe` 与 `params.codes` 指纹如实记录码表范围，执行日志写明「`freshness_verdict` 非 `stale` ≠ 覆盖全市场」——**文档口径兜住，不改 `src/`、不动 schema**。
