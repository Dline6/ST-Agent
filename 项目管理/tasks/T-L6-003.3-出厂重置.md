# T-L6-003.3 · 出厂重置

## 目标
交付 [08 §6](../../docs/技术架构-v2/08-L6-反思演进.md) 后半的**「回滚到出厂设置」（三次确认）**——演进状态清空：

- **Skill 参数恢复默认**——以演进变更历史为据，**逆序回放**全部 `old_value`（经 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md) 门面落值，每条各自产生新 `change_id` 并留痕）；
- **A/B 实验停止**——停止全部在跑实验（**留痕不删**，同 [`.3`](T-L6-002.3-AB实验.md) 的「留痕即事实」口径）；
- **授权档复位**——[`.1`](T-L6-003.1-演进授权档位与风险分级清单.md) 的档位回到缺省（`collaborative`）；
- **Memory 原始数据保留**（[08 §6](../../docs/技术架构-v2/08-L6-反思演进.md) 明文）——重置**不触碰** `memory` 分区、不调用任何删除面；
- **变更历史归档可查**——重置后历史仍在（可读），重置本身另留一条痕。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 用户点击「回滚到出厂设置」，When 确认次数**不足三次**，Then **拒**——不留痕、不执行任何重置动作、不留「做了一半」的状态；Given 三次确认齐备，Then 执行
- **GWT-2**：Given 三次确认齐备，When 执行，Then 三件事**逐件可查**：① 演进变更历史所涉条目的取值回到该条目**最早一条**演进变更的 `old_value`（逆序逐条回放，每条留痕）；② 全部在跑实验转为**已停止**（实验留痕保留，不删）；③ 授权档回到**缺省 `collaborative`**；重置本身落一条留痕（含时刻 / 触发方 / 三件动作的结果）
- **GWT-3**：Given 一次出厂重置，When 检查数据面，Then **Memory 原始数据逐字节不变**——`memory` 分区无任何写入 / 删除，且 L6 侧 `grep` 断言**不 import** L2 的删除面、不调用任何 `delete_*` / `wipe_*` 面（[08 §7](../../docs/技术架构-v2/08-L6-反思演进.md) 红线：副驾永不自主修改 Memory）
- **GWT-4**：Given 重置已完成，When 读**变更历史**，Then 重置前的全部演进变更**仍可查**（归档而非抹除），且能看出哪些已被重置回放、哪些是重置本身产生的；Given 重置前无任何演进变更，Then 重置**照常成功**（无事可回放，如实说明而非报错）

## 假设与前提
- **A1 · 重置范围＝演进变更历史所记录的条目**（2026-10-07 ④ 对齐拍定）——前提：读码核实条目的 `default` 槽存的是**当前取值**（[`weekly_store.py`](../../src/st_agent/l6/weekly_store.py) 的 `set`），门面无法泛化给出「出厂默认」；而 [08 §6](../../docs/技术架构-v2/08-L6-反思演进.md) 的措辞是「**演进状态**清空」。故以演进变更历史为准逆序回放，**不波及** `retention.*` / `mcp-hub/` 等与演进无关的条目——该口径同批写进 [08 §6](../../docs/技术架构-v2/08-L6-反思演进.md)。若错（要求「全量条目恢复出厂默认」）：返工面＝本叶范围（须逐族补默认值来源并触各族交付面）。验证方式：重置后条目值等于该条目最早一条演进变更的 `old_value`；未被演进改动过的条目取值不变。
- **A2 · 「实验停止」＝只增一个停止面，留痕不删**（2026-10-07 ④ 对齐拍定）——前提：[T-L6-002.3](T-L6-002.3-AB实验.md) 已把「留痕即事实」定为该面口径（结算幂等、不追加第二份），[08 §6](../../docs/技术架构-v2/08-L6-反思演进.md) 亦只要求「停止」而非删除；`ExperimentStatus` 是 `Literal`，补取值不破坏既有取值。若错（要求删除实验记录 / 要求状态值另立）：返工面＝本叶的停止面 + [`experiment.py`](../../src/st_agent/l6/experiment.py) 的状态面与其用例。验证方式：`abandon` 后实验记录仍可 `get` 到、`running()` 不再含它、既有 `start` / `settle` / `decide` 用例不改即全绿。
- **A3 · Memory 保留以机器断言钉住**（2026-10-07 ④ 对齐拍定）——前提：[08 §6](../../docs/技术架构-v2/08-L6-反思演进.md) 明文「Memory 原始数据保留」，[08 §7](../../docs/技术架构-v2/08-L6-反思演进.md) 红线「副驾不得自主修改 Memory 节点内容」；L2 的删除面（[T-L2-003](done/M1/T-L2-003-记忆删除与审计.md)）是**用户显式删除**的通道，出厂重置**不得**借道它。若错（要求重置一并清 Memory）：返工面＝本叶范围 + [08 §6](../../docs/技术架构-v2/08-L6-反思演进.md)（与 [§7](../../docs/技术架构-v2/08-L6-反思演进.md) 红线冲突，须先改红线）。验证方式：重置前后的 `memory` 分区清单与逐文件 `digest` 逐一致；`grep` 断言 `src/st_agent/l6/**` 不 import [`l2.memory.deleter`](../../src/st_agent/l2/memory/deleter.py)、不出现 `delete_node` / `wipe_partition` 调用。
