# T-UI-019 · Windows 安装器与安装体验

> **M7 打包发布叶之一**（[D-103](../决策日志.md) ③：先只做 Windows）。`T-UI-002.3` 已产出两份 PyInstaller 目录（`dist/st-agent-server/` + `dist/st-agent-shell/`，[packaging/README](../../packaging/README.md)），但它们是**绿色目录**而非**可安装包**——无开始菜单项、无卸载项、无前置检测。

## 目标

把现有两份产物打成 **Windows 可安装包**，并定安装 / 卸载体验：

- **安装包构建**：把 `dist/st-agent-server/` + `dist/st-agent-shell/` 收进一个安装器；安装路径 / 开始菜单 / 桌面快捷方式可配（安装技术选型待 ④，候选 Inno Setup / WiX / NSIS——**不在本叶预判**）
- **卸载项**：控制面板「应用和功能」可见、可卸载；卸载时**数据面与程序面分离**（用户记忆 / 行情库 / 凭据**默认保留**，是否需要「连数据一起删」的显式选项待 ④）
- **前置检测**：WebView2 Runtime 缺失时的检测与获取指引（Win11 自带，Win10 需检测）
- **两进程摆放**：遵守 [`st-agent-shell` 按摆放惯例找后端](../../packaging/README.md) 的既有约定，安装后仍成立
- **与 [`T-UI-020`](T-UI-020-代码签名与安装包可信性.md) 的接口**：本叶产**未签名**安装包 + 签名挂载点；签名由 `.2` 叠加

**本批的边界**（不越界）：

- **不改 `T-UI-002.3` 的产物构建**——PyInstaller 两份产物是冻结交付物，本叶在其**之上**包装。
- **不做 macOS / Linux**——[D-103](../决策日志.md) ③ 已显式标为未交付（须各平台构建机）。
- **不签名**——归 [`T-UI-020`](T-UI-020-代码签名与安装包可信性.md)。
- **不打 tag / 不发布**——收口与真机验收归 [`T-INT-008`](T-INT-008-M7集成关卡打包发布.md)。

## 验收标准（Given-When-Then）

- GWT-1：Given 两份冻结产物，When 跑安装器构建，Then 产出一个 Windows 安装包，且 `build.py` 的既有自检（dev 面物理剔除 / 壳产物不含业务层）在包装后**仍成立**
- GWT-2：Given 安装包，When 在一台干净 Windows 机安装，Then 完成安装、出开始菜单项与卸载项，双击启动能拉起后端并打开回环界面（握手成功）
- GWT-3：Given 已安装程序，When 卸载，Then 应用从「应用和功能」消失、程序文件清干净，**用户数据默认保留**（或按显式选项处置），卸载可重复执行
- GWT-4：Given 一台**无** WebView2 Runtime 的机器，When 安装 / 首启，Then 检测并给出获取指引，**不**静默失败
- GWT-5：Given 安装后的摆放，When 壳找后端，Then 按 [`packaging/README`](../../packaging/README.md) 的放置惯例成功定位同级后端（不回落 `python -m st_agent`）
