# T-L0-010 · 多源信息面采集与管理机制

## 目标

为 L0 数据源缓存接入 **BaoStock 之外的互补信息面**——**暂定四域**：公告 / 龙虎榜 / 股东变化 / 舆情。每域按[数据库设计 §多源扩展规约](../../docs/数据库设计-BaoStock数据层/00-设计总览.md)交付完整链路：`data_source` 注册 + 按域前缀建表组 + 复用 `sync_state` 同步任务 + 在 [05](../../docs/数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md) 登记新鲜度契约；采集通道一律 **L0 网关直抓**。

**范围口径**（[D-029](../../项目管理/决策日志.md)）：信息面取「**与 BaoStock 互补的部分**」，暂定四域，**后续可扩充**——收录判据为**两条并列**：① 供给侧不重复（BaoStock 无此域）② 需求侧有明确消费方（不预设）。仅 ① 不足以收录（BaoStock 的补集约 60 个端点，须由 ② 收敛）。

**本任务直接关闭** [L1 册 `C1`](../../项目管理/遗留问题/L1-遗留问题.md)——`stock-watch` 的「关键词」盯盘条件因**无公告域数据面**而以 `unevaluated_conditions: ["关键词"]` 显式标注跳过（[T-L1-004.3](../../项目管理/tasks/T-L1-004.3-主动服务Bundle执行器.md)），公告域落地后该条件可获得评估路径。

**四项前置已定案**（[未决登记册](../../项目管理/阻塞与未决.md)已清零）：

| 决策 | 内容 |
|---|---|
| [D-029](../../项目管理/决策日志.md) | 通道＝**L0 网关直抓**；官方 MCP Server 若保留则降为「L0 缓存的只读暴露面」（不出网 / 不采集 / 不写库） |
| [D-030](../../项目管理/决策日志.md) | 「单一事实源」粒度＝**业务键**：表边界按**实体语义**定、源为**行级 `source_id`**；`as_of` 一域多源取各源水位**保守下界**（`min`） |

## 拆分记录（③ 已执行）

命中拆分触发（四域的**获取方式、频率与新鲜度节奏各异**——公告事件驱动 / 龙虎榜盘后 T+0 晚 / 股东户数季频 / 舆情近实时且**易腐**；横跨 [00 §多源扩展规约](../../docs/数据库设计-BaoStock数据层/00-设计总览.md) · [05](../../docs/数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md) · [02 §5](../../docs/技术架构-v2/02-L0-本地优先基座.md) 三个以上契约小节；每域自成表组与同步任务，预计会话轮次 > 20），已拆为叶子子任务：

- `T-L0-010.1` **信息面基件**——跨四域共用的四件事：① 元数据层扩展 `indicator_source_map`（多源字段映射，[D-030](../../项目管理/决策日志.md)）② 文本承载基件（`data_cache` 文本目录规约 + 经 `Store` 落盘 + 表行/文件一致性判据，[D-031](../../项目管理/决策日志.md)）③ **L0 文档取数面**（`list_docs` / `read_doc` / `search_docs`，与 `MarketDb.query` 同构的鸭子类型注入）④ 主档**预过滤 + `filtered_unmapped` 计数**基件（[D-032](../../项目管理/决策日志.md)）。**不碰任何具体域语义**
- `T-L0-010.2` **公告域**——`announcement` 表组 + 巨潮主源（深市深交所官方 / 沪市东财按**覆盖分片**兜底）+ 正文落文件 + 新鲜度条目（含「不可逆缺口」）。**本叶子收口 L1 册 `C1`**（「关键词」条件获得评估路径，届时复核 [03 §2.2](../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 措辞）
- `T-L0-010.3` **龙虎榜域**——**按实体分两表**（`dragon_tiger` 上榜记录 / `dragon_tiger_seat` 席位明细）；席位明细以交易所官方为主、东财 TOP5 与机构动向为补充源
- `T-L0-010.4` **股东变化域**——`shareholder_num` 单表；**单源**（东财），不可用即 `unavailable`（无备胎）
- `T-L0-010.5` **舆情域**——**双市并行互补（非主备）**：深市互动易 + 沪市上证e互动 同表按市场分片；`sentiment_hot`（热榜 / 人气榜）为独立实体、按**易腐数据**处理，不进档案型新鲜度契约

`.2`–`.5` 均依赖 `.1`（需先有基件）。父任务 `T-L0-010` 的 `status` 由 children 派生，不手填。
