# T-UI-018 · 设置区与全局要素

> **M6 七面功能叶之一**（[D-103](../决策日志.md)）。补上 [11-sitemap §2 设置](../../docs/PRD-v2-Agent/11-sitemap.md) 与 [§2 全局要素](../../docs/PRD-v2-Agent/11-sitemap.md)——「本地优先 / 数据主权」的**用户可控面**（存储 / LLM / 数据源 / 隐私 / 备份恢复 / 清空 / 网络活动 / 离线降级）现**全无页面**（仅「演进授权」一页，属反思面）。

## 目标

把 [11-sitemap §2 设置](../../docs/PRD-v2-Agent/11-sitemap.md) 与**全局要素**的屏做成可用界面：

- **设置-存储页 / 设置-LLM 提供方页 / 设置-数据源页 / 设置-隐私页**
- **备份 / 恢复对话框**（[§3.8](../../docs/PRD-v2-Agent/11-sitemap.md)：一键备份 → 输入密码 → 单加密文件；恢复 → 输入密码 → 完整还原）
- **完全清空确认流程**（**三次确认** → 彻底删除本地数据）
- **网络活动面板**（常驻入口，与 story-08 共用）
- **离线模式横幅**（全局要素，[§3.9](../../docs/PRD-v2-Agent/11-sitemap.md) 离线降级）

**本批的边界**（不越界）：

- **备份 / 恢复 / 清空的本体归 L0**——本叶只做交互面与确认门，不重造加密 / 落盘逻辑。
- **设置项经统一配置注册表**（[01 §7](../../docs/技术架构-v2/01-平台共享契约.md)，`T-L1-012` 已交付门面）——本叶经 `setting_panel` 消费，**不旁路写盘**。
- **离线模式的检测与降级判定归既有层**——本叶只呈现横幅与标注。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 设置 / §2 全局要素](../../docs/PRD-v2-Agent/11-sitemap.md) 的屏，When 逐条走查，Then 每条有可见载体——四设置页、备份恢复对话框、三次确认清空、网络活动面板、离线横幅
- GWT-2：Given 一个设置项，When 改值，Then 经统一配置注册表（[01 §7](../../docs/技术架构-v2/01-平台共享契约.md)）生效并留痕，**不旁路写盘**
- GWT-3：Given 「完全清空」，When 触发，Then **三次确认**逐步收紧（不可一步到位），确认后彻底删除本地数据并显式回报
- GWT-4：Given 备份 / 恢复，When 触发，Then 走「输入密码 → 单加密文件 / 完整还原」，密码错误与文件损坏如实报错（**不道歉、不模糊**）
- GWT-5：Given 断网，When 呈现，Then 离线横幅出现，依赖 LLM 的功能**标注需联网或本地推理**，历史 / 记忆 / 已缓存 Skill 仍可用（[§3.9](../../docs/PRD-v2-Agent/11-sitemap.md)）
- GWT-6：Given 文案，When 核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**
- GWT-7：Given 真组合根 + 真回环服务，When 在 Edge 走查四设置页 / 备份恢复 / 清空三次确认 / 网络活动 / 离线横幅，Then 全程可用、控制台无新增报错
