# T-L2-001.2 · MemoryWriter 写入接口

## 目标

兑现 [04 §3.2](../../docs/技术架构-v2/04-L2-记忆图谱.md) 的写入面：两条写入路径（用户显式 / 系统推断）、编辑必经修正历史，以及 §3.2 的红线——**副驾不得自主修改既有 Memory 节点内容**。策略层（自主写入白名单 / 冲突检测 / 裁决，§4）不在本叶，归 `T-L2-002`；本叶只交付写入**原语**与红线形状。

## 验收标准（Given-When-Then）

- **GWT-1 · 用户显式路径直写**：Given 对话表达偏好 / Onboarding / 手动新增，When 经写入面落一条节点，Then 记录为 `source=user_stated` 并直接入库（非 `inferred` 者不带 `provenance`）。
- **GWT-2 · 系统推断路径留据**：Given 一次 Skill 结果 / 反馈 / 模式识别触发的写入，When 落一条节点，Then 记录为 `source=inferred` 且必带 `provenance.trace_id`（推断依据可追溯）；缺 `trace_id` 即显式拒绝。
- **GWT-3 · 编辑必留修正历史**：Given 用户显式修改一条既有节点，When 提交新值，Then 旧值进 `revision_history`（保留供审计）+ `updated_at` 刷新，图谱中无任何「静默覆盖」路径。
- **GWT-4 · 红线：推断面不得改既有节点**：Given 一个 `source=inferred` 的调用方，When 试图变更既有节点内容，Then 写入面**不存在**这样的入口——既有节点内容的变更唯一入口为用户显式编辑（并经受 GWT-3 的留史）；推断面只提供新增。

## 接口面

- **输入（消费的前置接口）**
  - T-L2-001.1 的节点 / 边模型与 `MemoryGraph`（`src/st_agent/l2/memory/models.py` · `graph.py`）——写入面只经该门面落盘，不自行拼 `Store` 路径
  - T-SC-001 `MemoryNodeId` / `TraceId`（[identifiers.py](../../src/st_agent/contracts/identifiers.py)）· 带时区时间（[time_events.py](../../src/st_agent/contracts/time_events.py)）
  - T-L0-001 `Store`（[store.py](../../src/st_agent/l0/storage/store.py)）
- **输出（本任务交付的公共 API / 落盘位置）**
  - 新增 `src/st_agent/l2/memory/writer.py`：`MemoryWriter`（`add_node` / `edit_node`（用户显式，留修正历史）/ `add_edge`）与两类写入入口
  - `src/st_agent/l2/memory/errors.py` 增写入侧错误类型
  - 落盘：沿用 `.1` 的 `memory` 分区布局，本叶不新增落盘位置

## 可关闭的遗留

- 无直接命中。**关联**：L0 册 `F1` 深市部分的解封链路含本叶——关注面须 `attention` 节点**能写入**，而写入面（两条写入路径 + 修正历史）正是本叶；处置见 [`T-L2-001.1`](T-L2-001.1-记忆图谱本体节点边模型与落盘.md) 的 `## 可关闭的遗留`（就地修正册内解封条件，不并入本任务验收）。

## 假设与前提

- **A1 · 「修改提案」不属本叶**：§3.2 只规定两条写入路径与红线，把「推断类写入触发冲突 → 进冲突队列 → L3 裁决」整套流程留给 §4（`T-L2-002`）。故本叶的推断面**只有新增**，既有节点内容的唯一变更入口是用户显式编辑。若错（推断面需要提案入口）：返工面 = `MemoryWriter` 推断面 API + `T-L2-002` 的消费面。
- **A2 · 红线用「无入口」而非「有开关」落实**：`T-L1-009.3` / [D-031](../决策日志.md) 的取向是权限与边界以 **API 形状**强制（不可配置关闭）。故红线靠「不提供 inferred 改既有节点的入口」兑现，不引入 `allow_inferred_edit=False` 之类的可绕行标志。若错：返工面 = 写入面 API 形状与其用例。
- **A3 · 修正历史的粒度＝整节点快照**：§1 只规定 `revision_history` 保留旧值供审计，未定粒度。本叶取「每次编辑存一份被替换前的节点快照 + 时间 + 触发方」，最简且可完整回放。若错（量级或差分需求）：返工面 = `RevisionEntry` 形态与其落盘，`MemoryWriter.edit_node` 内部实现。
