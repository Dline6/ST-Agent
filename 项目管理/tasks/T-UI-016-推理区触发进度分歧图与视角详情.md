# T-UI-016 · 推理区：触发、进度、分歧图与视角详情

> **分组节点**（[D-112](../决策日志.md) ①，2026-10-10 拆分）：交付由 [`.1`](T-UI-016.1-触发进度与视角阵容.md)（触发、进度与视角阵容）· [`.2`](T-UI-016.2-分歧图与视角详情.md)（分歧图两视图与视角详情）· [`.3`](T-UI-016.3-推理链面板与决策记录.md)（推理链面板与决策记录）三叶承接——本文件保留原立项的屏清单与验收，供父节点状态派生（[检查 7](../tools/verify_docs.py)）。

> **M6 七面功能叶之一**（[D-103](../决策日志.md)）。补上 [11-sitemap §2 推理](../../docs/PRD-v2-Agent/11-sitemap.md)——`divergence_map` 渲染件（含矩阵与证据网络两视图）**已实现**（`T-L4-004.2`），但**在 UI 里没有宿主页**；推理链展开面板（§3.3 的 `trace_timeline`）同理跨页复用无家。

## 目标

把 [11-sitemap §2 推理](../../docs/PRD-v2-Agent/11-sitemap.md) 声明的屏做成可用界面：

- **Deliberation 触发确认对话框**：快速模式（3 视角）/ 深度模式（7 视角）
- **多视角并行执行进度页**
- **分歧图矩阵视图 / 证据网络图视图**：复用已实现 `divergence_map`（一致 / 分歧 / 盲点三段**并列**，**不合并**）
- **视角详情页 / 追问对话框**
- **自定义视角创建页**
- **决策记录页**：决策 + 理由 + 采纳视角 + 忽略视角
- **推理链展开面板**（[§3.3](../../docs/PRD-v2-Agent/11-sitemap.md)）：从任意结论卡进入，**跨页复用** `trace_timeline`（同服务本 Flow、视角追问与反思报告）

**本批的边界**（不越界）：

- **不重造 `divergence_map` / `trace_timeline` 渲染件**——两者已是已实现型，本叶只做**宿主页与取数**。
- **推理链面板与 [`T-UI-012`](T-UI-012-Chat主界面对话流与生成式UI宿主.md) 共用**——入口在 Chat，本叶立"展开面板"这件**跨页复用件**，不重复定义。
- **多视角推理本体归 L4**——本叶只呈现其进度与结果，不改 L4 逻辑。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 推理](../../docs/PRD-v2-Agent/11-sitemap.md) 的屏清单，When 逐条走查，Then 每条屏有可见载体——触发确认（3 / 7 视角）、进度页、两视图分歧图、视角详情与追问、自定义视角、决策记录
- GWT-2：Given 一次多视角决策，When 呈现结果，Then 观点卡 + 分歧图 + 一致 / 分歧摘要 + 盲点提示**并列**（**不合并、不给统一建议**，[铁律 4](../工程宪法.md)），证据网络图可点开细看
- GWT-3：Given 「采用某视角 / 忽略某视角」，When 查看决策记录，Then 决策 + 理由 + 采纳视角 + 忽略视角**如实留痕**，未采纳的视角**不**被静默丢弃
- GWT-4：Given 推理链展开面板，When 从结论卡进入，Then 出调用序列 / 记忆片段 / 视角汇总 / 耗时，任一环可点开细看；该件**跨页复用**（§3.3 / 视角追问 / 反思报告三处同一渲染件）
- GWT-5：Given 文案，When 核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**（视角无「性格」称谓）
- GWT-6：Given 真组合根 + 真回环服务，When 在 Edge 走查「触发 → 进度 → 分歧图 → 追问 → 决策记录」，Then 全程可用、控制台无新增报错
