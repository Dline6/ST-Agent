# T-L1-002.3 · MCP Server 状态机 + 崩溃重连 + 降级 + 网关登记

## 目标
给 MCP Server 一个显式的生命周期：五态状态机 + 转移留痕；崩溃时明确提示并按可配次数自动重连；重连耗尽后**并列暴露**官方数据源 Skill 兜底候选（不自动切换、不给统一建议）；禁用 Server 时中止进行中调用；Server 的全部远程出网经 L0 网关登记且可查——兑现 [L0 遗留册 A1](../遗留问题/L0-遗留问题.md) 的「远程 MCP」半。

## 验收标准（Given-When-Then）
- GWT-1 五态状态机 + 留痕：Given 一个已注册 Server，When 经历 `connected` / `disconnected` / `reconnecting` / `permission_pending` / `disabled` 之间的合法转移，Then 每次转移被记录（含前后状态、时间、关联 `trace_id`），非法转移被显式拒绝；`permission_pending` 由 `.1` 的未批准权限触发。
- GWT-2 崩溃 → 提示 + 自动重连（次数可配）：Given 一个 `connected` 的 Server，When 连接断开，Then 产生显式提示事件并进入 `reconnecting`，按配置的重连次数自动重试；重试次数与间隔经 01 §7 `ConfigEntry` 形态注册（`config` 分区），可改且改动留 `change_id`。
- GWT-3 重连耗尽 → 降级候选并列暴露：Given 重连次数耗尽，When 查询降级候选，Then 得到该 Server 所遮蔽的官方数据源 Skill 候选**列表**（并列陈列，附各自可用性），**不自动切换、不合并、不给统一建议**（宪法铁律 4）；状态转 `disconnected` 并留痕。
- GWT-4 禁用 → 进行中调用中止：Given 该 Server 有进行中的调用，When 用户禁用该 Server，Then 状态转 `disabled`，进行中调用经取消信号中止且结果走显式失败分支（不留「成功」假象）。
- GWT-5 出网全登记可查：Given 该远程 Server 发生过若干次调用，When `gateway.query(kind="remote_mcp", initiator=<server_id>)`，Then 每条出网都有审计记录（含目的说明与字节数，无明文）；`remove_server` 后历史审计记录**保留**（审计不可被注销）。
- 回归：既有 591 用例全绿；`verify_docs.py --strict` PASS。

## 假设与前提
- **A1 · 重连策略是可配置项，按 01 §7 注册**：重连次数与间隔以 `ConfigEntry` 落 `config`，`scope="global"`，`change_policy.record_history=True`。若错（策略应是 per-Server）：返工面＝`ConfigEntry.scope` 与落盘路径 + GWT-2 用例。验证：`Entry` 读回为七字段形态、改动产生 `change_id`。
- **A2 · 降级只暴露候选，不自动切换**：宪法铁律 4（不合并、不给统一建议）与 03 §5.3「**可**降级」的措辞都指向「暴露选项、由上层决定」。若错（产品要自动兜底）：返工面＝降级面 + 需与 L3/L4 协商切换点。验证：GWT-3 用例断言返回值为候选列表且不改变任何执行路径。
- **A3 · 禁用即中止，不留半成品结果**：进行中调用经 `cancel` 信号中止，结果走显式失败分支。若错（要求等本次调用跑完）：返工面＝`cancel_inflight` 语义。验证：GWT-4 用例断言信封为失败分支且审计含 `cancelled`。
- **A4 · 审计记录随 Server 删除而保留**：出网审计属 L0 分层留痕，`remove_server` 只删注册表与映射，不动 `execution_log`。若错（要求连带清理）：返工面＝`remove_server` + 可能触碰 L0 审计不可删的红线。验证：GWT-5 用例断言删除后 `query` 仍可查得历史记录。
- **A5 · 状态机留痕落 `execution_log` 而非新分区**：沿用 L1 既有留痕口径（如 `sandbox-violation/`）。若错：返工面＝留痕分区与查询入口。验证：`list_files("execution_log")` 可见、格式自洽。
