# T-L6-001.3 · L6 装配缝与报告投出

## 目标
交付 L6 的**层内装配缝**与**报告投出**：`build_l6` 把 [`.1`](T-L6-001.1-反思数据池.md) 的池子与 [`.2`](T-L6-001.2-每周反思报告本体.md) 的报告面接成一个 `L6Stack`——**注入 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md) 族**（适配器住 L6、门面住 L1，注入而非 import）、**订阅 `FeedbackRecorded`**（反馈经总线自动落池，一跳到底）、并把报告经 [07 §3](../../docs/技术架构-v2/07-L5-主动触达.md) 的**既有渠道面**投出；「一周一次」去重**从盘上读**，重启安全。

**上游与本叶的边界**（2026-10-06 读码核实）：

- **本模块只装配 L6 一层**——跨层组合根 `build_m4_runtime`（把 L6 与 L0–L5、UI 面接起来、加常驻循环）归关卡 [T-INT-005](T-INT-005-M4集成关卡反思演进与生态闭环.md)。先例＝[`l5/runtime.py`](../../src/st_agent/l5/runtime.py) 只装配 L5、`build_m3_runtime` 归 [T-INT-004](done/M3/T-INT-004-M3集成关卡主动触达投递闭环.md)（[工作流](../工作流.md)「跨层装配与端到端验证不按此拆分——归里程碑集成关卡」）。
- **投出面不自造**：[07 §3](../../docs/技术架构-v2/07-L5-主动触达.md) 的 [`ChannelDispatcher`](../../src/st_agent/l5/channels.py) 已交付「按链序 + 即时降级」，[T-L5-003.1](done/M3/T-L5-003.1-每日报告本体与模板配置.md) 的日报已按同一路径投出——本叶复用该面（**不新增投递路径**、**不新增渠道**）。
- **订阅面不是 L6 私有**：[`EventBus`](../../src/st_agent/l1/events.py) 支持一事件多订阅者（L5 疲劳面已订阅同一 `FeedbackRecorded`，[T-L5-003.3](done/M3/T-L5-003.3-推送疲劳监控与答复回流.md)）——两订阅者并列、逐订阅者记因，故 L6 的接管**不影响**疲劳面的既有行为。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 一份已生成的周报与其订阅渠道链，When `deliver(report)`，Then 报告经注入的渠道面投出、并把**真正投出的渠道**回写留痕；Given 渠道全不可用 / 未注入投出面，Then **不假装送达**（留痕渠道为空、`deliver` 原样返回），且**不丢**（下一轮仍会重试）
- **GWT-2**：Given 该周报告已存在且已投出，When 再推进一轮，Then **不重复投**；Given 已生成但**未投出**（渠道当时不可用），Then 照常重试——去重判据是**盘上的既成事实**（留痕），不是进程内的一次性记忆，故**重启后依然成立**
- **GWT-3**：Given `build_l6(..., events=总线)`，When 总线收到一条 `FeedbackRecorded`，Then 该反馈**自动落进池子**（一跳到底，无需调用方手递）；Given 未注入总线，Then **不订阅**、池子仅可经显式 `consume` 写入（**不假装已接线**）；Given 注入了门面，Then `weekly-report.*` 族**登记成功**、经门面可读到本层条目
- **GWT-4**：Given 任一可选面缺省（`Store` / 总线 / 门面 / 渠道面 / 记忆面 / 各 L5 读面），When 装配，Then 各面走**显式降级**（纯内存态 / 不订阅 / 不登记 / 投出缺席显式 / 该段空态）——**没有一处静默降级**，且降级原因可从各面自身读面看出
- **GWT-5**：Given 注入的门面，When 对 `weekly-report.*` 逐条目读 / 写，Then **读面全接**（四项皆可读回）；标量条目（`day-of-week` / `time` / `min-feedback`）经统一落值面**可写**、产生 `change_id` 留痕；对象类条目（`template`）**fail-closed 并点名**其写面归属（本层自有 API），**不静默落一个半截值**（同 [L5 四个族](../../src/st_agent/l5/registry_adapter.py) 的逐条目裁定）

- **A1 · 装配缝归 L6、跨层组合根归关卡**——前提：[`l5/runtime.py`](../../src/st_agent/l5/runtime.py) 已立下「层自持装配缝、组合根归 `T-INT-*`」的先例，[工作流](../工作流.md) 明写「跨层装配与端到端验证不按此拆分——归里程碑集成关卡」。若错（要求本叶直接产 `build_m4_runtime`）：返工面＝本模块范围 + [T-INT-005](T-INT-005-M4集成关卡反思演进与生态闭环.md) 的范围。验证方式：`grep` 断言 `src/st_agent/l6/**` 不 import `app`（层不得反向依赖组合根，[`test_layering.py`](../../tests/test_layering.py) 同向把关）。
- **A2 · 「一周一次」去重读留痕、不存进程标志**——前提：[T-L5-003.1](done/M3/T-L5-003.1-每日报告本体与模板配置.md) 的日报已按此口径落地（投出结果回写留痕，故「是否已投」是可从盘上读出的既成事实）；L6 的常驻后端与 UI 客户端**可分离**（[D-060](../决策日志.md) ②），进程内标志会在重启后失效并造成重复推送。若错（要求队列 / 定时器层面的去重）：返工面＝本叶去重面。验证方式：新开一个构造器续读既有留痕、不重投的用例（重启安全）。
- **A3 · 本层不自订阅以外的任何自发行为**——前提：`build_l6` 只做「注入 / 订阅 / 接线」三件事，**不**在层内起定时器或后台线程（常驻循环归生产入口，同 [T-INT-004](done/M3/T-INT-004-M3集成关卡主动触达投递闭环.md) 的「判定与推进是显式时刻的纯函数」口径）。若错（要求层内自跑）：返工面＝本模块线程模型与全部用例的确定性。验证方式：全部用例无 sleep / 无后台线程即可跑绿。
