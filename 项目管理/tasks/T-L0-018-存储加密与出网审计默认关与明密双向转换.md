# T-L0-018 · 存储加密与出网审计 · 默认关 + 实现降耗 + 明密双向转换

> **本任务已拆分为两个子任务**（2026-10-04，沿用 [T-L0-007](T-L0-007-全量首次同步与限流实测.md) → `.1`/`.2` 先例）：
>
> - [`T-L0-018.1`](T-L0-018.1-存储加密可选与明密双向转换.md) —— 存储面：加密默认可关 + 格式可辨 + 明密双向转换 + 落盘往返降耗
> - [`T-L0-018.2`](T-L0-018.2-出网审计可选与落盘形态批量化.md) —— 网关面：审计默认可关 + 审计落盘由「一请求一文件」改为批量化
>
> 父任务只承载分组与依赖骨架；验收标准、接口面与假设由子任务各自实填。

## 目标
把 L0 基座里**两处开销与「是否必要」耦合在一起**的机制解耦：加密与出网审计改为**可选、默认关**，并把二者的实现开销降下来；另交付**加密 ⇄ 明文的双向转换**。触发数据（2026-10-04 实测）：逐码全量同步时「一次事务＝整库 blob 加解密」达 **5.3 秒/GB/次**（使长跑呈 n² 行为）；出网审计「一请求一文件 + 每次重写整分区清单」达 **≈16 ms/次**（n=3.7 万），12 万次请求累计 20–45 分钟。

## 验收标准（Given-When-Then）

- [`T-L0-018.1`](T-L0-018.1-存储加密可选与明密双向转换.md)：GWT-1 加密默认可关 / GWT-2 格式可辨 / GWT-3 明密双向转换 / GWT-4 完整性不随降密而降 / GWT-5 契约先行
- [`T-L0-018.2`](T-L0-018.2-出网审计可选与落盘形态批量化.md)：GWT-1 审计默认可关 / GWT-2 开关可配 / GWT-3 关闭时的连带口径 / GWT-4 落盘批量化 / GWT-5 契约先行
