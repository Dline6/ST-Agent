# T-UI-011.1 · 多面端口注入与各面门面装配

> [T-UI-011](T-UI-011-底座与骨架多面端口注入与全IA页面登记.md) 的**端口与门面叶**（[D-109](../决策日志.md) ①）。把各功能面的**取数口**在组合根造齐、经**同形鸭子端口**注入表现层，使七面功能叶（[`T-UI-012`](T-UI-012-Chat主界面对话流与生成式UI宿主.md) ~ [`T-UI-018`](T-UI-018-设置区与全局要素.md)）只剩「往已登记的页面里填内容」，不再各自接线。

## 目标

三件交付，都落在**组合根与表现层的骨架面**（本叶**不填任何业务内容**）：

1. **七个新鸭子端口**——[`UiApp`](../../src/st_agent/ui/app.py) 现只有四端口（`chat` / `reflection` / `eco` / `memory`，**本叶一字不动**）。按 [11-sitemap §2.2](../../docs/PRD-v2-Agent/11-sitemap.md) 的分区取数需求，新增 **`workspace` · `skills` · `mcp` · `graph` · `deliberation` · `delivery` · `settings`** 七个字段，`build_ui(...)` / [`serve`](../../src/st_agent/ui/server.py) 加同名可选关键字，[`__main__.py`](../../src/st_agent/__main__.py) 的 `run_backend` 从 [`M5Runtime`](../../src/st_agent/app.py) 经 `getattr(runtime, "<面>", None)` 注入（老根无该面即 `None` ⇒ fail-closed，不启不来）。
2. **组合根造**六个**薄门面**——[`st_agent/app.py`](../../src/st_agent/app.py) 新增 `SkillsFacade` / `McpFacade` / `GraphFacade` / `DeliberationFacade` / `DeliveryFacade` / `SettingsFacade`，各**持真句柄**（L1 能力注册表与 MCP 注册表 · L2 图谱 · L4 roster / viewer · L5 派发与投递留痕 · L0 配置注册表），在 `M5Runtime` 上以同名属性暴露。**薄**＝只持有句柄与存在性，**不加业务读端点**（那归七面叶）。`workspace` 面**不装配门面**——钉住物的落盘归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)，故该面刻意保持 fail-closed。
3. **面可用性探针**——[`server.py`](../../src/st_agent/ui/server.py) 的 `_GET_ROUTES` 新增 **`/api/workspace/status` · `/api/skills/status` · `/api/mcp/status` · `/api/graph/status` · `/api/deliberation/status` · `/api/delivery/status` · `/api/settings/status`** 七条，全部走既有 [`api_face_status(face)`](../../src/st_agent/ui/app.py)，与既有三条探针（`reflection` / `evolution` / `eco`）**同形**。新增路径**只有**这七条**只读**探针——写面白名单逐条不变。

**本批的边界**（不越界）：

- **不填业务内容**——各页的具体读面 / 交互 / 渲染件归七面功能叶；薄门面只证「面在」，不冒充业务内容。
- **不动既有四端口语义**——`chat` / `reflection` / `eco` / `memory` 保持原形，新面只增。
- **不登记页面、不改 `nav`**——`PAGE_PATHS` / `pages.js` 与导航收敛归 [`.2`](T-UI-011.2-全IA页面登记与导航收敛.md)（故 `.2` `depends_on` 本叶：它要把探针写成各页的 `statusPath`）。
- **不动壳的路由机制**——`PAGE_PATHS` 精确匹配 + SPA 回退 + 令牌分档（[D-063](../决策日志.md)）不变；新探针属 `/api/*` 数据面，**要令牌**，不放宽守卫。
- **不引构建链**（[D-063](../决策日志.md)）。
- **不越层取数**——组合根是唯一装配点，表现层只经鸭子端口（[铁律 7](../工程宪法.md)）。

## 验收标准（Given-When-Then）

- **GWT-1** Given 某面端口未注入（该面 `None`），When 取该面 `/api/<面>/status`，Then HTTP 200 + 合法信封（`status="unavailable"`、非空 `reason`、`render.presentation="delayed"`、带 `last_updated_at`），`reason` **点名**「未接入 <面> 面 / 装配归生产入口」——不 500、不装空表冒充。
- **GWT-2** Given 某面端口已注入，When 取该面探针，Then `status="ok"` 且 `data=={"face": <面>, "available": True}`（与既有三条探针逐字段同形）。
- **GWT-3** Given **真 M5 组合根**（[`build_m5_runtime`](../../src/st_agent/app.py) 真装配），When 取七面探针，Then 六个有门面的面回 `ok`、**`workspace` 仍 `unavailable` + 点名**（它的门面归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)，本叶刻意不装配）；同一根上既有四端口探针行为不变。
- **GWT-4** Given 七条新探针，When 不带令牌 / 用 `POST` 请求，Then 分别 401 / 404（数据面恒要令牌、写面白名单**逐条不变**）；既有 15 条 `_POST_ROUTES` 与新注册前后**一一相等**（新增路径不可能悄悄开一个写面）。
- **GWT-5** Given 本叶改动，When 跑 `pytest tests/contracts tests/test_layering.py tests/test_tools.py tests/integration tests/ui` + `python tools/verify_docs.py --strict`（在 `项目管理/` 下），Then 范围套件全绿、检查 1–9 全过 0 断链；且 [`tests/test_layering.py`](../../tests/test_layering.py) 的 `test_ui_is_client_only` / `test_app_is_composition_root_only` **不改即绿**（`ui` 仍不 import `app`，门面只能经端口传）。

## 假设与前提

- **A1**：端口名取**面名小写**（`workspace` / `skills` / `mcp` / `graph` / `deliberation` / `delivery` / `settings`），与既有四端口同形，故 `api_face_status(face)` 的 `getattr(self, face)` 直接可用。**若错的影响**：属性名与探针路径不一致 ⇒ 探针永远 `unavailable`（把「面在」误报成「未接线」）。**验证方式**：GWT-2 以「注入即 `ok` 且 `data.face == 面名`」钉住；GWT-3 在真组合根上逐面复核。
- **A2**：`ui` **不 import** `st_agent.app`（[`test_app_is_composition_root_only`](../../tests/test_layering.py) 钉住），故各面门面**只能**经鸭子端口传；门面造在组合根。**若错的影响**：若改走 import，`ui` 会绑上层内 API 形状，且破既有守卫。**验证方式**：GWT-5 的 layering 守卫**不改即绿**。
- **A3**：`workspace` 面在本叶**不装配门面**——钉住物的落盘与读面归 [`T-UI-013`](T-UI-013-工作区钉住的持久组件.md)（其 `depends_on` 含 [`T-UI-012`](T-UI-012-Chat主界面对话流与生成式UI宿主.md)，因「钉」是对话流宿主的容器动作）。**若错的影响**：若误装一个空门面，探针会**假报「面在」**，掩盖「工作区读面尚不存在」这个事实（[01 §5](../../docs/技术架构-v2/01-平台共享契约.md) 六态不可混用）。**验证方式**：GWT-3 在真 M5 组合根上断言 `/api/workspace/status` 仍 `unavailable` + 点名。
- **A4**：薄门面**只持句柄、不加业务读端点**。**若错的影响**：越界填业务内容，与本叶边界冲突并与七面叶重复（两处读面会分叉）。**验证方式**：GWT-4 断言新增路径**只有**七条只读探针、`_POST_ROUTES` 逐条不变；GWT-5 的范围套件含 `tests/ui` 与 `tests/integration`。
- **A5**：门面持真句柄**不引入反向依赖**（组合根向下取用各层）。**若错的影响**：破 [铁律 7](../工程宪法.md)，`tests/test_layering.py` 报红。**验证方式**：GWT-5 的 `pytest tests/test_layering.py` 全绿。
