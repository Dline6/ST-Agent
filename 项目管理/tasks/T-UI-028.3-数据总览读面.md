# T-UI-028.3 · 数据总览读面（P0）

## 目标

- 设置新增「数据同步」视图（`/settings?view=data`），展示：
  - 汇总：本地市场库是否建立、任务总数、已成功任务数、表总数、总行数、最后更新时间；
  - 逐任务表：域 / 任务 / 目标表 / 行数 / 最近成功 / 水位 / 状态 / 覆盖范围 / 触发节奏；
  - 逐表清单：表名 / 行数 / 所属域。
- 未建库时显式说明「首次同步尚未完成」，不把空表读成「没有数据」。

## 验收标准（Given-When-Then）

- GWT-1：Given 尚未建立本地市场库，When 打开数据同步视图，Then 汇总显式标注「未建库」并给出首次同步建议，逐任务仍列出（状态「未同步」）。
- GWT-2：Given 已同步若干任务，When 打开视图，Then 逐任务显示 `sync_state` 的真实状态 / 水位 / 最近成功，逐表行数与库内一致。
- GWT-3：Given 行情与信息面任务并存，Then 两类任务同表呈现且域可区分；关注面任务标注「按用户关注面」。
- GWT-4：Given 表数超过一页，When 浏览，Then 走既有 `table` 组件的排序 / 分页能力，不另造表格。

## 接口面

- 输入：
  - `MarketDb.exists()` / `sync_state` / `sync_state` 种子（[`T-L0-005`](done/M0/T-L0-005-数据源缓存BaoStock首个源落地.md)）
  - `SYNC_TASKS`（`l0/market/tasks.py`）与 `INFO_TASKS`（`l0/info/sources.py`）
  - `enabled_task_map(store)`（信息面源级开关）
- 输出：
  - `MarketDb.table_counts()` 与 `MarketDb.sync_state_rows()`（单次读取内完成）
  - `st_agent/l0/sync_runner.py` 的 `DataSyncRunner.overview()`（只读面）
  - `SettingsFacade.data_sync`；`UiApp.api_settings_data`；`GET /api/settings/data`
  - `src/st_agent/ui/web/js/pages/settings.js` 的 `VIEWS` 增 `data` 与数据视图装配

## 可关闭的遗留

无。

## 假设与前提

- A1：逐表行数在**一次**只读连接内完成（`_readonly` 每次都会解密整库 blob），故新增 `table_counts()` 而非逐表调用 `query`。若错：页面加载会反复解密大库。验证方式＝用例断言只读取一次。
- A2：「未建库」与「建库但该表为空」是两种态，分别呈现（同 [01 §5](../../docs/技术架构-v2/01-平台共享契约.md) 六态不混用）。验证方式＝两条用例各断言一次。
- A3：总行数只统计**同步任务写入的表**，不统计 `sqlite_master` / 内部表。若错：汇总数与任务口径不符。验证方式＝与任务表行数求和比对。
