# T-L1-001.3 · 执行沙箱越界拦截

## 目标
实现 03 §1.5 执行沙箱：文件访问限于声明 `local_read` 范围、网络限于 `net_access` 模式、命令执行需 `exec_command` 审批；越界即拦截 + `BehaviorViolation` 事件（01 §11）+ 警示与禁用选项。

## 验收标准（Given-When-Then）
- GWT-S1（文件越界拦截）：Given Skill 声明 `local_read` 仅限某目录，When 执行访问声明外路径，Then 拦截 + `BehaviorViolation` 事件留痕，不执行原操作。
- GWT-S2（网络越界拦截）：Given Skill 未声明 `net_access`，When 执行发起出网，Then 拦截 + 事件留痕，不触碰网关 sender。
- GWT-S3（命令审批）：Given Skill 未获 `exec_command` 批准，When 执行请求命令执行，Then 拦截 + 警示「这个 Skill 行为异常」+ 提供禁用选项。

## 假设与前提
- A3 沙箱为进程内声明式 enforcement（执行上下文携带已批准权限，文件/网络/命令三类出口统一核对，非 OS 级隔离）/ 若错：换隔离强度大返工 / 验证：三类越界拦截测试（对齐已确认）
- A7 违反事件按 01 §11 组装 `PlatformEvent(BehaviorViolation)`（payload 只含 skill_id/越界类别，不含数据内容）/ 若错：事件面返工 / 验证：事件载荷断言
- A8 禁用选项取注册表级最小口径（`sandbox.disable(skill_id)` 后该 Skill 会话三类出口全拒，状态落 config 分区）/ 若错：禁用实现返工 / 验证：TestDisableOption 全组
- A9 本任务只交付沙箱子系统（会话 + 三类受限出口 + 网关包装），不接 runner 注入（.3 依赖图只连 .1，接线留给消费任务）/ 若错：需补接线任务 / 验证：runner 测试不变（零回归）
