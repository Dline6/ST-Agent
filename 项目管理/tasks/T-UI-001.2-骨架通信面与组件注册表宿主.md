# T-UI-001.2 · 骨架、通信面与组件注册表宿主

## 目标
交付前端工程骨架与**本机通信面**：loopback 服务 + 启动令牌握手（含 Origin / 自定义头防 DNS rebinding）、`ResultEnvelope` 六态渲染、**组件类型注册表宿主**、渲染前中性化校验（[01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2）；并交付 **dev 开关下的浏览器直开**（[D-060](../决策日志.md) ④ 可达性）。

## 验收标准（Given-When-Then，从 Story 抄）
- 待 ④ 对齐时补全。预期覆盖：dev 开关可浏览器直开 · 非 dev 构建不含该面 · 令牌握手失败即拒 · 六态（`ok`/`empty`/`unavailable`/`dependency_failed`/`failed`/`validation_failed`）各有确定渲染 · 组件描述 → 注册表解析（**不解析任意代码**）· 渲染前过中性化校验

## 接口面
- 暂无（④ 对齐时补：**输入**＝[T-UI-001.1](T-UI-001.1-IA骨架与页面Flow.md) 的 IA、[01 §5](../../docs/技术架构-v2/01-平台共享契约.md) `ResultEnvelope`、[01 §7](../../docs/技术架构-v2/01-平台共享契约.md) `panel_form_spec`、[05 §6](../../docs/技术架构-v2/05-L3-对话主入口.md) 的 UI 描述；**输出**＝前端工程 + 组件类型注册表契约（供 [T-L3-004](T-L3-004-GenerativeUI推理链可视化.md) 消费））

## 假设与前提
