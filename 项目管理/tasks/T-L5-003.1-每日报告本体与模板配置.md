# T-L5-003.1 · 每日报告本体与模板配置

## 目标
交付 [07 §5](../../docs/技术架构-v2/07-L5-主动触达.md) 的**日报本体**：到用户配置时刻本地生成「给你的信」——**昨日回顾 + 今日关注 + 多视角摘要 + Memory 更新摘要**四段；结构模板注册进 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md)（可订阅到任一渠道）；无内容时**显式写「今天没有需要打扰你的事」**，不硬凑；生成过程**走完整 Trace**。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 用户配置的日报时刻（[07 §2](../../docs/技术架构-v2/07-L5-主动触达.md) 的时钟区间口径，如「每天早晨 8 点」）与当日已积累的待汇总项 / 昨日留痕，When `build(day, now)`，Then 产出四段齐备的 `DailyReport`：**昨日回顾**（昨日投递与结算的中性陈述统计）· **今日关注**（当日待汇总项与在途投递）· **多视角摘要**（逐待汇总项的逐视角摘要**并列保留、不合并分歧**，铁律 4）· **Memory 更新摘要**（经注入的记忆读取面取材）
- **GWT-2**：Given 日报模板（生成时刻 / 四段开关 / 订阅渠道），When 经对话与面板两通道配置，Then 两通道读到**同一份值**、且**可订阅到任一渠道**（取值是对象 ⇒ 按 01 §7 由本叶自有 API 写、注册族为只读声明面）；Given 未配置，Then 走内置缺省（不臆造用户偏好）
- **GWT-3**：Given 某日四段**均无内容**，When 生成，Then 正文显式写「今天没有需要打扰你的事」（**不硬凑**、也不产出空壳报告）；Given 仅部分段有内容，Then 只在该段为空时给出该段的显式空态说明
- **GWT-4**：Given 一次生成，When 观察产出，Then 报告携**完整 Trace** 锚点（参与组装的 `signal_id` / `delivery_id` / `memory_node_id` / `evidence_refs` 逐条可回溯，[01 §4](../../docs/技术架构-v2/01-平台共享契约.md)），且**整段文案过 [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2**（命中即显式抛错，不静默吞）
- **GWT-5**：Given 同一 `(day, 留痕状态)`，When 重复 `build`，Then 结论恒同且（落盘时）**写同一路径**（`execution_log/daily_report/<YYYY-MM-DD>.json`）——生成可安全重入、不产生重复报告；Given 记忆读取面未注入 / 查询抛错 / 无切片，Then 该段走**显式空态**（不阻断其余三段、不臆造）

## 假设与前提
- **A1 · 日报只凭本层留痕 + 注入的记忆面组装**——前提：待汇总项连文案一起落盘（[T-L5-002.2](T-L5-002.2-投递编排与升级链.md) 的「留痕自足」），记忆面经鸭子端口注入。若错（要求上游重发信号 / 另存上下文）：返工面＝本叶取材面与 GWT-1。验证方式：新开一个构造器只读既有留痕即可组出四段（用例钉住）。
- **A2 · 生成是显式时刻的纯函数、落盘幂等**——前提：日报要能被离线重复验证、到点重跑不产生重复报告（同 [T-L5-002.2](T-L5-002.2-投递编排与升级链.md) 的纯函数口径）。若错（要求本层自读系统时钟 / 每次生成新 ID 新路径）：返工面＝`build` 签名与落盘键。验证方式：GWT-5 的重入用例。
- **A3 · 四段中「昨日回顾」取昨日留痕统计、「今日关注」取当日待汇总项与在途**——前提：[07 §5](../../docs/技术架构-v2/07-L5-主动触达.md) 只给段名不给结构（「模板完整结构属 PRD 待澄清项」原文），故以本层**已有的**数据面（留痕 + 记忆切片）组装，不新增上游依赖。若错（要求新上游数据源）：返工面＝本叶取材面与 [07 §5](../../docs/技术架构-v2/07-L5-主动触达.md) 行文。验证方式：四段各自的取材用例（含空态）。
- **A4 · 「可订阅到任一渠道」＝日报经既有渠道链投出**——前提：[07 §5](../../docs/技术架构-v2/07-L5-主动触达.md) 原文「结构模板注册为配置（可订阅到任一渠道）」；投出面复用 [T-L5-002.1](T-L5-002.1-渠道适配器与渠道偏好.md) 的渠道面，**不另造投递路径**。若错（要求独立的日报订阅面）：返工面＝本叶订阅配置与投出路径。验证方式：日报经注入替身渠道投出、载荷内容与报告本体一致的用例。
