# T-UI-027.1 · 窗口规格与记忆、关窗说明、图标资源、壳快捷键与默认启动路径（P0）

> M7 叶之五的第一半（[`T-UI-027`](T-UI-027-桌面壳闭合与默认启动路径.md) 按「GWT > 5」拆出，[D-126](../决策日志.md)）。
> 口径见 [14 册](../../docs/PRD-v2-Agent/14-desktop-form.md) §1（窗口是一等公民）与 §11（桌面壳闭合）。

## 目标

把壳从「能开出一个窗口」补成**合规格的桌面应用壳**（多窗口除外，归 [`T-UI-027.2`](T-UI-027.2-多窗口.md)）：

- **窗口规格**：默认 1440×900；**最小 1024×640**；尺寸 / 位置 / 最大化态**跨会话恢复**；多显示器下不跑出屏幕
- **宽度档位**：窄于 1240px 时右栏自动收起、窄于 1024px 时左栏折成 48px 图标条（前端已有，本叶只补原生最小尺寸，使其成为硬约束）
- **关窗语义**：关窗 = 收进托盘（保留 `closing → False`），但**首次关闭有一次显式说明**（仍在后台 / 如何恢复 / 如何真正退出）
- **托盘**：16 / 32 / 256 **多尺寸资源**（现为程序绘制）+ **深浅主题适配**；菜单补「主动触达设置…」
- **应用图标资源**：产出多尺寸 `.ico`——本叶是产出方，[`T-UI-019`](T-UI-019-Windows安装器与安装体验.md) 是消费方
- **壳快捷键**：`Ctrl+W` 收托盘、`Ctrl+Q` 退出（壳无 JS 桥 ⇒ 经回环意图端点 + 既有 stdout 管道）
- **默认启动路径改为壳**：`[project.scripts] st-agent` 指向壳；浏览器面降级为开发 / CI 面；`start-st-agent.bat` 原样保留

## 验收标准（Given-When-Then）

- GWT-1：Given 已调整过尺寸与位置的窗口，When 完全退出后再次启动，Then **窗口尺寸、位置与最大化态被恢复**
- GWT-2：Given 窗口，When 尝试把它缩到小于 1024×640，Then **缩不下去**；窄于 1240px 时右栏自动收起
- GWT-3：Given 首次点关闭，When 关窗，Then 出现**一次性说明**（说明应用仍在后台、如何恢复与真正退出）；再次关闭**不再出现**；此后可从托盘恢复主窗口
- GWT-4：Given 托盘图标资源，When 在浅色与深色系统主题下查看，Then 图标**各有适配版本**且含 16 / 32 / 256 三档
- GWT-5：Given 安装后的系统入口或 `st-agent` 命令，When 启动，Then 打开的是**壳窗口**而非浏览器标签页；`start-st-agent.bat` 仍可用作试用 / 开发入口

## 假设与前提

- A1：pywebview 提供 `width` / `height` / `x` / `y` 属性与 `moved` / `resized` / `maximized` / `restored` 事件，`create_window` 接受 `width/height/x/y/min_size/maximized`。若错：退化为「仅启动时设定、退出时读取当前值」，GWT-1 的最大化恢复可能失准。验证方式＝pywebview 6.2.1 源码核对 + 离屏替身用例。
- A2：多显示器夹取只做 Windows（`ctypes` 枚举显示器）；其余平台不夹取、保留记忆值。若错：非 Windows 上多显示器边界不设防，不影响 GWT-1 的主路径。验证方式＝注入屏幕矩形的纯函数用例 + 平台分支自审。
- A3：壳仍**不 import 业务层、不加 JS 桥**；`Ctrl+W` / `Ctrl+Q` 走回环意图端点 + 既有 stdout 管道，不新增壳专有通道。若错：触发既有守卫 `test_shell_has_no_js_bridge_or_business_imports` 与 `test_ui_is_client_only`。验证方式＝既有守卫继续全绿。
- A4：窗口态与「首次关窗已说明」落 `%LOCALAPPDATA%\STAgent-shell\window.json`（macOS / Linux 各自用户配置目录），**不写进存储根**，不影响数据面、备份与完全清空。若错：界面偏好与数据面耦合。验证方式＝`state_path` 用例与「存储根未被触碰」断言。
- A5：「默认启动路径」的落点是 `[project.scripts] st-agent` + 打包入口口径；系统入口（开始菜单 / 桌面快捷方式）由 [`T-UI-019`](T-UI-019-Windows安装器与安装体验.md) 消费本叶产物接线。若错：GWT-5 只在安装后才成立。验证方式＝入口守卫 + `packaging/build.py` 自检。
