# T-L0-010.4 · 股东变化域采集与管理

## 目标

交付**股东变化域**的完整链路（股东户数，即筹码集中度），服务 [L4 情绪视角](../../docs/PRD-v2-Agent/story-04-multi-lens.md) 的支撑面。

- **表组**：`shareholder_num`（`code` / `stat_date` / `holder_num` / `change_num` / `change_ratio` / `avg_shares` / `source_id`）——字段清单由外部信源的返回形态反推（见 [L1 册 `C1` 补充](../../项目管理/遗留问题/L1-遗留问题.md)）
- **单源**：仅东财（**无备胎**）——不可用即走 `unavailable` 信封并标注最后更新时间；`Q-003` 的 A / B / C 三候选在本域**退化为同一结果**（[D-030](../../项目管理/决策日志.md) / `Q-003` 决议）
- **新鲜度**：季频，但**源端更新不定期**——逐域登记时须给出可判定的陈旧判据（不能照抄「落后一个自然季」了事）
- **风险**：东财有 IP 级风控（实测封禁可持续 20+ 小时），且本域**无备胎**，故「长期 `unavailable`」是**必须显式可见**的常态风险，不得静默

## 验收标准（Given-When-Then，从 Story 抄）

- 待 ④ 对齐时逐条定稿。草拟方向（④ 复核）：
  - GWT-1 季度序列可查：Given 一次同步，When 按代码查股东户数，Then 按 `stat_date` 可读环比变化
  - GWT-2 单源不可用不编造：Given 源端不可达，When 查询，Then 信封 `unavailable` 且带最后更新时间（**不**返回空表冒充「无数据」）
  - GWT-3 长期不可用可见：Given 连续多期未同步，When 自检，Then 陈旧状态可判定并与「正常但无更新」区分
  - GWT-4 预过滤不炸批：Given 批次含 `security` 未收录代码，When 同步，Then 批次成功、计数如实登记
