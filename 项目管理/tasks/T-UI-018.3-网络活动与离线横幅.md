# T-UI-018.3 · 设置区：网络活动与离线横幅

> [`T-UI-018`](T-UI-018-设置区与全局要素.md) 三叶之一（[D-114](../决策日志.md) ① / ④）——补上 [11-sitemap §2 设置](../../docs/PRD-v2-Agent/11-sitemap.md) 的**网络活动面板**（与 [§2 全局要素](../../docs/PRD-v2-Agent/11-sitemap.md) **共用一屏**）与 [§2 全局要素](../../docs/PRD-v2-Agent/11-sitemap.md) 的**离线模式横幅**（[§3.9 离线降级](../../docs/PRD-v2-Agent/11-sitemap.md) 的入口）。

## 目标

- **网络活动面板**（`?view=network`，复用 `table`）——过去 N 小时（缺省 24）的出网留痕：时刻 / 发起方 / 类目 / 目标主机 / 目的 / 数据量 / 结果；**三态互不混同**（[02 §6](../../docs/技术架构-v2/02-L0-本地优先基座.md)）：审计开启且有记录 ⇒ `ok`；开启但窗口内无记录 ⇒ `empty` + 原因；**未开启 ⇒ `unavailable` + 原因**（不得静默呈现空表被读成「没有请求」）。
- **导出**——`POST /api/settings/network/export` 把报告写到导出目录并回报路径与条数（[story-05](../../docs/PRD-v2-Agent/story-05-local-first.md) 的「可导出」）。
- **离线模式横幅**（壳面）——[`index.html`](../../src/st_agent/ui/web/index.html) 新增挂点、[`main.js`](../../src/st_agent/ui/web/js/main.js) 判定与渲染：按 `navigator.onLine` 显隐，在线态**同步给后端**（[`L1Runtime.set_online`](../../src/st_agent/l1/runtime.py)，由离线翻回在线时按策略补跑）；横幅内容是 [02 §7](../../docs/技术架构-v2/02-L0-本地优先基座.md) 的**三类清单**（可用 / 受限 / 不可用），受限项带降级标注。
- **出厂能力声明**——补一组平台能力的 `offline_level` 声明并由组合根**播种**（[`seed_default_capabilities`](../../src/st_agent/l0/net/capabilities.py)、[`DEFAULT_CAPABILITIES`](../../src/st_agent/l0/net/capabilities.py)）：`register_capability` 此前**全仓只有测试在调**，真装配下 `offline_report()` 恒空，三类清单会是一片空白。
- **在线态同步口**——`POST /api/settings/online`（`{online}`）→ `L1Runtime.set_online`；**唯一的探测器在出口**（浏览器），平台侧本来只有手动态。

**本批的边界**（不越界）：

- **出网审计与离线分级的本体归 L0**（[`EgressGateway`](../../src/st_agent/l0/net/gateway.py)）——本叶只做取数、呈现与「谁在探测」的接线。
- **审计开关的落值归 [`.1`](T-UI-018.1-四设置页与配置落值面.md) 的隐私页**（经 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md)）——两处**同源**：面板只读 `gateway.audit_enabled`，不另存一份状态。
- **横幅是壳面**（[11-sitemap §2.1](../../docs/PRD-v2-Agent/11-sitemap.md)）——不落页面路径、不进描述体系；联机时不出现（它不是常驻状态条）。
- **不做网络探测**——不新增 ping / probe 一类能力；「到底有没有网」由出口（浏览器）说了算。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 设置 / §2 全局要素](../../docs/PRD-v2-Agent/11-sitemap.md) 的这两条屏，When 逐条走查，Then **两条都有可见载体**——网络活动面板（表 / 空态 / 不可用三态）与离线横幅（含三类清单）
- GWT-2：Given 审计**未开启**，When 打开网络活动面板，Then 回 `unavailable` + 「审计未开启」+ 原因，**不得**呈现为空表（三态可区分是 [02 §6](../../docs/技术架构-v2/02-L0-本地优先基座.md) 的硬要求）；开启后窗口内无请求则为 `empty` + 另一句原因
- GWT-3：Given 导出，When 审计已开启，Then 报告写入导出目录并回报**路径与条数**；审计未开启时导出回 `unavailable` + 原因（不是一条空文件）
- GWT-4：Given 断网，When 触发 `offline` 事件，Then 横幅出现并列出**三类清单**（可用 / 受限 / 不可用），依赖 LLM 的能力**标注需联网或本地推理**（[§3.9](../../docs/PRD-v2-Agent/11-sitemap.md)）；恢复联网时横幅消失且在线态**已同步给后端**（由离线翻回在线触发补跑）
- GWT-5：Given 真组合根，When 读出参清单，Then **三类都非空**（出厂声明由组合根播种）——空清单是「无人声明」，不是「离线时什么都不可用」
- GWT-6：Given 文案，When 核对，Then 按[契约 9 中性表达](../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**
- GWT-7：Given 真组合根 + 真回环服务，When 在 Edge 走查网络活动面板（含审计开关两态）与离线横幅，Then 全程可用、控制台无新增报错

## 假设与前提

- **A1**：**唯一可用的网络探测器是浏览器**——平台侧**没有**网络探测（[`EgressGateway.online`](../../src/st_agent/l0/net/gateway.py) 是手动态，只有 `set_online` 能翻），而出口（浏览器）的 `navigator.onLine` 恰好是「这台机器现在有没有网」的现成答案。**若错的影响**：若坚持「后端自己判」，就得为它引入探测能力（ping / probe），那既是**新的出网面**（要走网关、要过审计、还要处理探测自身失败），又把一个已知信号重造一遍。**验证方式**：集成用例断言 `POST /api/settings/online` 真的翻转 [`gateway.online`](../../src/st_agent/l0/net/gateway.py)（走 [`L1Runtime.set_online`](../../src/st_agent/l1/runtime.py)）；走查时在浏览器切「离线」即出横幅。
- **A2**：**三类清单的出厂声明归平台、由组合根播种**——[02 §7](../../docs/技术架构-v2/02-L0-本地优先基座.md) 只说「每项平台能力声明 `offline_level`」，未说谁登记；而 [`register_capability`](../../src/st_agent/l0/net/gateway.py) 此前**全仓只有测试在调** ⇒ 真装配下清单恒空。故把声明做成**常量表**（[`DEFAULT_CAPABILITIES`](../../src/st_agent/l0/net/capabilities.py)）由 [`build_l1_runtime`](../../src/st_agent/l1/runtime.py) 播种，**只补缺失**（幂等：第二次装配不重置用户改动）。**若错的影响**：不播种则 GWT-4 的「三类清单」在真装配下是三个空段——横幅会出现，但什么都没说，比不出现更糟。**验证方式**：集成用例在真组合根上断言三段的 `lines` 非空且受限项含「本地推理端点」；`seed_default_capabilities` 的幂等性由「只补缺失」的实现与 `offline_report` 的排序稳定共同保证。
- **A3**：**联机时横幅不出现**——[11-sitemap §2.1](../../docs/PRD-v2-Agent/11-sitemap.md) 把离线横幅归为壳面，语义是「**离线模式**横幅」；把三类清单做成常驻状态条会让「离线降级」这一信息在联机时也占用注意力，与 [08 §1](../../docs/技术架构-v2/08-L6-反思演进.md) 的注意力预算取向相悖。**若错的影响**：走查 / 验收看不到横幅（在联网的机器上）——故走查步骤必须**显式切浏览器离线模式**，本任务备注写明这一步。**验证方式**：GWT-7 的走查步骤含「DevTools → Network → Offline」，横幅随即出现。
- **A4**：**窗口参数非法即拒，不静默夹取**——`?hours=` 非正整数或超上限（30 天）回 `validation_failed`。**若错的影响**：夹取会让用户以为筛的是自己填的区间（读到的是被改过的窗口），而网络活动面板的价值全在「这份列表覆盖的到底是什么时段」。**验证方式**：单测钉 `_window_start` 对 `"abc"` / `"0"` / `"-3"` / `"999999"` 均抛。
