# T-AGT-004.3 · 产出接入、留痕与失败语义

## 目标

把循环跑出来的东西**接回既有链路**——产出、留痕与失败三条线都不另造：

1. **产出为结构化证据包**：循环交出 `ResultEnvelope`（载荷＝各步 `skill_run_id` 与输出、引用清单），**不是**自由文本结论；交 [05 §6](../../docs/技术架构-v2/05-L3-对话主入口.md) 的 UI 描述与组件注册表呈现，**不另造第二条渲染路径**。
2. **留痕**：落 `agent_run_id`（[01 §1](../../docs/技术架构-v2/01-平台共享契约.md)），记**步数 / 终止原因 / 上界**（[D-090](../决策日志.md) ⑥）。
3. **中性边界**：模型中间推理（为何选下一步）**一律不外显**；最终交付物过 [01 §6](../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2；**不给统一建议或方向研判**（[铁律 4](../../项目管理/工程宪法.md)）。
4. **失败与降级**（[D-090](../决策日志.md) ⑨）：端点不支持 / 不可用 → **fail-closed + 显式降级告知**，**不静默退回**确定性路径。
5. **单步失败不终止**：该步**如实记为失败信封并回填**（模型可据此改选），**不静默略过**；最终产出里失败步**照实呈现**。

## 验收标准（Given-When-Then）

- **GWT-1 · 产出是信封不是散文**：Given 循环结束，When 取产出，Then 为合法 `ResultEnvelope`；**模型产出的自由文本不直接进 `data`**（只作渲染方的数据源之一且逐槽标注 `text_kinds`）。
- **GWT-2 · 走既有渲染路径**：Given 一次循环产出，When 出站，Then 经 [01 §12](../../docs/技术架构-v2/01-平台共享契约.md) 的 UI 描述 + 组件注册表（**未登记组件即显式降级**），**不存在第二条渲染路径**。
- **GWT-3 · 留痕字段齐备**：Given 跑完的循环（含触界与正常结束两种），When 取留痕，Then 含**步数 / 终止原因 / 上界**，且可被审计读面取到。
- **GWT-4 · 中间推理不外显**：Given 一次多步循环，When 扫最终交付物与留痕，Then **无**「为何选下一步」的自由文本外露（该文本不落盘、不出站）。
- **GWT-5 · 不给统一建议**：Given 一次多步循环，When 取产出载荷，Then 无 `verdict` / `recommendation` / `advice` 类字段；证据**并列**呈现（[铁律 4](../../项目管理/工程宪法.md)）。
- **GWT-6 · 端点不支持即显式降级**：Given 端点能力为「不支持工具调用」，When 该去向被派发，Then `unavailable` + **中性降级告知**，**不静默改跑确定性路径**。
- **GWT-7 · 单步失败如实呈现**：Given 循环中某步得 `failed` / `validation_failed`，When 循环继续并于结束出产，Then 该步**在产出中标记为失败**，**不呈现为成功、不静默略过**。

## 假设与前提

- **A1 · 产出复用既有 UI 描述，不新增组件型**——前提：[01 §12](../../docs/技术架构-v2/01-平台共享契约.md) 已登记 `table` / `trace_timeline` / `report_card` 等；证据包可用既有型表达（各步结果用 `table`，链用 `trace_timeline`）。新增组件型属**改契约**（[铁律 8](../../项目管理/工程宪法.md)），本期不做。
  **若错的影响**：若证据包必须有专属形态，须先改 [01 §12](../../docs/技术架构-v2/01-平台共享契约.md) 登记新组件型 + 表现层渲染件——**跨契约与 `ui` 层**。
  **验证方式**：GWT-2 以「未登记组件即显式降级」钉住；④ 对齐时确认用哪几个既有型。
- **A2 · `agent_run_id` 的形态与落盘**——前提：[01 §1](../../docs/技术架构-v2/01-平台共享契约.md) 只登记其**存在与用途**（留痕与审计单位），未定形态；本叶定形态与落盘位置（**存储布局不构成契约**，[01 §7](../../docs/技术架构-v2/01-平台共享契约.md) 的同时口径）。
  **若错的影响**：形态后改属实现返工，不动契约。
  **验证方式**：GWT-3 以字段齐备钉住。
- **A3 · 降级告知复用既有文案口径**——前提：[05 §4](../../docs/技术架构-v2/05-L3-对话主入口.md) 的 `LLM_DEGRADED_NOTICE` 已是「显式降级告知」的既有实现，本叶**沿用同口径**而不另撰。
  **若错的影响**：两套降级文案会让用户难以分辨「是同一个原因」。
  **验证方式**：GWT-6 以「显式告知」钉住；文案是否复用同一条在 ④ 对齐时定。
