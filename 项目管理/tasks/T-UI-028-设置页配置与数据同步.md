# T-UI-028 · 设置页配置与数据同步（P0）

> 负责人 2026-10-25 提出：设置页的存储位置不可变更、`base_url` / `api_key` 无法配置、
> 没有数据同步入口。本任务把三件事做进设置区，并补齐「目前有哪些数据」的读面。
>
> 拆四叶（[工作流](../工作流.md)「拆分触发」：>5 GWT、跨 2+ 契约小节、>20 轮）：
> [`.1`](T-UI-028.1-存储位置可变更.md) / [`.2`](T-UI-028.2-LLM引导配置可编辑.md) /
> [`.3`](T-UI-028.3-数据总览读面.md) / [`.4`](T-UI-028.4-手动同步与后台任务.md)。

## 目标

- 存储位置：可在设置页迁移到新根或切换指向已有根；指针落在存储根之外，重启生效。
- LLM 引导配置：`base_url` / `model` / `api_key` 可在设置页查看与修改，保存即热更新。
- 数据：设置内新增「数据同步」视图，展示逐任务 / 逐表数据现状，并支持勾选任务手动同步。

## 验收标准（Given-When-Then）

- GWT-1：Given 设置-存储页，When 迁移或切换存储位置并重启，Then 后端握手 `root` 为新根，迁移模式下原数据完整可读。
- GWT-2：Given 设置-LLM 提供方页，When 修改 `base_url` / `model` / `api_key` 并保存，Then 下一次 LLM 调用使用新端点，页面与接口均不返回 Key 明文。
- GWT-3：Given 设置-数据同步视图，When 打开，Then 逐任务与逐表的数据现状可读；未建库时显式说明而非空表。
- GWT-4：Given 已勾选若干同步任务，When 触发同步，Then 后台按顺序执行并回报逐任务结果，页面可离开并在返回时看到进度与结果。

  - [`T-L1-011`](done/M1/T-L1-011-LLM端点与会话装配接线.md)：`LlmBootstrap` / `open_runtime` 的 `.env` 引导装载
  - [`T-L0-005`](done/M0/T-L0-005-数据源缓存BaoStock首个源落地.md) / [`T-L0-010`](done/M2/T-L0-010-多源信息面采集与管理机制.md)：`BaoStockSync` / `InfoSync` 的 `setup` / `run_task`

- A1：三件事可以共用「设置区」这一页面与统一回环面，不新开分区。若错：需改 IA 与左栏分区模型。验证方式＝`11-sitemap` 与前端页面登记同批更新。
