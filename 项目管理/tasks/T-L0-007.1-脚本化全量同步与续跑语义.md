# T-L0-007.1 · 脚本化全量同步与续跑语义

## 目标
把「全市场首次全量同步」从一次性手工操作变为**可重复流程**：交付一个参数留痕的长跑脚本（复用 `BaoStockSync`，不重写引擎）与 `tests/live/` 真实用例骨架；并以 Fake 抓取器兑现**续跑语义**（中断后续跑不重复写、水位单调不回退、失败不静默）。真实全市场长跑归 [T-L0-007.2](T-L0-007.2-真实全量长跑与限流续跑实测.md)。

## 验收标准（Given-When-Then）
- GWT-1 中断续跑不重复写：Given 全量同步中途某任务中断（如 `bs_k_daily` 第 2 只证券抓取失败），When 修复后重跑同一任务，Then 已入库行不重复（每 `(code, trade_date)` 唯一）、缺失行补齐、总行数等于预期。
- GWT-2 水位单调不回退：Given 水位已推进到 D，When 发生失败或重跑，Then 失败不推进水位、成功后的重跑不使水位后退；窗口起点随水位前进。
- GWT-3 失败不静默可查：Given 抓取失败，When 查 `sync_state` 与 `freshness_verdict`，Then `last_status='failed'` 且 `last_error` 非空可查，相应数据域 `stale=True` 并在 detail 中点名未完成任务。
- GWT-4 抓取全经审计：Given 跑一次全量（Fake 注入），When 查网关，Then `data_fetch` 审计条数与实际抓取次数一致。
- GWT-5 流程可重复（脚本化 + 参数留痕）：Given 长跑脚本，When 以参数运行，Then 产出一份 JSON 摘要（含逐任务 status / 行数 / 水位 / 耗时 + 总时长 + 参数块）；主口令只经环境变量传入，**不进 argv、不进摘要**。

## 接口面
- 输入（消费的前置接口）：

  - T-L0-005.1 [`live.py`](../../src/st_agent/l0/market/live.py)：`BaoStockFetcher`（上下文管理登录/登出；缺包构造即 `FetchUnavailableError`）
  - T-L0-004 [`gateway.py`](../../src/st_agent/l0/net/gateway.py)：`EgressGateway.execute(kind="data_fetch", target_host="baostock", …, sender=…)`（审计落 `execution_log/net/**`）
  - T-L0-001 [`store.py`](../../src/st_agent/l0/storage/store.py)：`Store.create` / `.open`（`data_cache` 分区容器）
- 输出（本任务交付的公共 API / 落盘位置）：
  - `RUN_ORDER`：`sync.py` 新增公开别名（全量同步执行序），供长跑脚本逐任务计时
  - [`项目管理/tools/run_full_sync.py`](../tools/run_full_sync.py)：长跑脚本——`summarize_run(sync, *, watchlist, enabled, timeout_ms, clock)` 返回摘要 dict；`main(argv)` CLI 产出 JSON 摘要文件（口令取 `ST_AGENT_PASSPHRASE`，默认 `--root` 落 `tmp/live-market`）
  - [`tests/l0/test_full_sync.py`](../../tests/l0/test_full_sync.py)：续跑语义用例（Fake 注入，进 CI）
  - [`tests/live/test_full_sync_live.py`](../../tests/live/test_full_sync_live.py)：`@pytest.mark.live` 真实同步入口（默认排除，不进 CI）

## 假设与前提
- A1 现有幂等 UPSERT（`ON CONFLICT … DO UPDATE`）+ 失败不推进水位，已足够支撑续跑，无需为 `run_task` 新增退避/重试逻辑 / 若错：需在 `sync.py` 加退避重试并新立任务，返回信封语义随之变化 / 验证：本任务 GWT-1 / GWT-2 用例（Fake 中断→重跑）已证实成立
- A2 为 `sync.py` 加公开 `RUN_ORDER` 别名，优于脚本内引用私有 `_RUN_ORDER` / 若错：改为脚本内私有引用或另立取序 API，`T-L0-005` 接口面需回改 / 验证：脚本逐任务计时成立且 `T-L0-005` 接口面已同步该行
- A3 长跑脚本落 `项目管理/tools/`（与本仓库其余运营工具同址），不引入包内 CLI 入口 / 若错：改落点，任务链接与文档随之调整 / 验证：`pyproject.toml` 的 `pythonpath` 已含 `项目管理/tools`，脚本与用例均可导入执行
- A4 真实数据只落本地加密库与 `tmp/`，不进 Git / 若错：违反数据主权红线，按 [Git协作规范 §7.4](../Git协作规范.md) 安全事件处理 / 验证：脚本默认 `--root` 指向 `tmp/live-market`，收工 `git status` 无真实库被追踪
- A5 `tests/live/` 默认被 `addopts = "-q -m 'not live'"` 排除，不进 CI / 若错：CI 触发真实网络长跑，无法重复且拖垮流水线 / 验证：默认 `pytest` 收集不受影响、live 用例零执行
