# T-L0-011 · 数据快照 ID 契约化与消费方直取

## 目标

闭掉 [L0 遗留问题册 `E3`](../../../遗留问题/L0-遗留问题.md)：`MarketDb.snapshot_id()` 返回的是**水位组合串**（`snap|k:w@t|…`，满任务表下约 350 字符），既超出 `EvidenceRef.ref` 与 `DataAnchor.dataset_snapshot_id` 的 **128** 上限，也不合 01 §1 的 `dataset_snapshot_id` 形态 `snap_<20 位十六进制>`——任何真实消费方（证据引用 / 数据锚点）在满表下**构造即失败**（T-L1-004.1 实测暴露）。本任务把 `snapshot_id()` 改造为**契约形态的有界确定性摘要**，把可读水位串移到独立访问面（保「可复核」）；L1 消费方 `snapshot_ref` 随之去掉二次摘要、**直取 L0 ID**；摘要口径与 `announcement_id` / `qa_id` 的既有实现**合一**，不留第二份副本。

## 验收标准（Given-When-Then）

- **GWT-1 契约形态与有界**：Given 满任务表（20 条 `sync_state` 行）的库，When 取 `MarketDb.snapshot_id()`，Then 返回串匹配 `^snap_[0-9a-f]{20}$`（恒 25 字符，远低于 128），且可直接构造 `EvidenceRef(kind="dataset_snapshot_id", ref=…)` 与 `DataAnchor(dataset_snapshot_id=…)` 而不抛异常。
- **GWT-2 确定性与可复核**：Given 同一水位状态，When 两次取 ID，Then 相等；When 任一任务的 `watermark` 或 `last_success_at` 变化，Then ID 随之变化；`snapshot_components()` 给出**摘要输入**（可读组合串），对其实施同一摘要可复算出同一 ID。
- **GWT-3 消费方直取 L0 ID**：Given 取数源为 L0（`MarketDb` / `BaoStockSync`），When 调 `snapshot_ref(source)`，Then 返回的 `EvidenceRef.ref` **等于** `source.snapshot_id()`——旧的「组合串 → 二次摘要」路径不再存在；`BaoStockSync.dataset_snapshot()` 与新口径一致。
- **GWT-4 违规与缺能力两态显式**：Given 取数源返回**非**契约形态的水位串，When `snapshot_ref(source)`，Then **显式失败**（不静默二次摘要、不放行越界串），错误信息可定位到来源；Given 取数源**无** `snapshot_id` 能力，When `snapshot_ref(source)`，Then 返回 `None`（既有口径不变，不编造证据）。
- **GWT-5 摘要口径唯一**：Given 公告 / 舆情的业务键 ID 与新的快照 ID，When 分别构造，Then 走**同一**确定性摘要实现（`<前缀>_<sha256 前 20 位十六进制>`），全仓不存在第二份口径副本。

- 输入（消费的前置接口）：

  - T-L0-010.1 [`info/sync.py`](../../../../src/st_agent/l0/info/sync.py)：`digest_id(prefix, *parts)`（既有确定性摘要实现，`announcement_id` / `qa_id` 在用）
  - T-SC-001.1 [`identifiers.py`](../../../../src/st_agent/contracts/identifiers.py)：`DatasetSnapshotId` 形态（`^snap_[0-9a-f]{20}$`）；[`result_envelope.py`](../../../../src/st_agent/contracts/result_envelope.py) `EvidenceRef`；[`time_events.py`](../../../../src/st_agent/contracts/time_events.py) `DataAnchor`
  - T-L1-004.1 [`official/common.py`](../../../../src/st_agent/l1/skills/official/common.py)：`snapshot_ref` / `MarketQuerySource`（本任务改其实现，**协议面不变**）
- 输出（本任务交付的公共 API / 落盘位置）：
  - `MarketDb.snapshot_id() -> str`：**返回契约形态** `snap_<20 位十六进制>`（`dataset_snapshot_id`）
  - `MarketDb.snapshot_components() -> str`：新增，返回可读水位组合串（摘要输入，供复核）
  - `BaoStockSync.dataset_snapshot() -> str`：随新口径（签名不变）
  - `snapshot_ref(source)`：改为**直取**源 ID 并按契约形态校验（形态非法 → 显式异常；无能力 → `None`）
  - 落盘 / 分区布局**零变更**：不新增快照登记表（02 §5）
  - 消费面：`T-L1-004.2` / `.3` 的执行器（经 `evidence_of` 取证据引用）、未来任何 `DataAnchor` 构造方
