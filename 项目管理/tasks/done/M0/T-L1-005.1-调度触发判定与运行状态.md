# T-L1-005.1 · 调度触发判定与运行状态

## 目标

交付调度器的**判定侧**：枚举可触发的目标（工作流 / 带频率参数的 Skill），按注入时钟算出谁到期，并把逐目标的运行状态落盘——不执行任何 Skill（执行接线归 `T-L1-005.2`）。cron 求值件随本任务交付。

## 验收标准（Given-When-Then）

Story 02 的验收段不含定时调度，故 GWT 锚定 [03 §6](../../../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 原文与 [01 §1](../../../../docs/技术架构-v2/01-平台共享契约.md)：

- GWT-1 触发目标枚举：Given 已注册的运行环境（若干工作流 + 描述体声明 `frequency_minutes` 的 Skill + 已禁用 Skill），When 查调度目标，Then 目标集 = `schedule.mode != manual` 的工作流 ∪ 声明 `frequency_minutes` 的 Skill，已禁用者**不在**其中，且按标识升序、结果确定。
- GWT-2 到期判定与幂等：Given `mode=interval`（`interval_minutes=N`）的目标与注入时钟，When 时钟推进到「上次运行 + N」之前 / 之后，Then `due_targets(now)` 分别不含 / 含该目标；同一到期点重复 `tick` 只产出**一次**到期（clock 不变则第二次为空）。
- GWT-3 cron 求值：Given `0 8 * * *` / `*/15 * * * *` / `0 9 * * 1-5` 及含列表与区间的表达式，When 逐个时刻求命中，Then 与预期一致（含跨月与月末边界）；非法表达式（段数不符 / 取值越界 / 非法字符）在**构造期**即拒。
- GWT-4 运行状态可查与跨实例落盘：Given 已注册目标，When 记录一次运行后查询状态，Then 得到「上次运行时间 / 上次结果 / 下次到期时刻」，该记录落 `config/scheduler/<target>.json`，**换一个 `Scheduler` 实例重建后仍可读回**（不依赖进程内副本）；`mode=manual` 的目标**不**出现在自动到期集。
- GWT-5 无 `Store` 退化：Given 未注入 `Store`，When 记录一次运行，Then 仅进程内可见且行为与注入时逐字段一致（与 `SkillSandbox` 的既有口径同构）。

- A1 `WorkflowSchedule` 现有形态足以承载调度判定，不必返工 `T-L1-003.1` / 若错：返工该字段并同步 [03 §3.1](../../../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md)，本任务 GWT-2 / GWT-3 连带调整 / 验证：本任务消费 `WorkflowSchedule` 时零改动（`T-L1-003.1` 的 A5 已交此棒）。
- A2 「Skill 的频率参数」＝描述体声明 `frequency_minutes` 的**约定口径**（全仓唯一载体为 `sk_stock_watch`，[pack.py:85](../../../../src/st_agent/l1/skills/pack.py)） / 若错：口径改为显式登记制并记决策日志，目标枚举面返工 / 验证：GWT-1 的目标集用例覆盖该约定。
- A3 运行状态落 `config` 分区（可变状态，与 `skill-registry` / 工作流同构），**不**落 `execution_log`（append-only 审计） / 若错：改落点并同步 [02 §2.1](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) / 验证：GWT-4 的状态读回 + 备份/清空后一致性。
- A4 cron 取**自研最小 5 段子集**（`分 时 日 月 周`，支持 `*` / `a,b` / `a-b` / `*/n` / `a-b/n`），不引第三方依赖（与 [D-009](../../../决策日志.md) 拒引 `jsonschema` 同源） / 若错：需引入依赖或缩减支持面，GWT-3 用例重写 / 验证：GWT-3 的表达式矩阵。
- A5 `mode=event` 本轮只交付**形态与显式 API 触发**（事件总线尚无归属，不臆造订阅机制） / 若错：需改 [03 §6](../../../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) 或另立事件总线任务 / 验证：目标枚举不含 event 目标进入自动到期集，显式触发可用。
