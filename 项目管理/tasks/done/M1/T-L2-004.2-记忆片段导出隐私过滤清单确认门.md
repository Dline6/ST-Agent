# T-L2-004.2 · 记忆片段导出：隐私过滤 + 清单 + 确认门（§8）

## 目标

兑现 [04 §8 片段分享](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的 **L2 侧三步**（[09 §2](../../../../docs/技术架构-v2/09-生态与分享.md) 同文）：强制过滤 `private` / `sensitive` 节点 → 展示「本次导出包含的公开信息」清单 → 用户确认后才产出。交付**片段 payload**（公开节点与相接边的可移植形态），不含文件容器——`.stmem` 的 `header` / `manifest` / 校验和 / 来源追溯链归 [`T-ECO-001`](../M4/T-ECO-001-分享物类型格式导出流程来源追溯链.md)（边界见父任务）。

## 验收标准（Given-When-Then）

- **GWT-1 · 只放公开节点**：Given 图谱里混有 `public` / `private` / `sensitive` 节点，When 构建片段，Then 片段只含 `public` 节点，另两类一条不留。
- **GWT-2 · 无悬空边**：Given 一条边的一端被隐私过滤掉，When 构建片段，Then 该边一并剔除；片段内每条**内部边**的两端都在片段内（`refers_to` 只看内端），不出现指向空气的边。
- **GWT-3 · 公开信息清单**：Given 片段已成形，When 取清单，Then 得到中性措辞的包含清单（公开节点总数 + 逐类型计数 + 相接边数），不含第一人称与情感措辞（[01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 的**文本本体**，但本清单由 L2 生成，措辞由本叶自持中性）。
- **GWT-4 · 未经确认不产出**：Given 一个片段计划，When `confirmed_by` 非 `"user"`，Then 显式拒绝（同 [`MemoryWriter.edit_node`](../../../../src/st_agent/l2/memory/writer.py) 的用户确认门）；取值为 `"user"` 时才产出 payload。
- **GWT-5 · 片段只承载当前值**：Given 一个带 `revision_history` 的公开节点（历史快照里含早先的私有取值），When 构建片段，Then payload 不含 `revision_history`——旧私有快照不随公开节点外泄（§8 只写「过滤 private/sensitive 节点」，本条是其推论，见 [D-052](../../../决策日志.md)）。

## 假设与前提

- **A1 · 片段过滤粒度＝节点 `privacy_level`，不递归审 `revision_history` 内容**：§8 只写「过滤 `private`/`sensitive` 节点」。本叶按节点级过滤，并在 payload 层**省略** `revision_history`（GWT-5）——既不外泄旧私有快照，也不引入「逐快照判隐私」的新判据。若错（须逐快照判并保留历史）：返工面 = `FragmentNode` 增历史字段 + 过滤判据下沉到快照粒度。
- **A2 · 「本次导出包含的公开信息」清单的粒度＝计数与类型**：§8 只说「展示清单」。本叶给「总数 + 逐类型计数 + 边数」的中性摘要，**不**逐条回显节点原文——回显用户原话属渲染面（[L2 册 `A1`](../../../遗留问题/L2-遗留问题.md) 的中性化校验落点），且逐条回显会让清单本身成为二次数据面。若错（须逐条回显）：返工面 = `included_summary` 的产出规则。
- **A3 · 片段承载的是「当前值」而非可回放的全部历史**：与 A1 同源。若错：返工面同上。
