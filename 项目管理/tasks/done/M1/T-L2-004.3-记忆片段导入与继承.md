# T-L2-004.3 · 记忆片段导入 / 继承：他人公开片段入库（§8）

## 目标

兑现 [04 §8](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的第三段（「继承」＝导入他人公开片段，见父任务 A1）：导入的片段**作为 `source: inferred`（他人陈述）类节点入库**，置信度低于本人表达、可编辑可删除，导入数据同样过隐私分级；同批把 [04 §1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的 `provenance` 放宽为「可追溯依据二选一」（本地推理 `trace_id` ／导入来源 `imported`），使「他人陈述」有合法溯源形状而非借一个并不存在的本地推理链。

## 验收标准（Given-When-Then）

- **GWT-1 · §1 不变量的放宽**：Given 一个记忆节点，When 构造，Then `provenance` 的 `trace_id` 与 `imported` **恰有其一**（都无或都有即拒）；`source=inferred` 仍必带 `provenance`、`source=user_stated` 仍不得带——既有 `trace_id` 路径的语义一字不变。
- **GWT-2 · 入库为「他人陈述」**：Given 一个公开片段 payload 与导入来源（分享者 / 校验和 / 导入时刻），When 导入，Then 节点入图谱且 `source=inferred`、`provenance.imported` 携全部四项（含出处链）；原文的 `user_stated` 被改写成 `inferred`。
- **GWT-3 · 置信度不高于推断基线**：Given 片段里 `confidence` 高于 [§5](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 推断基线的节点，When 导入，Then 入库取值＝`min(原值, ConfidenceModel.baseline("inferred"))`；因此导入项**必然低于**本人表达（本人表达基线更高）。
- **GWT-4 · 可编辑可删除**：Given 一个刚导入的节点，When 经 `MemoryWriter.edit_node(confirmed_by="user")` 修改、或经 `MemoryDeleter.delete(confirmed_by="user")` 删除，Then 两条路径都通（导入节点不是只读异物）。
- **GWT-5 · 重复导入幂等**：Given 同一片段导入两次，When 第二次导入，Then 全部节点 id 落在 `skipped`、`created` 为空、图谱节点数不变、不报错、不静默覆盖。
- **GWT-6 · 隐私分级同守**：Given 载荷里出现 `private` / `sensitive` 节点（手工构造或损坏文件），When 导入，Then 显式拒绝并点名违规节点（§8「导入数据同样过隐私分级」）——不静默丢弃、不静默降级。
- **GWT-7 · 溯源留痕**：Given 一次成功导入，When 复查，Then `execution_log` 分区多一条 `memory-import/<import_id>.json`，含分享者 / 校验和 / 导入时刻 / 出处链 / 新增与跳过的节点 id / 载荷摘要；`import_id` 是**业务键的确定性摘要**（同一次导入重放得同一 id）。

## 假设与前提

- **A1 · 导入项**绕过**自主写入白名单与冲突队列**（§4 不管用户发起的路径）：[§4](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的白名单明写「只约束 `source: inferred` 的写入」，而 §8 的导入是**用户显式**动作（`confirmed_by="user"`）。导入进来的节点虽标 `inferred`（他人陈述），但它的**来源**不是副驾自主推断，故不进冲突队列。若错（须按 §4 走裁决对话）：返工面 = `import_fragment` 增 `WritePolicy` / `ConflictQueue` 接线，入库从「直接写」改「提案」。
- **A2 · 保留分享方的原 `memory_node_id`**：§8 未规定 id 是否重发。[§1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的 `memory_node_id` 是「本机生成的 20 位十六进制」，跨设备撞 id 的概率可忽略；保留原 id 使**重复导入天然幂等**且出处链可复核（[D-052](../../../决策日志.md)）。若错（须本机重发 id）：返工面 = 入库前重编 id + 幂等判据改按「来源 + 载荷摘要」。
- **A3 · 导入节点的 `privacy_level` 沿用载荷取值（`public`）**：§8 只说「导入数据同样过隐私分级」。本叶把它落成**入口校验**（载荷含非 `public` 即拒）＋ 入库沿用 `public`；不把导入项自动改判为 `private`。若错（须导入即降级为私有）：返工面 = 入库构造时改写 `privacy_level`，过滤面与 GWT-6 不变。
- **A4 · `imported` 的形状与 [01 §2](../../../../src/st_agent/contracts/capability_types.py) 的 `Provenance` 同构但**不复用该类****：契约层的 `Provenance` 属 `SkillDescriptor`（[09 §5](../../../../docs/技术架构-v2/09-生态与分享.md) 的 Skill 导入面），其 `imported_at` 是 ISO 字符串、必填性由 Skill 层判；记忆节点需要带时区的 `datetime` 与 §1 的不变量。故在 L2 侧定义同形状的 `ImportOrigin`（四字段同名），**不**把契约类型嵌进节点模型。若错（须复用契约类）：返工面 = `models.ImportOrigin` 删除、`Provenance` 改引用契约类。
