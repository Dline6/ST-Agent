# T-UI-001.1 · IA 骨架（站点地图）与页面 Flow

## 目标
产出 PRD 侧预留的 **IA 骨架（站点地图）** 与 **页面 Flow 设计资产**，作为表现层的权威输入——兑现 [PRD README 的占位段](../../../../docs/PRD-v2-Agent/README.md)（原文「待生成」），不留空指针。

## 验收标准（Given-When-Then）
- Given [PRD README 的占位段](../../../../docs/PRD-v2-Agent/README.md)（原文「待生成」），When 打开它，Then 可点到 `11-sitemap.md`，且全项目断链为 0
- Given 10 个 story，When 查看各自「关联页面（Sitemap 占位）」与「设计资产」字段，Then 均无「待生成」残留，且指回 `11-sitemap.md` 的对应锚点
- Given `11-sitemap.md` 的页面集，When 与各 story「设计触点 · 屏」逐条对位，Then 双向可追溯、无未归并的屏
- Given 页面集，When 判断是否凭空新增顶层页，Then 全部可由 10 个 story 的屏清单归并得出（不新增 story 未点名的页）

## 接口面
- **输入**：
  - [PRD README](../../../../docs/PRD-v2-Agent/README.md) 的占位段与 Story 索引（`:51-74`、`:104-110`）
  - 10 个 story 的「设计触点 · 屏」清单：story-01:55 · 02:70 · 03:63 · 04:74 · 05:58 · 06:60 · 07:60 · 08:54 · 09:60 · 10:55
  - [00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md)（后端常驻 + UI 可分离，页面集须落在该形态下）· [05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) / [§6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) / [§7](../../../../docs/技术架构-v2/05-L3-对话主入口.md)（首页＝Chat + 上下文卡片，无传统菜单式入口层级）
- **输出**：
  - 新增 `docs/PRD-v2-Agent/11-sitemap.md`（IA 树 + 逐 Flow，Mermaid 表达）
  - 10 个 story 的「关联页面（Sitemap 占位）」「设计资产」两字段回填
  - `docs/PRD-v2-Agent/README.md` 占位段改指 `11-sitemap.md`

## 假设与前提
- **A1 · 本任务纯 docs，产出落 PRD 侧，不新增任何架构接口或契约**——前提：页面集只描述「有哪些页、页间怎么走」，页面消费的数据源均已在 [00](../../../../docs/技术架构-v2/00-架构总览.md) / [03](../../../../docs/技术架构-v2/03-L1-能力底座-Skills与MCP.md) / [05](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 声明。若错（页面集隐含新接口或新数据源）：须走 [铁律 8](../../../工程宪法.md) 的「先 01 → 各层 → 代码」顺序，本任务范围扩张。验证方式：收工时逐页核「该页消费的数据源在架构文档中已有出处」。
- **A2 · 页面集不新增各 story「设计触点」未点名的顶层页**——前提：首页（Chat）+ 上下文卡片，其余各区（记忆 / 能力 / 推理 / 触达 / 反思 / 设置）皆可由 10 个 story 的屏清单归并得出，遵循 [05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的「无传统菜单式入口层级」——故导航以「对话为主 + 少量全局区」组织。若错（凭空扩页）：产品范围漂移，IA 与 story 双向对位会失败。验证方式：`11-sitemap.md` 的每个页在该 story 的屏清单中有对应条目，反之 story 的每个屏都被归并。
- **A3 · 页面 Flow 以 Mermaid 文字表达**——前提：PRD 侧无图形工具产物，且 docs 已有 Mermaid 先例（`数据库设计-BaoStock数据层/00-设计总览.md`）。若错（需图形设计资产）：范围扩张，另立任务承接，「设计资产」字段改为指向该任务的产出。验证方式：④ 与负责人确认表达形态；收工时 Mermaid 块可渲染。
