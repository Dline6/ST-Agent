# T-L2-001.1 · 记忆图谱本体（节点/边模型 + memory 分区落盘）

## 目标

把 [04 §1 节点模型 / §2 边模型](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 落成 L2 的本体：六类节点（含 §1 通用字段与各类型专属字段）、四类边，加上只经 `Store` 读写的图谱门面与 `memory` 分区落盘。它是 `.2` 写入接口、`.3` 查询接口、L2 后续任务（§4–§8）与 L3–L6 消费方的共同形态来源。

## 验收标准（Given-When-Then）

- **GWT-1 · 六类节点齐备**：Given §1 的六类节点表，When 建模完成，Then `identity` / `attention` / `thesis` / `history` / `pattern` / `evolution` 各有其类型专属字段，且六者共有通用字段（`memory_node_id` / `confidence` / `source` / `provenance` / `privacy_level` / `revision_history` / `created_at` / `updated_at`）。
- **GWT-2 · 通用字段不变量**：Given 一个待建节点，When 构造，Then `memory_node_id` 须合 `mn_<20 位十六进制>`（经 `MemoryNodeId`）；`source=inferred` 必带 `provenance.trace_id`（推断依据可追溯），`source=user_stated` 不得带推断依据；`privacy_level ∈ {public, private, sensitive}`；非法构造显式失败，不静默补默认。
- **GWT-3 · 四类边齐备**：Given §2 的边表，When 建模完成，Then `related_to` / `evolves_from` / `derived_from` / `refers_to` 四类边可用；前三类两端为 `memory_node_id`，`refers_to` 的一端可指向外部 ID（`stock_id` / `announcement_id`）。
- **GWT-4 · 落盘往返**：Given 一张含节点与边的图谱，When 写入 `memory` 分区后重开读回，Then 逐字段一致；该分区内只有 L2 的节点 / 边文件，不混入他层数据。
- **GWT-5 · 图不变量**：Given 一条边，When 其内端节点不存在，Then 写入显式失败（不产生悬空边）；同一 `(from, edge_type, to)` 重复写入幂等，不产生第二条。

## 假设与前提

- **A1 · 逐实体落盘（一节点一文件 + 一边一文件）够用**：Memory Graph 是单用户本地图谱（量级百至数千实体），逐实体落盘使节点级增删与将来的级联删除（`T-L2-003`）不必重写整图；代价是查询按清单扫描。若错（量级使扫描成瓶颈）：返工面 = `MemoryGraph` 内部存取实现，公共 API 与落盘 schema 不变。
- **A2 · 边用确定性组合键、不新增契约 ID 类**：04 §2 未给边定义 ID，[01 §1](../../../../docs/技术架构-v2/01-平台共享契约.md) 亦无 `edge_id`；新增契约 ID 类须先改 01（铁律 8），且随机边 ID 会引入「同一条边可重复」的面。故边以 `<from>__<edge_type>__<to>` 作落盘键——同一条边天然幂等。若错（外部需引用边级稳定 ID）：返工面 = 补登 01 §1 并迁移落盘键。
- **A3 · `refers_to` 的外端不建影子节点**：`refers_to` 指向 `stock_id` / `announcement_id` 时，**不**在 `memory` 分区为外部实体建节点（L2 不复制 L0 数据），外端只作引用键；同理，图不变量只校验**内端**（`memory_node_id`）存在性。若错：返工面 = 边模型外端类型与图不变量范围。
- **A4 · §6 中性化校验不在本体层落点**：`user_stated` 内容（如「我看好 XX 板块」）是**用户数据**，不受 [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 输出校验约束（误加会把用户原话判失败）；系统产出的 `pattern` 文本是否过子句 2，须由产出方而非模型层决定。本条只约束「L2 本体层不引入校验」，渲染期如何处置归 L3（见 [§6](../../../../docs/技术架构-v2/01-平台共享契约.md) 三种执行点的措辞为「渲染前」）。若错（应在写入期拦）：返工面 = 模型层 / 写入层增校验钩子。**④ 对齐处置：留作假设，不另立未决条目**。
