# T-L2-001.3 · MemoryReader 上下文切片查询

## 目标

兑现 [04 §3.1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的读取面：按（当前任务类型、对话主题、Token 预算）取相关节点切片，供 L3 上下文卡片、Skill 个性化参数、L4 视角注入、L5 文案个性化消费；三种浏览视图（图谱 / 列表 / 时间线）共享同一查询层；切片必须携带 `as_of` 与置信度。

## 验收标准（Given-When-Then）

- **GWT-1 · 切片查询**：Given（任务类型、对话主题、Token 预算），When 调用查询，Then 返回相关节点切片——按相关性排序并在预算内截断，不得超预算返回。
- **GWT-2 · 切片标注**：Given 任意一条切片，When 消费方读取，Then 携带该节点的 `as_of` 与 `confidence`（含 `source`），使消费方区分「用户说的 / 推断的」。
- **GWT-3 · 三视图同一查询层**：Given 图谱 / 列表 / 时间线三种浏览方式，When 取数，Then 均经同一查询面（视图只对同一结果做不同组织，不各自造查询路径）。
- **GWT-4 · 空结果语义**：Given 图谱中无与本次查询相关的记忆，When 查询，Then 返回 `empty` 并带原因（如「该维度尚无记忆」），不返回裸空、不编造内容。

## 接口面

- **输入（消费的前置接口）**
  - T-L2-001.1 的节点 / 边模型与 `MemoryGraph`（`src/st_agent/l2/memory/models.py` · `graph.py`）
  - T-SC-001 §5 `ResultEnvelope`（[result_envelope.py](../../../../src/st_agent/contracts/result_envelope.py)）——空 / 不可用走 `empty` / 非 ok 分支而非裸空 · §8 时间口径（[time_events.py](../../../../src/st_agent/contracts/time_events.py)）
  - T-L0-001 `Store`（[store.py](../../../../src/st_agent/l0/storage/store.py)）
- **输出（本任务交付的公共 API / 落盘位置）**
  - 新增 `src/st_agent/l2/memory/reader.py`：`MemoryReader`（切片查询入口）与 `MemorySlice` 形态（切片元素：节点 + `as_of` + `confidence`）
  - 只读面：**不新增落盘位置**

## 可关闭的遗留

- **L1 册 `C2`**（对象类输入无通道）——本叶交付其**注入面**：`MemoryReader.query` 的上下文切片使 L1 执行器可经 `attention` / `identity` 节点取用户持仓与偏好（`TASK_TYPE_AFFINITY` 已含 `decision` / `deliberation` 等任务类型）。**不整条关闭**：余下的 L1 侧接线（三个执行器改从该面取数）不在本层，已就地修正册内归属（见册内 2026-09-27 修正记）。
- 无其他命中（开工查 [遗留问题/README.md](../../../遗留问题/README.md) 册内索引仅 L0 / L1 两册）。

## 假设与前提

- **A1 · 相关性打分先用结构性判据、不引入语义检索**：§3.1 只要求「相关节点切片」，未定打分口径。本叶取无外部依赖的结构判据（节点类型与任务类型的映射 + 主题关键词命中 + 边距离 + 置信度/时近度加权），Token 预算用字符数近似。若错（需要语义相关）：返工面 = `MemoryReader` 的打分函数，切片形态与查询签名不变。
- **A2 · `as_of` 取节点自身时间锚**：节点无外部数据快照，故切片 `as_of` 取该节点 `updated_at`（§8 的 `dataset_snapshot_id` 不入本面，`memory` 非数据域）。若错：返工面 = `MemorySlice` 的时间字段口径。
- **A3 · 三视图共享的是查询面、不是渲染**：§3.1「三种浏览视图共享同一查询层」只约束取数；视图的组织/渲染归 L3（`T-L3-004`）。本叶交付的查询结果须足以支撑三种组织（含时间锚与边），但不含任何 UI 形态。若错（视图需专用查询）：返工面 = 查询面增参数或结果形态。
