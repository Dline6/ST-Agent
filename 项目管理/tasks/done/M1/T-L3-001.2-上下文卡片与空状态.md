# T-L3-001.2 · 上下文卡片与空状态（§2）

## 目标

兑现 [05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的首页常驻上下文卡片：内容取自 [04 §3.1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的 Memory 关键切片（持仓摘要 / 关注池 / 当前 thesis / 风险偏好画像卡「不超过 5 条关键标签」），并携「进入完整图谱」的导航目标；新用户无 Memory 时走空状态、引导 Onboarding。本叶交付**卡片的结构化内容面**（数据），不含渲染。

## 验收标准（Given-When-Then）

- **GWT-1 · 卡片内容取自记忆切片**：Given 图谱中有 `attention` / `thesis` / `identity` 节点，When 组装卡片，Then 持仓摘要 / 关注池 / 当前 thesis / 偏好画像四段的内容**全部来自 `MemoryReader` 切片**（逐项可回溯到切片节点），不额外取数、不编造。
- **GWT-2 · 偏好画像卡不超过 5 条标签**：Given 记忆里可提炼的画像标签多于 5 条，When 组装卡片，Then 画像卡**恰不超过 5 条**，且被截断这一事实在卡片上可见（携实际条数与上限）。
- **GWT-3 · 空状态引导**：Given 新用户无任何记忆，When 首页组装卡片，Then 卡片 `is_empty=True`、附中性措辞的引导文案与进入 Onboarding 的引导目标（[04 §7](../../../../docs/技术架构-v2/04-L2-记忆图谱.md)），**不阻断**其他功能。
- **GWT-4 · 未就绪槽显式不可用**：Given 某段内容的数据源尚未交付（未读告警数 → L5 未建；近期热点摘要 → 需 L3 §4 派发，见任务 `A2`），When 组装卡片，Then 该段以 `unavailable` 形态出现并**带原因**——不静默留空、不用其他数据顶替、不省略该段的占位语义。
- **GWT-5 · 进入完整图谱的导航目标**：Given 一张卡片，When 读取，Then 携可复核的导航目标（指向 [04 §3.1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的图谱视图查询），使「点击进入完整图谱」有明确落点；L3 **只产目标描述**，渲染归界面层。
- **GWT-6 · 卡片自身文案过中性校验**：Given 卡片携带的固定文案（卡片名、引导语、空状态提示），When 过 [`NeutralityGuard.check_name` / `check_output`](../../../../src/st_agent/contracts/neutrality.py)，Then **全部通过**（[01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 执行点 1/2）——[05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 与 Story 原文的示例措辞含第一人称，按铁律 2 中性改述（同 [`T-L2-004.1`](T-L2-004.1-Onboarding协议与空状态.md) 的 `EMPTY_STATE_HINT` 先例），见任务 `A1`。

## 可关闭的遗留

- **L2 册 [`A1`](../../../遗留问题/L2-遗留问题.md)**（§6 输出校验的落点在「渲染前」而非「写入期」，待明确「记忆内容在渲染期是否过输出校验、`user_stated` 原话如何豁免」）——本叶是**首个记忆内容渲染面**，按册内解封条件就地落定：**记忆本体内容（`user_stated` 原话 / 推断记录）作为数据展示不过 §6 输出校验**（§6 的三类对象是 LensOpinion / Skill 文案 / 推送文案，即系统**生成**的结论性文案）；**本叶自有的固定 UI 文案**则按铁律 2 中性改述、并过校验（GWT-6）。口径记决策日志，收工时销账并留痕。

## 假设与前提

- **A1 · 固定 UI 文案走中性改述，不豁免 spec 原文**：[05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的卡片名「副驾眼中的我」与 Story 的引导语、空状态示例均含第一人称，与 [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2 相抵。按 [`T-L2-004.1`](T-L2-004.1-Onboarding协议与空状态.md) 的既有处置（铁律 2 优先，`EMPTY_STATE_HINT` 即中性改述）取中性措辞并以 GWT-6 机器钉住；**记忆本体内容**（用户原话）另按 L2 册 `A1` 的落定不过校验。若错（须保留原文）：返工面 = 三个文案常量 + GWT-6。
- **A2 · 未读告警数与近期热点摘要建模为**不可用槽**，不在本叶接数据源**：[05 §2](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 明列这两段，但其生产方不在本叶 `depends_on` 内——未读告警数归 L5（M3 未建），近期热点摘要须经 [05 §4](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 派发走 L1 Skill（归 [`T-L3-002`](T-L3-002-意图理解与澄清协议任务派发总线.md)）。本叶只给槽位与 `unavailable` 原因，两段的生产方落地时**填槽不改造型**。若错（须本叶即接）：返工面 = `build_context_card` 增取数依赖，`depends_on` 随之扩。
- **A3 · 画像标签的取材＝切片节点的既有字段，不做二次推断**：「不超过 5 条关键标签」未定取材口径。本叶取 `attention.sector_preferences` / `theme_interests` 与 `identity.risk_preference` / `investing_years` 等**已有取值**，按切片相关性序截断到 5；不引入关键词抽取或 LLM 归纳（那属后续面的能力）。若错（须形态化标签）：返工面 = 标签提炼函数，卡片结构不变。
- **A4 · 切片预算用 `SliceQuery.token_budget=None`（浏览口径）**：卡片要展示「全貌」而非对话注入用的小切片，若沿用默认 800 字符预算会把四段内容截到只剩一两段。取 `None` 不截断、由本叶按段自行限长（画像卡按 5 条上限）。若错：返工面 = `build_context_card` 的查询参数与分段限长。
