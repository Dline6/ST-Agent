# T-UI-001 · 表现层骨架与本地服务通信面

## 目标
交付跨层表现层的**骨架工程**：前端工程骨架、本地服务通信面（loopback + 启动令牌）、`ResultEnvelope` 六态渲染与**组件类型注册表宿主**（开工 ④ 意图对齐时据 Story 补全）。

## 验收标准（Given-When-Then，从 Story 抄）
- 待 ④ 对齐时从 [story-01](../../../../docs/PRD-v2-Agent/story-01-chat-as-os.md) 与 [00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md) 逐条补全

## 接口面
- **输入**（各层已声明的输出契约，本任务不新造业务语义）：
  - [05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的 Generative UI 描述（组件类型 + 数据绑定 + 布局提示）与 L3 特有组件行为口径
  - [01 §5](../../../../docs/技术架构-v2/01-平台共享契约.md) `ResultEnvelope`（六态）· [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) `panel_form_spec`
  - [T-UI-001.1](T-UI-001.1-IA骨架与页面Flow.md) 的 IA 骨架与页面 Flow；L1 Studio 首页数据源（`StudioHome` / `TemplateSummary`）
- **输出**：
  - 前端工程骨架 + 本机通信面——loopback + 随机端口 + 启动令牌握手（+ Origin / 自定义头防 DNS rebinding，[D-060](../../../决策日志.md) ③F）；**只经该面取数，不提供壳专有通道**（如 Electron `preload` / IPC、Tauri `invoke`），以保住 [D-060](../../../决策日志.md) ① 的壳选型延后
  - 组件类型注册表（组件类型 → 渲染件；**只解析描述、不解析任意代码**，[05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md)）——宿主在本任务，供 [T-L3-004](T-L3-004-GenerativeUI推理链可视化.md) 及 L4 / L6 的渲染面消费
  - `ResultEnvelope` 六态渲染 + 渲染前中性化校验（[01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2）；dev 开关下的浏览器直开（构建期开关，发布构建剔除，[D-060](../../../决策日志.md) ④I）

## 假设与前提
- **A1 · Generative UI 描述类型按 [铁律 8](../../../工程宪法.md) 先登记 [01 平台共享契约](../../../../docs/技术架构-v2/01-平台共享契约.md) 再改各层**——前提：该描述是**跨层共享型**（L3 产出、本任务渲染、L4 / L5 / L6 的渲染面复用），不登记则各层各造形态。**本任务 ④ 对齐时正式判定**（[D-060](../../../决策日志.md)「01 契约本次不改」明说该判定落在此处）。若错（不登记或登记过晚）：下游渲染面按各自假想形态实现，后期统一时大改。验证方式：④ 对齐给出「登记 / 不登记」的裁定与理由；若登记，按 [铁律 8](../../../工程宪法.md) 的 01 → 各层 → 代码顺序与代码同批改。
- **A2 · 组件类型注册表须支持跨层复用同一渲染件**——前提：[05 §7](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 明说 Trace 视图与 [06-L4](../../../../docs/技术架构-v2/06-L4-多视角推理.md) 视角追问、[08-L6](../../../../docs/技术架构-v2/08-L6-反思演进.md) 反思报告**复用同一渲染组件**，故注册表以「组件类型 → 渲染件」登记、渲染件不绑 L3 语境。若错（做成层内私有）：L4 / L6 渲染面后期重写。验证方式：某组件类型经注册后，可在不改注册表结构的条件下被 L4 / L6 的渲染面直接取用。
