# T-L2-002.3 · 置信度模型（基线 + 时间衰减 + 事件重估）

## 目标

兑现 [04 §5 置信度模型](../../../../docs/技术架构-v2/04-L2-记忆图谱.md)：**基线**（`user_stated` > `inferred`；推断类必带 `trace_id` 已在 `T-L2-001.1` 强制）、**时间衰减**（thesis 类信心度随时间自动降低，曲线参数可配）、**被新事件引用时重估**（事件触发重估，与衰减结合，策略实现阶段定并注册为可配置项）三条，并让**消费方按置信度调整表述强度**有可取的数——即把有效置信度接到 [`MemoryReader`](../../../../src/st_agent/l2/memory/reader.py) 的切片上（§3.1 明列切片须携带置信度）。

## 验收标准（Given-When-Then）

- **GWT-1 · 基线序**：Given 两条其余相同、仅 `source` 不同的节点，When 取各自基线，Then `user_stated` 的基线严格高于 `inferred`；基线取值来自 01 §7 条目而非硬编码。
- **GWT-2 · thesis 时间衰减**：Given 一条 thesis 节点，When 龄期增大，Then 有效置信度**单调不增**（同一起点、同一参数下），且半衰期参数改变后同一点的有效值随之改变。
- **GWT-3 · 非衰减类型不受影响**：Given `identity` / `attention` 等非 thesis 类节点，When 取有效置信度，Then 等于其基线（不衰减）——§5 只把衰减写在 thesis 上。
- **GWT-4 · 被新事件引用时重估**：Given 一条已衰减的 thesis，When 它被一次新引用触发重估，Then 有效置信度回升到「衰减值 + 重估增量」与上限的较小者，且**不回写存量节点**。
- **GWT-5 · 参数可配且改动即生效**：Given 用户改基线 / 半衰期 / 重估参数，When 落盘，Then 产出一条 `ChangeRecord` 留痕（`change_id` 可回滚），且后续取数按新参数计算；条目缺失或损坏时回落缺省值。
- **GWT-6 · 切片携带有效置信度且可解释**：Given 一个切片结果，When 消费方读取，Then `MemorySlice.confidence` ＝**有效**（衰减 / 重估后）置信度，同切片另携**节点存储值**（`base_confidence`），使「这是用户说的还是推断的」「它被衰减了多少」都可追溯。

## 假设与前提

- **A1 · 衰减与重估是「算出来」的，不回写存量节点**：[04 §5](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 说 thesis 信心度「随时间自动降低」——若落成**改写节点**，即属「副驾自主修改既有 Memory 节点内容」，与 [§3.2 红线](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 直接相抵，且每次读都改盘。故取**派生值**：存量 `confidence` 是写入时刻的记录，有效值在读面计算（切片同时给出两者，GWT-6）。若错（须持久化衰减）：返工面 = 增一条「重估」写入路径，且须先解 §3.2 红线（人决）。
- **A2 · 衰减只作用于 `thesis` 类**：§5 原文只写 thesis，未提其余五类。若错（须覆盖更多类型）：返工面 = 动态参数条目的适用类型列表（已是配置项，改配置即可）。
- **A3 · 「被新事件引用」的判据＝该节点获得新边**：§5 未定义「引用」的机器形态。取 `MemoryGraph.edges_of(node_id)` 中**晚于该节点 `updated_at`** 的边存在即为「被新事件引用」——与 [§2 边模型](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 对齐，且不需另建引用登记表。若错（须由调用方显式传入引用事件）：返工面 = `effective` 的入口参数，落盘面无。
- **A4 · 基线与动态参数分两条条目**：§5 把「基线」与「衰减（+重估）」列为两件事；分开后各自的 `change_id` / 回滚单位互不牵连。若错（须合成一条）：返工面 = 条目与落盘文件各并一。
- **A5 · `MemoryReader` 接入是有意为之，不是顺手改**：§3.1 明列切片须携带置信度、§5 明列「消费方按置信度调整表述强度」——不接入则本叶交付的模型**无消费方**（`T-L0-005` 收工曾把同类「无消费方」项登记为遗留）。代价：`MemorySlice` 字段语义变化会触及 `T-L2-001.3` 的既有用例（同起点零龄期下有效值＝存储值，故预期不改结论，需实跑核对）。若错（不该在此叶接入）：返工面 = 撤 `MemorySlice.base_confidence` 与 reader 注入，模型留待 L3 接线。
