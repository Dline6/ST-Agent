# T-L2-004 · Onboarding 协议 + 导出/导入/继承

## 目标

把 [04 §7 Onboarding 协议 / §8 导出 / 导入 / 继承](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 落成代码：新用户首启的**对话式快速画像**（问题清单可配、可跳过、空维度不阻断），以及记忆的**出得去、进得来**——公开片段的隐私过滤与导出确认门，他人公开片段的导入入库语义（`source: inferred` 他人陈述、置信度低于本人表达、可编辑可删除）。

## 验收标准（Given-When-Then，概要）

- 新用户 Onboarding 完成 → 图谱建立初始画像（含风险偏好 / 投资年限 / 当前关注板块 3 个维度）；问题清单是 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 条目、不超过 10 问、可跳过（细见 `.1`）
- 某维度无记忆 → 可查到「该维度没有信息」且不阻断其他功能（细见 `.1`）
- 导出公开片段 → 强制剔除 `private` / `sensitive` 节点、相接边一并剔除（无悬空边）、显示「本次导出包含的公开信息」清单、用户确认后才产出（细见 `.2`）
- 导入他人公开片段 → 作为 `source: inferred`（他人陈述）入库、置信度不高于推断基线、可编辑可删除、重复导入幂等（细见 `.3`）

**边界（④ 对齐确认）**：`.stmem` 的**文件容器**（`header` / `manifest` / 校验和 / 格式版本 / 来源追溯链）归 [`T-ECO-001`](../../T-ECO-001-分享物类型格式导出流程来源追溯链.md)（[09 §1·§2·§5](../../../../docs/技术架构-v2/09-生态与分享.md) 明属其面；四类同构容器须待四类 payload 齐备才定稿，同 [D-044](../../../决策日志.md) 取向）。本任务只交付 **payload 级 API**：过滤面、清单、确认门、导入入库语义。
**§8 的「完整备份」**（加密全量、跨设备导入）已由 [`T-L0-006`](../M0/T-L0-006-备份恢复完全清空数据留存策略.md) 交付（`memory` 在 `BACKUP_PARTITIONS` 内），本任务不新增。
**§8 末条「从券商账单等外部数据导入初始画像」**原文标「实现阶段评估」，不在本批（见「可关闭的遗留」节）。
