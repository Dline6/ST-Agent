# T-UI-001.3 · UI 描述契约登记与组件注册表宿主

> 由原 `T-UI-001.2` 依[拆分触发](../../../工作流.md)拆出（2026-09-29）——「描述契约 + 注册表 + 中性化门」与「骨架 + 通信面」不属同一面。选型见 [D-063](../../../决策日志.md)。

## 目标
按 [铁律 8](../../../工程宪法.md) 的「先 01 → 05 → 最后代码」顺序，把 **Generative UI 的结构化描述**登记进 [01 平台共享契约](../../../../docs/技术架构-v2/01-平台共享契约.md)（新增小节），并在前端交付**组件类型注册表宿主**（类型 → 渲染件；**只解析描述、不解析任意代码**）与**渲染前中性化校验门**。

## 验收标准（Given-When-Then）
- Given [01 平台共享契约](../../../../docs/技术架构-v2/01-平台共享契约.md)，When 查看新增小节，Then UI 描述契约（组件类型 + 数据绑定 + 布局提示 + 文本分栏）已登记，且 [05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 有指针；提交顺序为 **01 → 05 → 代码**（[铁律 8](../../../工程宪法.md)）
- Given 未登记 / 未实现的 `component_type`，When 描述进入注册表，Then **显式降级占位**（类型名 + 原因 + 折叠原始 JSON），不执行、不猜测、不静默丢弃
- Given 一份描述，When 渲染，Then 只按 `component_type` 取渲染件、按 `slots` 名取值——**全程无可执行片段**（无 `eval` / `new Function` / 动态 `import()` / 模板求值）
- Given 契约标 `generated` 的字段含第一人称或情感措辞，When 出站，Then **阻断渲染**并回 `validation_failed` + 记录校验失败（[01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 执行点 2，**不可关闭**）
- Given 契约标 `data` 的字段含第一人称（用户原话 / 记忆本体），When 出站，Then **放行、原样呈现**——不整串复检（[D-053](../../../决策日志.md)）

## 假设与前提
- **A1 · UI 描述类型为跨层共享型，必须登记 [01](../../../../docs/技术架构-v2/01-平台共享契约.md)**——前提：[铁律 8](../../../工程宪法.md) 要求新增跨层类型先登记，且该描述已有多层消费者（L3 产出、本任务渲染、L4 视角追问与 L6 反思报告复用同一渲染组件，见 [05 §7](../../../../docs/技术架构-v2/05-L3-对话主入口.md) / [06 §5](../../../../docs/技术架构-v2/06-L4-多视角推理.md) / [08 §2](../../../../docs/技术架构-v2/08-L6-反思演进.md)）。[D-060](../../../决策日志.md) 明说该判定落在此处，负责人 2026-09-29 拍定「登记」。若错（不登记）：各层各造描述形态，[D-060](../../../决策日志.md) ⑤ 的分归属失去意义。验证方式：01 → 05 → 代码的提交顺序可核；[`verify_docs.py`](../../../tools/verify_docs.py) 全绿。
- **A2 · 中性化执行点 2 落 Python 侧的回环服务边界**——前提：[01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 的「渲染前」取「描述送达浏览器之前的最后一段 Python」；词表唯一真相源在 [`contracts/neutrality.py`](../../../../src/st_agent/contracts/neutrality.py)，规则库可随官方 Pack 更新。若错（前端复检）：规则分叉、且前端要携一份会漂移的词表。验证方式：改 `default_rulepack` 后行为随之变，**前端无需改动**；红-绿用例（`generated` 含第一人称即阻断）。
- **A3 · 注册表「不解析任意代码」= 类型枚举键 + 渲染件函数 + `slots` 按名取值**——前提：[05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 原文「不解析任意代码」；`slots` 只承载**服务端已解析的 JSON 值**或 §1 ID 引用。若错（引入表达式 / 模板）：渲染面变成任意代码执行面，安全与可审性同时失守。验证方式：扫描用例断言 `ui/web/**` 无 `eval(` / `new Function`；描述构造期拒绝任何非 JSON 值的槽。
- **A4 · 文本分栏（`generated` / `data`）必须显式标注**——前提：只有 `generated`（系统生成文案）过 [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md)，`data`（用户原话 / 记忆本体）原样呈现（[D-053](../../../决策日志.md)）；**留白即误伤用户数据**。若错（缺标注）：要么误判用户数据违规、要么让生成文案漏检。验证方式：两向红-绿用例（`generated` 命中即阻断、`data` 命中即放行）。
