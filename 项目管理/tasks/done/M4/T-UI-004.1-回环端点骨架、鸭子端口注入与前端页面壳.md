# T-UI-004.1 · 回环端点骨架、鸭子端口注入与前端页面壳

> 由 [`T-UI-004`](T-UI-004-反思中心与生态面的表现层入口.md) 按[拆分触发](../../../工作流.md)拆出的**共享底座叶**（D-089 ①）。后三叶各自依赖本叶——先立底座，避免三叶各建一次路由 / 注入 / 导航。

## 目标
把四处表现层入口**共同需要的那一层**立起来，令后三叶只填各自的页面与端点：

1. **鸭子端口注入**——[`build_ui`](../../../../src/st_agent/ui/app.py) / [`serve`](../../../../src/st_agent/ui/server.py) 新增可选端口（`reflection` / `eco`），由生产入口 [`__main__.py`](../../../../src/st_agent/__main__.py) 的 `run_backend` 从 [`M4Runtime`](../../../../src/st_agent/app.py) 的 `l6` / `eco` 注入；`ui` **不 import** `st_agent.app`（守卫已钉），与既有 `chat: Any` 端口同口径。
2. **路由表**——[`UiRequestHandler`](../../../../src/st_agent/ui/server.py) 的 `do_GET` / `do_POST` 由「硬编码几条」改为**白名单路由表**：新增 `/api/*` 端点挂载点、以及**已知页面路径回同一静态壳**（SPA 回退，令牌仍走 `#t=` fragment，不进 query / 路径）。
3. **前端页面壳与导航**——[`main.js`](../../../../src/st_agent/ui/web/js/main.js) 由「只取一次 `/api/health`」改为**按 `location.pathname` 选页**的壳；[`api.js`](../../../../src/st_agent/ui/web/js/api.js) 增 POST 助面（既有只有 GET 助面）。
4. **各新面 fail-closed 占位**——端口未注入时，任一新增 `/api/*` 回 `unavailable` + 点名（不 500、不伪造）。

## 验收标准（Given-When-Then）
- **GWT-1** Given 端口未注入（`reflection=None` / `eco=None`），When 访问任一新增 `/api/*` 只读端点，
  Then HTTP 200 + 合法信封（含 `status` ∈ 六态、`render.presentation`、非 ok 带 `reason`），
  `status="unavailable"` 且 `reason` **点名**未接入的门面。
- **GWT-2** Given 已知页面路径（`/`、`/reflection`、`/reflection/changes`、`/settings/evolution`、`/eco` 等），
  When GET，Then 回**同一静态壳** `index.html`；**未知路径**仍 404——不把任意路径都当页面。
- **GWT-3** Given 静态壳（`/` 与各页面路径），When **不带令牌**打开，Then 仍可加载（[D-063](../../../决策日志.md) 的
  「令牌只压数据面」不破）；非法 `Host` / `Origin` 仍 403。
- **GWT-4** Given 新增 POST 端点，When 请求体畸形 / 空 / 缺键，Then HTTP 200 + 信封 `validation_failed`
  （沿用 [`T-UI-003`](../M3/T-UI-003-对话端点请求体失败显式化.md) 的「回信封、不断连」口径）；
  **非白名单** POST 路径仍 404，`/api/chat` 行为逐字节不变。
- **GWT-5** Given 前端 POST 助面，When 发请求，Then 带 `X-ST-Token` + `credentials:'omit'` + `cache:'no-store'`，
  令牌**只在内存**（不落 `localStorage` / `sessionStorage`）；服务端**不回任何** `Access-Control-Allow-*`。
- **GWT-6** Given `ui/web/**`，When 扫描，Then 无 `eval(` / `new Function` / 动态 `import()` / `import st_agent`
  （既有纯性断言不破），且页面壳只用 `textContent` / `replaceChildren` 构造 DOM。

## 假设与前提
- **A1 · `ui` 消费 L6 / ECO 面只能经鸭子端口**——前提：[`tests/test_layering.py`](../../../../tests/test_layering.py) 的
  `test_ui_is_client_only` 允许 `ui` import `l6` / `eco`，但 `test_app_is_composition_root_only` 断言**除 `__main__.py`
  外无人 import `st_agent.app`**，而 `_EcoStack` 是 `app.py` 的私有类 ⇒ ECO 面**只能**经端口传；为免两套口径，
  L6 面同走端口（同既有 `chat: Any`）。
  **若错的影响**：若改走 import，`ui` 会绑上 L6 层内 API 形状且 `_EcoStack` 仍需端口——两套口径并存。
  **验证方式**：GWT-1 以「端口未注入即 `unavailable` + 点名」证实解耦；`tests/test_layering.py` 不改即仍绿。
- **A2 · 令牌在 fragment，故页面路由不能用 fragment**——前提：[`api.js`](../../../../src/st_agent/ui/web/js/api.js) 从
  `location.hash` 的 `#t=` 读令牌（[D-063](../../../决策日志.md) 的 A3），页面路由若也占 `hash` 会与令牌打架。
  **若错的影响**：路由与令牌互相覆盖，令牌丢失即全站 401（且静态壳可开、数据面全废）。
  **验证方式**：GWT-2 以 `location.pathname` 选页 + GWT-3 的「壳不带令牌可开」成对钉住；令牌仍经 `#t=` 读。
- **A3 · 静态壳回退不放宽守卫**——前提：页面路径属**静态壳**档（只校 `Host` / 存在的 `Origin`），`/api/*` 仍必带令牌。
  **若错的影响**：把页面路径并入 `/api/` 判定会让首次导航 401（[D-063](../../../决策日志.md) 实测过的坑）；
  反之若对 `/api/*` 放宽则数据面失守。**验证方式**：GWT-1 / GWT-3 成对（数据面要令牌、壳不要）。
