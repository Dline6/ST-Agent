# T-UI-004.4 · 生态面表现层入口

> 由 [`T-UI-004`](T-UI-004-反思中心与生态面的表现层入口.md) 按[拆分触发](../../../工作流.md)拆出（D-089 ①）；底座见 [`T-UI-004.1`](T-UI-004.1-回环端点骨架、鸭子端口注入与前端页面壳.md)。

## 目标
交付 [story-10「设计触点」](../../../../docs/PRD-v2-Agent/story-10-skill-sharing.md) 生态面的表现层入口（ECO 的读面 + 局限写面）：

- **导出对话框**（隐私过滤）——`.stmem` 强制三步：显示「本次导出包含以下公开信息」清单 → 用户确认 → 生成文件。
- **导入校验页**——「这个 Skill 想做什么」（权限申请 + 依赖树 + 来源追溯）+ 逐项批准后安装。
- **官方 Skill 索引浏览页**——只读元数据 + 外部下载地址展示（产品不经手文件）。
- **来源追溯页**——分享者标识 / 导入时间 / 校验和 / 多次转手的出处链。
- **越界行为警示**（`violation_alert`）——`BehaviorViolation` 的**拉取式**表现面 + 禁用选项。

**文件面口径**（D-089 ④，人 2026-10-07 拍定）：后端持**导出目录**与**导入收件目录**（落存储根下 `exports/` 与 `inbox/`），端点**只在这两个目录内读写**；前端显示路径、只做勾选与确认。不引入「按任意路径读写」的本地原语。

## 验收标准（Given-When-Then）
- **GWT-1** Given 用户发起 `.stmem` 导出，When GET 导出计划，Then 返回「本次导出包含的公开信息」清单（`FragmentPlan`，已滤除 `private` / `sensitive` 节点）；When 未经确认就导出，Then **拒**（不生成文件）；When 带 `confirmed_by="user"`，Then 在导出目录内产出文件并回其路径 + 分享卡片（描述 + 校验和 + 下载指引）。
- **GWT-2** Given 导出目录与收件目录，When 端点读写，Then **只在目录内**：路径穿越（`..` / 绝对路径 / `\0`）一律拒；四类扩展名正确（`.stskill` / `.stflow` / `.stlens` / `.stmem`）；端点**不**接受目录外的任意路径。
- **GWT-3** Given 收件目录里的一份分享文件，When 校验，Then 展示「这个 Skill 想做什么」——权限申请列表 + 依赖列表 + 来源追溯；**缺失依赖**明确提示获取途径（官方 Pack / 外部下载）且**不自动安装**；**损坏文件**明确报错、不安装。
- **GWT-4** Given 一份校验通过的导入物，When 安装，Then 须 `confirmed_by` 为导入确认口径且权限声明**全部批准**（`.stskill`），安装后来源追溯可查（分享者 / 导入时间 / 校验和 / 出处链）。
- **GWT-5** Given 官方索引浏览，When 索引不可用（未配端点 / 离线），Then 显式 `unavailable` + 点名（**不留半截数据**）；When 用户尚未导入任何第三方 Skill，Then 空态「你的 Skill 库目前只有官方 Pack」+ 引导浏览索引（不硬凑列表）。
- **GWT-6** Given 一条 `BehaviorViolation`，When 表现层取用，Then 警示含「这个 Skill 行为异常」的中性说明 + **禁用选项**；未接事件订阅面时**如实标注未受理 + 点名**（不假装送达）；越界项与禁用状态可复核。

## 假设与前提
- **A1 · 表现层只需「目录内读写」，无需任意路径原语**——前提：人 2026-10-07 拍定（D-089 ④），且分享文件的取送本就走本机文件系统、产品不经手。
  **若错的影响**：若 UX 要求「另存为任意路径」，需回头改端点契约并重新评估「任意本地文件读写」原语暴露到回环面的风险面。
  **验证方式**：GWT-2 以路径穿越用例钉住限界；导出目录 / 收件目录为存储根下常量（`exports/` / `inbox/`）。
- **A2 · 隐私过滤的判据在 ECO 侧，表现层只呈现**——前提：[09 §2](../../../../docs/技术架构-v2/09-生态与分享.md) 的强制三步与 [04 §3.1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 的记忆读取面切片是过滤的**唯一**出处。
  **若错的影响**：表现层自行过滤会造出第二套隐私判据，两侧口径漂移即可能导出私密节点（数据主权事故）。
  **验证方式**：GWT-1 的清单直接取 `plan_memory()`（不自行筛）；`confirmed_by` 非 `"user"` 即拒。
- **A3 · 越界警示本批取拉取式**——前提：[01 §11](../../../../docs/技术架构-v2/01-平台共享契约.md) 明写「**跨进程**（常驻后端 → 可分离 UI 客户端）的推送是表现层消费面的事，不在本口径内」。
  **若错的影响**：若要求实时推（SSE / 长轮询）而非拉取，需另立端口与生命周期，超出本叶范围。
  **验证方式**：GWT-6 以「订阅留痕 + 拉取端点」钉住；未接订阅面时如实标注未受理 + 点名。
