# T-L6-002.3 · A/B 实验

## 目标
交付 [08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md) 的 **A/B 实验**（后半）：`Experiment = {hypothesis, scope, sample, result, decision}` 五字段模型 + 启停结算的**全程留痕**（`reflection/experiments/<experiment_id>.json`，用户可查）+ **保守判定**（本地单用户小样本**不做统计显著性强断言**、用户反馈优先）+ **启用门**（受 [08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 授权档位约束 ⇒ 经**注入的授权面**表达，**缺省不注入即不启用**）。

**与上游的边界**（2026-10-06 读码核实）：

- **全仓无 A/B / `Experiment` 代码**（`grep` 零命中）——本叶从零建，且**不引第三方统计库**（悲观判定靠判据而非检验，本地优先）。
- **授权档位本体（`manual` / `collaborative` / `autonomous` 三档、切换留痕、风险分级清单）归 [T-L6-003](T-L6-003-演进授权与变更流回滚与出厂重置.md)**（[08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md)）。本叶**只交一个注入的授权端口**，不实现档位、不落授权状态。
- **出厂重置里的「A/B 实验停止」**（[08 §6](../../../../docs/技术架构-v2/08-L6-反思演进.md)）同样归 [T-L6-003](T-L6-003-演进授权与变更流回滚与出厂重置.md)——本叶只交「结算 / 判定 / 停止单个实验」的**面**供其调用。
- **投出 / 告知**（「每次变更经 L5 显式告知」）归 [T-L6-003](T-L6-003-演进授权与变更流回滚与出厂重置.md) 与关卡——本叶只落**留痕与读面**。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 一份低风险范围（推送策略 / 视角组合）的实验请求，When 启用，Then 经**注入的授权面**判定；**未注入授权面** ⇒ 返回「**未启用**」+ 原因（**不落盘、不假装开跑**）；Given 授权面**否决**，Then 同样不启用并写明——不存在「未接授权面却自行开跑」的路径
- **GWT-2**：Given 一个**不在低风险清单**内的范围，When 启用，Then **拒**（显式失败 + 说明合法范围），**不静默放行**
- **GWT-3**：Given 一次已启用的实验，When 落痕，Then `reflection/experiments/<experiment_id>.json` 含五字段（假设 / 范围 / 样本 / 结果 / 决策）+ 起止时刻，可**读回**；Given 换一个构造器续读，Then 实验仍在（**重启安全**）；Given 从未跑过实验，Then 读面给**空集**而非报错
- **GWT-4**：Given 一份样本／结果，When 判定，Then **保守**：样本数低于下限、或用户反馈未明确偏向任一侧 ⇒ `inconclusive`；只有用户反馈**明确偏向**且样本达下限才给 `adopt` / `revert`——判据里**没有**显著性检验，不产出 p 值 / 置信区间之类断言
- **GWT-5**：Given 实验在跑 / 已结算 / 已判定，When 读面，Then 三种状态可**分别查得**（`running` / `settled` / `decided`），用户「可查看实验日志」在**本层读面**即成立；Given 重复结算同一实验，Then **幂等**（同结果得同一留痕，不追加第二份）

## 假设与前提
- **A1 · 启用门经注入的授权面、缺省不启用**（2026-10-06 ④ 对齐拍定）——前提：[08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md) 末条「实验的启用受 §5 授权档位约束」，而 [§5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 归 [T-L6-003](T-L6-003-演进授权与变更流回滚与出厂重置.md)；缺省即跑等于在授权档位落地前造出一条自行开跑的路径（违 [08 §7](../../../../docs/技术架构-v2/08-L6-反思演进.md) 红线）。若错（要求缺省即跑 / 本叶实现档位本体）：返工面＝本叶启用门 + [T-L6-003](T-L6-003-演进授权与变更流回滚与出厂重置.md) 的范围（后者会与其范围重叠）。验证方式：未注入授权面时 `start` 恒 `enabled=False` 且**不落任何实验文件**的用例。
- **A2 · 低风险范围取「推送策略 / 视角组合」两项**（2026-10-06 ④ 对齐拍定）——前提：[08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md) 原文「仅适用于**推送策略 / 视角组合**等低风险参数」是唯一的范围登记者；更细的风险分级清单（哪些参数可自主改）属 [08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md)。取两项作**闭集白名单**，范围外**显式拒**。若错（要求更宽 / 更窄的范围）：返工面＝`LOW_RISK_SCOPES` 与相应用例（声明式常量，换集合不动引擎）。验证方式：清单内 / 清单外各一条用例。
- **A3 · `experiment_id` 走确定性摘要**（2026-10-06 ④ 对齐拍定）——前提：[01 §1](../../../../docs/技术架构-v2/01-平台共享契约.md) 的 15 类 ID 无「实验」一类，新增一类要改契约；[`weekly.py`](../../../../src/st_agent/l6/weekly.py) 已有「本层锚点走 `digest_id`」的先例。取 `digest_id("exp", scope, hypothesis)` ⇒ **同一实验的重复启用是同一份留痕**（幂等覆盖，同 [`.1`](T-L6-001.1-反思数据池.md) 池子的 `feedback_id` 口径）。若错（要求随机 ID / 登记为新 ID 类）：返工面＝本叶标识面 +（后者）[01 §1](../../../../docs/技术架构-v2/01-平台共享契约.md)（**须走 [铁律 8](../../../工程宪法.md) 契约先行**）。验证方式：同一输入两次得同一 `experiment_id`、且重复结算幂等的用例。
- **A4 · 保守判定为纯函数、不引统计库**（2026-10-06 ④ 对齐拍定）——前提：[08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md) 原文「本地单用户小样本下不做统计显著性强断言，效果判断保守（用户反馈优先）」；引第三方统计库既无必要也违背最小依赖取向。判据＝样本下限 + 用户反馈是否明确偏向。若错（要求统计检验）：返工面＝判定件与其用例（会新增依赖，须另立选型）。验证方式：样本不足 / 反馈未偏向 / 反馈明确偏向三类用例分别得 `inconclusive` / `inconclusive` / 非 `inconclusive`。
