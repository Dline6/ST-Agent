# T-L6-003.1 · 演进授权档位与风险分级清单

## 目标
交付 [08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 的**演进授权档位**（`manual` / `collaborative` / `autonomous` 三档，**配置注册表项、切换留痕**）+ **风险分级清单**（哪些参数可自主改、哪些必须协作、哪些永不可自主）+ 把两者接成**审批门与实验启用门的判据实体**——即 [T-L6-002.3](T-L6-002.3-AB实验.md) 只消费不实现的那个 `permits(scope) -> bool` 授权面。

**与上游的边界**（2026-10-07 读码核实）：
- [`ExperimentConsole`](../../../../src/st_agent/l6/experiment.py) 的启用门今日只认**注入的授权面**（鸭子面 `permits(scope)`），缺省即不启用；本叶交出该面的**实体**（组合根把它注入 `build_l6(authorizer=…)` 归关卡 [T-INT-005](T-INT-005-M4集成关卡反思演进与生态闭环.md)）。
- 本叶**不做**变更流（提案 → 生效 → 回滚）——那是 [`.2`](T-L6-003.2-变更流与变更历史回滚.md)；本叶只交**判据**（档位 + 风险分级），供其调用。

## 验收标准（Given-When-Then）
- **GWT-1**：Given 一件演进动作（一条提案 / 一次实验启用），When 判定，Then **按当前档位**给出结论——`manual` ⇒ 一律**不自动**（只能建议）；`collaborative` ⇒ **不自动**、走用户批准路径（默认档）；`autonomous` ⇒ **仅当**目标在风险分级清单的「可自主」类内才自动放行，清单外仍不自动
- **GWT-2**：Given 档位是三档之一，When 读面，Then 档位是**经登记的可配条目**（[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)：`config_id` / 取值契约 / 缺省 / 面板规格 / 对话描述），**缺省＝`collaborative`**；Given 切换档位，Then **留痕**（产生 `ChangeRecord`，含旧值 / 新值与时刻），可在变更读面查得
- **GWT-3**：Given 一次 A/B 实验请求，When 启用，Then 授权面**按档位**给结论——`autonomous` 且范围在低风险清单内 ⇒ `permits` 为真（实验可启用）；`manual` / `collaborative` ⇒ 为假（不自动开跑，走协作路径）；Given 范围不在低风险清单内，Then 由 [`ExperimentConsole`](../../../../src/st_agent/l6/experiment.py) 先行显式拒（本叶不接管该判定）
- **GWT-4**：Given 风险分级清单，When 分类任一条目，Then 三类语义可查——**可自主**（仅表现层参数：推送文案风格 / 报告结构等）· **必须协作**（Skill 参数 / 注意力预算 / 视角阵容）· **永不可自主**（Memory 内容——**即便 `autonomous` 档也恒不放行**，[08 §7](../../../../docs/技术架构-v2/08-L6-反思演进.md) 红线）；Given 一个**不在清单内**的条目，Then 按**保守**处理（视为必须协作，**不静默放行**）
- **GWT-5**：Given 档位条目缺失 / 损坏，When 判定，Then **fail-closed**（不放行任何自动动作 + 显式说明原因，**不臆测为 `autonomous`**）；Given 未注入 01 §7 门面，Then 条目面仍可读写（纯内存态）但**不假装已登记**

## 假设与前提
- **A1 · 档位与风险清单都是 01 §7 条目**（2026-10-07 ④ 对齐拍定）——前提：[08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 原文「三档授权（**配置注册表项**，切换留痕）」与「以**风险分级清单**形式注册」；[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)「新增条目同此」要求新增条目随实现接入门面。档位是标量枚举 ⇒ 走统一标量落值面；清单取值是对象 ⇒ 写面归自有 API（先例＝`weekly-report.template`）。若错（要求档位住代码常量）：返工面＝本叶条目面与其「切换留痕」验收。验证方式：档位经门面 `set` 落值并产生 `ChangeRecord`、缺省为 `collaborative` 的用例。
- **A2 · `autonomous` 只对「可自主」类放行，未分类条目按保守处理**（2026-10-07 ④ 对齐拍定）——前提：[08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 原文「**默认仅**推送文案风格、报告结构等表现层参数可自主；Skill 参数、注意力预算、视角阵容必须协作；Memory 内容永不可自主」——是白名单口径而非黑名单。若错（要求未分类即放行）：返工面＝`classify` 的缺省分支与相应用例（声明式数据，换口径不动引擎）。验证方式：清单内 / 清单外各一条用例；`never-autonomous` 类在 `autonomous` 档下仍恒不放行的用例。
- **A3 · 实验授权面以本面为推荐缺省**（2026-10-07 ④ 对齐拍定）——前提：[T-L6-002.3](T-L6-002.3-AB实验.md) 的 [`ExperimentConsole`](../../../../src/st_agent/l6/experiment.py) 需要 `permits(scope)` 的实现，而档位本体在本叶；`build_l6` 未显式传 `authorizer` 时**以本面充当**该口（口径同 `advisor` 缺省接提案引擎的先例），**显式传参仍可覆写**。若错（要求缺省不启用不变）：返工面＝`build_l6` 的一处缺省分支（本叶不实现档位时的行为可经显式 `authorizer=None` 复原）。验证方式：不传 `authorizer` 时 `ExperimentConsole` 可依档位启用、显式传 `None` 时仍恒不启用。
- **A4 · 「视角组合」在两处口径下不冲突**（2026-10-07 ④ 对齐拍定）——前提：[08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md) 把「视角组合」（`lens-composition`）列为**实验的低风险范围**，[08 §5](../../../../docs/技术架构-v2/08-L6-反思演进.md) 又把「视角阵容」列为**必须协作**——前者管**实验可否开跑**、后者管**配置条目可否自动生效**，是两条不同的判定，故不冲突。本叶只对实验范围回答「该范围在当前档位下可否自动启用」，`autonomous` 且范围在 [`LOW_RISK_SCOPES`](../../../../src/st_agent/l6/experiment.py) 内 ⇒ 放行；而对**承载视角阵容的配置条目**，`classify` 仍归「必须协作」。若错（要求两者一致）：返工面＝本叶 `permits` 的判据与相应用例。验证方式：`autonomous` 档下 `permits("lens-composition")` 为真、而 `classify("lens.<base>.<param>")` 归「必须协作」的成对用例。
