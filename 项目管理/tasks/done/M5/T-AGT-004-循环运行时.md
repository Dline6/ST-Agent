# T-AGT-004 · 循环运行时（分组节点）

> **本节点不直接交付**——按[拆分触发](../../../工作流.md)拆为三叶（[D-090](../../../决策日志.md) / 本次 ④ 对齐），交付由 [`.1`](T-AGT-004.1-工具目录消费与循环工作上下文装配.md) / [`.2`](T-AGT-004.2-循环驱动、协议端口与上界.md) / [`.3`](T-AGT-004.3-产出接入、留痕与失败语义.md) 承接。父状态与父 `depends_on` 由 `render` 按 children 派生。

## 目标

兑现 [05 §10 自主查证循环](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的**循环本体**——住 `src/st_agent/l3/runtime/`（[D-090](../../../决策日志.md) 落点 A）。拆三叶的边界是循环的**三段可独立验证的能力**：

| 叶 | 能力 | 依赖 |
| --- | --- | --- |
| [`.1`](T-AGT-004.1-工具目录消费与循环工作上下文装配.md) | 工具目录消费 + **循环工作上下文**装配（含截断 + `log_ref` 指针） | [`T-AGT-003`](T-AGT-003-工具目录读面.md) |
| [`.2`](T-AGT-004.2-循环驱动、协议端口与上界.md) | **协议端口**（工具调用协议可替换）+ 循环驱动 + **双上界** | [`.1`](T-AGT-004.1-工具目录消费与循环工作上下文装配.md) · [`T-AGT-001`](T-AGT-001-LLM工具调用通道.md) |
| [`.3`](T-AGT-004.3-产出接入、留痕与失败语义.md) | 产出接入既有渲染 + `agent_run_id` 留痕 + 失败与降级语义 | [`.2`](T-AGT-004.2-循环驱动、协议端口与上界.md) |

**拆分依据**：命中[拆分触发](../../../工作流.md)三条——GWT 合计 > 5 · 跨 [05 §10](../../../../docs/技术架构-v2/05-L3-对话主入口.md) / [01 §2](../../../../docs/技术架构-v2/01-平台共享契约.md) / [01 §4](../../../../docs/技术架构-v2/01-平台共享契约.md) / [01 §5](../../../../docs/技术架构-v2/01-平台共享契约.md) 多个契约小节 · 单次预计会话轮次 > 20。三段的**失败面与验证面互不重叠**（上下文装配是纯函数；驱动要 Fake 端点；产出要渲染断言），故可分叶。
