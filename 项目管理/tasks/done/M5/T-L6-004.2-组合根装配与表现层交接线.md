# T-L6-004.2 · 组合根装配与表现层「交 Studio」动作

## 目标
把 [`.1`](T-L6-004.1-L6侧翻译与Studio交接受体.md) 的 `StudioHandoff` **接进应用**，并让提案卡真的能「交 Studio」：

1. **组合根装配**（[`app.py`](../../../../src/st_agent/app.py)）：组合根立 `DraftIntake(store, skills)`（[T-UI-004.2](../M4/T-UI-004.2-反思中心表现层入口.md) 之前它**从未被装配**，`grep` 零命中）并经 [`build_l6(intake=…)`](../../../../src/st_agent/l6/runtime.py) 建成 `StudioHandoff` 挂 `L6Stack.studio`；`ReflectionFacade` 增两条适配方法（**表现层不 import 各层类型**，口径同既有 `ReflectionFacade`）。
2. **表现层动作**：提案卡的 skill 项给出「交 Studio」动作 → 固定回环路由 → 六态信封；成功后同一张卡给「接受 / 否决」，卡上**显式标注**「画布微调待 Studio 页面」（[T-L6-004 A5](T-L6-004-主动提案落Studio草稿接收面.md)）。
3. **契约先行**（[铁律 8](../../../工程宪法.md)）：先改 [08 §4](../../../../docs/技术架构-v2/08-L6-反思演进.md)（补「衔接 Studio 的落地口径」）与 [01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md)（`proposal_card` 的 skill 项补动作），再改代码。
4. **端到端**：集成套件以**真组合根**（真 `Store` + 真 `SkillRegistry` + 真 `DraftIntake`）钉住「提案 → 交 Studio → 落画布 → 接受落盘」。

**本叶的边界**（不越界）：**不出 Studio 画布页**（[T-L6-004 A5](T-L6-004-主动提案落Studio草稿接收面.md)：`ui/web/js/pages/` 无 studio / canvas，画布渲染是 [story-06](../../../../docs/PRD-v2-Agent/story-06-skill-studio.md) 的独立表现层任务）；**不动**周报第四段 / 训练建议 / 待批准队列的处置三动作（逐字节不变）。

## 验收标准（Given-When-Then）
- **GWT-1 · 组合根装配与适配面**：Given 生产组合根（`build_m4_runtime`），When 取 `M4Runtime.reflection`，Then 它暴露 `handoff_to_studio(proposal_id)` / `decide_studio(proposal_id, action)`，且**表现层不 import** 任何 L1 / L6 类型（`ui` 只经鸭子端口）。子面未接线（`L6Stack.studio is None`）→ 返回 `{"available": false, "reason": …}`，不伪造。
- **GWT-2 · 提案卡「交 Studio」动作**：Given `GET /api/reflection/proposals`，When 渲染 `proposal_card`，Then skill 项的 `actions` 含 `studio`（标签「交 Studio」）；When `POST /api/reflection/proposals/studio`（`{proposal_id}`），Then 经 [`DraftIntake.receive`](../../../../src/st_agent/l1/studio/draft.py) 落画布并回信封（`data` = 画布视图：`base` / 暂定 `flow_id` / 节点数 / 语义违规清单）。**输入类失败就地 `ValueError` → `validation_failed`**；未接线 → `unavailable` + 点名。
- **GWT-3 · 接受 / 否决**：Given 一条已交 Studio 的提案，When `POST /api/reflection/proposals/studio/decide`（`action=accept`），Then 经 L1 `DraftIntake.accept` 落 v1.0 并产生 `change_id`（信封 `data` 携 `flow_id` / `change_id`）；`action=reject` → 不落盘、值逐字节不变；非 `accept|reject` / 未交 Studio / 已处置 → `validation_failed`（点名）。
- **GWT-4 · 真装配端到端**：Given 真组合根的 `rig`（真 `Store` / 真 `SkillRegistry` / 真 `DraftIntake` / 真 `ProposalEngine`），When 检出提案 → 交 Studio → 接受，Then `config` 分区出现 `workflow/<flow_id>.json`、`execution_log` 分区出现 `workflow-change/<change_id>.json`，且 `flow_id` 尾版为 `v1.0`。
- **GWT-5 · 既有面回归**：Given 周报第四段候选 / 训练建议 / 待批准队列，When 处置，Then 三动作口径与返回**逐字节不变**（既有用例零改动仍绿）。

## 假设与前提
- **A1 · 组合根取「L6Stack 挂 StudioHandoff + ReflectionFacade 代理」**——前提：`StudioHandoff` 是 L6 面（[`.1`](T-L6-004.1-L6侧翻译与Studio交接受体.md)），其 `DraftIntake` 依赖 L1 的 `SkillRegistry`，故装配点在组合根 `_build_l6`（那里 `runtime.skills` 可用）；`UiApp` **不加新端口**（Studio 面与反思面同页，经既有 `reflection` 鸭子端口过）。
  **若错的影响**：若判「须新立 `StudioFacade` 独立端口」，返工面＝`UiApp` / `build_ui` / `server.py` 的端口与路由分组。
  **验证方式**：GWT-1 `grep` 断言 `ui/**` 不 import `st_agent.l1` / `st_agent.l6`；`tests/test_layering.py` 不改即绿。
- **A2 · 「交 Studio」是一条固定路由、接受 / 否决是另一条**——前提：既有卡片「处置恒发往固定回环路由」（[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md)），交 Studio 与处置是两种去向，故分两条路由（`/studio` 与 `/studio/decide`），不塞进既有的 `/proposals/decide`（那条属**配置变更流**，与 Studio 落点是两个面）。
  **若错的影响**：若要求合并为一条，返工面＝路由表与 `proposal_card.js` 的路由常量。
  **验证方式**：GWT-2 / GWT-3 断两条路由各自成事；GWT-5 断 `/proposals/decide` 行为不变。
- **A3 · 会话由组合根持有、跨请求经 `proposal_id` 寻址**——前提：[`.1 A2`](T-L6-004.1-L6侧翻译与Studio交接受体.md)（`StudioHandoff` 内存持会话）；表现层无状态（每请求重新按 `proposal_id` 找会话）。
  **若错的影响**：若要求会话跨重启存活，返工面＝[`.1`](T-L6-004.1-L6侧翻译与Studio交接受体.md) 引入落盘（与「编辑期不落盘」冲突）。
  **验证方式**：GWT-3 断同一 `proposal_id` 的 handoff → decide 两请求间会话延续。
- **A4 · 卡片标注「画布微调待 Studio 页面」，不假装有画布**——前提：[T-L6-004 A5](T-L6-004-主动提案落Studio草稿接收面.md)（无画布页，微调只到句柄）。
  **若错的影响**：若要求本叶出画布页，返工面＝本叶范围扩张到页面工程，应另立项（[story-06](../../../../docs/PRD-v2-Agent/story-06-skill-studio.md) 的独立表现层任务）。
  **验证方式**：GWT-2 断画布视图随信封回、卡片文案含标注；`grep` 断言不加画布页文件。
- **A5 · 真装配端到端落 `tests/integration/`，非新立关卡**——前提：[工作流](../../../工作流.md)「跨层装配与端到端验证不按此拆分——归里程碑集成关卡」，而本单无同里程碑关卡可挂（它是 M4 遗留、现归 M5）；[T-INT-005](../M4/T-INT-005-M4集成关卡反思演进与生态闭环.md) 已归档冻结、**不改写**。故端到端以 `tests/integration/` 的用例承载（该套件恒随跑）。
  **若错的影响**：若要求挂关卡，返工面＝[T-INT-006](T-INT-006-M5集成关卡受控自主闭环.md) 的收口范围。
  **验证方式**：GWT-4 在 `tests/integration/test_studio_handoff.py` 用 `rig_m4` 真装配跑通。
