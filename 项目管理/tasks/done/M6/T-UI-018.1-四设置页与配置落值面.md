# T-UI-018.1 · 设置区：四设置页与配置落值面

> [`T-UI-018`](T-UI-018-设置区与全局要素.md) 三叶之一（[D-114](../../../决策日志.md) ①）——把 `/settings` 立起来：页面骨架与 `?view=` 分派，以及**四设置页**（存储 / LLM 提供方 / 数据源 / 隐私）。维护面（备份 / 恢复 / 清空）归 [`.2`](T-UI-018.2-备份恢复与完全清空.md)，网络活动与离线横幅归 [`.3`](T-UI-018.3-网络活动与离线横幅.md)。

## 目标

- **`/settings` 页骨架**——[`pages.js`](../../../../src/st_agent/ui/web/js/pages.js) 挂 `render`（首屏不再走可用性探针），页内按 `?view=` 分派（[11-sitemap §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md)：一屏一路径，子面按页内视图 / 查询串聚合）。本叶立**共享基座**：多段响应装配、页内 tab、设置项经 `setting_panel` 渲染。
- **设置-存储页**——存储位置与大小（[02 §2.1](../../../../docs/技术架构-v2/02-L0-本地优先基座.md)）+ 落盘格式 + 凭据分区锁定态 + 逐分区用量（状态 / 文件数 / 明文字节数）+ **明密双向转换**（[02 §2.2](../../../../docs/技术架构-v2/02-L0-本地优先基座.md)：源不动、写新根）。
- **设置-LLM 提供方页**——提供方主机映射（`llm-provider-host/` 三件；复用 `setting_panel`）+ 已登记端点（`EndpointRegistry`）+ 凭据掩码清单（`CredentialVault`，只显示掩码）+ 凭据新增 / 重设 / 吊销。
- **设置-数据源页**——逐源开关（[story-05](../../../../docs/PRD-v2-Agent/story-05-local-first.md)「数据源逐个可开关」，**新建配置族并真接线**）。
- **设置-隐私页**——数据留存策略（`retention.*`）+ 出网审计开关（`net-audit/enabled`），两者同面、落值走同一条 [01 §7] 统一落值面。

**本批的边界**（不越界）：

- **设置项一律经统一配置注册表**（[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)）——本叶经门面落值，**不旁路写盘**。
- **加密格式是存储根属性，不是配置条目**——故**不**注册进 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)；改格式的唯一路径是 [`Store.convert`](../../../../src/st_agent/l0/storage/store.py)（**源不动、写新根**），本叶只接这一条口。
- **转换不置重启闸门**——它不碰当前根（与 [`.2`](T-UI-018.2-备份恢复与完全清空.md) 的破坏性动作不同类）；但「新根要生效」仍须用户重启进程并指向新根，故**回报里明说**，不靠闸门。
- **备份 / 恢复 / 清空本体归 L0**、**LLM 调用本体归 L0/L1**——本叶只做取数与门，不重造。
- **凭据明文永不出站**——页面只拿 `CredentialView.masked`。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 设置](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的四条屏，When 逐条走查，Then **四条都有可见载体**——存储页（位置 / 格式 / 分区用量 / 明密转换）、LLM 提供方页（映射 / 端点 / 凭据）、数据源页（逐源开关）、隐私页（留存 + 审计）
- GWT-2：Given 任一条设置项，When 改值，Then 经统一配置注册表（[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)）**真写进 `config` 分区**并产生 `change_id` 留痕；取值未变则**不落盘不留痕**；越界条目 / 非法取值回 `validation_failed`
- GWT-3：Given 数据源开关，When 关掉一个源，Then 该源的**全部同步任务**在喂给同步引擎的 `enabled` 映射里为 `False`（开关真生效），且**关注面任务的缺省语义不受影响**（不被顺带打开）
- GWT-4：Given 凭据分区未解锁，When 打开 LLM 提供方页，Then 凭据清单走 `unavailable` + **点名原因**（不是一张空表冒充「没有凭据」）；解锁后列出掩码清单
- GWT-5：Given 面未注入或缺句柄，When 访问四页端点，Then 回 `unavailable` + **点名缺哪一支**，不 500、不装空表
- GWT-6：Given 文案，When 核对，Then 按[契约 9 中性表达](../../../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**
- GWT-7：Given 真组合根 + 真回环服务，When 在 Edge 走查四设置页的取数与改值，Then 全程可用、控制台无新增报错

## 假设与前提

- **A1**：**存储加密格式（含明密转换）不是配置条目**——[02 §2.2](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) 把它定为**存储根的格式属性**（由 `Store.create` / `Store.open` 分派、`Store.convert` 迁移），[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 的注册表登记的是「可配置项」而非「根属性」。**若错的影响**：会为它硬造一条与 `Store` 并行的第二写路径（正是 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md)「逐条目一次落值」所防），并让「删了配置文件 ≠ 改了格式」这一不一致长期存在。**验证方式**：读 [02 §2.2](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) 与 [D-073](../../../决策日志.md)（格式标记 + `convert` 的落点）；本叶的存储页**读** `Store.mode`、写口只接 [`Store.convert`](../../../../src/st_agent/l0/storage/store.py) 这一条，不另造写路径。
- **A2**：**数据源开关的粒度是「源」而消费面是「任务」**——用户看得懂的是源（巨潮 / 深交所 / 东财 …），而 [`InfoSync`](../../../../src/st_agent/l0/info/sync.py) 的 `enabled` 映射按 `task_key` 收。**若错的影响**：若按任务开关，页面上会出现 20+ 条用户无法对应到「一个源」的条目；若只做源级而不派生任务级映射，「关闭舆情抓取」将不生效（映射无人构造 ⇒ 开关是装饰）。**验证方式**：`enabled_task_map` 的键＝非关注面任务的 `task_key`，且被 `InfoSync._is_enabled` 判为跳过（[`tests/l0/test_info_switch_config.py`](../../../../tests/l0/test_info_switch_config.py) 钉住）。
- **A3**：**`<select>` / `<input>` 的值恒为字符串**，故布尔与数值条目在页面上各有对策：布尔走 `enable` / `disable` **两个动作**（动作即取值），数值走 `options` 候选档位 + 服务端按 `value_schema.type` **还原类型**。**若错的影响**：字符串 `"false"` 直接落值会被族的值域门拒（`validation_failed`），页面上的开关会「看起来能点但不生效」。**验证方式**：集成用例断言 `action: disable` 真改 `get_source_switches`；单测钉 `_coerce_value("30") == 30`。
- **A4**：**凭据分区在真口令下已解锁**——进程级口令由启动参数提供（[`__main__`](../../../../src/st_agent/__main__.py) 的开局探测 ①），故页面**不需要**再要一次口令；未解锁时走 `unavailable` + 点名，而不是在页面上再开一个口令输入。**若错的影响**：若改为页面内解锁，会造出第二条解锁路径，与 [02 §3](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) 的「惰性解锁」口径并存。**验证方式**：集成用例断言真口令下 `store.secrets_unlocked is True`；未解锁分支见 [`tests/ui/test_ui_settings.py`](../../../../tests/ui/test_ui_settings.py) 与 [`_llm_parts`](../../../../src/st_agent/ui/app.py) 的显式分支。
