# T-UI-017 · 触达区：日报、历史与预算渠道配置

> **分组节点**（[D-118](../../../决策日志.md) ①，2026-10-12 拆分）：交付由 [`.1`](T-UI-017.1-日报与推送历史.md)（日报与推送历史）· [`.2`](T-UI-017.2-预算渠道与情境模式.md)（预算、渠道与情境模式配置）· [`.3`](T-UI-017.3-疲劳反馈与调整询问.md)（疲劳反馈与调整询问）三叶承接——本文件保留原立项的屏清单与验收，供父节点状态派生（[检查 7](../../../tools/verify_docs.py)）。

> **M6 七面功能叶之一**（[D-103](../../../决策日志.md)）。补上 [11-sitemap §2 触达](../../../../docs/PRD-v2-Agent/11-sitemap.md)——L5 Ambient Delivery 在 M3 已交付投递闭环（`T-INT-004` / `T-L5-*`），但其**用户可见面**（日报 / 历史 / 预算 / 渠道 / 情境模式 / 疲劳反馈）**全无页面**。

## 目标

把 [11-sitemap §2 触达](../../../../docs/PRD-v2-Agent/11-sitemap.md) 声明的六条屏做成可用界面：

- **每日报告页 / 推送历史时间线**
- **注意力预算配置页 / 渠道配置页 / 情境模式切换器**（三维矩阵与五情境模式的设置面，`T-L5-001.2` 已交付配置面）
- **推送疲劳反馈对话框**

**本批的边界**（不越界）：

- **不重造 L5 投递逻辑**——本叶只呈现与配置，不改投递编排 / 渠道适配 / 升级链。
- **反馈采集复用 `feedback_capture` 型**——五动作按钮组已是已实现型，本叶只做宿主与取数。
- **趋势 / 热力读面若需新型，归 [`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)**（预留型 `trend_chart` / `heatmap`）。

## 验收标准（Given-When-Then）

- GWT-1：Given [11-sitemap §2 触达](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的六条屏，When 逐条走查，Then 每条有可见载体——日报、历史时间线、预算配置、渠道配置、情境模式切换、疲劳反馈对话框
- GWT-2：Given 注意力预算三维矩阵与五情境模式，When 打开配置页，Then 可查看与改值，改值经 `setting_panel`（**带动作**）并留痕
- GWT-3：Given 一条推送，When 反馈采集，Then 五动作（[§3.6](../../../../docs/PRD-v2-Agent/11-sitemap.md)）齐备、原因入口独立；疲劳判定触发调整询问
- GWT-4：Given 数据面非 `ok`，When 呈现，Then 按六态如实（[§3.6](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的阅读 / 反馈流），**不静默留空**
- GWT-5：Given 文案，When 核对，Then 按[契约 9 中性表达](../../../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**（推送无人格化措辞）
- GWT-6：Given 真组合根 + 真回环服务，When 在 Edge 走查「日报 → 反馈 → 历史 → 预算 / 渠道 / 情境配置」，Then 全程可用、控制台无新增报错
