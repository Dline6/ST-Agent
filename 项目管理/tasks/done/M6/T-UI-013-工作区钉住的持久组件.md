# T-UI-013 · 工作区：钉住的持久组件

> **M6 七面功能叶之一**（[D-103](../../../决策日志.md)）。承接 [11-sitemap §2 工作区](../../../../docs/PRD-v2-Agent/11-sitemap.md)——生成式 UI 里「钉」下来的看板 / 图表 / 卡片 / 回测报告在对话之外**持久留驻**、可刷新可下钻。

## 目标

把 [11-sitemap §2 工作区](../../../../docs/PRD-v2-Agent/11-sitemap.md) 声明的一条屏做成可用界面：

- **钉住的持久组件**：看板 / 图表 / 卡片 / 回测报告；支持**刷新** / **下钻**（跳转推理链或 Skill 详情）/ **取消钉住**

**本批的边界**（不越界）：

- **「钉」入口归 [`T-UI-012`](T-UI-012-Chat主界面对话流与生成式UI宿主.md)**——本叶只消费被钉住的描述，不重造入口。
- **下钻终点归属于各分区叶**——「跳转推理链」落 [`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md)、「跳 Skill 详情」落 [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md)；本叶只出跳转，不建目标页。
- **新形态（如钉板 `pinned_board`）归 [`T-UI-010`](T-UI-010-契约先行组件型补齐与页面集口径.md)**——本叶不自行登记组件型。

## 验收标准（Given-When-Then）

- GWT-1：Given 一个被钉住的组件，When 打开工作区，Then 该组件以**持久**形态呈现（非对话内一次性），且刷新 / 下钻 / 取消钉住三个动作齐备
- GWT-2：Given 点「下钻」，When 目标为推理链或 Skill 详情，Then 跳到对应页（[`T-UI-016`](T-UI-016-推理区触发进度分歧图与视角详情.md) / [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md)），**不**在本页内联一份私有实现
- GWT-3：Given 被钉组件的数据面非 `ok`，When 呈现，Then 按 [01 §5 六态](../../../../docs/技术架构-v2/01-平台共享契约.md) 如实（`empty` 说原因 / `unavailable` 说不可用原因与最后更新），**不静默留空**
- GWT-4：Given 文案，When 核对，Then 按[契约 9 中性表达](../../../../docs/PRD-v2-Agent/10-platform-capabilities.md)撰写，**无拟人化**
- GWT-5：Given 真组合根 + 真回环服务，When 在 Edge 走查「钉 → 工作区呈现 → 刷新 → 下钻 → 取消钉住」，Then 全程可用、六态如实、控制台无新增报错

## 假设与前提

（2026-10-11 ④ 对齐实填；人已确认）

- **A1** —— [01 §5](../../../../docs/技术架构-v2/01-平台共享契约.md) 允许工作区的 `data` 为**描述序列**（[§12](../../../../docs/技术架构-v2/01-平台共享契约.md) 同批写明「工作区是**承载页**、钉住物按其**自身型**渲染、看板即该序列、`pinned_board` 保留预留」），故渲染面须支持对序列逐项按型渲染。**若错的影响**：若契约实为要求另立容器型，则须先改 `01 §12`（[铁律 8](../../../工程宪法.md)）再改码，返工面＝渲染路径 ＋ 组件注册表两处。**验证方式**：`GET /api/workspace/pins` 出 ≥2 个钉住项时逐项按自身型渲染，页面**不出现** JSON 直灌（集成用例 ＋ 浏览器走查）。
- **A2** —— 本期**唯一**真有纯只读取数口、可作重解析来源的型是 `context_card`（`DialogFacade.context_card()`，经 `/api/chat/context`）。**若错的影响**：若另有型也有纯读来源而本叶漏接，那些型的刷新走 `unavailable` ＋ 点名——这是**如实降级**（[01 §5](../../../../docs/技术架构-v2/01-平台共享契约.md)），不构成错误，无返工。**验证方式**：用例钉「带 `source_key` 的钉住项刷新成功且**保留原 `description_id`**」＋「无 `source_key` 的钉住项刷新回 `unavailable` ＋ 点名」。
- **A3** —— 「钉」入口在 [`chat.js`](../../../../src/st_agent/ui/web/js/pages/chat.js)（[`T-UI-012.3`](T-UI-012.3-生成式UI宿主.md) 交付），**落点**在本叶；同批把该按钮由占位改为真发 `POST /api/workspace/pin`（人已确认接上）。**若错的影响**：该按钮实属他叶范围时，返工面＝一处前端调用 ＋ 其断言。**验证方式**：浏览器走查「钉 → 工作区出现该组件」。
- **A4** —— 下钻目标页部分尚未落地（`/skills` 归 [`T-UI-015`](T-UI-015-能力区Skill库MCPHub与Studio附加面.md)，仍 `todo`）⇒ 下钻按 `unavailable` ＋ 点名呈现，**不**静默留白、**不**在本页内联一份私有实现。**若错的影响**：该降级分支不触发，无返工。**验证方式**：走查点「下钻到 Skill 详情」时出 `unavailable` ＋ 点名 `T-UI-015`。
- **A5** —— 钉住物落盘取 L0 **既有** `config` 分区（新增分区须同批改 [`partition.py`](../../../../src/st_agent/l0/storage/partition.py) 与 `tests/l0/test_storage.py::test_seven_partitions_registered`，属不必要的契约面扩张）。**若错的影响**：返工面＝分区注册表 ＋ 存储用例。**验证方式**：`tests/l0/test_storage.py` 的七分区断言**不动**而全绿。
