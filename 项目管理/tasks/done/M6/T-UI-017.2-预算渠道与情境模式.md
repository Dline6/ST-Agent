# T-UI-017.2 · 触达区：预算、渠道与情境模式配置

> [`T-UI-017`](T-UI-017-触达区日报历史与预算渠道配置.md) 三叶之一（[D-118](../../../决策日志.md) ①）——触达区的**设置面**：注意力预算三维矩阵、五情境模式切换器、逐级别渠道链。日报与推送历史归 [`.1`](T-UI-017.1-日报与推送历史.md)，疲劳反馈归 [`.3`](T-UI-017.3-疲劳反馈与调整询问.md)。

## 目标

- **注意力预算配置页**——**情境 × 时段 × 内容类型**三维矩阵（[07 §2](../../../../docs/技术架构-v2/07-L5-主动触达.md)）：**当前情境**下的逐格条目可读改（允许级别集合 + 每格上限 `max_per_slot`）；时段集合**本批只读呈现**（整表替换式 `set_slots` 要「覆盖全天且互不重叠」的全集，面板的逐条形态表达不了——不半途造一套编辑器）。呈现「注意力预算地图」。
- **情境模式切换器**——五情境模式（`workday` 工作日 / `weekend` 周末 / `business_trip` 出差 / `vacation` 休假 / `urgent` 紧急）当前态可读、可切换。
- **渠道配置页**——逐级别（`emergency` / `important` / `routine`）的**有序渠道链**（桌面通知 / TTS / 邮件 / IM Webhook）+ 每级未读等待；**断网补发开关**（`channel-delivery.resend-on-reconnect`）。
- 三面均经 [`setting_panel`](../../../../src/st_agent/ui/web/js/plugins/reflection/setting_panel.js)（面键 `delivery-config`）呈现；**写面归 L5 自有 API**——[07 §2](../../../../docs/技术架构-v2/07-L5-主动触达.md) / [§3](../../../../docs/技术架构-v2/07-L5-主动触达.md) 已定「取值为对象 / 列表的条目**不在** [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 统一标量落值面内」，故经组合根转到 `AttentionBudget.set_cell` / `set_slots` / `switch_mode` 与 `ChannelPolicies.set_policy` / `set_resend_on_reconnect`，**留痕经 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 的 `ChangeRecord`**（`change_id` 可回溯、可回滚）。

**本批的边界**（不越界）：

- **预算判定与渠道投递归 L5**——本叶只读矩阵与链、写配置，不改 `AttentionBudget.resolve` 与 `ChannelDispatcher` 的既有语义。
- **「按日历自动切换」不交付**——[07 §2](../../../../docs/技术架构-v2/07-L5-主动触达.md)：用户日历面尚未交付，故情境只做**手动切换**，页面上**不假装有日历**（缺面即显式不可用）。
- **渠道凭据（SMTP / Webhook）不在本叶**——凭据落 [02 §3](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) `secrets` 分区，其读写面归设置区（`T-UI-018.1` 的 LLM / 数据源面）；本叶只配「级别 → 渠道链」。

## 验收标准（Given-When-Then）

- GWT-1：Given 三维矩阵，When 打开预算页，Then 逐格可查看（允许级别集合 + 每格上限）与改值；改值经 `set_cell` **落盘并产生 `change_id` 留痕**；越界取值（空级别集 / `max_per_slot < 1`）⇒ `validation_failed` + 点名原因
- GWT-2：Given 五情境模式，When 切换，Then `switch_mode` 生效、当前态读面随之变化并留痕；**「按日历自动」不给入口**（若有则显式不可用 + 点名归属），**不假装**
- GWT-3：Given 逐级别渠道链与未读等待，When 改链序或等待，Then 经 `set_policy` 落值并留痕；**链长与等待长度的不变量**（`len(waits) == len(channels) - 1`）由后端校验，非法即 `validation_failed`
- GWT-4：Given 未注入预算面或渠道面，When 访问配置页，Then 回 `unavailable` + **点名缺哪一支**，不 500、不装空表
- GWT-5：Given 真组合根 + 真回环服务，When 在 Edge 走查「改一格 → 切情境 → 改渠道链 → 补发开关」，Then 全程可用、控制台无新增报错

## 假设与前提

- **A1**：**复合取值（矩阵格位 / 渠道链）不经统一标量落值面**——[01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 已定「取值为对象 / 列表的条目不在统一落值面内，其写面归各自 owner 的 API」，[07 §2](../../../../docs/技术架构-v2/07-L5-主动触达.md) / [§3](../../../../docs/技术架构-v2/07-L5-主动触达.md) 同批把格位与渠道链的写面点给 `AttentionBudget` / `ChannelPolicies`。故本页的 `setting_panel` 只是**呈现形态**（「候选项 + 应用动作」），**动作落点**是 L5 自有 API，**不**经注册表 `apply`。**若错的影响**：把对象塞进统一标量落值面会造出与 L5 校验并行的**第二条写路径**（[铁律 8](../../../工程宪法.md) 的契约冲突）。**验证方式**：读 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 的「落值语义是逐条目一次落值」段与 `budget.py` / `channel_policy.py` 的写面签名；集成用例断言改值后 `AttentionBudget.map()` / `ChannelPolicies.map()` 真变且 `change_id` 落 `execution_log/*-change/`。
- **A2**：**情境模式切换是标量、经哪条面都不冲突**——`attention-budget.current-mode` 取值是枚举标量（在统一落值面内），但 `switch_mode` 另返 `ChangeRecord` 且带 `trace_ref`。本叶统一走 **L5 自有写面**（`switch_mode`），使三条写口（格位 / 时段 / 情境）同源、留痕一致；**不**为它单开一条注册表 `apply` 路径。**若错的影响**：若要求情境切换走注册表，则同一页出现两套留痕路径。**验证方式**：读 `switch_mode` 的返回类型（`ChangeRecord|None`）与 `AttentionBudget.entries()`；集成用例断言切换后 `mode` 读面变化且留痕落 `attention-budget-change/`。
- **A3**：**矩阵按「当前情境」分段呈现**——全 cross-product 是 5 情境 × 5 时段 × 4 内容类型 = 100 格（[07 §2](../../../../docs/技术架构-v2/07-L5-主动触达.md) 取 `default_budget` 的 5 个缺省时段），逐格平铺成 `setting_panel` 条目会不可用。故 `GET /api/delivery/config` **只列当前情境模式下的格位条目**（缺省 5 × 4 = 20 条），情境切换器作为独立条目——切模式即重取该模式的格位。**若错的影响**：若产品要求一次看全 100 格，应改为 `table` 矩阵 + 选中格编辑器（页面形态变，`setting_panel` 仍承载选中格的编辑）。**验证方式**：读 `DEFAULT_SLOTS`（5 条）与 `map()` 的格数；集成用例断言条目数随 `current_mode` 变化。
- **A4**：**L5 未注入 / 条目损坏的降级是可读的**——`AttentionBudget` 条目缺失 / 损坏 ⇒ 回落内置缺省矩阵（`default_budget`）且 `source="default"` 可在 `BudgetCellView` 上读出（区别于 `"configured"`）；`ChannelPolicies` 同构（`DEFAULT_POLICIES`）。故页面对「未配置」与「已配置」**可分辨**，不把缺省冒充为用户配置。**若错的影响**：用户无法判断某格是「自己设过」还是「还是默认」。**验证方式**：读 `BudgetCellView.source` 与 `ChannelPolicy.source` 字段；集成用例断言未改过的格为 `default`、改过为 `configured`。
