# T-UI-017.1 · 触达区：日报与推送历史

> [`T-UI-017`](T-UI-017-触达区日报历史与预算渠道配置.md) 三叶之一（[D-118](../../../决策日志.md) ①）——把 `/delivery` 立起来：页面骨架与 `?view=` 分派，以及**每日报告页**（四段 + 报告时间 / 段开关）与**推送历史时间线**。预算 / 渠道 / 情境配置归 [`.2`](T-UI-017.2-预算渠道与情境模式.md)，疲劳反馈与调整询问归 [`.3`](T-UI-017.3-疲劳反馈与调整询问.md)。

## 目标

- **`/delivery` 页骨架**——[`pages.js`](../../../../src/st_agent/ui/web/js/pages.js) 挂 `render`（首屏不再走可用性探针），页内按 `?view=` 分派（[11-sitemap §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md)：一屏一路径、子面按页内视图 / 查询串聚合）：缺省＝每日报告，`?view=history`＝推送历史时间线。本叶立**共享基座**：多段响应装配、页内 tab、`setting_panel` 宿主。
- **每日报告页**（[11-sitemap §2.1](../../../../docs/PRD-v2-Agent/11-sitemap.md)：复用 `report_card`）——按日读取（`stored(day)`）/ 生成（`build(day)`）；四段如实呈现（`yesterday_review` 昨日回顾 / `today_focus` 今日关注 / `lens_digest` 多视角摘要 / `memory_update` Memory 更新摘要），**逐段空态显式**；**四段皆空** ⇒ 正文「今天没有需要打扰你的事」，**不硬凑**；**多视角摘要逐视角并列、不合并分歧**（[铁律 4](../../../工程宪法.md)）。
- **报告生成时刻**——`daily-report.time` 经 [`setting_panel`](../../../../src/st_agent/ui/web/js/plugins/reflection/setting_panel.js)（面键 `delivery-config`，与预算 / 渠道同键）读改；**到点触发不本叶**（常驻循环 `tick` 内的 `due` 判定已在）。**四段开关与订阅渠道（`daily-report.template`）本批只读**——它是对象取值（写面归 L5 `set_template`），而结构化编辑（逐段开关 + 渠道链）在本批的面板形态里表达不了，故不半途造一套。
- **推送历史时间线**（[11-sitemap §2.1](../../../../docs/PRD-v2-Agent/11-sitemap.md)：新登记 `timeline_view`）——逐条 `DeliveryRecord` 按时刻组织的只读呈现（渠道 / 级别 / 状态 / 时刻）；`pending_reconnect` 态**如实标注「离线，暂无法发送」**。
- **已生成报告清单**——哪些日已有报告（供历史翻页与「今日是否已生成」判定）。

**本批的边界**（不越界）：

- **日报组装归 L5**（[`DailyReportBuilder`](../../../../src/st_agent/l5/daily_report.py)）——本叶只取数与呈现，不改四段取材口径。
- **到点生成与投递编排不在本叶**（归组合根常驻循环，[T-INT-004](../M3/T-INT-004-M3集成关卡主动触达投递闭环.md) 已落）。
- **日报不重造图表段**——见 `## 假设与前提` A3。

## 验收标准（Given-When-Then）

- GWT-1：Given 某日已有报告，When 打开日报页，Then 四段如实呈现；某段无内容 ⇒ 该段**显式空态**；四段皆空 ⇒ 正文「今天没有需要打扰你的事」，**不硬凑内容**
- GWT-2：Given 某日尚无报告，When 打开，Then 回 `empty` + 原因（**不是一张空白的假报告**）；点「生成」⇒ 经 `build` 落 `execution_log/daily_report/<day>.json` 并读出
- GWT-3：Given 推送历史留痕，When 打开历史，Then 逐条呈现（渠道 / 级别 / 状态 / 时刻）；`pending_reconnect` 态标注「离线，暂无法发送」（[07 §3](../../../../docs/技术架构-v2/07-L5-主动触达.md)），**不静默留空**
- GWT-4：Given 未注入日报面或编排面，When 访问两视图端点，Then 回 `unavailable` + **点名缺哪一支**，不 500、不装空表
- GWT-5：Given 真组合根 + 真回环服务，When 在 Edge 走查「日报 → 生成 → 历史」，Then 全程可用、控制台无新增报错

## 假设与前提

- **A1**：日报**按日读取的键是 `YYYY-MM-DD` 本机日历日**，与 `build(day: date)` 同口径；配置项 `daily-report.time`（当日生成时刻）与「读哪一天」**正交**。**若错的影响**：把「报告时间」误当查询键会造出永为空的日期报告（页面「生成过也读不到」）。**验证方式**：集成用例按固定 `day` 走查 `build → stored(day)` 往返；读 [`daily_report_store.path_for`](../../../../src/st_agent/l5/daily_report_store.py) 确认路径即 `<day>.json`。
- **A2**：`timeline_view` 的 `entries` 形状（`at` / `kind` / `state` / `content` / `trace_ref`）已由 [`T-UI-010.1`](T-UI-010.1-组件型补齐屏形态对位与四型落地.md) 实现且**已有消费方**（记忆区时间线视图），本叶是[11-sitemap §2.1](../../../../docs/PRD-v2-Agent/11-sitemap.md) 明列的**第二个消费区**——故本叶**不改渲染件**。**若错的影响**：需改 [`timeline_view.js`](../../../../src/st_agent/ui/web/js/plugins/l3/timeline_view.js)，跨区影响记忆区既有用例。**验证方式**：读该渲染件的槽表 + 记忆区既有用例；集成用例断言条目的键名与槽表一致。
- **A3**：**日报不产图表数据**——[`DailyReportBuilder`](../../../../src/st_agent/l5/daily_report.py) 的四段是**中性陈述行 + 逐视角摘要**（文本），[11-sitemap §2.1](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的「趋势 / 热力段走 `trend_chart` / `heatmap`」在 L5 现行产出面上**无对应数据**。故本叶以 `report_card` 文本段呈现，**不伪造**图表；若产品要求图表段，须先由 L5 产出结构化数据（另立任务）。**若错的影响**：日报页少两段图表（功能缺失，非缺陷）。**验证方式**：读 `ReportSection` 形态（`lines` 为文本）；真组合根上 `/api/delivery/report` 出四段文本。
- **A4**：页面的「生成」是**对同一纯函数的显式重放**——日报生成本是常驻循环 `tick` 内 `due` 判定的职责，而 `build(day)` 是「显式时刻 / 留痕状态的纯函数」（[07 §5](../../../../docs/技术架构-v2/07-L5-主动触达.md)：同一 `(day, 留痕状态)` 恒得同一结论、写同一路径），故页面触发生成**不新增第二条生成逻辑**、不产生重复报告。**若错的影响**：若产品要求页面**不得**触发生成（只读），该动作退化为「仅当无报告时提示等待」。**验证方式**：集成用例断言两次 `build` 写同一路径、`stored(day)` 幂等。
