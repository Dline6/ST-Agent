# T-L4-004.1 · L4 侧分歧图视图投影与一致性语义

## 目标

交付 [06 §5](../../../../docs/技术架构-v2/06-L4-多视角推理.md) 分歧图的 **L4 侧视图数据面**与 [§6](../../../../docs/技术架构-v2/06-L4-多视角推理.md) 的一致性语义：把 [`T-L4-002`](T-L4-002-多视角执行编排.md) 的 `DeliberationResult`（全部参与视角的立场 / 信心度 / 链锚）与 [`T-L4-003`](T-L4-003-交叉对照MiniDebate冲突质询.md) 的 `DisagreementMap`（一致点 / 分歧点 / 盲点 / 证据网络 / Mini Debate 段）合成一份**视图就绪**的 `DivergenceView`——矩阵视图（视角 × 结论）的**取数面只能在这一层**（`DisagreementMap` 只带冲突对各两方立场，矩阵要**全部**参与视角）。

**范围边界（关键）**：本叶**只到 L4 侧数据面**。`divergence_map` 的 UI 描述件与组件升真属 [`T-L4-004.2`](T-L4-004.2-divergence_map描述件与组件升真.md)（[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md) 规定描述由 **L3 产出**，且 `test_layering.py` 的 `LAYER_ORDER` 是 `l3 < l4` —— L3 不得 import L4，故 `.2` 按属性取值收本叶产物）；接进 L3 总线与组合根属 [`T-INT-003`](T-INT-003-M2集成关卡多视角决策闭环.md)。

**架构级红线（06 §3／[铁律 4](../../../工程宪法.md)）**：`DivergenceView` **无**「汇总结论」字段——不合并分歧、不给统一建议；结论与证据**并列**呈现。L4 **不落盘**（视图为计算产物）。

## 验收标准（Given-When-Then，从 Story 4 + 06 §5–§6 抄，限本叶范围）

- **GWT-1**（矩阵视图取数面）Given 一次 Deliberation 结果与对照产物，When `build(result, map)`，Then `rows` 逐行给出**每个参与视角**的 `lens_id` / 中性名 / `stance` / `confidence` / `trace_id`（矩阵视图「视角 × 结论」的数据源）；`insufficient-data` 视角**照常成行**（如实呈现数据不足，不因降级而被剔除）。
- **GWT-2**（网络视图 + 四字段透传）Given 对照产物，When 生成视图，Then `agreements` / `disagreements` / `blind_spots` / `evidence_network`（节点 + 引用边）**原样承载**（辅视图网络图与摘要的取数面）；Mini Debate 段以 `conflicts` 承载为 `ConflictEntry`（`key` + `analysis`），**`key` 由本叶生成**（`.2` 用它并联生成文案槽，避免两处各造一次稳定键）。
- **GWT-3**（一致性语义，§6）Given 全部参与视角均有结论且立场唯一，When 生成视图，Then `unanimous=True`、`uniform_stance` 为该立场、`unanimity_notice` 为中性提示「罕见的高度一致，请警惕群体思维」（**过 [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md)**）；Given 存在 `insufficient-data` 视角或立场不唯一，Then `unanimous=False` 且 `unanimity_notice` 为空（不臆断高度一致）。**证据面不受一致性影响**（四条字段恒完整）。
- **GWT-4**（无合并结论）Given 视图模型，When 检视字段，Then **不存在** `verdict` / `recommendation` / `summary` 等合并结论字段（`hasattr` + `model_dump` 双向钉，沿用 `T-L4-003` 的 `test_no_merged_verdict` 手法）。
- **GWT-5**（生成文案过 §6）Given 阵容注入与未注入两种装配，When 生成视图，Then 视角名取 `Lens.name`（注册期已过 [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md) 保存校验）、缺省退回 `lens_id`（中性且不臆造）；`unanimity_notice` 逐条过 `check_output`，命中即不送达。

## 假设与前提

- **A1**：一致性判据＝「**全部参与视角均有结论**（无 `insufficient-data`）且立场唯一」。**若错**（要求放宽为多数同向即提示）：只改 `_uniform_stance` 谓词。**验证**：GWT-3 两用例（全一致 → 提示 / 含数据不足 → 不提示）。
- **A2**：`ConflictEntry.key` 由本叶生成（编排序号 `dfv-conflict-<n>`，稳定可复算），供 `.2` 并联生成文案槽——避免「键在哪造」两处各造一次而漂移。**若错**（要求按主题/视角对派生键）：只改键的算法，`.2` 的并联契约不变。**验证**：`test_conflict_entries_are_keyed`。
- **A3**：视角名经**鸭子注入的 roster** 取；未注入（或寻址失败）退回 `lens_id`——同 [`l4/crosscheck.py`](../../../../src/st_agent/l4/crosscheck.py) `_label` 的既有口径，**不臆造名字**。**若错**（要求未注入即报错）：改一处 fallback 为 `unavailable`。**验证**：GWT-5 两用例。
- **A4**：本叶**不碰** `divergence.py` 既有四字段模型（`DisagreementMap` 一行不改），视图是其**派生层**——故 `T-L4-003` 的既有用例不受影响。**若错**（若判定应扩 `DisagreementMap` 而非新增视图）：须回头动已 `done` 的 `T-L4-003` 产物与其 `done` 状态。**验证**：`tests/l4` 全绿且 `test_crosscheck.py` 零改动。
