# T-L2-005 · 券商账单导入初始画像（通用 CSV/Excel + 用户列映射）

## 目标

兑现 [04 §8](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 末条的「从券商账单等外部数据导入初始画像」（原文标「实现阶段评估」，销 [L2 册 `C1`](../../../遗留问题/L2-遗留问题.md)）：交付 **L2 侧账单导入引擎**——把用户导出的 CSV/Excel 账单（列结构因券商而异）经**用户列映射**装入 `attention`（持仓）与 `history`（决策事件）节点，导入数据同样过隐私分级、走用户确认门与审计留痕。

产品口径（[D-068](../../../决策日志.md)）：**不预置逐券商适配器、不做 PDF 版式解析**——以「通用 CSV/Excel 解析 + 导入时用户指定列映射」覆盖各家券商导出格式的差异；PDF 版式解析后续按需另立。这与 [`T-L2-004.3`](../M1/T-L2-004.3-记忆片段导入与继承.md) 的 `.stmem` 片段导入是**两条独立通道**（后者入 `source: inferred` 他人陈述，本通道入 `user_stated` 本人数据）。

## 验收标准（Given-When-Then）

- **GWT-1 · 列映射契约与校验**：Given 一份 CSV/Excel 账单（表头位置与列名因券商而异），When 用户逐列指定「账单列 → 节点字段」的映射，Then 产出**映射配置**（可保存复用、可复核），且**必需字段未映射即显式报缺**（不臆测列名、不静默跳过）。
- **GWT-2 · 持仓入库为 `attention`**：Given 已映射的账单，When 确认导入，Then 建 `attention` 节点，`stock_id` 列表取自映射的持仓列（代码归一与未收录口径见 A3）。
- **GWT-3 · 决策事件入库为 `history`**：Given 含成交/委托记录的账单，When 确认导入，Then 建 `history` 节点（决策事件），字段逐一对上映射。
- **GWT-4 · 来源与写入路径**：Given 一次导入，When 入库，Then 节点 `source=user_stated`（用户上传的本人数据，同 Onboarding），按 [§3.2](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) **直写**、不过 [§4](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 自主写入白名单与冲突队列；置信度取 `user_stated` 基线；按 [§1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) **不带** `provenance`。
- **GWT-5 · 导入治理（隐私 / 确认 / 幂等 / 留痕）**：Given 账单含 `private` / `sensitive` 级字段，When 导入，Then 过 [§8](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 隐私分级并**展示「本次将写入的节点」清单待用户确认**后入库；同一账单**重复导入幂等**（业务键去重，不产生重复节点、不静默覆盖）；每次导入落 `execution_log` 分区一条审计记录（确定性摘要 id）。

## 假设与前提

- **A1 · 导入节点 `source: user_stated`**：券商账单是**用户上传的本人数据**（同 Onboarding 的用户提供口径），故按 [§3.2](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 直写、不过 [§4](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) 白名单与冲突队列，且按 [§1](../../../../docs/技术架构-v2/04-L2-记忆图谱.md) **不得带 `provenance`**（`.stmem` 导入是 `inferred` 他人陈述，与本通道不同）。若错（须判为 `inferred` 或新增第三类来源）：返工面 = 入库构造的 `source` / `provenance` + 置信度基线 + 可能新增来源枚举（动 §1，属契约变更）。
- **A2 · 列映射由用户在导入时指定**（不预置逐券商适配器，[D-068](../../../决策日志.md)）：账单列名与节点字段的对应由用户认定，引擎只做校验与转换。若错（须内置逐券商适配器）：返工面 = 新增券商适配模块 + 映射推断，且口径回退到「覆盖哪些券商」的产品决策。
- **A3 · `stock_id` 归一与未收录代码**：账单常给裸代码 / 名称，`attention.stock_id` 需 `sh.` / `sz.` 前缀形态（[01 §1](../../../../docs/技术架构-v2/01-平台共享契约.md)）。未收录代码（北交所等）的处理**沿 L0 的 [D-032](../../../决策日志.md) 口径**（过滤 + 显式标注），L2 侧**不**为其补建主档。若错（须在 L2 侧另定）：返工面 = 归一规则 + 未收录计入与报告。
- **A4 · 交互面归 L3/UI**：本任务只交付 **L2 侧引擎**（文件 → 映射 → 节点）；选文件、拖列映射、确认卡的**渲染**归 [05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) / [`T-UI-*`](../M1/T-UI-001-表现层骨架与本地服务通信面.md)。若错（须本任务含交互）：返工面 = 本任务溢出 L2 层，须按铁律 7 拆出 L3/UI 任务。消费端口若需新契约，届时按 [铁律 8](../../../工程宪法.md) 先改 01 / 05 再改代码。
- **A5 · Excel（`.xlsx`）解析可能引入新依赖**：CSV 走标准库即可；若支持 Excel 需 `openpyxl` 类库（是否入 `pyproject` 运行时依赖由实现期定，参考 `baostock` 走可选 extra 的先例）。若错（不入依赖）：返工面 = 仅支持「Excel 另存为 CSV」并显式告知用户。
