# T-L1-013.2 · L1 容器本体与装载入口

## 目标

在 L1 落地泛化容器本体：`src/st_agent/l1/pack/`——`ResourceEntry(kind, version, payload)`、kind → loader 的**开放注册**、官方资源**容器**，以及统一装载入口 `load_official_pack(...)` 按 kind 分发。**Skill 种子并入 `skill` kind**（现 [`l1/skills/pack.py`](../../../../src/st_agent/l1/skills/pack.py) 的 `OFFICIAL_PACK` 成为容器的一类），保持 `install_official_pack` 既有播种行为不变。

## 验收标准（Given-When-Then）

- **GWT-1 · 容器与 kind 注册**：Given 空的 loader 注册表，When 注册一个 kind 的 loader 并装入该 kind 的资源条目，Then 容器按 kind 分派到对应 loader；**未注册任何 loader 的 kind 被显式拒**（不静默忽略、不猜）。
- **GWT-2 · 幂等装载**：Given 已装入的条目，When 再次装入同 kind 同 version，Then **不重复装载、不静默覆盖**（沿用 `ensure_official_pack` 的幂等口径）；异版本按 [01 §9](../../../../docs/技术架构-v2/01-平台共享契约.md) 语义显式呈现变更。
- **GWT-3 · Skill 种子仍生效**：Given 官方 Pack，When 走泛化容器装入，Then 12 个 Skill 描述体的播种结果与 [`install_official_pack`](../../../../src/st_agent/l1/skills/official/install.py) **逐字节一致**（既有 `tests/l1` 用例不变红）。
- **GWT-4 · 版本与形状校验**：Given 一条 `ResourceEntry`，When 构造，Then `kind` 非空、`version` 合规（[01 §9](../../../../docs/技术架构-v2/01-平台共享契约.md) 语义）、`payload` 原样承载（容器**不解读** payload——形态归各 kind 的 loader）。

## 接口面

- **输入（消费的前置接口）**
  - `.1` 交付：[01](../../../../docs/技术架构-v2/01-平台共享契约.md) 新增「官方资源包」节的容器契约（`ResourceEntry` / kind 注册 / 装载语义）
  - 既有：[`l1/skills/pack.py`](../../../../src/st_agent/l1/skills/pack.py)（`OFFICIAL_PACK` 12 条 Skill 种子）· [`l1/skills/ids.py`](../../../../src/st_agent/l1/skills/ids.py)（`skill_id_for`）· [01 §9](../../../../docs/技术架构-v2/01-平台共享契约.md) 版本语义
- **输出（本任务交付的公共 API / 落盘位置）**
  - 新增 `src/st_agent/l1/pack/`（`__init__.py` 导出；容器与装载入口的具体模块划分实现期定）
  - `load_official_pack(...)`：按 kind 分发给调用方给定的 loader 表（`.3` / `.4` 的接线入口）

## 可关闭的遗留

- 无（本叶只交付容器本体；`A1` 由 `.3` 兑现）

## 假设与前提

- **A1 · Skill 种子「并入」而非「迁移」**：`OFFICIAL_PACK` 仍是 Skill 种子的真相源，容器以 `skill` kind 引用它（不搬运、不复制），避免双写漂移。若错（须物理迁移）：返工面＝`skills/pack.py` 与 `install_official_pack` 的引用面。
- **A2 · `load_official_pack` 不改 `install_official_pack` 的对外行为**：既有播种入口保留或改为薄转发，`tests/l1` 中钉住其行为的用例不变红。若错：返工面＝装载入口签名与相关用例。
- **A3 · 无新依赖**：容器只用标准库 + 既有 `contracts` 类型。若错：返工面＝`pyproject.toml` 与测试分层。
