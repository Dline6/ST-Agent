# T-L1-013.3 · 命令种子与规则库接线（销 L3 册 A1）

## 目标

把 Pack 的两类资源接到消费面，**兑现 [05 §8](../../../../docs/技术架构-v2/05-L3-对话主入口.md)「可随官方 Pack 更新」的 Pack 侧**（销 [L3 册 `A1`](../../../遗留问题/L3-遗留问题.md)）：

1. **`command` kind**：快捷指令种子（现 [`l3/commands/registry.py`](../../../../src/st_agent/l3/commands/registry.py) 的 `DEFAULT_COMMANDS`）由 Pack 承载，装配层经既有的 [`CommandRegistry.register_source("official", …)`](../../../../src/st_agent/l3/commands/registry.py) 整组注入；
2. **`rulepack` kind**：中立性规则库（现 [`contracts/neutrality.py`](../../../../src/st_agent/contracts/neutrality.py) 的 `default_rulepack()`）由 Pack 承载，经 contracts 级解析器对**全部** `NeutralityGuard` 消费点生效（父 `A3`）。

## 验收标准（Given-When-Then）

- **GWT-1 · 命令种子来自 Pack**：Given 泛化容器装了 `command` kind，When 装配完成后列注册表，Then 官方指令集**来自 Pack**（非 `DEFAULT_COMMANDS` 硬编码），且 5 条预置指令（`/盯盘` `/回测` `/压测` `/今日看板` `/反思`）齐全、逐条过命名校验。
- **GWT-2 · 整组替换仍成立**：Given 已注入的官方指令集，When Pack 给出新一组同来源指令，Then 该来源整组替换、用户自定义条目不受影响、替换不触碰校验点（[`T-L3-001.3`](../M1/T-L3-001.3-快捷指令注册表.md) 既有 GWT-5 口径不变）。
- **GWT-3 · 规则库经 Pack 生效**：Given Pack 装了 `rulepack` kind（含一条自定义否定词），When 任一 `NeutralityGuard` 校验命中该词，Then **显式拒**——证明规则库对**全部**消费点（含 [L4](../../../../src/st_agent/l4/deliberation.py) 的模块级常量）生效，而非仅显式注入点。
- **GWT-4 · 无 Pack 时行为不变**：Given Pack 缺席，When 构造 `CommandRegistry()` / `NeutralityGuard()`，Then 行为与交付前**逐字节一致**（父 `A2`；既有 `tests/l3` / `tests/contracts` 不变红）。
- **GWT-5 · A1 销账**：Given 本叶交付，When 收工，Then [L3 册 `A1`](../../../遗留问题/L3-遗留问题.md) 移入册尾「已闭（备查）」、[05 §8](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的「尚未立项」表述同批改实、执行日志留痕。

## 接口面

- **输入（消费的前置接口）**
  - `.2` 交付：`load_official_pack(...)` 与 kind 注册面
  - 既有：[`CommandRegistry.register_source`](../../../../src/st_agent/l3/commands/registry.py)（L3 侧注入点，`T-L3-001.3` 交付）· [`NeutralityGuard(rulepack)`](../../../../src/st_agent/contracts/neutrality.py)（规则库注入面）· [01 §6](../../../../docs/技术架构-v2/01-平台共享契约.md)「校验点不可关闭」
  - 装配点：[`app.py::build_m1_runtime`](../../../../src/st_agent/app.py)（`commands = CommandRegistry()` 处）· [`l1/runtime.py`](../../../../src/st_agent/l1/runtime.py)（`install_official_pack` 处）
- **输出（本任务交付的公共 API / 落盘位置）**
  - `command` kind 的 loader（L3 侧）与装配接线
  - contracts 规则库解析器（可被装配层设置；`NeutralityGuard` 改为**取用时**解析）+ `rulepack` kind loader 与装配接线
  - [L3 册 `A1`](../../../遗留问题/L3-遗留问题.md) 移入「已闭（备查）」

## 可关闭的遗留

- [L3 册 `A1`](../../../遗留问题/L3-遗留问题.md)——**本批关闭**（Pack 侧承载落地，[05 §8](../../../../docs/技术架构-v2/05-L3-对话主入口.md)「两端齐全」）

## 假设与前提

- **A1 · contracts 规则库解析器形态**：新增一个可被装配层设置一次的解析器（缺省＝`default_rulepack()`），`NeutralityGuard` 由「构造时固化」改为「**取用时**解析」，使 [L4](../../../../src/st_agent/l4/deliberation.py) 模块级常量也能被 Pack 规则库覆盖。若错（人不接受全局钩子）：返工面＝改走「仅显式注入点生效」并放宽 GWT-3 的「全部消费点」表述。
- **A2 · 命令种子「由 Pack 供」不改变 `DEFAULT_COMMANDS` 的可用性**：`DEFAULT_COMMANDS` 保留为「无 Pack 时」回退（`CommandRegistry()` 缺省仍装载它）。若错（须删除）：返工面＝`l3/commands/__init__.py` 导出面与 `tests/l3`。
- **A3 · 「官网 5 条预置指令」迁入 Pack 的方式**：[`T-L3-001.3`](../M1/T-L3-001.3-快捷指令注册表.md) 的 `DEFAULT_COMMANDS` 即官方种子的真相源，Pack 的 `command` kind 引用之（不复制，避免双写）。若错：返工面＝种子落点与 [`tests/l3/test_commands_registry.py`](../../../../tests/l3/test_commands_registry.py)。
