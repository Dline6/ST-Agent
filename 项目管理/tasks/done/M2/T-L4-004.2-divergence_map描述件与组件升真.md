# T-L4-004.2 · divergence_map 描述件与组件升真

## 目标

把 `.1` 的 `DivergenceView` 变成用户可见的分歧图：交付 [`divergence_map`](../../../../docs/技术架构-v2/01-平台共享契约.md) 这一**已登记未实现**组件类型的实现——L3 侧描述件 [`describe_divergence_map`](../../../../src/st_agent/l3/render/describe.py)（[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md) 的**产出方＝L3**、[05 §6](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的分歧图属 L3 特有组件）+ 组件类型**升真**（两侧注册表）+ 前端渲染件。矩阵视图（视角 × 结论）为主、证据网络图为辅，**追问接口**由每行的 `trace_id` 承载（复用 [05 §7](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 的 `trace_timeline`，不另造渲染）。

**范围边界（关键）**：视图**数据面**归 [`T-L4-004.1`](T-L4-004.1-L4侧分歧图视图投影与一致性语义.md)（矩阵要全部参与视角的立场 → 只有 L4 有）；本叶**鸭子取值**消费它，**不 import `st_agent.l4`**（[铁律 7](../../../工程宪法.md)；`test_layering.py` 的 `LAYER_ORDER` 为 `l3 < l4`）。

**升真不是改契约**：[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md) 原文已列「已登记、本期不实现」并把 `divergence_map` 列入，其理由即「提前登记使后续补这些形态属于**实现**而不是改契约」——故本叶只动契约里的**实现态标记**，不改 §12 的字段表与槽形状（槽词汇表归 [D-064](../../../决策日志.md) 口径）。

## 验收标准（Given-When-Then，从 Story 4 + 06 §5–§6 抄，限本叶范围）

- **GWT-1**（两视图描述）Given `.1` 的 `DivergenceView`，When `describe_divergence_map(view)`，Then 产出 `ok` 信封包裹的 `divergence_map` 描述：`matrix`（视角 × 结论逐行）+ `network`（节点 / 引用边）**两视图槽齐备**——[06 §5](../../../../docs/技术架构-v2/06-L4-多视角推理.md)「两视图均实现」。
- **GWT-2**（追问接口）Given 矩阵某行视角，When 追问，Then 描述携该视角 `trace_id`（渲染方据此调 `trace_timeline` 展开，复用 [05 §7](../../../../docs/技术架构-v2/05-L3-对话主入口.md)）——描述件**不自造**推理链渲染。
- **GWT-3**（一致性提示 + 证据完整）Given 视图的 `unanimous=True`，When 描述，Then `unanimity_notice` 槽携中性提示且 `agreements` / `disagreements` / `blind_spots` / `network` / `conflicts` **一个不少**（不因高度一致裁证据面）；Given `unanimous=False`，Then 该槽为空串。
- **GWT-4**（分槽与降级）Given 任意视图，When 描述，Then `text_kinds` **逐槽显式标注且槽名集合与 `slots` 完全一致**（`generated`：`unanimity_notice` / `notes` / `conflict_reasons`；其余为 `data`）；输入缺失 / 形状不合走 `unavailable` / `validation_failed` + 点名原因，**不返回残缺卡**；`divergence_map` 在 Python 侧注册表与前端 `RENDERERS` **两侧相等**。
- **GWT-5**（无合并结论）Given 描述件与其槽值，When 检视，Then **无** `verdict` / `recommendation` / `summary` 槽（[铁律 4](../../../工程宪法.md)；描述件是并列呈现面，不是结论面）。

## 假设与前提

- **A1**：描述件按**属性取值**收 `.1` 的视图（鸭子类型），**不 import `st_agent.l4`**——[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md)「产出方＝L3」与 `LAYER_ORDER` `l3 < l4` 同时成立的唯一解（同 [`l4/deliberation.py`](../../../../src/st_agent/l4/deliberation.py) 收 `roster` / `runner` 的注入范式）。**若错**（要求 L3 直接 import L4 类型）：须改 `LAYER_ORDER` 或放开 `test_only_downward_dependencies`，属架构级返工。**验证**：`test_layering.py` 全绿且本层无 `st_agent.l4` import（AST 断言）。
- **A2**：`divergence_map` 升真属**实现**（[01 §12](../../../../docs/技术架构-v2/01-平台共享契约.md) 明文），且因 `PENDING_IN_FRONTEND` 已收紧为空集，「升真」**必然**要求同批交前端渲染件——否则 `test_frontend_registry_matches_the_python_side` 转红。**若错**（判定为契约变更）：按 [铁律 8](../../../工程宪法.md) 先改 01，且前端豁免项需重开（与「欠账由机器接住」的既有口径相悖）。**验证**：GWT-4 两侧相等 + 前端走查页可渲染。
- **A3**：生成文案槽**只放**本层**自有**文案——`unanimity_notice`（取自视图的同名中性常量）、`notes`（§3 降级标注）、`conflict_reasons`（Mini Debate 的 `ConflictAnalysis.reasons`，已由 `T-L4-003` 过 §6）。**用户/数据面文本一律入 `data` 槽**（视角名来自 `Lens.name`、盲点标签来自指标字典）。**若错**（若把视角名判为生成文案）：会让保存期已过 §6 的名字被二次复检，属误伤。**验证**：GWT-4 槽名集合与 `text_kinds` 相等；走查页 `data-violation` / `generated-violation` 两条路径不变红。
- **A4**：本叶**不**落 06 §6 的另三条（空状态**入口**属渲染面，数据面 `has_custom()` 已交付；无建议字段由 `hasattr` 自钉；触达联动归 M3/L5）——与父任务 `A4` 同口径，在父任务「接口面」的「不交付」段显式点名归属。**若错**（要求本叶一并落空状态入口）：须改前端骨架与阵容交互面，另立任务。**验证**：GWT-5 钉「无合并结论」；本叶改动面不含阵容 / 触达。
