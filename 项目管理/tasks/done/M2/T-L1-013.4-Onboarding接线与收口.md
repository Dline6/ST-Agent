# T-L1-013.4 · Onboarding 接线与收口

## 目标

把 Onboarding 问题清单接入泛化容器（`onboarding_questions` kind），兑现 [04 §7](../../../../docs/技术架构-v2/04-L2-记忆图谱.md)「问题清单由配置注册表管理（可随官方 Pack 更新）」。清单**已是** [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 配置条目（`memory-policy/onboarding-questions`），故接线点＝**该条目的官方缺省由 Pack 供**：装配层把 Pack 的清单注入 [`OnboardingProtocol`](../../../../src/st_agent/l2/memory/onboarding.py)，现有缺省 [`DEFAULT_ONBOARDING_QUESTIONS`](../../../../src/st_agent/l2/memory/onboarding.py) 保留为「无 Pack 时」回退。收口时跑父任务全量验证并刷新账本。

## 验收标准（Given-When-Then）

- **GWT-1 · 清单缺省来自 Pack**：Given 泛化容器装了 `onboarding_questions` kind，When 装配后取 [`OnboardingProtocol.question_entry()`](../../../../src/st_agent/l2/memory/onboarding.py)，Then 条目 `default` ＝ Pack 的清单（经 `checked_questions` 校验，≤10 条、字段在目标节点上、id 不重复）。
- **GWT-2 · 无 Pack 时行为不变**：Given Pack 缺席，When 构造 `OnboardingProtocol`，Then 缺省清单与交付前**逐字节一致**（`DEFAULT_ONBOARDING_QUESTIONS`，父 `A2`）。
- **GWT-3 · 配置条目机制不退化**：Given Pack 供的清单，When 用户经 [`set_questions`](../../../../src/st_agent/l2/memory/onboarding.py) 改一版，Then 仍产生 `ChangeRecord`、可回滚（01 §7 三能力不因来源改变而降级）。
- **GWT-4 · 非法清单显式拒**：Given Pack 给了超 10 条 / id 重复 / 字段不在节点上的清单，When 装载，Then **显式拒**（[`checked_questions`](../../../../src/st_agent/l2/memory/onboarding.py) 既有口径），不静默截断。
- **GWT-5 · 父任务收口**：Given 四叶全部 `done`，When 收口，Then 跑**全量** `pytest`（父为跨层任务，按[工作流「测试分层」](../../../工作流.md)全量）与 `verify_docs.py --strict` 全过、`render_ledger.py render` 刷新账本、[`T-INT-003`](T-INT-003-M2集成关卡多视角决策闭环.md) 依赖补入本任务（检查 7）。

## 接口面

- **输入（消费的前置接口）**
  - `.2` 交付：`load_official_pack(...)` 与 kind 注册面
  - 既有：[`OnboardingProtocol`](../../../../src/st_agent/l2/memory/onboarding.py)（`questions` / `question_entry` / `set_questions`）· [`memory_policy_family`](../../../../src/st_agent/l2/memory/registry_adapter.py)（L2 只读门面适配器）· [`DEFAULT_ONBOARDING_QUESTIONS`](../../../../src/st_agent/l2/memory/onboarding.py)
  - 装配点：[`app.py::build_m1_runtime`](../../../../src/st_agent/app.py)（`onboarding = OnboardingProtocol(...)` 处）
- **输出（本任务交付的公共 API / 落盘位置）**
  - `onboarding_questions` kind 的 loader（L2 侧）与装配注入
  - 父任务 [`T-L1-013`](T-L1-013-官方Pack泛化为类型化官方资源容器.md) 收口（父 `status` 由 children 派生 `done`）

## 假设与前提

- **A1 · 清单注入方式**：经 `OnboardingProtocol` 的构造参数（或等价注入面）注入 Pack 清单，`DEFAULT_ONBOARDING_QUESTIONS` 保留为缺省。若错（须让 L2 import L1 的 pack）：返工面＝层间方向与 `DEFAULT_*` 落点。
- **A2 · 现有缺省与 Pack 清单同源**：[`DEFAULT_ONBOARDING_QUESTIONS`](../../../../src/st_agent/l2/memory/onboarding.py) 的 6 条即官方种子真相源，Pack 的 `onboarding_questions` kind 引用之（不复制）。若错：返工面＝种子落点与 [`tests/l2`](../../../../tests/l2)。
- **A3 · 父收口不重开已 `done` 关卡**：全量验证以新用例 + 既有套件承载，不改已 `done` 的 [`T-INT-002`](../../T-INT-002-M1集成关卡首次可对话.md)。若错：返工面＝关卡任务状态。
