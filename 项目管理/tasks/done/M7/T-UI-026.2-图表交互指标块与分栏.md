# T-UI-026.2 · 图表交互、指标块与分栏（P1）

> M7 叶之四的第二半（[`T-UI-026`](T-UI-026-数据密集面表格图表与指标块.md) 按「GWT > 5」拆出，[D-127](../../../决策日志.md)）。
> 口径见 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) §6.1（`metric` / `split-pane`）与 §7（图表交互）。

## 目标

- **`trend_chart` 交互**：hover 出**十字线 + 数值浮层**；时间范围切换 `1D / 1W / 1M / 1Y / ALL`；**缺值点留断口**（分段绘制，不按 0 连线）
- **`metric` 指标块**：数字走 `--text-metric` + `--font-num`、`tabular-nums`；**标签在上、口径在下**；先由既有摘要锚点消费
- **`split-pane`**：等权左右分栏、可拖宽、可交换、可单侧折叠；宿主为推理页「视角详情与追问」下的**并排对照**——两栏各渲染一个视角，**不产出任何合并块**（[铁律 4](../../../工程宪法.md) 的结构载体）

## 验收标准（Given-When-Then）

- GWT-5：Given `trend_chart`，When hover 任一点，Then 出十字线与数值浮层；序列缺值时**留断口**而非按 0 连线
- GWT-6：Given 一个多视角结论页，When 用 `split-pane` 并列两方，Then 两栏同权、可拖宽、**不产生任何「合并后」的块**

## 假设与前提

- **A1**（横向轴语义）——前提：`points[].x` 只有在可解析为日期（ISO 日期 / 时间戳字符串）时才启用 `1D/1W/1M/1Y` 范围切换；否则按钮禁用并**显式说明**「横轴不是时间值」，保留 ALL；若错的影响：范围切换在非日期轴上不可用（不是假过滤）；验证方式：`parseAxis` 纯函数用例 + dev 样本改 ISO 日期后浏览器走查。
- **A2**（缺值断口）——前提：现行实现对 `y=None` 是「跳过该点后仍连线」，并非真正断口；本叶改为**按缺值切段**、段间不连线，且该点仍在横轴上占位（不压缩时间轴）；若错的影响：GWT-5 的「留断口」不成立；验证方式：`segments` 纯函数用例 + 样本第二序列（T-2 缺值）走查。
- **A3**（分栏宿主）——前提：分栏放推理页「视角详情与追问」下，两侧各取一个本次参与视角；冷开（无本次结果）时显式空态，不猜视角；若错的影响：GWT-6 没有可操作落点；验证方式：编排后走查两栏 / 拖宽 / 交换 / 折叠。
- **A4**（指标块消费方）——前提：摘要锚点是现成且每页常驻的 `metric` 消费方（标签 / 数值 / 口径三段结构）；若错的影响：`metric` 只有组件没有真实消费面；验证方式：`paintSummary` 改用 `metricBlock` 后走查四格。
- **A5**（不新增组件型）——前提：`metric` 与 `split-pane` 是**壳面原语**而非 `01 §12` 组件型，故不进描述契约；若错的影响：触发注册表两侧一致守卫；验证方式：`test_ui_registry.py` 与 `ui/registry.py` 名集不变。
