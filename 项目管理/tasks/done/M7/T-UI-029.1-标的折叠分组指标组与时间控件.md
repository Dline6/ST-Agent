# T-UI-029.1 · 标的折叠分组、指标组与时间控件

## 目标

重写同步面板的目录与控件：标的一级折叠、数据集二级、指标组 chips、按数据性质渲染时间控件，并接入自定义代码。

## 验收标准（Given-When-Then）

- GWT-1 折叠分组：Given 打开页面，When 展开/收起标的组，Then 组内数据集独立可选，组头显示数量与来源时间；键盘可操作。
- GWT-2 指标组：Given K 线或财务数据集，When 切换 chips，Then 只提交选中组；默认组与服务端声明一致；整取数据集不显示 chips。
- GWT-3 时间控件：Given 日期型/季度型/年份型/无时间数据集，When 渲染，Then 分别出现日期区间、最近 N 季或 `YYYYQn` 起止、年份区间、或“快照/全量”说明；不支持的组合在预检里显式忽略。
- GWT-4 自定义代码：Given 粘贴或导入文本，When 预检，Then 合法码去重后参与计划，非法行逐行列出；不静默丢弃。
- GWT-5 预检：Given 勾选若干标的×数据集，When 预检，Then 显示执行顺序、自动补入、重复标的合并、预计请求、跳过码数与警告；错误时禁用开始。

## 接口面

- 输入：
  - `T-UI-029` 的接口面；`T-L0-020` 数据集能力位；`T-L0-021` 覆盖计划。
  - `settings.js` 现有 `field` / `renderItem` / `renderCatalog` / `openDialog` 与 `app.css` 的 `.settings-*`。
- 输出：
  - `data_catalog.py` 的 `targets[] / datasets[] / groups[]` 与 `validate_catalog`。
  - `settings.js` 的 `renderDataWorkspace` / `renderTargetGroup` / `renderDatasetRow` / `renderTimeControl` / `renderIndicatorChips` / `renderCustomCodes`。
  - `app.css` 的折叠组、chips、时间行、自定义代码样式。

## 可关闭的遗留

- 无归属本任务的既有条目。

## 假设与前提

- A1 使用原生 `<details>` 折叠，不引入前端框架。若错：需自建可访问折叠组件。
- A2 时间控件的默认值由服务端 `default_time` 下发，前端不硬编码。若错：新增数据集要改前端。验证：目录驱动用例。
- A3 文件导入只读文本（`FileReader`），编码按 UTF-8；异常编码给显式错误。若错：需做编码探测。
- A4 目录校验要求每个任务恰属一个数据集，标的类数据集只能出现在标的组。若错：重复任务会被重复执行。验证：`validate_catalog` 用例。
