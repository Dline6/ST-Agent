# T-UI-034 · 表现层按面拆分

## 目标

把 `src/st_agent/ui/app.py`（6,617 行，其中 `UiApp` 一个类 4,617 行 / 116 个 `api_*`）按已有的**面分区注释**拆成 `st_agent.ui.surfaces` 下的一组视图模块；`ui/app.py` 只保留 `UiApp` 字段、继承、跨面共用端点与 `build_ui`。行为、路由表、公开导入面一律不变。

## 验收标准（Given-When-Then）

- GWT-1 行为不变：Given 拆分后的服务，When 走既有 `tests/ui` 的全部端点用例，Then 结果与拆分前一致（`/api/*` 路由表一字不改）。
- GWT-2 导入面不变：Given 既有 `from st_agent.ui.app import PAGE_PATHS, UiApp, build_ui, WEB_ROOT`，When 拆分后导入，Then 全部仍可取；`_load_dev` 仍在 `ui/app.py`（dev 剔除用例 monkeypatch 它）。
- GWT-3 尺寸受控：Given 拆分完成，When 跑 `tests/test_module_size.py`，Then `ui/app.py` ≤ 500 行、`ui/surfaces/**` 单文件 ≤ 800 行。
- GWT-4 测试同步：Given 拆分移动了私有纯函数，When 跑 `tests/ui`，Then 只允许既有的 2 例环境性 `test_shell` ERROR，无新增失败。

## 接口面

- 输入（消费的前置接口）：
  - 既有 `UiApp` 的 21 个鸭子端口字段（`chat` / `reflection` / `eco` / `memory` / `workspace` / `skills` / `mcp` / `graph` / `deliberation` / `delivery` / `settings` / `studio` / `commands` 等）。
  - 既有 `st_agent.ui.server` 的 `_GET_ROUTES` / `_POST_ROUTES`（它们按名字调 `app.api_*`）。
  - 既有 `st_agent.ui.tables` 的唯一表格漏斗与 `st_agent.ui.registry` 的必填槽校验。
- 输出（本任务交付的公共 API / 落盘位置）：
  - 新增 `src/st_agent/ui/surfaces/`：`base.py`（共用助手）、12 个面模块、`settings/`（read / write / shared）与 `delivery_shared.py`。
  - `src/st_agent/ui/app.py` 保留 `PAGE_PATHS` / `WEB_ROOT` / `RestartGate` / `UiApp` / `build_ui`；`UiApp` 改为继承各面 mixin。
  - 无新增 / 变更 HTTP 端点，无新增落盘格式。

## 可关闭的遗留

无（已扫各层遗留册未闭区，无归属本任务的条目；本任务是纯结构搬迁，不关闭功能遗留）。

## 假设与前提

- A1 mixin 不影响冻结 dataclass：`UiApp` 仍是 `@dataclass(frozen=True)`，各面 mixin 只带方法、不带字段注解。若错：改为委派对象并调整路由表（改动面会扩大到 `server.py`）。
- A2 面间耦合只在少数共用助手：开工前用 AST 扫过跨面 `self.*` 引用，只有 `_call_face` / `_gated_description` / `_gate_description` / `_described_part` / `dev_enabled` 与少量共用常量。若错：把新增共用项补进 `surfaces/base.py`。
- A3 测试只经公开导入面消费：`tests/ui` 里只有 `test_ui_settings.py` / `test_ui_delivery.py` 直接取私有纯函数，已改指向新模块；`test_ui_table_vocabulary.py` 的 AST 扫描已从「只扫 app.py」改为「扫整个 ui/」。若错：其余用例会在导入期报错，按报错改导入。
