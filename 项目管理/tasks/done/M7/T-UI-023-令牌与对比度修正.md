# T-UI-023 · 令牌与对比度修正（P0）

> **M7 桌面形态叶之一，且是批次首叶**（[D-120](../../../决策日志.md) / [D-121](../../../决策日志.md)）。目标值见 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) §3–§4。本叶**纯改值 + 扩守卫**：不动 DOM 结构、不动交互，故排在批次最前——风险最低、收益最直接。

## 目标

把视觉令牌层从「自造、已漂移」修到「对齐平台 ramp、可机器校验」：

- **间距令牌化**：`tokens.css` 补 8 档间距令牌（4/8/12/16/20/24/32/48，另 64 仅空态留白）；`app.css` 里 **18 个**裸间距值全部改为消费令牌——其中 **11 个不在 4px 网格**（2.4 / 3.2 / 4.8 / 5.6 / 6.4 / 7.2 / 8.8 / 9.6 / 11.2 / 12.8 / 14.4px）
- **字号**：五档（12.8 / 14.08 / 16 / 17.6 / 22.4px，比例 1.10 / 1.136 / 1.10 / 1.27 无规律）→ 对齐 ramp 的 **9 档**；**行高不再全局取 `1.7`**（界面 chrome 1.33–1.43，仅长文阅读面 1.5–1.6）
- **圆角**：三档（6/8/10）→ **四档按层级**（控件 4 / 块 8 / 浮层 12 / 徽标胶囊 999）
- **墨阶与界面边界**：`--fg-faint` 由 3.22:1 修到 ≥4.5:1；新增 `--line-strong`（≥3:1）承担**控件边界**，原 `--line` 退回**装饰线**
- **字重**：标题 700 → **600**（[13 册](../../../../docs/PRD-v2-Agent/13-visual-design.md) §3 本就只允许常规与 600；现行 `.masthead h1` 落到浏览器默认 700）
- **涨跌色**：修掉暗色下 `--down` 与 `--ok` **完全同值**（1.00:1，实测）与 `--up`/`--error` 仅差 1.07:1
- **同批替换**：[13 册 §2.1](../../../../docs/PRD-v2-Agent/13-visual-design.md) 的令牌**值**与 `tokens.css` 必须同批改——两处由守卫逐名断言，单改其一即漂移
- **守卫扩写**：`test_ui_design_tokens.py` 由「仅比令牌名」扩为「**名 + 值 + 对比度阈值**」三断言；新增「`app.css` 出现裸间距值即失败」

## 验收标准（Given-When-Then）

- GWT-1：Given `tokens.css` 与 13 册 §2.1，When 跑守卫，Then 两处的令牌**名与值逐项相等**，且 `app.css` 引用的每个令牌都已声明
- GWT-2：Given `app.css`，When 扫全部 box-model 声明，Then **0 个裸间距值**，且所有间距值可被 4px 整除（64 档除外）
- GWT-3：Given 令牌表，When 逐对算 WCAG 对比度，Then 正文对底 ≥ 4.5:1、**界面边界 ≥ 3:1**、大字 ≥ 3:1——**浅暗两套主题全部达标**
- GWT-4：Given 任一现有页面，When 渲染，Then 布局未破（无重叠 / 无溢出 / 无裁切），且 `tests/ui` 全绿
- GWT-5：Given 暗色主题，When 同屏出现涨跌与状态，Then `--down` ≠ `--ok` 且 `--up` ≠ `--error`（逐对比较可区分）

## 假设与前提

- **A1 · 13 册 §2.1 是唯一被测试解析的令牌文档**（14 册明文「不由测试断言」）⇒ 重写 §2.1 的表格与值不波及别处。**若错的影响**：另有解析源会翻红，须同批改。**验证方式**：跑 `tests/ui/test_ui_design_tokens.py`（全仓 grep 确认它是唯一读 §2.1 的用例）。
- **A2 · `app.css` 是令牌的唯一消费方** ⇒ 旧名移除不留死引用。**若错的影响**：某处 `var(--text-md)` 静默失效（回落到浏览器默认值，**页面不报错**，只在视觉上退化）。**验证方式**：`test_app_css_consumes_declared_tokens_only` ＋ 全仓 `grep -rn "var(--" src/st_agent/ui/web`（含 `js/` 与 `index.html`，实测 **0 命中**）。
- **A3 · 「间距就近取档 ＋ 字号按角色换名」的映射不破版**——间距最多动 ±2.4px、字号最多动 ±2px、行高由全局 1.7 收到 1.33–1.43（随档）。**若错的影响**：某页面重叠 / 溢出 / 裁切（GWT-4 失败）。**验证方式**：**改前 / 改后同页浏览器走查**（1440×900 逐页比对）＋ `tests/ui` 全绿。
- **A4 · 只有「可聚焦控件」的 1px 边框改 `--line-strong`**，装饰线（段间 / 行间 / 并列块）保留 `--line`。**若错的影响**：3:1 灰线铺满全屏成网格噪音，或反之漏改使控件边界仍停在 1.39:1。**验证方式**：读 diff 逐处判「控件 ⇄ 装饰」＋ GWT-3 钉住 `--line-strong` 的值。
- **A5 · 跌色换青绿不引入新的对比度失败**。**若错的影响**：涨跌色落到 4.5:1 以下（正文级文字）。**验证方式**：对比度断言（预算：浅 **6.30** / 暗 **7.53**，均 ≥ 4.5）＋ GWT-5（暗色 `--down` ≠ `--ok`、`--up` ≠ `--error`）。
- **A6 · 本叶不动 DOM / JS / 契约 / 端点** ⇒ 不触发[铁律 8](../../../工程宪法.md)、不触发「联网面必跑 live 子集」轴。**若错的影响**：须补跑 live 子集并补契约变更流程。**验证方式**：`git diff --name-only`（应只含 `tokens.css` · `app.css` · 13 册 · 守卫 · 任务文件 · 三本日志）。
- **A7 · 全局焦点环与 `prefers-reduced-motion` 并入本叶**（④ 对齐时负责人拍定；14 册 §12 的 P0 行列了它们，但本文件的目标与 GWT 未列）。**若错的影响**：本叶范围溢出到 P2 的交互底座叶，但那两段是无消费方亦无副作用的纯 CSS。**验证方式**：走查期用键盘 Tab 走一遍（焦点环 2px `--accent`、offset 2px 可见）；`prefers-reduced-motion` 规则由读码确认（当前 `transition` / `animation` 各 0 处，故它是**空操作的前置规则**）。
