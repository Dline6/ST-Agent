# T-UI-027 · 桌面壳闭合与默认启动路径（P4）

## 目标

把壳从「能开出一个窗口」补成**合规格的桌面应用壳**：

- **窗口规格**：默认 1440×900；**最小 1024×640**；尺寸 / 位置 / 最大化态**跨会话恢复**（现行 `shell/window.py` 的 `create_window(title, url)` 不传任何窗口参数、无任何记忆）；多显示器下不跑出屏幕
- **宽度档位**：窗口窄于 1240px 时**右栏自动收起**（保主区 480px 最小宽）；窄于阈值时左栏折成 48px 图标条
- **关窗语义**：关窗 = 收进托盘（**保留现行 `closing → False` 的行为**），但**首次关闭必须有一次显式说明**——现行无任何提示，用户会以为已退出而实际还在后台跑
- **托盘**：16 / 32 / 256 **多尺寸资源**（现为程序绘制、无资源文件）+ 深浅主题适配；菜单：显示主窗口 / 新建窗口 / 主动触达设置… / 开机自启 / 退出（「暂停主动触达」改由触达设置承载，见 [D-126](../../../决策日志.md)）
- **应用图标资源**：产出 `.ico`（多尺寸）——**本叶是它的产出方**，[`T-UI-019`](../../T-UI-019-Windows安装器与安装体验.md) 是其消费方（安装器与快捷方式图标）
- **默认启动路径改为壳**（[14 册 §1](../../../../docs/PRD-v2-Agent/14-desktop-form.md)）：桌面壳升为**产品交付面**，浏览器面降级为开发 / CI 面。仓库根的 `start-st-agent.bat` **保留**为试用 / 开发入口（仍是浏览器面），不删、不改其定位
- **壳快捷键**：`Ctrl+W` 收托盘、`Ctrl+Q` 退出（归本叶——交互底座那叶只管页内快捷键）
- **多窗口**：至少「主窗口 + 单个附属窗口」，把看板 / 图表 / 对比栏拖出去并排看（**本叶的最末项，可拆出**）

## 验收标准（Given-When-Then）

- GWT-1：Given 已调整过尺寸与位置的窗口，When 完全退出后再次启动，Then **窗口尺寸、位置与最大化态被恢复**
- GWT-2：Given 窗口，When 尝试把它缩到小于 1024×640，Then **缩不下去**（最小尺寸生效）；窄于 1240px 时右栏自动收起
- GWT-3：Given 首次点关闭，When 关窗，Then 出现**一次性说明**（说明应用仍在后台、如何恢复与真正退出）；再次关闭**不再出现**；此后可从托盘恢复主窗口
- GWT-4：Given 托盘图标资源，When 在浅色与深色系统主题下查看，Then 图标**各有适配版本**且含 16 / 32 / 256 三档
- GWT-5：Given 一次全新安装（或首次启动），When 用户从系统入口启动，Then 打开的是**壳窗口**而非浏览器标签页；`start-st-agent.bat` 仍可用作试用 / 开发入口
- GWT-6：Given 主窗口，When 触发「新建窗口」，Then 出现一个可并排使用的附属窗口，且**后端不因此重启**（进程形态不变）
