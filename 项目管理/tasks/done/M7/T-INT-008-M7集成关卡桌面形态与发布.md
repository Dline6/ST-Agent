# T-INT-008 · M7 集成关卡 · 桌面形态

> **M7 的收口关卡**（[D-103](../../../决策日志.md) ① 拆出、[D-121](../../../决策日志.md) 重定范围、[D-136](../../../决策日志.md) 二次收窄）。M7 自 [D-136](../../../决策日志.md) 起 ＝ **桌面形态**（五叶：令牌 / 外壳 / 交互 / 读面 / 壳闭合）——**发布两叶（安装器 / 签名）已移出 M7、`milestone` 置空悬空**，待负责人择时单独立「发布」里程碑。故本关卡**收口即 M7 可归档**，不再等打包与真机安装。

## 目标

M7 的收口：在**桌面壳形态**上端到端验收「**后端常驻启动 → 首启握手 → 壳窗口 → 桌面形态走查 → 全 IA 页面走查 → 关键链路**」：

- **形态验收**（[D-121](../../../决策日志.md) 新增）：首启后逐项确认 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) 的形态成立——三栏齐备且**外壳不随滚动移动**（滚到底后左栏 / 命令栏 / 状态栏仍在视口内）、左栏两级可展开、右栏 Chat 伴随栏可折叠与拖宽、主区可 `split-pane`、读面为 `compact` 密度；键盘可走完一条主线且焦点环处处可见
- **全 IA 页面走查**：按 [11-sitemap §2](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集逐区走查（装不装包不影响本项——走 **壳窗口**而非浏览器标签页）
- **端到端数据流**：按 [00 §5](../../../../docs/技术架构-v2/00-架构总览.md) 验证**后端口常驻 + 壳客户端**（[00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md) 的进程形态），不是浏览器直开
- **发布面不在本关卡**（[D-136](../../../决策日志.md)）：安装器、签名、真机安装与卸载随悬空的 [`T-UI-019`](../../T-UI-019-Windows安装器与安装体验.md) / [`T-UI-020`](../../T-UI-020-代码签名与安装包可信性.md) 一并移出

**锚点**：验收标准取自 [00 §5](../../../../docs/技术架构-v2/00-架构总览.md) 的端到端数据流、[11-sitemap](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的页面集与 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) 的形态条目；**不重复**单叶已覆盖的单元行为。

## 验收标准（Given-When-Then）

全部在**真桌面壳窗口**（pywebview + WebView2）上验，不以浏览器直开替代（[D-136](../../../决策日志.md)）。既有单叶用例已覆盖的单元行为不重复。

- **GWT-1 · 三栏形态与常驻外壳**（[14 §2](../../../../docs/PRD-v2-Agent/14-desktop-form.md)）
  - **Given** 壳窗口已打开任一页面，**When** 把主区滚到底，**Then** 命令栏、左栏分区导航、状态栏仍完整位于视口内，且滚动只发生在主区 / 左栏 / 右栏三个独立容器内（文档本身不滚动）。
  - **When** 展开某分区的二级项，**Then** 二级项出现在该分区之下且不占用一级项；左栏折叠为图标条后一级项仍可达。
  - **When** 折叠右栏、拖动主区/右栏分隔，**Then** 右栏收起与宽度变化可逆、主区不溢出。
  - **When** 在支持分栏的读面开启 `split-pane`，**Then** 两栏并列且各自独立滚动（铁律 4 的结构载体）。
- **GWT-2 · 全 IA 页面走查**（[11 §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md)）
  - **Given** 壳窗口，**When** 逐条进入 §2.2 声明的 **20 条路径**（`/` + 19 条），**Then** 每页主区渲染出该分区应有的内容、页面标题为「<分区> · <对象> — ST Agent」形态、无未捕获异常、非 ok 态走显式六态而非留空。
- **GWT-3 · 端到端数据流（后端口常驻 + 壳客户端）**（[00 §1.1 / §5](../../../../docs/技术架构-v2/00-架构总览.md)）
  - **Given** 壳进程，**When** 它拉起后端并开窗，**Then** 窗口地址＝握手给出的 `host:port` 且令牌在 fragment 里，用户数据全经 `/api/*` 携带令牌取得，后端是**独立常驻进程**（关窗后仍在、托盘可恢复）。
  - **When** 在壳窗口里跑一条主链路（对话提交 → 结果渲染 / 本地数据读面取数），**Then** 数据从本地缓存经 L0→L3→UI 贯通到壳窗口，且壳不提供 JS 桥或专有通道。
- **GWT-4 · 键盘主线与焦点可见**（[14 §8.1 / §9](../../../../docs/PRD-v2-Agent/14-desktop-form.md)）
  - **Given** 壳窗口，**When** 全程只用键盘走一条主线（`Ctrl+K` 命令面板 → 选页 → `/` 聚焦输入 → `Ctrl+Enter` 提交 → `Esc` 关最上层浮层），**Then** 每一步都可达且焦点顺序符合视觉顺序；逐跳 `:focus-visible` 命中统一焦点环。
- **GWT-5 · 桌面壳闭合**（[14 §1 / §11](../../../../docs/PRD-v2-Agent/14-desktop-form.md)）
  - **Given** 首次启动，**When** 查看窗口，**Then** 默认 1440×900、最小 1024×640，标题为原生标题栏的「<分区> · <对象> — ST Agent」。
  - **When** 改变尺寸与位置后退出再启动，**Then** 规格与位置恢复（只真退出才落盘；关窗不销毁）。
  - **When** 首次关窗，**Then** 出现一次性「已收进托盘、应用仍在后台」说明；此后关窗不再提示，托盘可恢复窗口。
  - **When** 在界面按 `Ctrl+W` / `Ctrl+Q`，**Then** 意图经回环端点回传后端、再沿既有 stdout 管道到达壳（收托盘 / 退出），且不新增专有通道。
  - **When** 从托盘「新建窗口」，**Then** 开出附属窗口且**复用同一后端进程**。

## 假设与前提

- **A1 · 壳窗口可被程序化驱动**：WebView2 的 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<port>` 开调试口后，`playwright-cli attach --cdp` 能读到**真实壳窗口**并与人工走查等价（快照 / 量尺寸 / 按键）。
  - 若错的影响：GWT-1/2/4 只能退化为截图 + 手工记录，证据粒度下降但验收结论不变；GWT-3/5 不依赖此假设。
  - 验证方式：④ 对齐前已实测——窗口标题为「总览 — ST Agent」，`/json/list` 返回唯一 page target，快照可读。走查时再逐条落证。
- **A2 · 走查用临时存储根与临时窗口态文件**：以 `--root temp/…` + `prefs_path=temp/…` 起壳，不碰用户真实根与真实窗口态。
  - 若错的影响：数据面多为空态或样本，**不能**覆盖「真实数据密度下的表格与图表表现」；该限制须在日志里如实写明，不得当作已验证。
  - 验证方式：启动命令与根路径写进日志；每页记录其数据来源（空态 / 样本 / 本地缓存）。
- **A3 · 关卡不重复单叶单元行为**：各叶的 Fake 单测已覆盖的部分（壳生命周期语义、表格键盘矩阵等）不重跑，只验**装配面**；走查发现缺陷时同批修复并重跑受影响范围套件。
  - 若错的影响：可能重复劳动，不改变结论。
  - 验证方式：GWT 只断言跨叶装配行为；修复后按「受影响范围映射」重跑。
- **A4 · 两例 `test_shell` ERROR 为本机既有环境性**：`ShellError: 后端需要口令`——真后端用例走的是用户真实根。按既有判据（[执行日志](../../../执行日志.md) 前几批同一原因）排除，不诊断、不修。
  - 若错的影响：若有**新的**失败形态混在同类名目下会被忽略；故全量结果须逐条比对报错文本，只在文本一致时按既有判据排除。
- **A5 · 发布面不在本关卡**：安装器 / 签名 / 真机安装卸载随悬空的 `T-UI-019` / `T-UI-020` 移出（[D-136](../../../决策日志.md)），本关卡不验、也不因缺它而不通过。
- **未决**：无 open `Q-NNN`。

## 备注

功能交付任务的关卡**不得**标 `gate: skip`（[工作流](../../../工作流.md)）。每新增一个 M7 叶，同批把其 id 补进本任务 `depends_on`——否则 [检查 7](../../../tools/verify_docs.py) 报「依赖未覆盖本里程碑任务」。

**文件名保留旧范围词**：本文件仍名 `…桌面形态与发布.md`。2026-10-27 收窄范围时**未改名**——改名会波及决策日志与执行日志里的多处历史引用，而 [D-121](../../../决策日志.md) 的旧例已证明「改名 → 机械修链」会打到冻结记录；以「文件名停在旧范围词 + 正文与标题为准」为更窄的处置。后续若重命名，须同批修正全部引用并重跑 `verify_docs --strict`。
