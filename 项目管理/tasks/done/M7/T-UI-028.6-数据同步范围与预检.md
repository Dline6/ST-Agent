# T-UI-028.6 · 数据同步范围（P0）

## 目标

- 同步请求支持显式起止日期，并只对窗口型任务生效；全量 / 快照 / 信息面任务显式回报「忽略区间」。
- 同步请求支持证券范围：全市场 / 仅 ST 股票池 / 仅关注池；只对逐码任务生效。
- ST 池取本地 `v_st_universe`（在市 × 最新日线 `is_st=1`），显示数量与数据截止；空池或缺视图时显式拒绝。
- 范围同步必须带显式起点，避免全库水位把新纳入范围的证券跳成空窗口。
- 发起前提供预检：执行顺序、自动补入前置、范围解析、被忽略的任务、首次全量等警告。

## 验收标准（Given-When-Then）

- GWT-1：Given 选中支持区间的任务并指定 `[start, end]`，When 同步，Then 该任务按区间取数；不支持区间的任务在结果与预检中标注「忽略区间」，不静默套用。
- GWT-2：Given 选择「仅 ST 股票」，Then 以 `v_st_universe` 解析代码集并显示数量与数据截止；空池 / 视图缺失时拒绝并说明原因；同步只覆盖该代码集。
- GWT-3：Given 选择「仅关注池」，Then 以持仓 + 关注面解析代码集；空池拒绝并说明。
- GWT-4：Given 范围不是全市场且未给起始日期，Then 明确拒绝（`validation_failed` + 原因），不产生「成功但 0 行」的空窗。
- GWT-5：Given 发起前预检，Then 返回 `order` / `auto_added` / `range_applied` / `range_ignored` / `scope` / `warnings`，界面在开始前展示。

## 接口面

- 输入：
  - [`T-UI-028.5`](T-UI-028.5-数据同步目录与页面重构.md) 的数据项目录与任务能力位。
  - `BaoStockSync.run_task(task_key, *, start, end, codes, cancel, ...)`（`src/st_agent/l0/market/sync.py`）。
  - `MarketDb` 的 `v_st_universe` 视图与 `security` 主档。
  - 关注池：`MemoryPositionsFacade.codes("holdings") + codes("watchlist")`（组合根注入 `DataSyncRunner`）。
- 输出：
  - `TaskSpec` 增加 `per_code` / `supports_range` / `window_desc`；`InfoTask` 增加同名默认位。
  - `BaoStockSync.run_task` 增加 `end`，并贯通日线 / 周月线 / 分钟线 / 复权 / 分红 / 快报 / 预告 / 财务；财务补 `start`/`end` 过滤，分钟线补区间且「显式 `codes` 优先」。
  - `DataSyncRunner.start(task_keys, *, start, end, scope)` 与 `.preflight(...)`；批次快照记录 `scope` / `start` / `end` / `codes_count` / `range_ignored` / `scope_ignored`。
  - `MarketDb.st_codes()` / `st_pool()`（数量 + 数据截止 + 可用原因）。
  - `UiApp.api_settings_data_preflight`；`POST /api/settings/data/preflight`。
  - `GET /api/settings/data` 的 `summary` 增加 ST 池与关注池规模；`settings.js` 的范围与日期控件。

## 可关闭的遗留

无（逐册查未闭区：与 T-UI-028.5 同批核查，无归属本任务的条目）。

## 假设与前提

- A1：ST 池以本地最新日线 `is_st=1` 为准，首期不用「证券名称含 ST」的启发式兜底。若错：新建库尚无日线时 ST 范围不可用。验证方式＝空池用例显式拒绝并提示先同步日线。
- A2：`sync_state` 水位是**全库**口径，范围同步必须给显式起点，否则新纳入代码会拿到空窗口。若错：范围同步「成功但无行」。验证方式＝用例断言范围 + 无起点被拒；范围 + 起点按区间执行。
- A3：`end` 需逐任务贯通；财务任务当前忽略 `start`，分钟线忽略显式区间，须同批补齐。若错：日期控件对部分任务静默无效。验证方式＝逐任务窗口用例与「忽略区间」回报断言。
- A4：信息面与全量 / 快照任务不接受证券范围与日期区间；预检与结果显式点名，不假装已应用。若错：用户误以为只同步了 ST。验证方式＝混合选择用例断言 `scope_ignored` / `range_ignored`。
- A5：旧库可能没有 `v_st_universe` 视图；读不到时按 `unavailable` 处理并给原因，不抛 500。验证方式＝缺视图替身用例。
