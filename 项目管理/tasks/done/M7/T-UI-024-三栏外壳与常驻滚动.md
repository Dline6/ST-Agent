# T-UI-024 · 三栏外壳与常驻滚动（P1）

> **M7 桌面形态叶之二**（[D-120](../../../决策日志.md) / [D-121](../../../决策日志.md)）。骨架与栏位规则见 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) §2–§3；导航模型见 [11 册 §1 / §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md)。本叶是**结构性**的一叶——之后各叶都挂在它给出的外壳上。

## 目标

把「浏览器里的 736px 单栏文档页」换成**常驻外壳 + 三栏**：

- **外壳三区**：命令栏（分区名 + 面包屑 + 命令面板入口 + 连接态，常驻 40px）、三栏主体、状态栏（本机回环 · 数据源 · 最后同步 · 网络活动，常驻 24px）
- **三栏**：左栏**分区导航**（200–240px，可折叠到 48px 图标条）、主区（可再分栏，最小宽 480px）、右栏 **Chat 伴随栏**（320–420px，可拖宽、可折叠）
- **三条硬规则**（14 册 §2）：① **外壳永不滚动**——只有三个栏位各自滚动；② 栏位可折叠可拖宽且**宽度记忆**；③ 主区**可分栏**
- **左栏两级**：一级＝**分区根**（与 [11 册 §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md) 表格逐分区对位，**集合不变**）；二级＝同一分区内的多个屏（即原「页内视图切换」升为左栏二级）。**路径一律不变**（仍走查询串，[D-120](../../../决策日志.md) 已决项 4）
- **摘要锚点**：主区顶部 sticky 摘要条（总值 / 当日 / 累计 / 最后更新）——投资类界面的第一原则是最重要的数字一屏可见、不滚动、不心算
- **随本叶一并落地的无障碍基线**：每页**唯一** `h1`＝页面标题（产品名移入「关于」/ 状态栏）、**skip link**、`aria-live` 只挂**专用状态区**（不再挂整个 `#root`）、全局 `:focus-visible` 焦点环、导航项热区 ≥ 24×24px（主行动 ≥ 32×32px）

## 验收标准（Given-When-Then）

- GWT-1：Given 外壳，When 检查 DOM 与计算样式，Then 命令栏 / 左栏 / 主区 / 右栏 / 状态栏五区齐备，且**五区中仅主区与两侧栏可滚**——`documentElement` 不出现整页滚动
- GWT-2：Given 任一分区页，When 把主区滚到最低，Then **左栏、命令栏、状态栏仍在视口内**（现状反例：`/memory` 滚到底后主导航 `top = -66px`）
- GWT-3：Given 左栏，When 读一级项集合，Then 它**等于** [11 册 §2.2](../../../../docs/PRD-v2-Agent/11-sitemap.md) 的分区根集合（既有漂移断言 `test_ui_shell_routing.py` 仍绿），且二级项展开态在跳页后保持
- GWT-4：Given 任一页面，When 渲染，Then 有且仅有一个 `h1` 且其文本＝页面标题；存在 skip link；`aria-live` 不在主内容容器上
- GWT-5：Given 键盘，When 从首元素连续 Tab，Then 焦点环**处处可见**（2px `--accent` + offset 2px），skip link 可越过左栏直达主区

## 假设与前提

- **A1 摘要锚点的四项数值当前没有数据面**：L2 的 `AttentionNode` 只存 `holdings` / `watchlist` 代码（[`models.py`](../../../../src/st_agent/l2/memory/models.py)），没有持仓数量与成本基数，`/api/memory/holdings` 也只回代码 / 名称 / 收盘 / 涨跌幅 / 换手；L0 的 `sync_state` 未接到表现层。**若错的影响**：需要扩 L2 持仓模型并新增聚合端点（跨层、改写记忆契约）。**验证方式**：实现期已读模型与端点确认（2026-10-22）；收工时摘要条四项显式呈「未接入」并点名缺口，**不显示任何推算数字**。
- **A2 主区分栏的交互归 `T-UI-026`**：[14 册 §12](../../../../docs/PRD-v2-Agent/14-desktop-form.md) 把 `split-pane` 列为 P3，本叶只保证主区是「可再分栏」的自适应容器（最小 480px）且内层结构不阻碍后续分栏。**若错的影响**：本叶需补拖拽 / 交换 / 单侧折叠。**验证方式**：GWT 不含分栏交互；走查确认主区可容纳左右分栏。
- **A3 右栏复用 Chat 页并拆分为 `renderChatRail`，`/` 主区改为总览页**：Chat 的对话流 + 输入 + `/` 菜单独占右栏，上下文卡片留在 `/` 主区（[11 册 §2](../../../../docs/PRD-v2-Agent/11-sitemap.md) 明说上下文卡片「常驻首页」）。**若错的影响**：`test_ui_chat_page.py` 的既有断言与 `/` 的语义需要重定。**验证方式**：保留 `renderChatPage` 导出，同批订正该守卫；浏览器走查确认 `/` 主区与右栏各司其职。
- **A4 页内视图切换全部升为左栏二级**：`/memory` 三视图、`/settings` 六视图、`/delivery` 四视图从页内切换器移入左栏二级，**路径仍走查询串**（`/memory?view=…` 等），页内不再保留同一组切换器。**若错的影响**：二级项集合与 §2.2 的屏归并不一致，或出现两套同源入口。**验证方式**：走查逐分区核对二级项与查询串渲染结果；`test_ui_shell_routing.py` 的既有分区根断言仍绿。
- **A5 浏览器面保留为开发 / CI 面**（[D-120](../../../决策日志.md) 已决项 3）：本叶不动 pywebview 原生窗口，也不做窗口尺寸记忆。**若错的影响**：需要同批改 `shell/window.py`（归 `T-UI-027`）。**验证方式**：测试仍走回环 HTTP；`git diff` 不触及 `src/st_agent/ui/shell/**`。
- **A6 栏宽 / 折叠 / 展开态用 `localStorage` 持久化**（键 `st.shell.nav.w` / `st.shell.chat.w` / `st.shell.nav.collapsed` / `st.shell.chat.collapsed` / `st.shell.nav.open`），不做后端落盘。**若错的影响**：关闭浏览器后态丢失。**验证方式**：浏览器内刷新与跨页跳转后宽度、折叠、展开态保持。
- **A7 唯一 `h1` 由外壳产出，页面内的 `h2.page__title` 移除**：`/delivery` 与 `/settings` 的视图名改为页面内 `h2`（不重复页面标题）。**若错的影响**：文档大纲与既有走查文本变化。**验证方式**：GWT-4 的浏览器断言逐页核对 `h1` 文本；走查各页标题层级。
