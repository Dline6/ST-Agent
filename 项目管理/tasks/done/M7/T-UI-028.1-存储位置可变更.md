# T-UI-028.1 · 存储位置可变更（P0）

## 目标

- 设置-存储页新增「更改存储位置」：**迁移**（复制当前存储到新根，源保留）或**仅切换**（指向已有存储根）。
- 存储根指针落**用户级启动配置**（存储根之外）；解析顺序：`--root` > `ST_AGENT_ROOT` > 启动指针 > 平台默认。
- 提供「恢复默认位置」（清除指针）；变更后置重启闸门，明确提示重启生效。

## 验收标准（Given-When-Then）

- GWT-1：Given 设置-存储页显示当前根与来源，When 选择迁移到新路径，Then 新根生成且源根未动，指针写入启动配置，回报含 `restart_required`。
- GWT-2：Given 新根已存在且为有效存储，When 选择「仅切换」，Then 只写指针、不复制数据。
- GWT-3：Given 指针已指向新根，When 重启后端且未传 `--root`，Then 握手 `root` 为新根；迁移模式下分区数据完整可读。
- GWT-4：Given 指针存在，When 选择「恢复默认位置」，Then 指针清除，重启后回到平台默认根。

## 接口面

- 输入：
  - [`T-L0-018.1`](../M1/T-L0-018.1-存储加密可选与明密双向转换.md) 的 `Store.convert(source, target, to_format=…)`
  - [`T-UI-002.1`](../M3/T-UI-002.1-生产运行入口与壳后端握手协议.md) 的后端启动参数（`--root` 缺省路径解析）
- 输出：
  - `st_agent/l0/bootstrap/root.py`：`bootstrap_path()` / `read_store_root()` / `write_store_root()` / `resolve_root()`
  - `src/st_agent/__main__.py` 的缺省根解析改走 `resolve_root()`
  - `SettingsFacade.root_boot`（读指针与来源）· `UiApp.api_settings_store_relocate` · `POST /api/settings/store/relocate`
  - `src/st_agent/ui/web/js/pages/settings.js` 的存储页 chrome

## 可关闭的遗留

无。

## 假设与前提

- A1：存储根指针放在用户级目录（`STAgent-boot/bootstrap.json`，平台惯例同 `ui/shell/prefs.py`），**不放进存储根**——否则「完全清空」会把它一并删掉。若错：清空后指针悬空。验证方式＝用例断言清空存储根后指针仍在。
- A2：迁移复用 `Store.convert` 的同格式复制（源不动、写新根），不自行 `copytree`——它经分区锁取一致快照并原子落新根。若错：运行期复制可能拿到半写状态。验证方式＝用例断言迁移后目标根可打开且源根文件集不变。
- A3：加密根的迁移需要当前主密码；页面提供口令输入，明文根可留空。若错：迁移在加密根上必然失败。验证方式＝加密根用例显式给/不给口令两条路径。
- A4：切换存储根**必须重启**，本进程不热切换 `Store` 句柄；成功后置 `RestartGate`，不假装已切换。验证方式＝用例断言其后数据面恒 `unavailable`。
