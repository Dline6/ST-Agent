# T-L3-008 · 会话消息完整落盘与历史读面

## 目标

把助手回复也写入 `chat_history`（含出站载荷），并提供会话列表与单会话读取两条只读端口，使对话历史可查、可回放、可继续。

## 验收标准（Given-When-Then）

- GWT-1 助手轮落盘：Given 一次 `POST /api/chat` 产出了回复，When 请求处理完成，Then 该会话新增一条 `role=agent` 消息，含中性文本摘要与完整出站载荷，并写回 `chat_history/session/<id>.json`。
- GWT-2 会话列表：Given 存在多个会话，When `GET /api/chat/sessions`，Then 按 `updated_at` 倒序返回列表（会话 id、标题、创建 / 更新时刻、消息数、末条摘要）；标题取会话标题，缺省取首条用户消息。
- GWT-3 单会话读取：Given 指定会话 id，When `GET /api/chat/session?id=`，Then 返回默认链路的用户与助手消息（含载荷）；未知 id 返回显式失败信封（`validation_failed` / `empty` + 原因），不返回 500。
- GWT-4 向后兼容：Given 旧版会话文件没有载荷字段，When 读取，Then 正常解析，载荷为 `null`，不报损坏。
- GWT-5 守卫不变：Given 两条新读端点，When 不带令牌访问或当作 POST 使用，Then 分别为 401 与 404；未注入对话门面时 `unavailable` 并点名。

## 接口面

- 输入（消费的前置接口）：
  - `T-L3-001` 起既有的 `l3/chat/session.py`：`SessionStore.create / load / append / chain / sessions / export_markdown`，分区 `chat_history`，路径 `session/<id>.json`。
  - `src/st_agent/app.py` 门面的 `turn(body)`（对话端口，注入 `ui/app.py`）。
  - `ui/app.py` 的 `api_chat` 已构造出最终出站载荷（`status` / `reason` / `description` / `clarification` / `needs_confirmation` / `traces` / `session_id`）。
- 输出（本任务交付的公共 API / 落盘位置）：
  - `l3/chat/session.py`：`ChatMessage.payload`（可选映射，默认 `None`）；`SessionStore.append(..., payload=None)`；会话摘要辅助（供列表用）。
  - `app.py` 门面：`record_reply(session_id, text, payload)`、`list_sessions()`、`read_session(session_id)`（均为鸭子端口，`ui` 不 import `l3`）。
  - `ui/app.py`：`api_chat` 末尾调用 `record_reply`；新增 `api_chat_sessions()` / `api_chat_session(session_id)`。
  - `ui/server.py`：`GET /api/chat/sessions`、`GET /api/chat/session`（查询串 `id`）。
  - `docs/技术架构-v2/05-L3-对话主入口.md` §1：补助手轮落盘与历史读面口径。

## 可关闭的遗留

无（已扫各遗留册未闭区，无归属本任务的条目）。

## 假设与前提

- A1 落盘的载荷是 **UI 的最终出站形态**（已过中性化门与必填槽检查），由 `ui/app.py` 在同一次请求内回传给门面。若错：历史回放与当时所见不一致（例如回放出未经门检查的卡片）。
- A2 会话列表按需逐个 `load()` 取标题与更新时间，不建派生索引，避免第二事实源；本地会话数量有限。若错：会话很多时列表变慢，可另行引入索引（需单独决策）。
- A3 `payload` 为可选字段，pydantic 缺省 `None`，旧文件可读。验证：用现有 `chat_history` 文件跑读取用例。
- A4 助手消息的 `text` 取中性摘要（确认卡 / 澄清 / 结果类型 / 失败原因），供搜索与 Markdown 导出；完整内容在载荷里。若错：搜索命中变粗，但不丢数据。
- A5 本批只做列表与读取；重命名、删除、分支切换留待后续（本批 UI 不提供）。
