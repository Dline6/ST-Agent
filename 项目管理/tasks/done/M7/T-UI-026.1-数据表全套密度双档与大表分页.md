# T-UI-026.1 · 数据表全套、密度双档与大表分页（P1）

> M7 叶之四的第一半（[`T-UI-026`](T-UI-026-数据密集面表格图表与指标块.md) 按「GWT > 5」拆出，[D-127](../../../决策日志.md)）。
> 口径见 [14 册](../../../../docs/PRD-v2-Agent/14-desktop-form.md) §3.2（密度双档）与 §7（数据密集面）。

## 目标

把 `table` 渲染件从「静态表格」补成**桌面级可操作的数据表**（[14 册 §7](../../../../docs/PRD-v2-Agent/14-desktop-form.md)）：

- **sticky 表头**：主区滚动时表头常驻
- **列排序**：点击表头三态（升 / 降 / 无），三角指示；排序按**底层值**（数字按数值、其余按本地化文本），不改动显示编码
- **列宽**：拖拽列边界改宽；**双击边界自适应内容**；宽度**跨跳页保持**（本机偏好，按「表标题 + 列键」标识）
- **行选中**：整行选中（`--accent-weak` 底 + 1px `--accent` 描边）、`Ctrl+点击` 多选、`Space` 切换
- **键盘行导航**：`↑↓` / `Home` / `End` / `PageUp` / `PageDown` / `Enter`（打开行详情）/ `Space`（选中）
- **复制**：`Ctrl+C` 把选中行复制为 **TSV**（无选中则复制当前行），列序与屏上一致
- **密度双档**：`[data-density]` 换 `--row-h` / `--cell-y` / `--cell-x` 一组变量（同一套组件）；数据读面默认 `compact`，每张表可临时切，默认值可在设置里改
- **大表策略**：**分页**（阈值 100 行、每页 50 行），不做无限长表；排序 / 选中 / 键盘 / TSV 的语义都落在当前页

## 验收标准（Given-When-Then）

- GWT-1：Given 一张多行表，When 滚动主区，Then 表头常驻；点击表头可排序且三角指示三态正确
- GWT-2：Given 一张表，When 拖拽列边界，Then 列宽改变并**跨跳页保持**；双击边界自适应内容宽
- GWT-3：Given 一张表，When 全程只用键盘，Then 可 `↑↓` / `Home` / `End` / `PageUp` / `PageDown` 移动、`Enter` 打开、`Space` 选中；`Ctrl+C` 复制出的内容为 **TSV** 且列序与屏上一致
- GWT-4：Given 同一张表，When 在 `comfortable` 与 `compact` 间切换，Then 行高与内距按档变化，**列宽与选中态不丢**，且两种密度下数字列仍右对齐 + `tabular-nums`

## 接口面

- 输入（消费的前置接口）：
  - `table` 描述的既有槽形状：`slots.columns`（`{key, label, kind, digits}`）与 `slots.rows`（键控对象数组），产出方唯一漏斗 [`ui/tables.py`](../../../../src/st_agent/ui/tables.py)；**本叶不改描述契约、不新增槽**
  - 既有渲染路径 [`registry.js`](../../../../src/st_agent/ui/web/js/registry.js) 的 `table: renderTable` 与 [`render.js`](../../../../src/st_agent/ui/web/js/render.js) 的描述调度
  - 既有键盘与焦点约定 [`shortcuts.js`](../../../../src/st_agent/ui/web/js/shortcuts.js)（全局键不抢占表内按键）
  - 本机偏好通道：`localStorage`（与 [`main.js`](../../../../src/st_agent/ui/web/js/main.js) 的栏宽 / 折叠态同类）
- 输出（本任务交付的公共 API / 落盘位置）：
  - [`components/table.js`](../../../../src/st_agent/ui/web/js/components/table.js)：`renderTable` 扩展；导出纯函数 `sortRows` / `toTsv` / `nextRowIndex`（供静态守卫断言）
  - [`css/tokens.css`](../../../../src/st_agent/ui/web/css/tokens.css)：`:root` 的缺省密度变量与 `[data-density="comfortable"|"compact"]` 两组覆盖
  - [`css/app.css`](../../../../src/st_agent/ui/web/css/app.css)：`.data-table*` 的 sticky / 拖拽柄 / 选中 / 焦点 / 分页条 / 行详情样式
  - 本机偏好键：`st.density.default`（缺省 `compact`）、`st.table.widths.<身份>`（列宽百分比）
  - 设置页「界面偏好」块（[`pages/settings.js`](../../../../src/st_agent/ui/web/js/pages/settings.js)，`?view=storage` 顶部）改默认密度
  - 守卫：扩 [`test_ui_design_tokens.py`](../../../../tests/ui/test_ui_design_tokens.py)（密度令牌在 4px 网格上、`app.css` 允许消费 `--cell-x` / `--cell-y`）；新增 `tests/ui/test_ui_data_table.py`（静态断言 + 纯函数口径）

## 假设与前提

- **A1**（表身份）——前提：同一张表的 `title` 稳定、且与列键组合在本应用内唯一（已核 `记忆列表` / `分区与用量` / `持仓行情` 等各页表标题）；若错的影响：同页两张同标题同列的表会共用列宽；验证方式：身份串 `title + '|' + keys.join(',')`，守卫用例断言不同列键得到不同身份。
- **A2**（偏好可用性）——前提：`localStorage` 在壳内 WebView 与浏览器均可用；若错的影响：宽度与默认密度退化为仅本次会话；验证方式：读写包在 try/catch 中，坏值回落缺省。
- **A3**（分页而非虚拟滚动）——前提：分页能同时满足 sticky / 键盘 / TSV 的语义而不互相打架（[14 册 §7](../../../../docs/PRD-v2-Agent/14-desktop-form.md) 明说二者选一）；若错的影响：大表的滚动顺滑度不如虚拟滚动，但能力面完整；验证方式：GWT-1～4 的浏览器走查 + 纯函数分页边界用例。
- **A4**（不改契约）——前提：所有交互都在渲染面完成，`kind` 三值与三路冗余编码原样保留；若错的影响：触发 [`test_ui_table_vocabulary.py`](../../../../tests/ui/test_ui_table_vocabulary.py) 与 `test_ui_registry.py` 的既有断言；验证方式：既有守卫继续全绿。
- **A5**（密度令牌）——前提：密度变量须进 `tokens.css` 的 `:root` 才能被 `app.css` 消费守卫识别，并同批登记 [13 册 §2.1](../../../../docs/PRD-v2-Agent/13-visual-design.md)；若错的影响：`test_ui_design_tokens.py` 的名集 / 值断言翻红；验证方式：令牌守卫与 13 册表同批更新后全绿。
