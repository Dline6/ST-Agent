# T-UI-027.2 · 多窗口（P0）

> M7 叶之五的第二半（[`T-UI-027`](T-UI-027-桌面壳闭合与默认启动路径.md) 按「GWT > 5」拆出，[D-126](../../../决策日志.md)）。
> 口径见 [14 册 §1](../../../../docs/PRD-v2-Agent/14-desktop-form.md)「多窗口：至少支持主窗口 + 单个附属窗口」。

## 目标

- **附属窗口**：从托盘「新建窗口」开一个可并排使用的第二窗口（同一回环地址与令牌）
- **后端不重启**：附属窗口复用主窗口的后端句柄；壳不额外拉起后端子进程
- **生命周期**：附属窗口可单独关闭（不触发「收进托盘」语义，也不退出应用）；主窗口退出时一并回收

## 验收标准（Given-When-Then）

- GWT-1：Given 主窗口，When 触发「新建窗口」，Then 出现一个可并排使用的附属窗口，且**后端不因此重启**（进程形态不变）

## 接口面

- 输入（消费的前置接口）：
  - [`T-UI-027.1`](T-UI-027.1-窗口规格记忆与桌面壳闭合.md) 的 `WindowPort` 与 `PywebviewWindow`（`create` / `show` / `hide` / `destroy` / `load_url`）
  - [`T-UI-002.1`](../M3/T-UI-002.1-生产运行入口与壳后端握手协议.md) 的 `BackendHandle.client_url`（含令牌 fragment）
- 输出（本任务交付的公共 API / 落盘位置）：
  - `WindowPort.open_secondary(url)`（`src/st_agent/ui/shell/window.py`）
  - `Shell.open_window()` 与托盘菜单「新建窗口」（`src/st_agent/ui/shell/app.py`）；附属窗口登记与退出时回收
  - 守卫并入 `tests/ui/test_ui_shell_desktop.py`

## 可关闭的遗留

无（同 [`T-UI-027.1`](T-UI-027.1-窗口规格记忆与桌面壳闭合.md) 的逐册查册结果，`T-UI-027` 0 命中）。

## 假设与前提

- A1：pywebview 在 `start()` 之后仍可 `create_window` 追加窗口；每窗口独立生命周期。若错：附属窗口需改为启动前预建或另立方案。验证方式＝pywebview 源码核对 + 替身用例；真实 GUI 由关卡兜底。
- A2：附属窗口关闭**不**触发主窗口的 `closing → False` 逻辑（每个窗口独立订阅）。若错：关附属窗口会把主窗口收进托盘，语义混淆。验证方式＝替身用例断言各窗口的关闭回调互不影响。
- A3：多窗口**不改进程形态**（[00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md)）——仍是一个壳进程 + 一个后端子进程。若错：需重新论证进程边界。验证方式＝用例断言后端句柄未被二次拉起。
