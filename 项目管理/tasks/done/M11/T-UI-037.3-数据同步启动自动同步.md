# T-UI-037.3 · 数据同步启动自动同步

## 目标

在设置-数据同步页为每个「标的 × 数据集」提供「启动应用时自动同步」复选；后端启动时按勾选集合后台发起一个批次：
有数据按水位补齐到当天，无数据只取最新一期。

## 验收标准（Given-When-Then）

- **GWT-1 · 勾选持久化**：Given 勾选「全部 A 股 · 日线行情」，When 应用，Then 配置项
  `data-sync/auto.all_a.k_daily` 为真并产生 `data-sync-change/` 留痕；刷新页面仍勾选。
- **GWT-2 · 启动起批次**：Given 至少一项勾选，When 后端启动，Then 后台自动发起一个同步批次，不阻塞就绪握手。
- **GWT-3 · 有数据补齐到当天**：Given 该数据集已有水位，When 自动同步，Then 时间口径为按水位增量（`incremental`）。
- **GWT-4 · 无数据只取最新一期**：Given 该数据集无数据，When 自动同步，Then 日期类取最近 1 天、季度/年度取最近 1 期、
  信息面首轮传单日窗口。
- **GWT-5 · 不可用与并发跳过**：Given 标的不可用、自定义代码为空或已有批次在跑，When 启动自动同步，
  Then 跳过对应项并记录原因，不抛启动失败、不覆盖手动批次。

## 接口面

**输入**

- `DataSyncRunner` 的 `preflight_items` / `start_items` / `overview`（[`l0/sync_runner.py`](../../../../src/st_agent/l0/sync_runner.py)）。
- `DATASETS` / `TARGETS` / `resolve_targets`（[`l0/market/datasets.py`](../../../../src/st_agent/l0/market/datasets.py) /
  [`l0/market/targets.py`](../../../../src/st_agent/l0/market/targets.py)）。
- 统一配置注册表 [`l1/registry/facade.py`](../../../../src/st_agent/l1/registry/facade.py) 与 `/api/settings/apply`。
- `M5Runtime.data_sync` 与 `M5Runtime.settings.store`（[`composition/runtime/m5.py`](../../../../src/st_agent/composition/runtime/m5.py)）。

**输出**

- 新增 L0 模块 [`l0/market/auto_sync.py`](../../../../src/st_agent/l0/market/auto_sync.py)：`data-sync/auto.<target>.<dataset>` 的读写与校验。
- 新增 L1 族 `DataSyncAutoFamily`（`config_prefix = "data-sync/auto."`，留痕 `data-sync-change/`）。
- `DataSyncRunner.start_auto_sync(keys)`：按数据现状组装 items 并发起批次；信息面支持单日 `window` 透传。
- 数据同步读面 `values.auto_sync` 增加 `target:dataset` → 是否勾选。
- `__main__.run_backend` 就绪后在后台调用自动同步；前端每行新增复选。

## 可关闭的遗留

无。

## 假设与前提

- **A1 · 粒度＝标的×数据集**（2026-11-02 负责人 ④ 选定）：配置键与页面选择单位一致。
  **若错的影响**：改为按数据集一个开关，需迁移配置键并改前端行渲染。
  **验证方式**：GWT-1。
- **A2 · 自动同步使用数据集默认指标组**，不沿用页面临时选择。**验证方式**：GWT-3 / GWT-4 的 items 断言。
- **A3 · 自定义标的不参与自动同步**（启动时无代码集），跳过并记录。**验证方式**：GWT-5。
- **A4 · 信息面首轮压到单日**（2026-11-02 负责人 ④ 选定）：`DataSyncRunner` 新增 `window` 透传到
  `DataInfoSync.run_task`。**若错的影响**：信息面首轮会按既有 90 天 / 8 季基线多拉数据。
  **验证方式**：GWT-4。
- **A5 · 自动同步与手动批次共用单飞锁**：已有批次时跳过，不排队。**验证方式**：GWT-5。
