# T-UI-037.4 · 对话历史删除会话

## 目标

对话历史页支持删除会话：单条删除与勾选多条批量删除；删除活动会话后回到新对话。

## 验收标准（Given-When-Then）

- **GWT-1 · 单条删除**：Given 历史列表有一个会话，When 点该行「删除」并确认，Then 该会话从列表与
  `chat_history` 分区移除，响应 `deleted` 含该 id。
- **GWT-2 · 批量删除**：Given 勾选多个会话，When 点「删除所选」并确认，Then 全部移除，列表刷新。
- **GWT-3 · 删除活动会话**：Given 当前活动会话被删除，When 删除完成，Then 前端回到「新对话」状态。
- **GWT-4 · 未知标识不报错**：Given 传入不存在的 session_id，Then 回 `missing` 而整体仍 `ok`。
- **GWT-5 · 删除前确认**：Given 点删除，Then 弹出确认框；取消不发请求。

## 接口面

**输入**

- `SessionStore` 的 `sessions()` / `load()` / `save()` 与 `Store.delete`（[`l3/chat/session.py`](../../../../src/st_agent/l3/chat/session.py) /
  [`l0/storage/store.py`](../../../../src/st_agent/l0/storage/store.py)）。
- `DialogFacade.list_sessions` / `read_session`（[`composition/facades/chat.py`](../../../../src/st_agent/composition/facades/chat.py)）。
- 对话历史页与共享会话宿主（[`ui/web/js/pages/chat_history.js`](../../../../src/st_agent/ui/web/js/pages/chat_history.js) /
  [`ui/web/js/pages/chat.js`](../../../../src/st_agent/ui/web/js/pages/chat.js)）。

**输出**

- `SessionStore.delete(session_id)`——删除 `chat_history` 分区对应文件；不存在即 `SessionNotFoundError`。
- `DialogFacade.delete_sessions(session_ids)`——返回 `deleted` / `missing` 并留 `as_of`。
- `POST /api/chat/sessions/delete`（body `{session_ids: [...]}`）。
- `/chat` 页每行复选、全选、单行删除、批量删除与确认框。
- [05 §1](../../../../docs/技术架构-v2/05-L3-对话主入口.md) 补删除写面口径。

## 可关闭的遗留

无。

## 假设与前提

- **A1 · 物理删除、无回收站**（2026-11-02 负责人要求）：删除即从本地分区移除，不可恢复。
  **若错的影响**：若要求软删除，需增加 tombstone 字段与留存清理任务。
  **验证方式**：GWT-1 / GWT-2。
- **A2 · 删除只动会话文件，不级联**：消息全在同一会话 JSON 内，无独立消息表。
  **验证方式**：GWT-1 的文件计数断言。
- **A3 · 未知 id 回 `missing` 而非整体失败**：批量删除容忍部分不存在。**验证方式**：GWT-4。
