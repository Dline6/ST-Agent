# T-UI-002 · 桌面壳与打包

> **本任务已拆分（2026-10-05，命中[拆分触发](../../../工作流.md)「验收 GWT 条数 > 5」「涉及 2 个及以上契约小节 / 架构层」「单次预计会话轮次 > 20」）**——父任务只承载分组与验收口径，交付由三叶承接：[`T-UI-002.1`](T-UI-002.1-生产运行入口与壳后端握手协议.md)（生产运行入口与握手协议）· [`T-UI-002.2`](T-UI-002.2-桌面壳本体窗口托盘自启与通知接线.md)（桌面壳本体）· [`T-UI-002.3`](T-UI-002.3-打包与产物.md)（打包与产物）· [`T-UI-002.4`](T-UI-002.4-启动期凭据口令交互与凭据可用性.md)（启动期凭据口令交互——**由 `.2` 的 Windows 走查实测暴露**）。选型见 [D-076](../../../决策日志.md)。

## 目标
把表现层骨架套入**桌面壳**并完成打包：原生窗口、托盘常驻、自启、原生通知接线——壳**不含任何业务逻辑**，业务一律在后端（[D-060](../../../决策日志.md) ①）。壳选型在本任务 ④ 对齐时裁定为 **pywebview（系统 WebView 三引擎）**，[D-060](../../../决策日志.md) ① 的兼容底线因此字面成立（[D-076](../../../决策日志.md)）。

## 验收标准（Given-When-Then，从 Story 抄）
- Given 桌面壳产物已安装，When 启动，Then 原生窗口打开并加载本机回环界面（含启动令牌握手），**壳内渲染与浏览器直开表现一致**
- Given 窗口已打开，When 关闭窗口，Then **后端仍在运行**（托盘可唤起）——[00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md)「后端比任何窗口活得久」
- Given 托盘图标，When 选择显示 / 退出，Then 窗口被唤起 / 应用与后端一并**优雅回收**（无孤儿进程）
- Given 开机自启开关，When 打开或关闭，Then 平台的登录项注册随之生效（可关闭）
- Given 一条原生通知，When 触发，Then 通知在桌面**可达且不出网**
- Given 打包产物，When 在**无 Python 环境**的机器上运行，Then 界面可用（**产物含后端二进制**）

## 接口面
- **输入**：
  - [`T-UI-001`](../M1/T-UI-001-表现层骨架与本地服务通信面.md) 交付的前端工程与本机通信面——`ui.server.serve()` / `ui.app.build_ui()`、令牌经 URL fragment `#t=` 下发（[`api.js`](../../../../src/st_agent/ui/web/js/api.js) 只从 fragment 读、不落任何浏览器存储）
  - 生产组合根 [`app.build_m2_runtime`](../../../../src/st_agent/app.py)（L0–L4 装配，`chat` 门面**经鸭子端口**注入 `serve(chat=…)`——[`ui` 不 import `app`](../../../../tests/test_layering.py)）
  - [00 §1.1](../../../../docs/技术架构-v2/00-架构总览.md) 进程形态 · [02 §2.1/§2.4](../../../../docs/技术架构-v2/02-L0-本地优先基座.md)（分区 / 单一写者＝后端）· [02 §7](../../../../docs/技术架构-v2/02-L0-本地优先基座.md)（离线 `full` 档含本地通知）
- **输出**：
  - 生产运行入口 `python -m st_agent`（后端二进制形态）与**机器可读握手**（`host` / `port` / `token` / `pid`），以及**不依赖控制台**的收尾通道（stdin 停止指令 / EOF；GUI 壳无控制台，控制台信号送不到）——两者合起来即「壳↔后端的拉起 / 回收协议」，是壳消费的唯一接口
  - 桌面壳模块：`src/st_agent/ui/shell/**`（窗口 / 托盘 / 自启 / 通知接线；鸭子端口注入，便于离线单测）
  - 打包配置与产物：`packaging/**`（后端二进制 + 壳 + 静态资产）+ Windows 实测产物；macOS / Linux 构建口径（产物待各自主机，显式标注）
  - **不交付**：壳专有通道（Electron `preload` / IPC、Tauri `invoke` 一类）——UI 只经回环面取数（[T-UI-001](../M1/T-UI-001-表现层骨架与本地服务通信面.md) 的约束）；业务通知真链路归 [`T-L5-002`](T-L5-002-渠道适配器投递编排与升级链.md)

## 假设与前提
- **A1 · 壳只把回环 URL 交给系统 WebView，不需要壳专有通道**——前提：令牌经 URL fragment 下发、前端只经 HTTP 取 JSON，故壳的全部职责是「开窗 + 原生能力接线」。若错（壳需注入桥 / IPC）：破坏 [T-UI-001](../M1/T-UI-001-表现层骨架与本地服务通信面.md) 的「无壳专有通道」约束，并把壳选型重新锁死。验证方式：`ui/shell/**` 内不出现向 WebView 注册 JS 桥的调用；三叶用例钉住「壳经 HTTP 取数」。
- **A2 · 默认存储根可由实现自定，本批不触发契约变更**——前提：[02 §2.1](../../../../docs/技术架构-v2/02-L0-本地优先基座.md) 明说「物理组织由实现决定」，仅约束分区可独立导出 / 清空。若错（须登记根路径口径）：返工面＝默认根解析函数与其用例。验证方式：默认根按平台惯例 + `ST_AGENT_ROOT` 覆盖，用例逐平台断言。
- **A3 · 存储加密默认关 ⇒ 后端可免口令启动**——前提：[D-073](../../../决策日志.md) / [D-074](../../../决策日志.md) 把加密改为可选、默认关。加密根（用户显式开启后）的主密码交互形态**不在本批**，由后端显式 fail-closed。若错（须本批含口令交互）：返工面＝入口的启动面与壳的提示面。验证方式：加密根启动用例断言非零退出 + 显式原因，不静默降级为明文。
- **A4 · 三平台产物中本机只实测 Windows**——前提：本机为 Windows，macOS / Linux 产物须各自主机或 CI。若错（要求本批产出三平台产物）：须引入跨平台构建 runner，本批不能收口。验证方式：Windows 产物实测 + macOS / Linux 的构建口径（前置与命令）落在 `packaging/`，产物缺位**显式标注**。
- **A5 · 开机自启不注册为 01 §7 条目**——前提：自启的真相源是**操作系统的登录项注册本身**，注册为配置条目会造出第二份副本（与「单一事实源」取向相悖）；其交互面属[原生呈现面](../../../../docs/PRD-v2-Agent/11-sitemap.md)（已划出页面集、归本任务）。若错（要求「对话即配置自启」）：按[铁律 8](../../../工程宪法.md) 先补 [01 §7](../../../../docs/技术架构-v2/01-平台共享契约.md) 条目再实现。验证方式：自启开关读写 OS 注册项并对读；01 §7 注册表**不新增**该条目。
