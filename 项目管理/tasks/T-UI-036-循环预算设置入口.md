# T-UI-036 · 循环预算设置入口

## 目标

把已登记进 [01 §7](../../docs/技术架构-v2/01-平台共享契约.md) 的三条自主查证预算条目
（`investigate.max_steps` / `investigate.max_llm_calls` / `investigate.context_budget`）
接入设置区 `/settings?view=agent`（运行期授权页），让端用户经**结构化面板**自主调整，
落值仍走既有 `/api/settings/apply`（面键 `settings-config`）与 `investigate-change/` 留痕。

本任务**不新增配置条目、不改写面**：条目与 owner（[`LoopBounds`](../../src/st_agent/l3/runtime/bounds.py)）
由 [`T-AGT-007`](done/M5/T-AGT-007-循环上界开放为配置项.md) 交付；本任务只补「面板通道」的呈现与取数。

## 验收标准（Given-When-Then）

- **GWT-1 · 三条目可见**：Given 组合根已注册 `investigate` 族，When `GET /api/settings/agent-authorization`，
  Then 响应含 `budget` 段（`setting_panel`，面键 `settings-config`），`entries` 恰为三条，
  `config_id` 与当前值（缺省 8 / 12 / 16000）正确，每条 `actions` 为 `["set"]`、`input` 为 `text`。
- **GWT-2 · 落值生效并留痕**：Given 用户把 `investigate.max_steps` 从 8 改为 5，When `POST /api/settings/apply`
  `{config_id, action: "set", value: "5"}`，Then 回 `changed=true`；再取 `budget` 段当前值为 5；
  `LoopBounds.steps()` 得 5；`execution_log` 下出现 `investigate-change/` 记录。
- **GWT-3 · 非法取值 fail-closed**：Given `0` / 超上限 / `"abc"`，When `apply`，Then `validation_failed`，
  读回仍是原值，且不产生新落盘 / 留痕。
- **GWT-4 · 预算不依赖反思面**：Given 设置面在、`reflection` 面缺席，When `GET`，Then `panel` / `trail`
  为 `unavailable`，而 `budget` 段仍 `ok`（循环预算与运行期档位是两条独立登记族）。
- **GWT-5 · 设置面缺席 fail-closed**：Given 设置面缺席，When `GET`，Then 三段（含 `budget`）均为
  `unavailable` 且点名「未接入」，不 500、不装空表。

## 假设与前提

- **A1 · 入口并入 `view=agent` 而非新视图**（2026-11-02 负责人 ④ 选定）——前提：运行期授权页已是
  「Agent 运行控制面」的宿主，预算同屏可减少导航层级。
  **若错的影响**：迁移为独立设置视图，返工面＝前端视图装配 + 一条 `VIEW_TITLES`，后端段可原样复用。
  **验证方式**：GWT-1 断言该段挂在 `/api/settings/agent-authorization` 下。
- **A2 · 三条目用自由文本输入（`input: "text"`）**——前提：`setting_panel` 的取值面只有
  「下拉 / 自由文本 / 动作」三态；Skill 参数对 `number` / `integer` 已用自由文本先例
  （[`skills.py`](../../src/st_agent/ui/surfaces/skills.py)），值域由后端 owner 校验。
  **若错的影响**：若要求数字步进器，须先改 [01 §12](../../docs/技术架构-v2/01-平台共享契约.md) `setting_panel`
  的 `input` 取值域，再改前端渲染件——属契约 + 前端返工。
  **验证方式**：GWT-1 断言 `input == "text"`；GWT-2 / GWT-3 验证字符串经 `_coerce_value` 还原与拒绝。
- **A3 · 预算段不依赖反思面**——前提：预算条目属 `investigate` 族（`config_registry`），与运行期档位
  （L6 反思面）是两条独立登记族；反思面缺席不应连带隐藏预算。
  **若错的影响**：若产品要求整页同进退，恢复「任一段失败各段同错」即可，返工面＝一处分支。
  **验证方式**：GWT-4。
- **A4 · 不新增页内回滚按钮**——前提：`investigate` 族当前只有 `ChangeRecord` 留痕、未提供
  `changes()` / 回滚 API；本任务不扩大 owner 写面。
  **若错的影响**：若要求页内回滚，需给 `LoopBounds` 增读留痕与回滚接口，属另一个任务量。
  **验证方式**：GWT-2 只断留痕文件存在，不断回滚。
- **A5 · `_coerce_value` 把 `"integer"` 与 `"number"` 同口径还原**——前提：表单回传恒为字符串，
  而三条目的 `value_schema.type` 是 `"integer"`，不还原会被 `LoopBounds._check` 拒绝。
  **若错的影响**：若不改 `_coerce_value`，面板改值一律 `validation_failed`，功能不可用。
  **验证方式**：GWT-2 真链路落值 + GWT-3 非法值拒绝。
