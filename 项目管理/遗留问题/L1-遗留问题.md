### C1 补充 · 外部信源参考与三层分解（2026-09-26 核实；不改上述「归属 / 解封条件」）

负责人 2026-09-26 提出以开源项目 [`simonlin1212/a-stock-data`](https://github.com/simonlin1212/a-stock-data) 承接本条。核实结论：**可借鉴，不可「引入」**——取知识、不取依赖。该仓库是**信源字典**而非**机制**，按下表三层分解。

| 层 | 内容 | 仓库贡献 | 终态占比 |
|---|---|---|---|
| **A · 信源知识** | 端点 URL / 参数 / Referer / UA · 字段清单 · 防封限流参数（`em_get()`：串行 + 最小间隔 1 s + 抖动 + 复用 Session）· 主备源映射 | **高保真移植** | ~35–40% |
| **B · 数据建模** | 四域表组 DDL · 主键与去重口径 · `sync_state` 模式与水位 · 05 新鲜度契约 · `data_source` 注册 · 清洗规范化 | 被返回形态**加速**，仍须自研 | ~45% |
| **C · 机制** | 通道归属（[Q-002](../阻塞与未决.md)）· 配置开关（[01 §7](../../docs/技术架构-v2/01-平台共享契约.md)）· 降级编排 · 消费面接线 · 单一事实源约束 | **无** | ~15% |

**B 层的加速点**——仓库各端点的返回结构即表结构的列清单，互补部分（暂定四域）可直接反推（省掉调研期最易猜错的「这个域有哪些字段可得」）：

| 域 | 仓库端点 | 返回形态（已核实） | 反推表组 |
|---|---|---|---|
| **公告** | §7.1 巨潮 `cninfo_announcements`；备胎 `announcements_backup`（深交所官方 / 东财） | `{title, type, date, url}`；备胎带 `{title, time, pdf}` | `announcement` |
| **龙虎榜** | §3.5 `dragon_tiger_board` · §3.9 全市场；备胎 `dragon_tiger_backup`（沪深交易所官方，含营业部席位） | 上榜记录 + 买卖席位 TOP5 + 机构动向 | `dragon_tiger` + `dragon_tiger_seat` |
| **股东变化** | §4.3 `holder_num_change` | `{date, holder_num, change_num, change_ratio, avg_shares}` | `shareholder_num` |
| **舆情** | §10.1 互动易 · §10.3 上证e互动 · §10.2 热榜/人气榜 · §5.x 新闻 | 互动易 `{code, company, question, answer, answerer, ask_time}` | `sentiment_qa` + `sentiment_hot` |

**仓库实况（2026-09-26 经 `gh api` 核实）**：Apache-2.0 · 10,349 star / 1,888 fork · 创建 2026-05-11 · 最后推送 2026-09-25 · 单文件 `SKILL.md`（425 KB / 7,509 行，15 层 · 87 端点 · 34 源）· 根目录**无 `pyproject.toml` / `setup.py`**（**非 Python 库，不可 `pip` 安装**）· `.github/` 下仅 `FUNDING.yml`（**无 CI**）。四域所需端点**全为纯 `requests` / `urllib`**；重依赖（mootdx / pandas / stockstats）只落在行情 / 研报 / 基础数据 / 宏观层——本机制**不需要**。

**为何不可「引入」**：其消费模型是把内嵌 Python 注入 LLM 上下文、由调用方临时执行抓取代码，与[单一事实源](../../docs/数据库设计-BaoStock数据层/00-设计总览.md)（Skill 只读 L0、不直连外源）及官方 Pack 执行面的 `GWT-5` AST 断言正面冲突。正确姿势＝**重写进 L0 `Fetcher` 协议**（[fetch.py](../../src/st_agent/l0/market/fetch.py)：`(fields, rows)` → `map_*`），出网经 [02 §6 网关](../../docs/技术架构-v2/02-L0-本地优先基座.md)。

**两项须写进设计的风险**：① **舆情域无官方备胎**，且互动易只覆盖深市（沪市须走上证e互动）→ 表设计须容纳双源拼接或按交易所路由；② 抓取源随时失效（其自身记录：通达信 K 线 2026-09 失效、东财 IP 级封禁持续 20+ 小时、网易财经整站下线）→ [05 新鲜度契约](../../docs/数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md) 须把「源不可达」写成一等状态；现有 `unavailable` 信封已兼容，**无需新机制**。

**范围口径：互补而非「四域」固定（2026-09-26 修正）**——信息面取「**与 BaoStock 互补的部分**」，**暂定四域**，后续可能再引入其他域。收录判据为**两条并列**：① **供给侧不重复**（BaoStock 无此域）② **需求侧有明确消费方**（不预设）。仅 ① 不足以收录——仓库 87 端点里「BaoStock 补集」约 60 个，须由 ② 收敛。**去重口径以 [06-API映射契约](../../docs/数据库设计-BaoStock数据层/06-API映射契约.md) + `indicator_dictionary` 为单一事实源逐列比对**；已核出的**六处重叠**（照抄即需按 [多源扩展规约 §3](../../docs/数据库设计-BaoStock数据层/00-设计总览.md) 另建独立源表 + `v_` 聚合视图，成本高收益低）：

| 仓库层 | 与既有面的重叠 |
|---|---|
| L1 行情 | `k_line_daily` / `k_line_period` / `k_line_minute` / `adjust_factor` |
| L4.4 分红送转 | `dividend`（`query_dividend_data`） |
| L6 财务三表 · 申万行业 | `financial_quarter` · `stock_industry`（后者**部分**：仓库给**时点历史**，我们只存**当前快照**——同域不同语义，仍属 §3 的独立源表 + 聚合视图，**不可直接合并**） |
| L11 货币供应 / 存准 / 利率 | `macro_*` ×5 |
| L12 指数成分 / 交易日历 | `index_constituent` · `trade_calendar` |
| L14 业绩预告 | `profit_forecast` |

**文本类信息单独文件存储（2026-09-26 负责人提出）**——公告全文 / 舆情问答 / 新闻等**文本类**信息拟**单独以文件落盘**（而非仅入库表列），便于后续接入 **RAG** 与 **AI 自主查阅文档**。已核实的就绪底座（**无技术阻塞**）：[02 §2.1](../../docs/技术架构-v2/02-L0-本地优先基座.md) 的 `data_cache` 分区内容**已明列**「公告 / 行情 / 龙虎榜 / 股东 / 舆情」，**不需新分区**；[`Store`](../../src/st_agent/l0/storage/store.py) 已是「分区 + 分区内相对路径 → bytes」的通用 KV（含逐文件 `digest` + `size` 清单、落盘加密、分区级校验与独立导出 / 清空），**文本文件可直接落 `data_cache`，存储层零改动**。**未定的规格**（文件与表的事实源关系 · `announcement_id` 与路径的映射及 `EvidenceRef.ref` ≤128 约束 · 查阅面归属（L1 沙箱拦截越界，Skill 不能直接 `open()`，须经 L0 鸭子类型接口）· RAG 索引作为派生数据的落点 · 档案型文本是否升为默认备份）已登记 [未决 `Q-005`](../阻塞与未决.md)；**主备口径**与**未收录代码主键**另见 `Q-003` / `Q-004`。

**本补充不改** `C1` 的归属与解封条件；本文**核实时（2026-09-26）不构成** [Q-002](../阻塞与未决.md) 的决议——**随后负责人于同日裁定候选 A**（**L0 网关直抓**，见 [D-029](../决策日志.md)），上列互补范围口径、三层分解与去重口径即该决议的依据。
