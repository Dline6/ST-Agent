# 平台通用契约（面向所有 Story）

> 本文档定义所有功能 Story 共享的基础能力契约。**实现任何 story 前必读**：已有契约直接复用，不要在单个 story 内重复定义；若某 story 需要新契约，应先补入本文档。
> 契约的理论依据见 [03-goals.md](03-goals.md) 的设计原则；硬约束与合规见 [05-constraints.md](05-constraints.md)。

## 契约 1 · 本地数据底座

产品应能在用户本地存储与索引 ST 股票的财务指标、板块行情、公告、龙虎榜、股东变化、舆情等多源数据（首次运行需联网抓取一次建立本地缓存，之后可离线访问历史数据）。所有 Skill 共享同一份本地数据源，避免口径不一。
→ 主权与离线要求的完整定义见 [story-05 本地优先基座](story-05-local-first.md)；数据获取通道见 [story-08 MCP Hub](story-08-mcp-hub.md)。

## 契约 2 · 本地记忆持久化

Memory Graph、Skill 配置、对话历史、执行日志、反思日志、用户偏好全部存本地加密文件，用户可随时导出/导入/删除。
→ 记忆图谱的节点结构与编辑体验见 [story-03 Memory Graph](story-03-memory-graph.md)；加密与备份机制见 [story-05](story-05-local-first.md)。

## 契约 3 · LLM 调用抽象

产品支持用户自带 API Key（云端 LLM）或本地推理（本地小模型），两种模式可切换；产品方不中转、不留存任何 prompt / response。任何依赖 LLM 的功能必须定义"LLM 不可用"时的降级行为（见各 story 边缘情况）。
→ 提供方选择与 Key 管理见 [story-05](story-05-local-first.md)。

## 契约 4 · 数据协同复用

任何 Skill 可引用其他 Skill 的输出结果，无需重复计算；每次调用都留下可查的推理链记录。
→ Skill 间引用与工作流编排见 [story-02](story-02-skills-runtime.md)、[story-06](story-06-skill-studio.md)。

## 契约 5 · 结构化研判输出

所有非结构化信息（公告/舆情）经 Skill 处理后，产出带完整依据引用的结构化观点（立场/理由/证据/信心度/来源）。每条结论可追溯依据（引用了哪条公告/哪个指标）。
→ 多视角汇总的结构见 [story-04](story-04-multi-lens.md)。

## 契约 6 · 双通道配置（可配置性优先的落地形式）

所有能力必须同时提供两种配置入口：
- **对话入口**：自然语言表达意图 → 自动生成配置草稿 → 用户确认/微调（见 [story-01](story-01-chat-as-os.md)）
- **结构化配置面板**：显示全部参数 + 说明 + 默认值 + 修改历史（见 [story-02](story-02-skills-runtime.md)/[story-06](story-06-skill-studio.md)）

配置本身是产品的一等公民：可导出、可导入、可版本化。

## 契约 7 · 执行可追溯

每一次 Skill 运行都应留下可查的执行记录，含输入快照、输出、耗时、依赖链、错误信息。
→ 追溯记录的消费方（推理链可视化、反思闭环）见 [story-01](story-01-chat-as-os.md)、[story-09](story-09-reflection-loop.md)。

## 契约 8 · 多视角分歧并列

不同视角的分歧必须并列呈现，不合并、不掩盖、不给"统一建议"。
→ 完整定义与可视化见 [story-04](story-04-multi-lens.md)；对应设计原则 2/5 见 [03-goals.md](03-goals.md)。

## 契约 9 · 中性表达约束

所有 Agent 输出禁止拟人化：无人名、无性格设定、无第一人称立场表达（"我认为"❌）、无情感表达（"我担心"❌）、无对话体（"你说得对，但是"❌）。视角与副驾一律使用中性、功能化措辞（"从流动性视角看，证据显示……"）。此约束适用于所有生成文本的位置：分析结论、推送文案、反思报告、Skill 描述、错误提示。
→ 校验机制见 [story-04](story-04-multi-lens.md)；命名强制校验见 [story-06](story-06-skill-studio.md)。

## 说明

具体实现选型（模型、框架、后端/前端技术栈、加密算法、本地存储格式）与量化考核指标均不在本 PRD 约束范围内。
