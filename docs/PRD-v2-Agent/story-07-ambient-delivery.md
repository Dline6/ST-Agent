# Story 7 · Ambient Delivery 主动触达与注意力预算

> 本 Story 是产品的**触达层**：从"用户打开 App"翻转为"副驾主动融入用户生活节奏"。它消费 [story-04](story-04-multi-lens.md) 的研判结果、[story-03](story-03-memory-graph.md) 的个性化偏好，直接落地 [Anti-metrics](03-goals.md)（不追求推送量、不追求使用时长）。

## 功能描述

Ambient Delivery 层负责把副驾产出的信号主动送到用户面前，核心是"注意力预算管理"：
- **多渠道编排**：本地桌面通知、系统托盘、邮件（用户自带 SMTP）、IM Webhook（微信服务号 / 飞书 / 钉钉 / Telegram，用户自行配置）、语音朗读（TTS 本地）
- **注意力预算**：用户为每种情境设定预算（早通勤 20 分钟能看长内容 / 盘中工作时间只推紧急 / 晚上 30 分钟交互式对话 / 周末长周期回顾）
- **主动 vs 被动分级**：从"仅按需响应"到"温和提示"到"紧急打断"，用户为每种信号类型设定级别
- **每日报告作为主叙事**：副驾每天生成一份"给你的信"（本地生成，含昨日回顾、今日关注、多视角摘要），是主内容形态；实时告警是插入项
- **情境模式自动切换**：工作日/周末/出差/休假/紧急，可手动切换或按日历自动
- **不打扰作为一等公民**：默认策略是"少而准"，不是"多而全"

**覆盖的既有需求**：原"个股监控推送、风险预警触达、机会挖掘呈现"的送达通道。

## In Scope

- **多渠道适配**：桌面通知、邮件、IM Webhook（4-5 家主流）、TTS 语音
- **渠道偏好可配**：每种信号类型（紧急/重要/日常）对应哪些渠道，用户可配
- **注意力预算配置**：情境 × 时段 × 内容类型的三维矩阵，可视化配置
- **每日报告**：本地生成，含"昨天你做了什么、今天值得注意什么、多视角摘要、Memory 更新摘要"
- **紧急触达升级**：本地通知无响应 → 邮件 → IM → 语音（可配升级链）
- **推送疲劳监控**：如果用户连续忽略某类推送，副驾主动询问"这类推送对你有用吗？要不要减少？"（数据供 [story-09](story-09-reflection-loop.md) 消费）
- **推送文案个性化**：结合 Memory Graph，同样信号对不同用户措辞不同（激进型和稳健型）
- **离线降级**：断网时本地通知依然可用；云端渠道（邮件/IM）明确标注"离线，暂无法发送"（离线契约见 [story-05](story-05-local-first.md)）

## Out of Scope

- 基于位置的推送（本地优先 + 隐私考虑，不做）
- 短信推送（成本高、合规复杂）
- 电话语音推送（暂缓）
- 推送的自动 A/B 测试（由 [story-09](story-09-reflection-loop.md) 承接）

## 验收标准（Given / When / Then）

- Given 用户首次配置注意力预算，When 完成引导，Then 显示"你的注意力预算地图"（情境 × 时段 × 内容类型的可视化矩阵）
- Given 副驾产生一条紧急信号（如持仓退市风险），When 触达策略判断，Then 按用户配置的升级链依次发送（桌面通知 → 5 分钟未读 → 邮件 → 15 分钟未读 → IM）
- Given 副驾产生一条日常信号，When 触达策略判断，Then 汇总到"每日报告"中，不单独推送（除非用户显式配置）
- Given 每天早晨 8 点（用户配置的时间），When 到点，Then 本地生成"给你的信"日报，含昨日回顾 + 今日关注 + 多视角摘要 + Memory 更新摘要
- Given 用户连续忽略某类推送 5 次，When 检测到，Then 副驾主动询问"这类推送对你有用吗？要不要调整？"，用户可选择减少/关闭/保持
- Given 用户切换情境模式（如从工作日切到休假），When 切换，Then 触达策略立即变化（休假模式只推最紧急）
- Given 断网状态，When 有紧急信号，Then 本地通知正常发送 + 云端渠道明确标注"离线，暂无法发送"+ 网络恢复后自动补发（用户可关闭补发）
- 边缘情况：某渠道配置错误（如 IM Webhook 失效）→ 明确提示 + 自动降级到下一渠道
- 空状态：某日无值得推送的信号 → 日报明确写"今天没有需要打扰你的事"，不硬凑内容

## 设计触点

- **屏**：注意力预算配置页、渠道配置页、情境模式切换器、每日报告页、推送历史时间线、推送疲劳反馈对话框
- **组件**：预算矩阵、渠道开关、情境选择器、日报卡片、推送时间线
- **状态**：正常/离线降级/渠道失效/推送成功/推送失败/被忽略
