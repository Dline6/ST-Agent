# Story 5 · Local-first Foundation 本地优先与数据主权基座

> 本 Story 是产品的**基座**，是[设计原则 1（本地优先）](03-goals.md)的落地。所有其他 Story 都构建在它之上——数据的存储、加密、离线运行、导出携带、LLM 主权，都在此统一定义，其余 story 不再重复。

## 功能描述

产品的所有能力都建立在"本地优先"原则上：
- **本地存储**：Memory Graph、Skill 配置、对话历史、执行日志、反思报告、用户偏好全部存本地加密文件
- **离线运行**：核心能力（历史数据分析、Memory 读写、Skill 组合、多视角推理）在断网状态下可用；只有 LLM 推理和新数据抓取需要网络
- **数据可携带**：用户可以一键导出"我的整个投资大脑"（Memory + Skill 配置 + 对话历史 + 反思报告）为单个加密文件，跨设备迁移
- **数据可删除**：用户可以彻底删除任何数据（含派生数据），产品提供"完全清空"选项
- **LLM 调用主权**：用户自带 API Key（云端 LLM）或使用本地推理（本地小模型）；产品方不中转、不留存任何 prompt / response
- **数据源本地抓取**：ST 相关公开数据由客户端主动抓取（不通过产品方服务器中转）
- **首次运行需联网**：建立初始本地数据缓存，之后可长期离线使用

## In Scope

- **本地加密存储**：所有用户数据加密，密钥由用户密码派生
- **一键备份/恢复**：单个加密文件包含全部用户数据
- **完全清空**：一键删除所有数据（含备份文件位置提示）
- **LLM 提供方选择**：设置页允许配置云端 API Key（多家可选）或本地推理端点
- **数据源开关**：用户可以逐个开关数据源（比如禁用舆情抓取）
- **网络活动透明化**：产品应显示"过去 24 小时发起的网络请求"列表（域名 + 目的 + 时间 + 数据量），完全透明
- **离线模式指示**：断网时明确显示"离线模式，以下能力可用/不可用"
- **数据留存策略可配**：用户可设置对话历史、执行日志的自动清理周期

## Out of Scope

- 云端同步（即使多设备也靠用户手动导出导入）
- 端到端加密的多人协同（本地优先原则下不需要）
- 产品方的数据托管备份（用户自己负责备份）

## 验收标准（Given / When / Then）

- Given 用户首次安装产品，When 完成 Onboarding，Then 所有数据存本地（用户可查看存储位置和大小），无任何数据发送到产品方服务器
- Given 用户断网，When 打开产品，Then 明确显示"离线模式"+ 历史数据可查、Memory 可编辑、已缓存 Skill 可运行；LLM 依赖的功能明确标注"需要联网或本地推理"
- Given 用户点击"一键备份"，When 输入密码，Then 生成单个加密文件（含 Memory + Skill 配置 + 对话历史 + 反思报告），可复制到任何存储介质
- Given 用户在另一台设备恢复备份，When 输入密码，Then 完整还原所有数据（含 Memory 图谱结构、Skill 参数、历史对话）
- Given 用户配置云端 LLM API Key，When 调用 LLM，Then API Key 存本地加密 + 请求直接发到 LLM 提供方（不经过产品方服务器）+ 请求内容不留存
- Given 用户查看"网络活动"，When 打开面板，Then 显示过去 24 小时所有对外请求（域名 + 目的 + 时间 + 数据量），可导出
- Given 用户点击"完全清空"，When 三次确认，Then 所有本地数据（含派生数据、缓存、日志）彻底删除 + 提示备份文件位置由用户自行处理
- 边缘情况：本地存储损坏 → 从最近备份恢复；无备份则明确告知数据丢失范围
- 边缘情况：LLM API Key 泄露风险 → 提供"Key 使用记录"查询，用户可随时吊销重设

## 设计触点

- **屏**：设置-存储页、设置-LLM 提供方页、设置-数据源页、设置-隐私页、备份/恢复对话框、完全清空确认流程、网络活动面板、离线模式横幅
- **组件**：加密文件卡片、API Key 输入框（掩码）、数据源开关、网络请求列表、清空进度条
- **状态**：在线/离线/存储损坏/备份中/恢复中/清空中
