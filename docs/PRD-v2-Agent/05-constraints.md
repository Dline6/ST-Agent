# 约束与风险

> 本文档定义产品需求层面的硬约束（范围、设计、数据隐私合规）与关键风险。
> 冲突仲裁优先级（从高到低）：[03-goals.md](03-goals.md) 设计原则 > 本文档约束 > 各 story 内描述。
> 只保留产品需求层面的约束；技术选型约束、量化指标、发布/项目管理事项不在本 PRD 范围内。

## 范围与形态约束

- 数据以公开市场数据可得的更新频率为准，本产品非实时行情系统；
- 定位是"投资决策辅助 + 风险预警"，**不接管账户、不执行实盘买卖**；
- ST 为首个验证场景，本版不向其他板块铺开；
- 桌面客户端形态（Windows / macOS / Linux），本版不做移动原生 App（移动端通过 Ambient 渠道推送 + 响应式 Web 兜底，见 [story-07](story-07-ambient-delivery.md)）；
- 单机运行，本版不做多用户协同（本地优先原则，见 [story-05](story-05-local-first.md)）。

## 设计约束（不可妥协）

1. **本地优先**：所有用户数据必须本地存储；断网可运行核心能力；LLM 调用由用户自带 Key，产品方不中转。→ 详见 [story-05](story-05-local-first.md)
2. **中性视角**：多视角推理必须使用中性、功能化命名；禁止拟人化（人名/性格/第一人称/情感表达/对话体）。→ 详见 [story-04](story-04-multi-lens.md)
3. **可配置性优先**：所有能力必须提供对话 + 结构化面板双通道；配置可导出、可导入、可版本化。→ 详见 [10-platform-capabilities.md](10-platform-capabilities.md)
4. **多视角分歧并列**：不得为"看起来统一"而合并视角分歧；不给"统一建议"。→ 详见 [story-04](story-04-multi-lens.md)
5. **可解释性**：每条结论必须附完整推理链（数据来源 → Skill 调用 → 视角汇总）。→ 详见 [story-01](story-01-chat-as-os.md)
6. **共同演化透明**：反思演进的任何自动变更必须显式告知 + 可回滚。→ 详见 [story-09](story-09-reflection-loop.md)

## 数据 & 隐私 & 合规

- 本产品为**投资决策辅助**，非投资建议、非收益承诺，须显著风险揭示（ST 高风险 + 退市风险）；
- 用户自设持仓/关注池/Memory 属最敏感信息，必须本地加密存储；密钥由用户密码派生；产品方永远不接触；
- 须规避荐股、操纵等合规红线；提供"不构成投资建议"免责声明；不输出目标价与买卖指令；
- 多视角推理的中性化命名同时是合规策略——避免"AI 荐股""AI 分析师"的定性风险；
- MCP Server 挂载第三方工具时，用户必须逐个批准权限；产品方对第三方 Server 行为不承担责任，但必须提供透明化审计（网络活动面板，见 [story-05](story-05-local-first.md)/[story-08](story-08-mcp-hub.md)）；
- Skill 分享走本地文件（见 [story-10](story-10-skill-sharing.md)），产品方不托管；导入时必须校验 + 恶意行为拦截。

## 关键风险表

| 风险 | 可能性 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| **核心假设不成立**：用户不愿"共同演化"，只想开箱即用 | High | High | 先用 [story-01 Chat](story-01-chat-as-os.md) + [story-03 Memory](story-03-memory-graph.md) 的小样本验证：Onboarding 完成率、30 天后 Memory 自然丰富度；如证伪则退回表单化配置形态 |
| **本地优先的算力瓶颈**：本地推理质量不够，云端 LLM 又依赖用户 Key | High | M | 提供多档 LLM 选择（云端多家 + 本地小模型，见 [story-05](story-05-local-first.md)）；核心能力（数据检索、Memory 读写、Skill 编排）设计为不完全依赖 LLM |
| **中性化约束削弱推理表现力**：多视角输出过于结构化失去"洞见感" | M | M | 在结构化观点卡之外提供"关键分歧摘要"叙述段（仍禁止拟人化）；小样本测试用户理解度（见 [story-04](story-04-multi-lens.md)） |
| **Memory Graph 冷启动难**：新用户无记忆时体验打折 | High | M | Onboarding 快速构建初始画像（≤10 问）+ 首次使用引导用户在真实对话中自然沉淀（见 [story-03](story-03-memory-graph.md)） |
| **隐私敏感数据的用户信任成本**：即使本地存储，用户仍担心 | M | High | 网络活动透明化面板 + 一键备份/清空 + 明确产品方零数据接触声明（见 [story-05](story-05-local-first.md)）；开源核心加密模块列为后续候选 |
| **Skill 生态冷启动**：官方 Pack 之外无第三方 Skill | High | M | 官方 Pack 完整覆盖既有功能作为种子（见 [story-02](story-02-skills-runtime.md)）；MCP Hub 让用户可挂载现有 MCP 生态（见 [story-08](story-08-mcp-hub.md)）；Skill 分享走本地文件降低门槛（见 [story-10](story-10-skill-sharing.md)） |
| **Ambient 触达变成骚扰**：主动推送过度 | M | M | 默认策略"少而准"+ 推送疲劳监控 + 用户可一键切"仅按需响应"模式（见 [story-07](story-07-ambient-delivery.md)） |
| **Reflection Loop 漂移**：副驾学歪了 | M | High | 演进授权三档 + 所有自动变更可回滚 + 每周反思报告显式告知 + 用户可"训练"修正（见 [story-09](story-09-reflection-loop.md)） |
| **合规红线（被误当荐股工具）** | L | High | 强制风险揭示与免责 + 不给目标价/买卖指令 + 多视角分歧并列 + 中性化命名 + 决策记录归用户 |
| **桌面客户端分发与更新成本** | M | M | 提供主流平台安装包 + 自动更新（用户可关）+ 完整离线安装包 |
| **数据源稳定性**：公开数据源变更导致官方 MCP Server 失效 | M | M | 数据源开关可配 + 用户可自行挂载替代 MCP Server + 官方 Pack 快速跟进 |

> **异常态说明**：本文档未做异常态系统穷举。重点待穷举场景：离线模式、LLM 不可用、MCP Server 崩溃、本地存储损坏、演进漂移。当前各 story 内以"边缘情况/空状态"粗粒度覆盖，后续应补充独立的异常态文档（`12-edge-cases.md`，占位见 [README.md](README.md)）。
