# Story 9 · Reflection Loop 反思演进闭环 ⭐

> ⭐ 承载关键假设中"愿意长期共同演化"这一半——这是整个范式相对传统工具最深差异化，也是最后落地（P2）的能力，因为它依赖前面各层积累的行为数据。
> 本 Story 落地[设计原则 6（共同演化）](03-goals.md)：透明、可撤销、可回滚。消费 [story-02](story-02-skills-runtime.md) 执行日志、[story-04](story-04-multi-lens.md) 决策记录、[story-07](story-07-ambient-delivery.md) 推送反馈。

## 功能描述

Reflection Loop 让整个系统随时间演进：
- **反馈闭环**：用户对每次推送/结论的反应（采纳/忽略/追问/否定/点赞）自动记录，作为演进依据
- **每周反思报告**（本地生成，非邮件）：每周固定时间副驾主动生成一份"本周反思"，含：本周为你做了什么（触达 X 次、命中 Y 次采纳、过滤 Z 条噪音）；我观察到的你的偏好漂移；我犯的错误（哪些推送被你否定，我从中理解了什么）；我建议调整的配置（每条建议可一键接受/否决/延后）
- **用户可"训练"副驾**：用户明确说"这条不对，因为..."→ 副驾做概念性学习（不是简单加权），更新 Memory + Skill 参数建议
- **副驾主动提案新能力**：观察到"你反复问某类问题"→ 主动提议"要不要我为你创建一个专门处理这类问题的 Skill？"
- **A/B 自我实验**：小流量尝试新推送策略/新视角组合，效果好固化，不好回滚；用户可查看实验日志
- **演进授权级别可配**（对应[设计原则 3](03-goals.md)）：手动模式（永不自动变，只能建议）/ 协作模式（副驾提议→用户批准→生效）/ 自主模式（小步自主优化 + 每次变更显式告知 + 可回滚）

**覆盖的既有需求**：原"Agent 日志中心"升级为"反思中心"（不只记录执行，还做自我评估与演进）。

## In Scope

- **反馈采集**：所有推送/结论/建议都有"采纳/忽略/否定/追问"入口
- **每周反思报告**：本地生成，含上述 4 部分；用户可订阅到 Ambient 渠道（[story-07](story-07-ambient-delivery.md)）
- **训练对话**：用户可发起"我想训练你"对话，明确修正副驾的理解
- **主动提案**：副驾观察模式后主动提议新 Skill / 新视角 / 新配置
- **A/B 实验日志**：所有实验可查看（假设、样本、结果、决策）
- **演进授权级别**：设置页三档切换（手动/协作/自主）
- **变更历史**：任何自动变更都有完整日志，可一键回滚
- **回滚到出厂设置**：任何时候可完全重置演进状态（保留 Memory 原始数据）

## Out of Scope

- 跨用户的模式学习（本地优先，无联邦）
- 副驾自主修改 Memory（Memory 修改必须用户确认，见 [story-03](story-03-memory-graph.md)）
- 超过 3 个月的长期演进趋势分析（暂缓）

## 验收标准（Given / When / Then）

- Given 用户对某条推送点击"否定 + 说明原因"，When 记录，Then 反馈进入反思数据池 + 副驾在下次对话中主动提及"上次你说 XX 不对，我理解了 YY，是这样吗？"
- Given 每周日晚 8 点（用户配置时间），When 到点，Then 本地生成"本周反思报告"，含 4 部分完整内容 + 通过 Ambient 渠道推送
- Given 用户查看反思报告的"建议调整"，When 逐条处理，Then 每条建议可一键接受/否决/延后，接受后立即生效并记入变更历史
- Given 副驾观察到"用户反复问某类问题超过 5 次"，When 触发，Then 主动提议"要不要我为你创建一个专门 Skill？"+ 给出草稿（衔接 [story-06](story-06-skill-studio.md)）
- Given 用户切换演进授权级别到"自主"，When 副驾做小步优化，Then 每次变更都通过 Ambient 显式告知 + 用户可在变更历史中一键回滚
- Given 用户点击"回滚到出厂设置"，When 三次确认，Then 所有演进状态清空（Skill 参数恢复默认、A/B 实验停止、变更历史归档但可查）+ Memory 原始数据保留
- Given 用户发起"训练对话"，When 明确修正，Then 副驾做概念性理解（不是简单加权）+ 更新 Memory 中的"你的模式"节点 + 生成对应 Skill 参数调整建议
- 边缘情况：反馈数据不足（新用户）→ 反思报告明确写"数据还不够，下周见"，不硬凑
- 空状态：某周无任何推送 → 反思报告只写"本周无触达，无反馈可分析"

## 设计触点

- **屏**：每周反思报告页、反馈采集组件、训练对话页、主动提案卡片、A/B 实验日志页、变更历史时间线、演进授权设置页
- **组件**：反馈按钮组、反思报告卡（4 段式）、提案接受/否决按钮、实验假设-结果对照表、回滚按钮
- **状态**：反思生成中/已推送/已读/建议待处理/变更已生效/已回滚
