# 价值主张与差异化

> 本文档定义产品对不同用户的价值、竞争差异化、以及战略押注。
> 用户画像见 [02-personas.md](02-personas.md)；问题域与竞品对比表见 [01-overview.md](01-overview.md)；差异化依赖的能力落地见各 story。

## 对主用户（老周）

老周终于可以"拥有一个完全属于自己、越用越懂他、可离线运行、可携带可导出的投资副驾"，而不必"把持仓和心理弱点托管到云端 SaaS、每次用通用 AI 都要重新解释偏好、只能看结论不能看推理"——因为本产品把 Agent Runtime、Memory Graph、Skills、Multi-Lens Deliberation 全部搬到本地，让"懂你"这件事第一次归他自己所有。

**支撑这个承诺的能力**：[story-05 本地优先](story-05-local-first.md) · [story-03 Memory Graph](story-03-memory-graph.md) · [story-04 多视角推理](story-04-multi-lens.md) · [story-07 主动触达](story-07-ambient-delivery.md)。

## 对进阶配置者（小林）

小林可以通过对话 + 可视化编排组合 Skills、挂载自己的 MCP Server、把分析逻辑沉淀为可导出可分享的本地模板，实现"使用即学习 + 使用即创作"，而不必从零写代码或忍受黑盒工具，也不必被中央化商店的规则束缚。

**支撑这个承诺的能力**：[story-06 Skill Studio](story-06-skill-studio.md) · [story-08 MCP Hub](story-08-mcp-hub.md) · [story-10 本地分享](story-10-skill-sharing.md)。

## 对隐私敏感者（陈姐）

陈姐可以在完全断网状态下运行产品的核心能力（数据源缓存 + 本地记忆 + 本地推理），拔网线也不影响她对自己数据的完全掌控，且随时可以用一份加密文件把整个"她的投资大脑"备份到移动硬盘。

**支撑这个承诺的能力**：[story-05 本地优先](story-05-local-first.md) · [story-03 Memory 导出](story-03-memory-graph.md)。

## 竞争差异化（要具体）

- **对手做对的**：数据完整、实时、检索强（资管终端/信息终端）；对话式体验、可解释（通用 AI）；策略能力强（量化平台）。
- **对手留下的空白**：本地数据主权、个人化长期记忆、多视角中性推理、主动服务、自演进、ST 专项——六项没有任何单一竞品同时具备（对比表见 [01-overview.md](01-overview.md)）。
- **本产品填的是这个完整交叉空白**：本地优先 + 对话式主入口 + 个人记忆图谱 + 多视角中性推理 + 主动服务 + 自演进 + ST 专项。

## 战略押注

押"**数据主权 + 共同演化**"这条被主流 SaaS 忽视的赛道——不追求最大用户量，追求"每个用户都拥有自己的投资副驾"，形成极深的个人化锁定（因为记忆和技能沉淀在用户本地、不可迁移到其他产品）。

**这个押注成立的前提**是关键假设（见 [03-goals.md](03-goals.md) 末尾）：用户愿意投入初始意图表达并与产品共同演化，而不是只想开箱即用。
