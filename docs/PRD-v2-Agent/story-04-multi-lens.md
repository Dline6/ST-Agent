# Story 4 · Multi-Lens Deliberation 多视角推理 ⭐

> ⭐ 承载关键假设：多视角中性研判对用户决策真正有用且可信赖。
> 本 Story 受[设计原则 2（中性视角）](03-goals.md)与[设计原则 5（决策自主）](03-goals.md)双重硬约束，是全产品合规策略的核心（见 [05-constraints.md](05-constraints.md)）。
> 视角 = 一组 Skill（[story-02](story-02-skills-runtime.md)）+ 一套评判准则；推理输入含个性化记忆（[story-03](story-03-memory-graph.md)）。

## 功能描述

任何重要决策（如"是否值得关注某 ST 股"、"我的组合在 XX 情景下会怎样"、"这个策略靠不靠谱"）都进入 **Multi-Lens Deliberation** 流程：并行调用多个**中性视角**，每个视角独立产出结构化观点，然后进行"观点对照"（不是"辩论对话"），最后输出**分歧图**（一致点/分歧点/关键证据），交由用户判断。**系统永远不给统一建议。**

**核心约束（对应设计原则 2，不可协商）**：

- 视角命名必须中性、功能化：使用「机会视角 / 风险视角 / 流动性视角 / 基本面视角 / 情绪视角 / 合规视角 / 宏观视角」等描述性名称
- **禁止拟人化**：不给人名（"老张""小李"❌）、不给性格（"激进派""保守派"❌）、不用第一人称（"我认为..."❌）、不做情感表达（"我担心..."❌）、不用对话体（"你说得对，但是..."❌）
- 输出必须是结构化观点：`{ 立场: 看好/看空/中性, 关键理由: [...], 证据: [...], 信心度: 高/中/低, 触发的 Skill: [...] }`，而非一段"角色台词"

**覆盖的既有需求**：原"散户模拟 Agent、机构模拟 Agent"（去拟人化为情绪/基本面视角）、原"风险预警、机会挖掘、组合压力测试、策略评判"的深度决策形态。

## In Scope

**常设视角阵容**（官方预置 7 个，用户可增删）：

| 视角 | 职责 |
|---|---|
| 机会视角（Opportunity Lens） | 识别潜在上涨/反转/摘帽机会 |
| 风险视角（Risk Lens） | 识别退市/流动性/合规/系统性风险 |
| 基本面视角（Fundamental Lens） | 财务健康度、持续经营能力、安全边际 |
| 情绪视角（Sentiment Lens） | 舆情热度、龙虎榜资金、散户行为模式 |
| 流动性视角（Liquidity Lens） | 换手率、成交量、买卖价差、大额冲击 |
| 宏观视角（Macro Lens） | 政策导向、赛道景气度、系统性因素 |
| 合规视角（Compliance Lens） | 监管红线、信息披露完整性、异常交易嫌疑 |

**机制**：
- **用户自定义视角**：用户可创建自己的视角（本质是"一组 Skill + 一套评判准则 + 一个中性名字"），加入阵容
- **观点对照（Cross-Examination）**：并行输出后，系统自动比对各视角的**一致点**（哪些证据被多个视角引用）、**分歧点**（哪些结论冲突）、**盲点**（哪些数据没有任何视角引用）
- **分歧图可视化**：矩阵视图（视角 × 结论）+ 证据网络图（证据节点 + 引用关系）
- **用户可追问**：针对某个视角"你的信心度为什么是中？"→ 该视角展开完整推理链（对接 [story-01](story-01-chat-as-os.md) 的推理链可视化）
- **快速模式 vs 深度模式**：快速模式 = 3 个核心视角 + 简化对照；深度模式 = 全部视角 + 多轮交叉质询
- **Mini Debate**：当两个视角结论冲突时，自动触发一轮"证据交叉质询"，输出"冲突原因分析"（哪条证据被 A 引用被 B 忽略、哪个前提假设不同）
- **决策记录**：用户在 Deliberation 后做出的决策 + 理由，自动写入 [story-03 Memory Graph](story-03-memory-graph.md)

## Out of Scope

- 视角之间的"多轮自由对话"（严格中性化，只做结构化观点对照）
- "AI 帮用户拍板"（永远输出分歧图，不给统一建议）
- 预设视角的"权重"（用户自己判断）

## 验收标准（Given / When / Then）

- Given 用户问"是否值得关注 \*ST XX"，When 副驾识别为复杂决策，Then 询问"要走多视角推理吗？快速模式（3 视角）还是深度模式（7 视角）？"
- Given 用户选择深度模式，When 执行，Then 7 个视角并行运行，每个视角输出结构化观点卡（立场/理由/证据/信心度/触发 Skill），全程不出现任何拟人化措辞
- Given 所有视角输出完毕，When 汇总，Then 生成分歧图（矩阵 + 证据网络）+ 一致点摘要 + 分歧点摘要 + 盲点提示
- Given 两个视角结论冲突，When 检测到，Then 自动触发 Mini Debate 输出"冲突原因分析"
- Given 用户点击某个视角的"追问"，When 提问"信心度为什么是中"，Then 该视角展开完整推理链（数据来源、Skill 调用、判断规则）
- Given 用户创建自定义视角，When 命名，Then 强制校验中性化（拒绝"老张""激进派"等命名 + 拒绝第一人称描述）
- Given 用户做出决策，When 记录，Then 决策 + 理由 + 采纳的视角 + 忽略的视角全部写入 Memory Graph
- 边缘情况：某个视角的依赖 Skill 失败 → 该视角标注"数据不足，无法给出观点"，不影响其他视角
- 边缘情况：所有视角结论完全一致 → 明确提示"罕见的高度一致，请警惕群体思维"，仍展示证据
- 空状态：新用户未创建任何自定义视角 → 显示 7 个官方视角 + "创建你自己的视角"入口

## 设计触点

- **屏**：Deliberation 触发确认对话框、多视角并行执行进度页、分歧图矩阵视图、证据网络图视图、视角详情页、追问对话框、自定义视角创建页、决策记录页
- **组件**：视角卡（中性配色，立场标签）、分歧矩阵、证据节点、Mini Debate 冲突分析卡、决策记录表单
- **状态**：视角运行中/成功/失败/数据不足；决策待定/已记录
