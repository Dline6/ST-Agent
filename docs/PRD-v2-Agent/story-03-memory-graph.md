# Story 3 · Personal Investment Memory Graph 个人投资记忆图谱 ⭐

> ⭐ 承载关键假设：用户愿意让副驾沉淀关于自己的投资记忆并共同演化。
> 本 Story 是产品的**个性化核心**——所有 Skill 调用都读 Memory（个性化推理）、写 Memory（新事件/新观点/新反馈）。
> 记忆持久化的存储与加密契约见 [story-05 本地优先](story-05-local-first.md)。

## 功能描述

Memory Graph 不是简单的"用户设置"，而是一张结构化图谱，含 **6 类节点**：

1. **你是谁**：风险偏好、资金规模、投资年限、认知偏差自评
2. **你在关注什么**：持仓、观察池、板块偏好、题材兴趣
3. **你的 thesis**：对每只股/每个板块的看法，带时间戳和信心度
4. **你的历史**：每次决策、每个采纳/忽略的信号、每次对错
5. **你的模式**：副驾观察到的行为模式（如"总在周一冲动加仓"、"听信舆情多过基本面"）
6. **你的偏好演化**：时间序列（三年前偏激进、现在偏稳健）

用户可以直接查看、修改、删除任何记忆条目，也可以导入（从券商账单、从其他产品）或导出（备份、迁移、继承）。记忆既是个性化的根，也**本身就是配置面**——用户不需要填表，只需要说话/操作，副驾学习并沉淀（对应 [03-goals.md](03-goals.md) 可配置性优先原则）。

## In Scope

- **Memory Graph 可视化**：图谱视图 + 列表视图 + 时间线视图三种浏览方式
- **偏好画像卡**：首页上下文卡片显示"副驾眼中的我"摘要（风险偏好、当前主 thesis、近期决策倾向），一键进入完整图谱（卡片嵌在 [story-01](story-01-chat-as-os.md) 首页）
- **可查可编辑**：用户可修改任何节点（"你记错了，我不是稳健型"→ 立即修正 + 记录修正历史）
- **可导出可导入**：Memory 可导出为加密文件（用户完全拥有），可从文件导入（跨设备迁移、备份恢复）
- **记忆置信度与衰减**：每条记忆带置信度（来自用户明确表达 vs 副驾推断）和时间衰减（旧 thesis 信心度自动降低）
- **记忆冲突处理**：新信息与旧记忆冲突时，副驾主动询问"你之前说过 X，现在似乎 Y，是想法变了吗？"
- **记忆写入策略可配**：用户可设置"哪些维度副驾可自主推理写入、哪些必须问我"
- **隐私分级**：Memory 节点分公开/私有/敏感三级；导出/分享时（[story-10](story-10-skill-sharing.md)）不会附带私有敏感记忆
- **Onboarding 快速构建**：新用户首次使用时，通过一段对话快速建立初始画像（不超过 10 个问题）

## Out of Scope

- 多用户共享 Memory（本地优先，不做）
- Memory 的自动跨设备同步（用户手动导出导入）
- "模仿某位大 V"的记忆继承订阅（涉及合规，暂缓，见 [README.md](README.md) 占位候选清单）

## 验收标准（Given / When / Then）

- Given 新用户首次运行产品，When Onboarding 对话完成，Then Memory Graph 已建立初始画像（至少含风险偏好、投资年限、当前关注板块 3 类节点）
- Given 用户在 Chat 中说"我看好 XX 板块的反转机会"，When 副驾处理，Then 自动写入一条 thesis 节点（带时间戳 + 信心度中）+ 提示"已记录你的看法"
- Given 用户打开偏好画像卡，When 查看，Then 显示"副驾眼中的你"摘要（不超过 5 条关键标签），点击进入完整图谱
- Given 用户在图谱中发现某条记忆错误，When 编辑，Then 立即生效 + 记录修正历史（保留旧值供审计）+ 影响后续所有推理
- Given 副驾发现新信息与旧记忆冲突，When 触发写入，Then 主动询问用户，不擅自覆盖
- Given 用户导出 Memory，When 生成文件，Then 文件加密（用户设密码）+ 完整含所有节点 + 可在另一台设备完整导入
- Given 用户删除某条记忆，When 确认删除，Then 该节点及其派生推理链一起从图谱移除（不影响历史执行日志的原始记录）
- 边缘情况：Memory 数据损坏 → 从最近备份恢复 + 明确告知用户
- 空状态：某维度无记忆 → 显示"这个维度你还没告诉我任何信息" + 引导对话入口

## 设计触点

- **屏**：Memory Graph 图谱视图、列表视图、时间线视图、偏好画像卡、节点详情页、修正历史页、导入导出面板、Onboarding 对话
- **组件**：图谱节点、边、置信度徽章、时间戳、隐私分级标签、修正历史时间线
- **状态**：正常 / 冲突待处理 / 损坏恢复中 / 空维度
