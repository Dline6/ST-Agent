# 用户画像与分层

> 本文档定义产品为谁做、各类用户的 JTBD 与痛点、以及明确不为谁做。
> 以下 Persona 基于目标场景合理推断，**标注为待用研验证**（校准方法见 [README.md](README.md) 末尾占位清单）。
> 产品目标与设计原则见 [03-goals.md](03-goals.md)。

## Primary persona — 关注 ST 且重视数据主权的个人投资者「老周」

```
姓名：老周（推断锚点，非真实用户）
身份：30-45 岁个人投资者，有 A 股交易经验，风险偏好较高，关注 ST 反转/摘帽机会
情境：白天要上班，无法实时盯盘；面对 ST 公告、财报、舆情读不过来也读不懂；
     对把持仓和心理弱点托管到云端 SaaS 有明确抵触
JTBD：当持有多只 ST 股并担心退市风险时，老周想让一个"完全属于自己、可离线运行、
     越用越懂我"的副驾替他持续盯公告与风险信号、按他自己的偏好主动推送多视角研判，
     从而不错过反转机会、也不踩到退市/流动性大坑，同时保留对数据和决策的完全掌控。
当前 workaround：刷行情软件 + 手动翻公告 + 加社群听消息 + 偶尔问通用 AI（但每次都要重新解释偏好）
痛点：
  - 消息分散滞后、缺乏个性化条件、风险没有量化预警
  - 工具不"懂我"，我的 thesis 和偏好演化没地方沉淀
  - 云端 SaaS 数据主权焦虑，我不想让平台知道我的持仓和心理弱点
  - 只看结论不看推理，我不知道该不该信
```

**主要消费的功能**：[story-01 Chat 主入口](story-01-chat-as-os.md)、[story-03 Memory Graph](story-03-memory-graph.md)、[story-04 多视角推理](story-04-multi-lens.md)、[story-07 Ambient 触达](story-07-ambient-delivery.md)。

## Secondary persona — 学习型/进阶配置者「小林」

```
姓名：小林（推断锚点）
身份：对量化与技术分析有兴趣的个人用户，愿意自己动手配置分析链路
情境：想深入理解 ST 分析逻辑，不只是被动看结论；也希望能挂载自己写的数据爬虫
JTBD：当她想验证某套 ST 选股思路时，想通过对话 + 可视化编排组合 Skills、
     必要时挂载自己的 MCP Server 接入私有数据源，把分析逻辑沉淀成可复用可导出的模板，
     从而"使用即学习"，逐步建立起属于自己的投资工具箱。
痛点：
  - 现成工具要么全黑盒、要么门槛太高（要写代码）
  - 想接入自己的数据源（比如自己爬的雪球舆情）没有标准入口
  - 想分享自己的分析逻辑给朋友，但平台模板只能在平台内用
```

**主要消费的功能**：[story-02 Skills Runtime](story-02-skills-runtime.md)、[story-06 Skill Studio](story-06-skill-studio.md)、[story-08 MCP Hub](story-08-mcp-hub.md)、[story-10 Skill 分享](story-10-skill-sharing.md)。

## Tertiary persona — 隐私敏感的资深投资者「陈姐」

```
姓名：陈姐（推断锚点）
身份：45+ 岁，多年投资经验，资产规模较大，对隐私和合规极度敏感
情境：不愿意把任何持仓数据上传到云端；愿意为"本地部署 + 数据主权"付费
JTBD：她想找一个"完全离线可用、数据永远在自己电脑上、可以随时拔网线"的分析工具，
     即使功能少一点也能接受，只要不把她的秘密交出去。
痛点：所有 SaaS 都要求账号登录 + 数据上云；本地工具又太老太弱
```

**主要消费的功能**：[story-05 本地优先基座](story-05-local-first.md)（核心）、[story-03 Memory Graph](story-03-memory-graph.md)（数据主权）、[story-01 Chat 主入口](story-01-chat-as-os.md)。

## 这个产品不为谁做

- 不为机构资管交易员做（那类用户已有专业终端）；
- 不为完全不做风险管理的纯赌博型短线客做；
- 不为追求"AI 帮我下单、我不想动脑"的用户做——产品立场是决策辅助，不代替决策；
- 不为不愿配置任何偏好、期待"开箱即完美"的用户做——AI Native 产品的价值来自"共同演化"，需要用户投入初始的意图表达（对应关键假设，见 [03-goals.md](03-goals.md)）。
