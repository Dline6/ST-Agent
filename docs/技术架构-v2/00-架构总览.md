# 00 · 架构总览

本文定义 ST Agent v2 的整体架构形态、分层职责、依赖规则与端到端数据流。各层详细契约见对应文档，跨层公共契约见 [01-平台共享契约](01-平台共享契约.md)。

## 1. 系统形态

- **单机桌面客户端**（Windows / macOS / Linux），无产品方业务服务端
- 产品运行仅存在四类对外网络交互，全部经 [02-L0](02-L0-本地优先基座.md) 的统一出网网关并登记审计：
  1. 公开市场数据源抓取（客户端直连，建立本地缓存）
  2. 用户自带 Key 的 LLM 提供方（或本地推理端点，不出网）
  3. 用户自配的触达渠道（邮件 SMTP / IM Webhook，仅 [07-L5](07-L5-主动触达.md) 使用）
  4. 用户主动挂载的远程 MCP Server（默认禁用，显式开启）
- 除「只读的官方 Skill 索引」（浏览元数据与外部下载地址，见 [09-生态与分享](09-生态与分享.md)）外，不存在任何产品方托管的数据通道

## 3. 依赖规则

1. **单向向下**：第 n 层只能调用第 1..n-1 层暴露的接口；禁止下层调用上层、禁止任何形式的循环依赖
2. **契约先行**：跨层交互的数据结构一律使用 [01-平台共享契约](01-平台共享契约.md) 定义的类型（ResultEnvelope、Trace、SkillDescriptor、LensOpinion 等），各层不得私造跨层格式
3. **事件上行**：下层向上层只允许通过事件通知（如 Skill 执行完成、反馈产生、渠道失效），由上层订阅；事件携带 01 定义的 `trace_id` 保证可追溯
4. **基座不可绕过**：任何层的持久化、网络、LLM 调用必须经由 L0 子系统，不允许层内直连

## 4. 三条产品硬约束的架构落点

| 产品约束（PRD §4） | 架构落点 |
| --- | --- |
| 本地优先 | L0 是唯一持久化与出网出口；每项能力声明离线级别（full/degraded/none），见 [02-L0 §7](02-L0-本地优先基座.md) |

## 5. 端到端数据流（一次典型主动预警的生命周期）

以「持仓 ST 股出现退市风险公告 → 用户收到告警 → 反馈被记录」为例：

1. **数据入湖**：L0 数据源网关抓取公告 → 写入本地数据缓存（带快照 ID，首个数据源 BaoStock 的库表落地见 [数据库设计-BaoStock数据层](../数据库设计-BaoStock数据层/README.md)），登记 NetworkEvent
2. **Skill 执行**：L1 调度 `risk-alert` Skill（读取用户持仓配置 + 公告快照），产出 ResultEnvelope（含证据引用），记录 SkillRun 与 Trace
3. **记忆注入**：Skill 执行时经 L2 MemoryReader 读取用户风险偏好切片，个性化阈值判断
4. **信号生成**：命中阈值 → 产生 Signal（emergency 级，带 dedup_key），进入 L5
5. **触达编排**：L5 按注意力预算与情境模式选择渠道，沿升级链投递（桌面通知 → 邮件 → IM），每次投递留痕
6. **用户交互**：用户在 L3 对话中追问「为什么是高危」→ L3 消费 Trace 展开完整推理链（公告原文 → Skill 参数 → 触发规则）
7. **反馈回流**：用户点「已读/忽略/否定+原因」→ L6 记录 FeedbackEvent，进入反思数据池
8. **反思演进**：每周 L6 生成反思报告，若发现该类推送被连续忽略 → 提出配置调整建议 → 按演进授权档位走变更流（见 [08-L6 §5](08-L6-反思演进.md)）

反向流（用户发起）：用户在 L3 输入意图 → 澄清 → 任务派发（Skill / Deliberation / 配置草稿）→ 结果渲染 → 决策记录写回 L2。

## 6. 架构级设计原则

- **失败显式化**：任何环节不得静默失败或编造结果；所有输出使用 ResultEnvelope 结构化状态（01 §5）
- **一切可追溯**：数据快照、Skill 运行、视角观点、触达投递、配置变更均携带 trace_id 并落本地日志
- **一切可回滚**：配置、自建 Skill、视角、演进状态全部版本化；Memory 修改保留修正历史
- **能力与数据分离**：Skill 是无状态能力，用户状态只存在于 L2 记忆与配置注册表——这是 Skill 可分享（[09](09-生态与分享.md)）的前提
- **离线优先设计**：每项功能先定义离线行为，再定义联网增强
