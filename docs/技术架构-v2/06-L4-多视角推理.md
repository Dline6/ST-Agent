# 06 · L4 多视角推理（Multi-Lens Deliberation）

承载 [Story 4](../PRD-v2-Agent/story-04-multi-lens.md)。复杂决策场景（是否关注某标的、组合情景推演、策略评判）进入 Deliberation 流程：多个**中性视角**并行分析 → 结构化观点 → 交叉对照 → **分歧图**。用户是唯一决策者。

**架构级红线**：L4 不存在「汇总结论」组件——任何实现不得产出合并后的统一建议；输出物只有分歧图及衍生摘要。这是产品硬约束「多视角分歧并列」的代码化（PRD §7 设计约束 4）。

## 1. 视角模型（Lens）

| 字段 | 说明 |
| --- | --- |
| `lens_id` | 01 §1 标识 |
| `name` | 中性功能化命名（保存时过 01 §6 中性化校验，拒绝人名/性格标签/第一人称描述） |
| `skill_bundle` | 该视角运行的一组 Skill（引用 SkillDescriptor） |
| `judging_criteria` | 评判准则：规则化表达（可由用户配置；配置形态——自然语言 or 规则表达式——属 PRD 待澄清项，实现预留两种入口） |
| `confidence_policy` | 信心度判定规则（数据充分度 → high/medium/low） |
| `kind` | `builtin`（官方预置）/ `custom`（用户自建） |

### 常设视角阵容（官方预置，用户可增删）

| 视角 | 关注维度 | 承接 |
| --- | --- | --- |
| 机会视角 | 上涨/反转/摘帽机会 | v1 6.5 |
| 风险视角 | 退市/流动性/合规/系统性风险 | v1 6.4 |
| 基本面视角 | 财务健康度、持续经营、安全边际 | v1 A4（去拟人化） |
| 情绪视角 | 舆情热度、资金流向、散户行为模式 | v1 A3（去拟人化） |
| 流动性视角 | 换手率、成交量、买卖价差、大额冲击 | — |
| 宏观视角 | 政策导向、赛道景气、系统性因素（情景推演） | v1 6.6 |
| 合规视角 | 监管红线、信披完整性、异常交易嫌疑 | — |

## 2. 执行编排

```
触发确认 → 视角并行执行 → 结构化观点收集 → 交叉对照 → 分歧图
                └── 失败视角隔离（标 insufficient-data，不阻塞他者）
```

1. **触发确认**：L3 识别为复杂决策 → 询问模式（快速 = 3 核心视角；深度 = 全部视角）。快速模式默认组合（如 机会+风险+基本面）为官方预置配置，用户可改
2. **并行执行**：每个视角 = skill_bundle 调度（走 [03-L1 §1.2](03-L1-能力底座-Skills与MCP.md) 完整流水线）+ MemoryReader 注入用户偏好切片；输出 LensOpinion（01 §3），全程过中性化输出校验
3. **失败隔离**：某视角依赖 Skill 失败 → 该视角 `stance: insufficient-data`，其余照常
4. **记忆沉淀**：Deliberation 后用户的决策 + 理由 + 采纳/忽略的视角 → 写入 [04-L2](04-L2-记忆图谱.md) `history` 节点（供 [08-L6](08-L6-反思演进.md) 消费）

## 3. 交叉对照（观点对照，非辩论对话）

对照产物为 DisagreementMap：

| 字段 | 说明 |
| --- | --- |
| `agreements[]` | 一致点：被 ≥2 视角引用的同一证据 + 同向结论 |
| `disagreements[]` | 分歧点：每项含 topic、各视角立场（lens_id → stance）、冲突证据对 |
| `blind_spots[]` | 盲点：数据缓存中与主题相关、但无任何视角引用的数据维度（提示分析盲区；「数据维度」的可枚举集合以本地市场数据库的表结构与指标字典为准，见 [数据库设计 §05 指标字典](../数据库设计-BaoStock数据层/05-同步策略与新鲜度契约.md)） |
| `evidence_network` | 证据节点 + 引用关系（分歧图网络视图数据源） |

对照是**算法性比对**（证据引用交集/差集 + 结论方向比对），不引入额外 LLM「裁判」——任何带裁判的实现在架构上违规。

## 4. Mini Debate（冲突质询）

- 触发：两个视角结论方向冲突（positive vs negative）且引用证据重叠或前提相关
- 流程：对冲突证据做一轮**交叉质询**——每方视角对其对方引用的关键证据重新评估（证据是否成立/时效/权重），产出**冲突原因分析**：哪条证据被 A 引用被 B 忽略、哪个前提假设不同
- 形态约束：仍是结构化对照记录，非拟人化对话；禁止「你说得对，但是」式输出

## 5. 分歧图可视化

- 矩阵视图（视角 × 结论）为主视图；证据网络图为辅视图（主视图形态属 PRD 待澄清项，两视图均实现）
- 追问接口：点击某视角 → 展开该视角完整 Trace（复用 [05-L3 §7](05-L3-对话主入口.md) 推理链渲染）

## 6. 边界与特殊情形

- **全部视角结论一致**：明确提示「罕见的高度一致，请警惕群体思维」，仍完整展示证据
- **决策记录**：用户决策后写入 Memory（§2.4）；不做任何「建议」字段
- 空状态：无自定义视角时显示 7 官方视角 + 「创建你自己的视角」入口
- 触达联动：Deliberation 产生的紧急信号（如风险视角高危）走 [07-L5 Signal](07-L5-主动触达.md) 投递，摘要形态为「多视角摘要」而非单视角结论
