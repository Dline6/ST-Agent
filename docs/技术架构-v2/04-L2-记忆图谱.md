# 04 · L2 记忆图谱

承载 [Story 3](../PRD-v2-Agent/story-03-memory-graph.md)。Memory Graph 是产品个性化核心：一张**本地、可查、可编辑、可导出**的结构化图谱。所有 Skill 调用读它（个性化推理）、写它（新事件/观点/反馈）。物理存储在 L0 `memory` 分区（[02-L0 §2.1](02-L0-本地优先基座.md)）。

## 1. 节点模型

六类节点（type 枚举固定，字段按类型扩展；高级用户自定义节点 schema 属 PRD 待澄清项，实现预留类型扩展位但本版不承诺）：

| type | 对应 PRD 六问 | 核心字段（除通用字段外） |
| --- | --- | --- |
| `identity` | 你是谁 | 风险偏好、资金规模档、投资年限、认知偏差自评 |
| `attention` | 你在关注什么 | 持仓（`stock_id` 列表）、观察池、板块偏好、题材兴趣 |
| `thesis` | 你的 thesis | 对象（个股/板块）、观点内容、信心度、时间戳 |
| `history` | 你的历史 | 决策事件、采纳/忽略的信号（`feedback_id`）、结果对错 |
| `pattern` | 你的模式 | 副驾观察到的行为模式（如「总在周一冲动加仓」）、触发依据（引用 history 聚合） |
| `evolution` | 你的偏好演化 | 时间序列：某维度偏好随时间的迁移记录 |

**通用字段（所有节点必带）**：

| 字段 | 说明 |
| --- | --- |
| `memory_node_id` | 01 §1 标识 |
| `confidence` | 置信度（见 §5） |
| `source` | 枚举：`user_stated`（用户明确表达）/ `inferred`（副驾推断） |
| `provenance` | 推断类节点必带**可追溯依据**，二者**恰有其一**：`trace_id`（本地推理链锚点，01 §4；其产生方为 L1 调度器）或 `imported`（导入来源＝分享者 / 导入时刻 / 校验和 / 出处链，见 §8 与 [09 §5](09-生态与分享.md)）。导入并无本地推理链，故不借 `trace_id`——见 [D-051](../../项目管理/决策日志.md) |
| `privacy_level` | 枚举：`public` / `private` / `sensitive`（导出过滤依据，见 [09-生态](09-生态与分享.md)） |
| `revision_history` | 修正历史（旧值保留供审计） |
| `created_at` / `updated_at` | 时间戳 |

## 2. 边模型

| 边类型 | 语义 | 示例 |
| --- | --- | --- |
| `related_to` | 一般关联 | 持仓节点 ↔ thesis 节点 |
| `evolves_from` | 演化链 | 新 thesis ← 旧 thesis（偏好漂移分析的基础） |
| `derived_from` | 派生 | pattern 节点 ← 聚合的 history 节点（删除历史时级联评估） |
| `refers_to` | 外部引用 | thesis → `stock_id` / `announcement_id` |

## 3. 读写接口

### 3.1 MemoryReader

- **上下文切片查询**：输入（当前任务类型、对话主题、Token 预算），输出相关节点切片——供 [05-L3](05-L3-对话主入口.md) 上下文卡片、Skill 个性化参数、[06-L4](06-L4-多视角推理.md) 视角注入、[07-L5](07-L5-主动触达.md) 文案个性化使用
- 三种浏览视图（图谱/列表/时间线）共享同一查询层
- 切片必须携带 `as_of` 与置信度，让消费方知道「这是用户说的还是推断的」

### 3.2 MemoryWriter

- 写入路径二类：
  - **用户显式**（对话中表达偏好、Onboarding、手动编辑）→ `source: user_stated`，直接写入（编辑走修正历史）
  - **系统推断**（Skill 结果、反馈、模式识别）→ `source: inferred`，按 §4 写入策略决定直接写或进冲突队列
- **红线**：副驾不得自主修改既有 Memory 节点内容——修改必须经用户确认（PRD Story 9 Out of Scope 的架构化）；系统只能新增节点或发起修改提案

## 4. 写入策略与冲突裁决

- **自主写入白名单**：按节点维度配置（注册进 01 §7 配置注册表）——哪些维度副驾可自主写入、哪些必须询问。**粒度＝§1 的六类节点**；白名单只约束 `source: inferred` 的写入，`source: user_stated` 按 §3.2 直接写入
- **冲突检测**：新信息与既有节点语义冲突（如 thesis 方向相反、偏好标签变更）→ 产生 `MemoryConflictDetected` 事件（01 §11）→ L3 发起裁决对话：「你之前说过 X，现在似乎 Y，是想法变了吗？」
- **裁决结果**：用户确认变更 → **新增**一个节点作新版本（新 `memory_node_id`，**旧节点内容一字不改**——`evolves_from` 的两端须同存）+ `evolves_from` 边（新 → 旧，保留演化链）；确认不变 → 丢弃冲突提案并记录
- 不存在任何「静默覆盖」

## 5. 置信度模型

- 基线：`user_stated` > `inferred`；推断类节点必须带 `trace_id` 供下钻
- **时间衰减**：thesis 类节点信心度随时间自动降低（衰减曲线参数可配）；被新事件引用时重估（事件触发重估，两者结合，具体策略实现阶段定并注册为可配置项）
- 衰减与重估是**派生值**——按需计算，**不改写存量节点**（改写即「副驾自主修改既有节点内容」，与 §3.2 红线相抵）；消费方读到的切片同时携带有效值与节点存储值，使衰减可见、可追溯
- 消费方（视角、推送文案）按置信度调整表述强度

## 6. 删除与审计

- 删除任一节点 → 级联删除其**派生推理链**（`derived_from` 下游：边按「**派生方 → 依据方**」方向存储，故被删节点的下游＝以其为 `target_id` 的那些边的 `source_id`，递归取传递闭包）；该节点与下游节点**相接的边一并移除**（不留悬空边，与 §2 边模型的不变量一致），且删除是**用户显式**动作（`confirmed_by="user"`，同 §3.2 红线）
- 删除留一条**记录**（被删节点与相接边的快照、时刻、缘由）落 `execution_log` 分区供复核——但该分区中的**既有**原始记录一字不动：审计与反思依据不因记忆删除而失真
- 「完全清空」走 [02-L0 §8.3](02-L0-本地优先基座.md)

## 7. Onboarding 协议

- 新用户首启：对话式快速画像构建，**不超过 10 个问题**，产出至少 3 类初始节点（风险偏好 / 投资年限 / 当前关注板块）
- 问题清单由配置注册表管理（可随官方 Pack 更新），支持跳过（跳过维度进空状态引导）
- 空状态语义：某维度无记忆 → 展示「这个维度还没有任何信息」+ 引导对话入口；不阻断其他功能。**空状态是查询**（返回「哪些维度没有信息」），渲染与引导入口归交互层（L3）

## 8. 导出 / 导入 / 继承

- **完整备份**：随 L0 归档（含私有敏感数据，主密码加密）——由 L0 备份承载（`memory` 分区本在归档分区表内，见 [02 §8.1](02-L0-本地优先基座.md)），L2 侧不另立整库导出路径
- **片段分享**：L2 侧交付**强制三步**——过滤 `private`/`sensitive` 节点 → 展示「本次导出包含的公开信息」清单 → 用户确认后产出，产物是**片段载荷**（公开节点与相接边）；`.stmem` 的**文件容器**（`header` / `manifest` / 校验和 / 来源追溯段）归 [09 §1·§2](09-生态与分享.md)（四类分享物同构，待四类 payload 齐备定稿）。两处口径：
  - 片段只承载**当前值**——节点清空 `revision_history`：历史快照可能含早先的私有取值，节点级过滤管不到它（见 [D-052](../../项目管理/决策日志.md)）
  - 与过滤掉节点相接的边**一并剔除**（不留悬空边，同 §2 不变量）
- **导入他人公开片段**（即「继承」；他人的记忆公开片段，非「模仿某位大 V」的订阅式继承——后者见 story-03 Out of Scope）：
  - 入库为 `source: inferred`（他人陈述），`provenance.imported` 记分享者 / 导入时刻 / 校验和 / 出处链（[09 §5](09-生态与分享.md)）
  - **置信度封顶到推断基线**（故必低于本人表达——本人表达的基线更高），不必引入第三种 `source`
  - 节点 `memory_node_id` **保留分享方原值**，故重复导入**幂等**（已存在即跳过并报告，不产生副本、不静默覆盖）
  - 可编辑（走用户确认门 + 修正历史）可删除（走 §6 级联删除）
  - 载荷中含非 `public` 节点即**拒**——合法片段经导出侧强制过滤，出现即说明文件被改写或损坏（「导入数据同样过隐私分级」的落地形态）
- 从券商账单等外部数据导入初始画像：属导入通道（格式适配器方向，实现阶段评估），导入数据同样过隐私分级——**尚未立项**，登记于 [L2 遗留册](../../项目管理/遗留问题/L2-遗留问题.md)
