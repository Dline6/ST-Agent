# ST Agent 技术架构文档（v2）

本目录是《面向个性化投资决策的可配置主动服务 Agent》v2 PRD 的技术架构与数据契约文档族，供工程实现者与编码 Agent 直接消费。

- 需求来源：[PRD-v2-Agent/](../PRD-v2-Agent/README.md)（结构化 Story 目录，开发侧唯一需求真相源）
- 本文档族**不含**：具体技术栈选型、任何工具的具体版本号、目录/代码结构约定。所有约束以「能力契约 + 数据契约」形式表达，实现自由度留给工程阶段
- 变更规则：PRD 需求变更时，受影响的架构文档须同步修订；层间接口变更必须先改 [01-平台共享契约](01-平台共享契约.md) 再改各层文档

## 阅读路径

- **实现顺序（自底向上）**：01 共享契约 → 02 L0 → 03 L1 → 04 L2 → 05 L3 → 06 L4 → 07 L5 → 08 L6 → 09 生态
- **按任务切入**：
  - 做存储/加密/离线能力 → [02-L0](02-L0-本地优先基座.md)
  - 做 Skill 系统或 MCP 接入 → [03-L1](03-L1-能力底座-Skills与MCP.md) + [09-生态](09-生态与分享.md)
  - 做对话交互或 Generative UI → [05-L3](05-L3-对话主入口.md)
  - 做多视角分析引擎 → [06-L4](06-L4-多视角推理.md)
  - 做推送/通知 → [07-L5](07-L5-主动触达.md)
- **任何实现开始前必读**：[01-平台共享契约](01-平台共享契约.md)——它定义了全平台统一的 ID、错误、Trace、中性化校验与配置元模型，各层文档默认遵守

## 全局硬约束（源自 PRD §4，架构层不可妥协）

1. **本地优先**：所有用户数据本地加密存储；产品方零数据接触；核心能力离线可用——由 [02-L0](02-L0-本地优先基座.md) 承载
2. **中性视角**：禁止拟人化（人名/性格/第一人称/情感/对话体）——由 [01-平台共享契约](01-平台共享契约.md) 的中性化校验在契约层强制
3. **可配置性优先**：所有能力提供对话 + 结构化面板双通道，配置可导出/导入/版本化——由 [01-平台共享契约](01-平台共享契约.md) 的配置元模型承载
4. **多视角分歧并列**：不合并分歧、不给统一建议——由 [06-L4](06-L4-多视角推理.md) 架构上排除汇总组件
5. **可解释**：每条结论可追溯完整推理链——由 [01-平台共享契约](01-平台共享契约.md) 的 Trace 结构承载
6. **共同演化透明**：任何自动变更显式告知 + 可回滚——由 [08-L6](08-L6-反思演进.md) 的变更流承载
