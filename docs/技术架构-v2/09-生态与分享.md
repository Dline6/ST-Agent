# 09 · 生态与分享

承载 [Story 10](../PRD-v2-Agent/story-10-skill-sharing.md)。本地优先原则下**不做中央 Skill 商店服务端**：分享 = 本地文件导出/导入 + 只读的官方索引。本分册定义四类分享物的文件格式契约、导入校验流水线与来源追溯。

## 1. 分享物类型与文件格式

| 文件 | 内容 | 本体 |
| --- | --- | --- |
| `.stskill` | 单个 Skill（原子或复合） | SkillDescriptor + 实现定义（[03-L1](03-L1-能力底座-Skills与MCP.md)） |
| `.stflow` | 工作流 | WorkflowDAG |
| `.stlens` | 自定义视角 | Lens 定义（[06-L4](06-L4-多视角推理.md)） |
| `.stmem` | Memory 公开片段 | 经隐私过滤的记忆节点与边 |

**统一容器结构**（四类同构）：

| 段 | 内容 |
| --- | --- |
| `header` | 格式标识 + 格式版本（遵循 01 §9 版本语义） |
| `payload` | 分享物本体 |
| `manifest` | 元数据：作者声明、创建时间、依赖声明（所需 skill_id 清单）、**来源追溯**（分享者标识、原始出处链）、**校验和** |

注意与 [02-L0 §8.1 备份归档](02-L0-本地优先基座.md)的区别：备份 = 加密容器 + 含私有敏感数据；分享文件 = 明文可检视 + **强制隐私过滤**。两者格式同族但互不通用。

## 2. 导出流程

- 任何自建 Skill / 工作流 / 自定义视角可导出；导出物**不含任何 Memory 私有数据**
- `.stmem` 导出的强制三步：过滤 `private`/`sensitive` 节点 → 展示「本次导出包含的公开信息」清单 → 用户确认后生成
- 命名与描述过 01 §6 中性化校验（导出前拦截拟人化命名）
- 可选生成「分享卡片」：描述 + 校验和 + 下载指引，用户自行发布到任何外部渠道

## 3. 导入校验流水线

```
格式校验 → 依赖解析 → 权限审核 → 用户批准 → 安装
                └── 任一环节失败：明确报错，不安装
```

1. **格式校验**：header/校验和/结构合法性；损坏文件明确报错不安装
2. **依赖解析**：对照 manifest 依赖声明检查本地 Skill 库；缺失 → 明确提示 + 给出获取途径（官方 Pack / 外部下载），不自动安装
3. **权限审核**：展示「这个 Skill 想做什么」（权限申请列表，01 §10 模型）+ 依赖列表 + 来源追溯；用户逐项批准
4. **运行时防护**：安装后运行仍受 [03-L1 §1.5 执行沙箱](03-L1-能力底座-Skills与MCP.md) 约束——试图读取超出声明范围的本地文件等越界行为 → 拦截 + `BehaviorViolation` 警示「这个 Skill 行为异常」+ 提供禁用选项

## 4. 官方 Skill 索引

- 产品方维护**只读索引**：官方 Pack 更新信息 + 认证的社区 Skill 推荐（描述 + 外部下载地址 + 校验和）
- 索引仅提供元数据浏览；下载本身走用户直连外部渠道，文件到手后走 §3 导入流水线——产品方不经手任何用户数据与 Skill 文件
- 索引更新频率与恶意 Skill 检测规则库的维护机制属 PRD 待澄清项，架构上两者均为可随官方 Pack 更新的规则资源

## 5. 来源追溯链

- 每个导入物记录完整 provenance：分享者标识、导入时间、校验和、导入历史（多次转手的出处链）
- 溯源信息在 Skill 详情页可查；导入物在 Skill 库中以 `source: imported` 显式标识，与官方/自建/MCP 映射类并列

## 6. 生态边界

- 不做：中央商店（上传/下载/评分/评论服务端）、付费交易、自动更新订阅（重新导入需手动）
- 社区互动（评分、讨论）全部走外部渠道，产品只保证导入导出与安全校验能力
