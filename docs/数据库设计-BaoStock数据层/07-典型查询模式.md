# 07 典型查询模式

面向 Agent 高频场景的示例 SQL，全部可直接执行（表结构见 [schema.sql](schema.sql)）。执行任何分析前先跑新鲜度自检（见 [05-同步策略与新鲜度契约.md](05-同步策略与新鲜度契约.md)）。

## 1. 当前 ST 股票池（基础视图）

```sql
SELECT code, code_name, st_mark_date, close, pct_chg
FROM v_st_universe
ORDER BY pct_chg;
```

`v_st_universe` 已封装「在市（`security.status=1` 且 `type=1`）× 最新日线 `is_st=1`」双条件。ST 标记随行情日变化，池子的历史演变见场景 9。

## 2. ST 池 × 最新财务全景（行情 + 财务单次联查）

```sql
SELECT s.code, s.code_name, l.close, l.pe_ttm, l.pb_mrq,
       f.roe_avg, f.np_margin, f.yoy_ni, f.liability_to_asset, f.pub_date
FROM v_st_universe s
JOIN v_k_line_latest l       ON l.code = s.code
LEFT JOIN financial_quarter f ON f.code = s.code
     AND f.stat_date = (
        SELECT max(stat_date) FROM financial_quarter
        WHERE code = s.code)
ORDER BY f.yoy_ni;
```

`LEFT JOIN` 是刻意的：ST 公司财报披露延迟常见，缺财务行不应把证券从结果里挤掉。

## 3. 财务多季对比（一家公司近 8 季趋势）

```sql
SELECT stat_date, pub_date, roe_avg, np_margin, gp_margin, net_profit,
       yoy_ni, liability_to_asset, cfo_to_np
FROM financial_quarter
WHERE code = :code
ORDER BY stat_date DESC
LIMIT 8;
```

杜邦三分解视角（ROE = 净利率 × 周转 × 杠杆）：

```sql
SELECT stat_date, dupont_roe, dupont_nitogr, dupont_asset_turn, dupont_asset_sto_equity
FROM financial_quarter
WHERE code = :code
ORDER BY stat_date DESC LIMIT 8;
```

## 4. ST 池风险预告扫描（业绩预告信号）

```sql
SELECT f.code, s.code_name, f.pub_date, f.forecast_type, f.chg_pct_dwn, f.chg_pct_up
FROM profit_forecast f
JOIN security s ON s.code = f.code
WHERE f.forecast_type IN ('预亏','续亏','首亏','略减','预减')
  AND f.pub_date >= date(:today, '-180 days')
ORDER BY f.pub_date DESC;
```

`forecast_type` 为源文本（见 [06-API映射契约.md](06-API映射契约.md)），如需扩展信号词在其上做文本判断，不做枚举硬编码到 schema。

## 5. 前复权价格序列（收益计算专用）

```sql
SELECT trade_date, close, pct_chg
FROM v_k_line_daily_qfq
WHERE code = :code AND trade_date >= :start_date
ORDER BY trade_date;
```

区间累计收益直接用 `pct_chg` 累乘（涨跌幅复权法保证复权前后涨跌幅一致）：

```sql
SELECT round((exp(sum(ln(1 + pct_chg/100.0))) - 1) * 100, 4) AS cum_return_pct
FROM v_k_line_daily_qfq
WHERE code = :code AND trade_date >= :start_date;
```

**口径提醒**：跨系统比较价格时注意 BaoStock 涨跌幅复权法与同花顺/通达信不同（见 [02-行情数据层.md](02-行情数据层.md)）。

## 6. 分红历史与股息率

```sql
-- 历年分红
SELECT divid_plan_announce_date, divid_operate_date, divid_pay_date,
       divid_cash_ps_before_tax, divid_stocks_ps, divid_reserve_to_stock_ps, divid_cash_stock
FROM dividend
WHERE code = :code AND divid_operate_date IS NOT NULL
ORDER BY divid_operate_date;

-- 近12个月现金分红合计 / 现价（税前口径）
SELECT round((SELECT sum(divid_cash_ps_before_tax) FROM dividend
              WHERE code = :code
                AND divid_pay_date >= date(:today, '-365 days')) / l.close * 100, 4) AS dividend_yield_pct
FROM v_k_line_latest l
WHERE l.code = :code;
```

## 7. 行业视角（当前行业 + 行业内 ST）

```sql
-- 当前行业分布（最新快照）
WITH cur AS (
  SELECT code, industry, update_date,
         max(update_date) OVER (PARTITION BY code) AS md
  FROM stock_industry
)
SELECT industry, count(*) AS n_st
FROM cur c JOIN v_st_universe v ON v.code = c.code
WHERE c.update_date = c.md AND c.industry IS NOT NULL
GROUP BY industry ORDER BY n_st DESC;
```

行业变更历史（分析信号）：

```sql
SELECT update_date, industry
FROM stock_industry WHERE code = :code ORDER BY update_date;
```

## 8. 指数成分视角

```sql
-- 某快照日的沪深300成分（最新）
SELECT c.code, c.code_name
FROM index_constituent c
WHERE c.index_key = 'hs300'
  AND c.update_date = (SELECT max(update_date) FROM index_constituent WHERE index_key = 'hs300')
ORDER BY c.code;

-- 成分变动检测：两期快照差集
SELECT 'in' AS direction, a.code
FROM index_constituent a
WHERE a.index_key = 'hs300' AND a.update_date = :new_date
  AND a.code NOT IN (SELECT code FROM index_constituent
                     WHERE index_key = 'hs300' AND update_date = :old_date)
UNION ALL
SELECT 'out', b.code
FROM index_constituent b
WHERE b.index_key = 'hs300' AND b.update_date = :old_date
  AND b.code NOT IN (SELECT code FROM index_constituent
                     WHERE index_key = 'hs300' AND update_date = :new_date);
```

## 9. ST 状态演变（戴帽/摘帽事件）

```sql
-- 识别戴帽/摘帽日：相邻两交易日 is_st 翻转
WITH flagged AS (
  SELECT code, trade_date, is_st,
         lag(is_st) OVER (PARTITION BY code ORDER BY trade_date) AS prev_st
  FROM k_line_daily
)
SELECT code, trade_date,
       CASE WHEN is_st = 1 THEN '戴帽' ELSE '摘帽' END AS event
FROM flagged
WHERE prev_st IS NOT NULL AND is_st <> prev_st
  AND trade_date >= :start_date
ORDER BY trade_date;
```

## 10. 停牌监控

```sql
-- 当前停牌（最新日线 trade_status=0）的在市股票
SELECT s.code, s.code_name, l.trade_date
FROM security s
JOIN v_k_line_latest l ON l.code = s.code
WHERE s.type = 1 AND s.status = 1 AND l.trade_status = 0;
```

## 11. 宏观环境快照

```sql
-- 最新一期利率与准备金率 + 最新 M2 同比
SELECT (SELECT pub_date FROM macro_deposit_rate ORDER BY pub_date DESC LIMIT 1) AS last_deposit_pub,
       (SELECT fixed_1y  FROM macro_deposit_rate ORDER BY pub_date DESC LIMIT 1) AS deposit_1y,
       (SELECT pub_date  FROM macro_loan_rate   ORDER BY pub_date DESC LIMIT 1) AS last_loan_pub,
       (SELECT loan_6m_1y FROM macro_loan_rate  ORDER BY pub_date DESC LIMIT 1) AS loan_1y,
       (SELECT pub_date || ' → ' || effective_date FROM macro_reserve_ratio
         ORDER BY pub_date DESC LIMIT 1) AS last_reserve_adjust,
       (SELECT m2_yoy FROM macro_money_supply_month
         ORDER BY stat_year DESC, stat_month DESC LIMIT 1) AS m2_yoy_latest;
```

## 12. 数据新鲜度自检（每次分析前置）

SELECT task_key, table_name, last_status, last_success_at, watermark, last_error
FROM sync_state

-- 行情实际截止日
