# 03 财务与公司报告层

## financial_quarter — 季频财务指标宽表

**建模决策**：BaoStock 六个季频财务接口（盈利/营运/成长/偿债/现金流量/杜邦）共享完全相同的键结构（`code` + `pubDate` + `statDate`）与同一披露节奏，且杜邦与偿债、盈利之间存在算法重叠（如 `dupont_roe` ≡ `roe_avg`、`dupont_asset_turn` ≡ `asset_turn_ratio`）。拆六张表会让「一家公司一季度的财务全景」需要六次查询 + 六路拼接；合并为一张按 `(code, stat_date)` 对齐的宽表后，一次行读即得全景，且跨接口重叠指标的口径一致性由合并动作强制保证。

| 列组 | 来源接口 | 列 |
| --- | --- | --- |
| 键 | — | `code`(PK 1/2, FK→security)、`stat_date`(PK 2/2，季度末日如 `2017-06-30`) |
| 披露 | 六接口合并 | `pub_date`（**六接口 pubDate 的最大值**，即最新披露）、`updated_at`（入库时间，自动） |
| 盈利能力 | `query_profit_data()` | `roe_avg`、`np_margin`、`gp_margin`、`net_profit`、`eps_ttm`、`mb_revenue`、`total_share`、`liqa_share` |
| 营运能力 | `query_operation_data()` | `nr_turn_ratio`、`nr_turn_days`、`inv_turn_ratio`、`inv_turn_days`、`ca_turn_ratio`、`asset_turn_ratio` |
| 成长能力 | `query_growth_data()` | `yoy_equity`、`yoy_asset`、`yoy_ni`、`yoy_eps_basic`、`yoy_pni` |
| 偿债能力 | `query_balance_data()` | `current_ratio`、`quick_ratio`、`cash_ratio`、`yoy_liability`、`liability_to_asset`、`asset_to_equity` |
| 现金流量 | `query_cash_flow_data()` | `ca_to_asset`、`nca_to_asset`、`tangible_asset_to_asset`、`ebit_to_interest`、`cfo_to_or`、`cfo_to_np`、`cfo_to_gr` |
| 杜邦指数 | `query_dupont_data()` | `dupont_roe`、`dupont_asset_sto_equity`、`dupont_asset_turn`、`dupont_pnitoni`、`dupont_nitogr`、`dupont_tax_burden`、`dupont_intburden`、`dupont_ebittogr` |

全部指标列为 `REAL`、可空（源即存在大量空值，如银行股无存货周转）。完整字段语义、单位与算法说明以 [06-API映射契约.md](06-API映射契约.md) 为单一事实源，亦以种子数据形式落 `indicator_dictionary` 表供运行时内省。

```sql
CREATE TABLE financial_quarter (
  code      TEXT NOT NULL REFERENCES security(code),
  stat_date TEXT NOT NULL,
  pub_date  TEXT,
  roe_avg REAL, np_margin REAL, gp_margin REAL, net_profit REAL,
  eps_ttm REAL, mb_revenue REAL, total_share REAL, liqa_share REAL,
  nr_turn_ratio REAL, nr_turn_days REAL, inv_turn_ratio REAL, inv_turn_days REAL,
  ca_turn_ratio REAL, asset_turn_ratio REAL,
  yoy_equity REAL, yoy_asset REAL, yoy_ni REAL, yoy_eps_basic REAL, yoy_pni REAL,
  current_ratio REAL, quick_ratio REAL, cash_ratio REAL, yoy_liability REAL,
  liability_to_asset REAL, asset_to_equity REAL,
  ca_to_asset REAL, nca_to_asset REAL, tangible_asset_to_asset REAL,
  ebit_to_interest REAL, cfo_to_or REAL, cfo_to_np REAL, cfo_to_gr REAL,
  dupont_roe REAL, dupont_asset_sto_equity REAL, dupont_asset_turn REAL,
  dupont_pnitoni REAL, dupont_nitogr REAL, dupont_tax_burden REAL,
  dupont_intburden REAL, dupont_ebittogr REAL,
  updated_at TEXT NOT NULL DEFAULT (datetime('now')),
  PRIMARY KEY (code, stat_date)
);
```

**合并契约**（同步任务必须遵守）：

1. 六接口按 `(code, stat_date)` 对齐后 UPSERT 合并，列各写各的。
2. `pub_date` 取六接口可用 `pubDate` 的**最大值**；各接口披露日不一致的差值（通常同日）不单独保留。
3. 财务数据会被公司**修正**（更正公告）：同步采用「重拉窗口」策略——每次重拉最近 8 个季度 UPSERT 覆盖（见 [05-同步策略与新鲜度契约.md](05-同步策略与新鲜度契约.md)），`updated_at` 记录最后修正入库时间。
4. 数据范围：2007 年至今；`stat_date` 仅取季度末日四值（03-31 / 06-30 / 09-30 / 12-31）。

## performance_express — 业绩快报

| 列 | 类型 | 说明 |
| --- | --- | --- |
| code | TEXT, PK(1/2), FK→security | |
| stat_date | TEXT, PK(2/2) | 快报统计日期（通常为季度末/年末） |
| pub_date / update_date | TEXT | 披露日 / 最新披露日 |
| total_asset / net_asset | REAL | 总资产 / 净资产，元 |
| eps_chg_pct | REAL | 每股收益增长率 |
| roe_wa | REAL | 加权 ROE |
| eps_diluted | REAL | 摊薄 EPS |
| gr_yoy / op_yoy | REAL | 营业总收入同比 / 营业利润同比 |

```sql
CREATE TABLE performance_express (
  code      TEXT NOT NULL REFERENCES security(code),
  stat_date TEXT NOT NULL,
  pub_date  TEXT,
  update_date TEXT,
  total_asset REAL, net_asset REAL,
  eps_chg_pct REAL, roe_wa REAL, eps_diluted REAL, gr_yoy REAL, op_yoy REAL,
  PRIMARY KEY (code, stat_date)
);
```

**契约要点**：并非强制披露（交易所仅对若干情形要求），故覆盖率天然不全——「无快报行」不等于「无数据」，Agent 不得以本表缺失推断财务异常。同一 `stat_date` 多次更新时以最新 `update_date` 的值覆盖。

## profit_forecast — 业绩预告

| 列 | 类型 | 说明 |
| --- | --- | --- |
| code | TEXT, PK(1/2), FK→security | |
| stat_date | TEXT, PK(2/2) | 预告统计日期 |
| pub_date | TEXT | 发布日期 |
| forecast_type | TEXT | 预告类型（如 略增/预增/预亏/扭亏/续亏 等，文本原样落库） |
| abstract | TEXT | 摘要原文（含公司自述细节，是文本分析素材） |
| chg_pct_up / chg_pct_dwn | REAL | 归母净利润增长上限 / 下限，% |

```sql
CREATE TABLE profit_forecast (
  code         TEXT NOT NULL REFERENCES security(code),
  stat_date    TEXT NOT NULL,
  pub_date     TEXT,
  forecast_type TEXT,
  abstract     TEXT,
  chg_pct_up   REAL, chg_pct_dwn REAL,
  PRIMARY KEY (code, stat_date)
);
```

**契约要点**：`forecast_type` 保持源文本不做枚举归一（源类型集合未在手册中封闭列举，归一化属于业务层职责）；对 ST 场景，`预亏/续亏/扭亏` 类预告是风险信号的高优先级来源，典型用法见 [07-典型查询模式.md](07-典型查询模式.md)。
