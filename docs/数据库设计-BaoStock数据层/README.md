# 数据库设计 — BaoStock 数据层

ST Agent 本地市场数据库（SQLite 单文件）的设计文档族。以 BaoStock 为首个数据源，为全部 Skill 提供共享的行情/财务/公司报告/板块/宏观数据查询面，对齐产品「本地优先、单一数据源口径」的基座要求。

## 核心设计决策速览

1. **只存不复权行情 + 复权因子**，前/后复权价经视图推导（涨跌幅复权法，推导后 pct_chg 与源一致）。
2. **K 线按数据形态分三表**（日 / 周月 / 分钟），对应 API 三套字段集；分钟线为可选域默认不拉。
3. **财务六接口合并为一张 `(code, stat_date)` 宽表**，跨接口口径一致性由合并动作强制保证。
4. **板块数据保留历史快照**（周频），行业变更与指数成分调入调出本身是分析信号。
5. **同步状态即元数据**（`sync_state`），Agent 分析前先跑新鲜度自检，数据陈旧时降级而非静默使用。
