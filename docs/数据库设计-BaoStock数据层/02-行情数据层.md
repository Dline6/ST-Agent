# 02 行情数据层

行情域覆盖价格量额（K 线）与股本事件（除权除息、复权因子）。核心决策见 [00-设计总览.md](00-设计总览.md)：**只落不复权原始行情，复权价经视图推导**。

K 线按数据形态分三张表，而非一张大表加频率列——因为日/周月/分钟线的字段集本来就不同（日线独有估值与交易状态指标，分钟线无指数数据），分表是字段集差异的正确映射，不是冗余：

| 表 | frequency 取值 | 独有字段 | 指数支持 |
| --- | --- | --- | --- |
| `k_line_daily` | 固定日线 | `preclose`、`turn`、`trade_status`、`pct_chg`、估值四指标、`is_st` | 支持 |
| `k_line_period` | `w` / `m` | `pct_chg`（区间口径）、`turn` | 支持 |
| `k_line_minute` | `5` / `15` / `30` / `60` | 无 | 不支持（源限制） |

## k_line_daily — 日线行情（不复权）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| code | TEXT | PK(1/2), FK→security | 证券/指数代码 |
| trade_date | TEXT | PK(2/2) | 交易日 |
| open / high / low / close / preclose | REAL | | 价格，精度 4 位，元 |
| volume | INTEGER | | 成交量，股 |
| amount | REAL | | 成交额，元 |
| turn | REAL | | 换手率 %，精度 6 位；停牌为 NULL |
| trade_status | INTEGER | CHECK IN (0,1) | 1正常 0停牌 |
| pct_chg | REAL | | 日涨跌幅 %，精度 6 位 |
| pe_ttm / pb_mrq / ps_ttm / pcf_ncf_ttm | REAL | | 估值四指标 |
| is_st | INTEGER | CHECK IN (0,1) | 当日是否 ST |

```sql
CREATE TABLE k_line_daily (
  code         TEXT NOT NULL REFERENCES security(code),
  trade_date   TEXT NOT NULL,
  open REAL, high REAL, low REAL, close REAL, preclose REAL,
  volume       INTEGER,
  amount       REAL,
  turn         REAL,
  trade_status INTEGER CHECK (trade_status IN (0,1)),
  pct_chg      REAL,
  pe_ttm REAL, pb_mrq REAL, ps_ttm REAL, pcf_ncf_ttm REAL,
  is_st        INTEGER CHECK (is_st IN (0,1)),
  PRIMARY KEY (code, trade_date)
);
CREATE INDEX idx_k_line_daily_date ON k_line_daily(trade_date);
```

**契约要点**：

- 仅落 `adjustflag=3`（不复权）。拉取时即固定该参数，不落复权行。
- **停牌行照落**：源数据中停牌日开高低收均等于前收、量额为 0、`turn` 为空。这些行是「该证券当日无交易」的事实，不能丢弃（否则时间序列出现空洞）；`turn` 清洗为 NULL。
- `preclose` 在除权除息日不等于前一日 `close`（是交易所公布的理论前收），这是正确行为，消费方不得自行「修正」。
- 存储范围：1990-12-19 起至今全市场（A 股 + 指数）。
- 指数行：`turn`、`is_st`、估值指标等个股专属字段为 NULL。

## k_line_period — 周线/月线（不复权）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| code | TEXT | PK(1/3), FK→security | |
| frequency | TEXT | PK(2/3), CHECK IN ('w','m') | w周线 m月线 |
| trade_date | TEXT | PK(3/3) | 区间最后一个交易日 |
| open / high / low / close | REAL | | |
| volume / amount | INTEGER / REAL | | 区间累计 |
| turn / pct_chg | REAL | | pct_chg 为区间口径（相对区间首个交易日前收盘） |

```sql
CREATE TABLE k_line_period (
  code       TEXT NOT NULL REFERENCES security(code),
  frequency  TEXT NOT NULL CHECK (frequency IN ('w','m')),
  trade_date TEXT NOT NULL,
  open REAL, high REAL, low REAL, close REAL,
  volume INTEGER, amount REAL, turn REAL, pct_chg REAL,
  PRIMARY KEY (code, frequency, trade_date)
);
```

**契约要点**：周线仅在每周最后一个交易日产生、月线仅在每月最后一个交易日产生——同步任务据此判断增量窗口（见 [05-同步策略与新鲜度契约.md](05-同步策略与新鲜度契约.md)）。**不落周月线也可由日线聚合推导**，落库目的仅为高频查询加速；若存储紧张本表可降级为按需物化。

## k_line_minute — 分钟线（不复权，可选域）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| code | TEXT | PK(1/3), FK→security | 仅个股，指数无分钟线 |
| frequency | TEXT | PK(2/3), CHECK IN ('5','15','30','60') | 分钟周期 |
| bar_start | TEXT | PK(3/3) | bar 起始时刻 `'YYYY-MM-DD HH:MM:SS'`（API `time` 字段 `YYYYMMDDHHMMSSsss` 归一化） |
| open / high / low / close | REAL | | |
| volume / amount | INTEGER / REAL | | 周期内累计 |

```sql
CREATE TABLE k_line_minute (
  code      TEXT NOT NULL REFERENCES security(code),
  frequency TEXT NOT NULL CHECK (frequency IN ('5','15','30','60')),
  bar_start TEXT NOT NULL,
  open REAL, high REAL, low REAL, close REAL,
  volume INTEGER, amount REAL,
  PRIMARY KEY (code, frequency, bar_start)
);
```

**契约要点**：本表为**可选域**，初始化不拉取（全市场分钟线体量与 ST Agent 决策场景不匹配）；仅对用户关注池证券按需拉取，任务 `bs_k_minute` 默认禁用（见 [05-同步策略与新鲜度契约.md](05-同步策略与新鲜度契约.md)）。

## adjust_factor — 复权因子

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| code | TEXT | PK(1/2), FK→security | |
| ex_date | TEXT | PK(2/2) | 除权除息日期（API `dividOperateDate`） |
| fore_adjust_factor | REAL | NOT NULL | 向前复权因子 |
| back_adjust_factor | REAL | NOT NULL | 向后复权因子 |
| adjust_factor | REAL | NOT NULL | 本次复权因子 |

```sql
CREATE TABLE adjust_factor (
  code              TEXT NOT NULL REFERENCES security(code),
  ex_date           TEXT NOT NULL,
  fore_adjust_factor REAL NOT NULL,
  back_adjust_factor REAL NOT NULL,
  adjust_factor     REAL NOT NULL,
  PRIMARY KEY (code, ex_date)
);
```

**契约要点**：BaoStock 采用**涨跌幅复权法**（与同花顺/通达信口径不同，跨系统比较时须注意）。因子行仅在除权除息日产生，视图推导时对「无事件区间」取因子 1。

## dividend — 除权除息信息

| 列 | 类型 | 说明 |
| --- | --- | --- |
| dividend_id | INTEGER | 代理主键 |
| code | TEXT, FK→security | |
| divid_pre_notice_date … divid_stock_market_date | TEXT × 8 | 预披露/股东大会/预案/实施/股权登记/除权除息/派息/红股上市 各日期，未公告为 NULL |
| divid_cash_ps_before_tax | REAL | 每股股利税前，元 |
| divid_cash_ps_after_tax | REAL | 每股股利税后，元；源含「或」多值时取第一个数值 |
| divid_stocks_ps | REAL | 每股红股 |
| divid_cash_stock | TEXT | 分红送转描述原文（如 `10转1派5.15元（含税…）`），保留不解析 |
| divid_reserve_to_stock_ps | REAL | 每股转增资本 |

```sql
CREATE TABLE dividend (
  dividend_id              INTEGER PRIMARY KEY,
  code                     TEXT NOT NULL REFERENCES security(code),
  divid_pre_notice_date    TEXT,
  divid_agm_pum_date       TEXT,
  divid_plan_announce_date TEXT,
  divid_plan_date          TEXT,
  divid_regist_date        TEXT,
  divid_operate_date       TEXT,
  divid_pay_date           TEXT,
  divid_stock_market_date  TEXT,
  divid_cash_ps_before_tax REAL,
  divid_cash_ps_after_tax  REAL,
  divid_stocks_ps          REAL,
  divid_cash_stock         TEXT,
  divid_reserve_to_stock_ps REAL
);
CREATE UNIQUE INDEX uq_dividend ON dividend(code, divid_operate_date);
```

**契约要点**：`divid_operate_date` 可能为 NULL（预案已披露未实施），因此不能用自然主键；唯一索引 `(code, divid_operate_date)` 上 NULL 互不冲突，同日多次除权在源数据中不存在。同一预案从预披露到实施各日期字段逐步补全，同步采用 UPSERT（按唯一索引冲突更新）。

## 复权视图（推导层）

四个视图定义于 [schema.sql](schema.sql)：

| 视图 | 语义 |
| --- | --- |
| `v_k_line_daily_hfq` | 后复权日线：价格 × Π(除权日≤当日的 `back_adjust_factor`) |
| `v_k_line_daily_qfq` | 前复权日线：价格 × Π(除权日>当日的 `fore_adjust_factor`) |
| `v_k_line_latest` | 每只证券最新一根日线（窗口函数） |
| `v_st_universe` | 当前 ST 股票池：在市股票中最新日线 `is_st=1` |

**一致性验证**（已实测）：构造除权事件 `back_adjust_factor=1.05` 后，后复权序列的日涨跌幅推导值 -0.0796 与源 `pct_chg` -0.07962 一致；前复权对除权日前行乘 `fore_adjust_factor`、除权日及之后行不变——推导性质与涨跌幅复权法定义吻合。

依赖 SQLite 数学函数 `LN`/`EXP`（3.35+ 默认启用），视图内以 `COALESCE(..., 1.0)` 处理无因子证券。**消费方禁止**绕过视图自行用 `preclose` 推复权价——`preclose` 在除权日是理论价，直接做除法会得到错误因子。
