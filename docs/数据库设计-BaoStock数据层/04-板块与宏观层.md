# 04 板块与宏观层

## stock_industry — 行业分类快照

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| code | TEXT | PK(1/2), FK→security | |
| update_date | TEXT | PK(2/2) | 快照日期（BaoStock 每周一更新） |
| code_name | TEXT | | 快照时证券名称 |
| industry | TEXT | | 所属行业（如 `银行`） |
| industry_classification | TEXT | | 分类体系（如 `申万一级行业`） |

```sql
CREATE TABLE stock_industry (
  code                    TEXT NOT NULL REFERENCES security(code),
  update_date             TEXT NOT NULL,
  code_name               TEXT,
  industry                TEXT,
  industry_classification TEXT,
  PRIMARY KEY (code, update_date)
);
```

**契约要点**：BaoStock 行业分类每周一更新，本表**保留全部历史快照**而非只留最新——行业变更（重组、更名后转行业）本身是分析信号。查询当前行业用 `MAX(update_date)` 过滤（见 [07-典型查询模式.md](07-典型查询模式.md)）。退市证券行业可能为空。

## index_constituent — 指数成分快照

三个成分股接口（上证50/沪深300/中证500）结构完全一致，合并为一张表，以 `index_key` 区分：

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| index_key | TEXT | PK(1/3), CHECK IN ('sz50','hs300','zz500') | sz50=上证50、hs300=沪深300、zz500=中证500 |
| code | TEXT | PK(2/3), FK→security | 成分证券 |
| update_date | TEXT | PK(3/3) | 快照日期（每周一更新） |
| code_name | TEXT | | 快照时证券名称 |

```sql
CREATE TABLE index_constituent (
  index_key   TEXT NOT NULL CHECK (index_key IN ('sz50','hs300','zz500')),
  code        TEXT NOT NULL REFERENCES security(code),
  update_date TEXT NOT NULL,
  code_name   TEXT,
  PRIMARY KEY (index_key, code, update_date)
);
CREATE INDEX idx_index_constituent_date ON index_constituent(index_key, update_date);
```

**契约要点**：`index_key` 使用接口标识而非指数代码，避免引入手册之外的代码映射假设。历史快照语义同 `stock_industry`：成分调入调出（进出上证50 等宽基是 ST 风险的先行信号之一）需要历史才能识别。

## 宏观域五表

宏观表之间结构差异大（发布事件型 vs 统计期型），强行合并为 EAV 会牺牲 Agent 的可读性，故按源结构各建一表，统一 `macro_` 前缀。数据量均为百行级，同步策略一律全量校验。

### macro_deposit_rate — 存款利率

```sql
CREATE TABLE macro_deposit_rate (
  pub_date       TEXT PRIMARY KEY,     -- 发布日期
  demand         REAL,                 -- 活期
  fixed_3m       REAL, fixed_6m REAL, fixed_1y REAL,
  fixed_2y       REAL, fixed_3y REAL, fixed_5y REAL,   -- 定期整存整取
  installment_1y REAL, installment_3y REAL, installment_5y REAL  -- 零存整取等
);
```

### macro_loan_rate — 贷款利率

```sql
CREATE TABLE macro_loan_rate (
  pub_date         TEXT PRIMARY KEY,
  loan_6m REAL, loan_6m_1y REAL, loan_1y_3y REAL,
  loan_3y_5y REAL, loan_above_5y REAL,               -- 期限档位贷款利率
  mortgage_below_5y REAL, mortgage_above_5y REAL     -- 住房公积金贷款
);
```

### macro_reserve_ratio — 存款准备金率

```sql
CREATE TABLE macro_reserve_ratio (
  pub_date       TEXT PRIMARY KEY,   -- 公告日期
  effective_date TEXT,               -- 生效日期
  big_pre REAL, big_after REAL,      -- 大型机构 调整前/后
  medium_pre REAL, medium_after REAL -- 中小型机构 调整前/后
);
```

**契约要点**：主键取 `pub_date`（公告日）；同一公告日不重复。`query_required_reserve_ratio_data()` 的 `yearType` 参数（按公告日/生效日过滤）在拉取侧固定为公告日口径，`effective_date` 以数据列保留。

### macro_money_supply_month — 货币供应量（月度）

```sql
CREATE TABLE macro_money_supply_month (
  stat_year  INTEGER NOT NULL,
  stat_month INTEGER NOT NULL CHECK (stat_month BETWEEN 1 AND 12),
  m0 REAL, m0_yoy REAL, m0_chain REAL,   -- 月度值/同比/环比
  m1 REAL, m1_yoy REAL, m1_chain REAL,
  m2 REAL, m2_yoy REAL, m2_chain REAL,
  PRIMARY KEY (stat_year, stat_month)
);
```

### macro_money_supply_year — 货币供应量（年底余额）

```sql
CREATE TABLE macro_money_supply_year (
  stat_year INTEGER PRIMARY KEY,
  m0 REAL, m0_yoy REAL, m1 REAL, m1_yoy REAL, m2 REAL, m2_yoy REAL
);
```

**契约要点**：月度表数值单位为亿元；源数据中同比/环比字段存在 `—` 前导负号（如 `—0.790000`），清洗规则见 [00-设计总览.md](00-设计总览.md)。月度与年度两表独立存在（源为两个接口），**不互推**。
