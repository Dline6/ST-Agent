# ST Agent

面向个性化投资决策的**可配置主动服务 Agent**。本地优先、数据主权、Agent 严格中性——所有用户数据本地加密存储，产品方零接触；核心能力离线可用；产出不做拟人化，多视角分歧并列呈现，不合并、不给统一投资建议。

## 能力概览

底层是本地 Skills + MCP Hub 能力池，中层是个人投资记忆图谱，交互层是 Chat-as-OS 主入口；复杂决策走多视角中性推理（Multi-Lens），主动服务经 Ambient Delivery 触达，最上层 Reflection Loop 实现自我演进。整体为六层架构：

| 层 | 名称 | 职责 |
|---|---|---|
| SC | 平台共享契约 | 跨层类型与接口契约，唯一跨层协作通道 |
| L0 | 本地优先基座 | 加密存储、密钥凭据、LLM 端点抽象、出网审计、数据源缓存 |
| L1 | 能力底座 | Skill Runtime、MCP Hub、WorkflowDAG、定时调度 |
| L2 | 记忆图谱 | 个人投资记忆的节点/边模型、写入策略、冲突裁决 |
| L3 | 对话主入口 | Chat-as-OS：会话模型、意图理解、对话即配置、Generative UI |
| L4 | 多视角推理 | Lens 阵容、多视角编排、交叉对照与分歧可视化 |
| L5 | 主动触达 | 信号模型、渠道投递编排、每日报告与频控 |
| L6 | 反思演进 | 反馈采集、每周反思、演进授权与回滚 |
| ECO | 生态与分享 | 分享物导出/导入、官方 Skill 索引 |
